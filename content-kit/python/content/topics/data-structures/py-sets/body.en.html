Ask who belongs, rather than which position

A workshop attendance sheet may contain the same roll twice. If you only need to know who attended, duplicate entries should not count twice. A set stores distinct members and lets you ask whether a value belongs to the group.

Sets are useful for comparing registrations, finding missing submissions and checking previously visited values. They do not attach a position to a member. If the task needs the first arrival or every repeated mark, keep a list as well.

A set changes the meaning of your data. Converting [80, 80, 90] to a set leaves two values, although the original list described three students. Decide whether repetitions are noise or meaningful observations before removing them.

Create sets and combine groups

registered = {12, 18, 25}
submitted = set([18, 18, 30])
missing = registered - submitted
common = registered & submitted

Nonempty braces with comma-separated values create a set. Empty braces create a dictionary instead, so use set() for an empty set. Passing an iterable to set collects each distinct item it supplies. A string supplies characters, not whole words.

Set operations for two groups A and B
ExpressionMeaning
A | BMembers in either group
A & BMembers shared by both
A - BMembers of A absent from B
A ^ BMembers in exactly one group
A <= BEvery member of A belongs to B

These operations produce new sets without editing their operands. Use readable names such as registered and submitted to make the direction of difference clear. Parentheses can make combinations easier to review when several operators appear together.

Equality decides whether a member already exists

A set uses hashes to locate likely positions quickly, then equality to distinguish values. A hash is a numeric lookup aid, not a unique identifier. Different values can share a hash, so equality checks still matter. Members must be hashable for this mechanism to remain reliable.

Integers, strings and suitable tuples are common members. Lists, dictionaries and ordinary sets are mutable and unhashable. You cannot store a normal set inside another set. Use frozenset when the group itself must be a member or dictionary key.

For ordinary data, membership is constant time on average. The cost can rise in adverse collision cases. The important practical contrast is with a list search, which may inspect each element. A set often helps when a loop repeatedly asks whether a value was seen before.

Equality can cross numeric types: 1, 1.0 and True compare equal and have compatible hashes. A set does not promise to preserve their separate type identities as separate members. Keep validation separate if your application treats these categories differently.

If you know C

C has no built-in set type. You might scan an array for duplicates or build a hash table. Python provides the container and memory management, but you still choose hashable members and decide whether losing order and repetition is appropriate.

Update a membership register

Adding 12 twice still stores it once. update visits all values in its input. discard tolerates missing 99, whereas remove requires its argument to exist. The remaining rolls are 12 and 25.

Store immutable teams

A frozenset cannot be edited and can itself be a set member. Order does not affect equality, so the two equal two-person teams count once. Union produces a new group containing 12, 18 and 25.

Change a register or freeze a group

The add method inserts one hashable member. Adding an existing equal member leaves the size unchanged. The update method reads all items from an iterable and adds them individually. Updating with a word adds its letters; adding the word stores the entire string as one member.

The remove method expects its member to exist and raises KeyError if it does not. The discard method ignores an absent member. Choose remove when absence signals a broken assumption. Choose discard when an already-absent value is an acceptable state.

The pop method removes an arbitrary member, not the smallest or earliest member. It raises KeyError on an empty set. If your algorithm needs a specific member, choose it explicitly. A queue or ordered list is better when removal order carries meaning.

A frozenset has set membership behavior without editing methods. Operations such as union return another group instead of changing the original. Two frozensets are equal when they contain equal members, regardless of construction order.

Frozen groups are useful for deduplicating teams. The team {12, 18} is the same membership group as {18, 12}. Converting each team to a frozenset allows an outer set to keep one copy of each team. This approach intentionally ignores repeated names and member order.

The empty set is a subset of every set because it has no member that violates inclusion. Two equal sets are subsets of each other. For a proper subset, use the strict comparison A < B: every A member belongs to B and at least one B member is absent from A.

Set operators expect set-like operands. The named method forms can accept general iterables in useful places: for example, registered.intersection(submitted_list) reads a list of submissions. Convert inputs explicitly when operator notation makes the intended membership model clearer.

For two groups that should never overlap, isdisjoint expresses the question directly. It returns true when no shared member exists, including when one group is empty. This can read more clearly than constructing an intersection only to check whether its length is zero.

Preserve the information your problem needs

Expecting indexes or sorted iteration

Writing members[0] raises TypeError because a set is not a sequence. Convert to a sorted list for an ordered report. Converting to a plain list gives positions, but it does not invent a meaningful business order.

Reversing a difference

registered - submitted finds missing work. submitted - registered finds unknown submissions. These answer different questions. Test a tiny example with one roll unique to each side before trusting a longer expression.

Editing during iteration

Adding or removing members while iterating over the same set can raise RuntimeError. Calculate a separate set of members to remove, then apply the change after traversal. Reading membership during iteration is safe when the container is otherwise stable.

Set comparisons express inclusion, not a total ranking. Two groups may be incomparable: each has members missing from the other. If you need a report ordered by group size, sort using their lengths rather than expecting subset comparisons to rank every pair.

Membership is stable; display order is not promised

Set and frozenset operations in this lesson work on Python 3.10–3.12. Set iteration order is not guaranteed across runs or versions, so numeric reports explicitly sort their results.
