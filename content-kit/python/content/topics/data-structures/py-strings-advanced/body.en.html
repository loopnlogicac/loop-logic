Turn text into values you can compare

A student may type a course list with extra spaces or inconsistent letter case. Your program needs a clear rule for turning that text into useful values. String methods clean boundaries, divide fields, replace text and build readable reports.

A string remains immutable throughout these operations. Methods return strings or other results rather than editing the original text in place. Save the returned value when the next step should use the cleaned version.

Text algorithms depend on what you count as meaningful. A palindrome may ignore spaces, but a course code comparison may require every character. Describe that policy before writing the loop. Otherwise a program can run successfully while answering the wrong question.

Clean boundaries, separate fields and join results

raw = "  CSE101, MAT101  "
codes = [part.strip() for part in raw.split(",")]
report = " | ".join(codes)
changed = report.replace("MAT101", "MAT102")

The strip method removes leading and trailing whitespace by default. It does not remove internal spaces. Passing characters to strip means any of those characters may be removed repeatedly from either end; the argument is not an exact substring.

split without an argument treats runs of whitespace as boundaries and removes empty outer fields. With an explicit separator, every separator creates a boundary. Thus two adjacent commas create an empty field, which may represent missing data rather than something to discard.

join belongs to the separator string. It places that separator between consecutive input strings, with no extra separator at either end. Joining an empty collection returns an empty string. Convert numeric items to strings before joining them.

The replace method returns a changed string. An optional count limits the number of replacements. Use find to locate the first occurrence of a substring; it returns a zero-based position or minus one. Membership is often clearer when only presence matters.

Make a text-processing pipeline

A pipeline is a sequence where each step prepares the next step's input. For a comma-separated course list, remove outer whitespace, split at commas, trim every field and then join the cleaned values for display.

Keep the intermediate values while learning. Printing the fields reveals accidental empty entries or leftover spaces. Once the behavior is clear, a comprehension can express the per-field cleanup. Compact code should still show which rule is applied at each boundary.

Splitting and joining usually visit the text or its pieces in linear time. Repeatedly extending a growing string inside a long loop can copy accumulated text many times. Collect pieces and join once when assembling a large report.

The generator form used inside join supplies transformed items one at a time. It resembles a comprehension but omits square brackets. Generators later explains lazy iteration in detail; here it avoids an unnecessary temporary list of characters.

If you know C

Python strings carry their length and manage storage. You do not reserve a writable char buffer for split or replace. A returned string is a new value; assigning it does not write into the original string. Unicode characters also differ from C byte-oriented char processing.

Choose a display rule and a comparison rule

An f-string field may contain a colon followed by a format specification. Alignment symbols place text left, right or centered in a minimum width. A precision such as .2f prints two digits after the decimal point; a percentage format multiplies by one hundred for display and adds a percent sign.

Width is not a maximum length. A long item name expands the field and may push later columns right. This matters for real reports. Unicode code points also do not always occupy one terminal column, so a width that aligns ASCII labels may not align every script.

A palindrome reads the same forwards and backwards under the chosen cleaning rules. Normalize the text, reverse it with a slice and compare. Both cleaning and reversal need linear work, and the new strings require extra space.

An anagram uses the same characters with the same counts in another order. Sorting normalized letters gives a convenient comparison, taking roughly n log n work. Counting letters in dictionaries can use average linear time and makes multiplicities explicit.

A word count needs a definition of word. Whitespace splitting is useful for simple lab input, but notes and notes, remain different tokens unless punctuation is cleaned. A language-aware tokenizer needs rules beyond splitting at spaces.

casefold is designed for caseless Unicode comparisons and can change a character into several characters. It is more thorough than lower, but does not solve every Unicode matching problem. These examples do not claim to normalize all equivalent Unicode spellings or grapheme clusters.

Test boundaries instead of guessing

Using find directly as a Boolean

A match at position zero is false in a condition, while the absent result minus one is true. Write position != -1, or use substring in text. This avoids reversing success and failure at the most common boundary.

Deleting all punctuation without a policy

Removing punctuation may join words that were separated by a dash. Replacing punctuation with spaces has a different effect. For a palindrome, deleting separators may be intended; for word counts, preserving a word boundary may be necessary.

Comparing only unique letters

A set discards multiplicity. It cannot distinguish aab from abb, so it is insufficient for anagram checking. Sort all retained letters or compare full frequency mappings.

Expecting formatting to fix money arithmetic

Printing two decimal places controls appearance. It does not make binary floating-point decimal-exact. Store whole poisha as integers when exact small currency totals matter, or study decimal arithmetic for broader requirements.

Text policies outlive individual methods

split, join, strip, replace, find, casefold and the f-string formats shown work on Python 3.10–3.12. Unicode data may evolve, so the practice tasks specify ASCII where exact character categories matter.
