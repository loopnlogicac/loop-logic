অনেক call ঘিরে একই আচরণ

কয়েক ফাংশনে একই logging-validation copy করলে পরে change বারবার। Decorator ফাংশন নিয়ে তার বদলি value ফেরায়। সাধারণত wrapper, যা original call ঘিরে কাজ যোগ করে।

ফাংশন value আর closure enclosing ভেরিয়েবল মনে রাখে জানো। Decorator দুটো মেলায়। Wrapper original মনে রাখে, decorated name-এ caller এলে কখন original চলবে বাছে।

Original source body rewrite নয়, name decorator-এর ফলে rebind। তাই অসাবধান wrapper return হারায়, valid argument বাদ দেয় বা metadata ঢাকে।

@-কে assignment-এ বোঝো

def calculate-এর ওপরে @announce ফাংশন তৈরির পরে announce চালিয়ে ফল calculate-এ বসায়। ধারণায় calculate = announce(calculate)। Decorator definition time-এ, returned wrapper সাধারণত পরে call time-এ।

from functools import wraps

def announce(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        print("begin")
        result = function(*args, **kwargs)
        print("end")
        return result
    return wrapper

Outer original callable পায়, inner পরের কল সামলায়। *args positional, **kwargs keyword জড়ো, expansion forward। return wrapper ফাংশন দেয়; wrapper() খুব আগে চালায়।

Decoration আর invocation আলাদা

Definition-এ original তৈরি, decorator-এ পাঠিয়ে replacement original নামে রাখা। তখন business calculation লাগবে না। Invocation-এ caller replacement পায়, তা remembered original ডাকে।

Wrapper begin, original, end, তারপর result। Original raise করলে পরের line বাদ। Failure-তেও শেষ logging/cleanup লাগলে try/finally। Recovery contract না হলে failure গিলবে না।

সংজ্ঞায়:
    original function --> decorator --> wrapper নামে bind
কলে:
    caller --> wrapper --> original --> result --> caller

C জানা থাকলে

C ফাংশন পয়েন্টার পাঠানো যায়, ordinary C-তে closure-এর supporting state হাতে লাগে। Python wrapper enclosing scope-এ original আর config রাখে। @ name binding, preprocessor expansion নয়।

Wrapper ইচ্ছা করে argument বা result বদলাতে পারে, তবে transparent logging থেকে অন্য promise। Validation body-র আগে negative reject, formatting সংখ্যা বদলে string দিতে পারে। Caller-কে জানাও।

Argument, value আর নাম রাখো

প্রথমটি call order, দ্বিতীয় wraps metadata। Configurable validator-এ তিন nested ফাংশন। শেষটি ভেরিয়েবল timing না মেপে stable message-এ stacking দেখায়।

Before, result আর after trace

Wrapper positional-keyword forward। Original-এর আগে begin, পরে end, তারপর caller returned 30 প্রিন্ট।

রাখা metadata দেখো

wraps square নাম আর docstring রাখে। __wrapped__ original callable, যা 16 দেয়।

Minimum amount configure

Factory ten config রাখে। Twelve calculation-এ, five original-এর আগেই rejected।

Stacked wrapper order

নিচের decorator আগে apply, call-এ outer wrapper আগে। Exit উল্টো ক্রমে খুলে ফেরে।

ফাংশনের দরকারি পরিচয় রাখো

সাহায্য ছাড়া decorated name-এর __name__ wrapper, docstring wrapper-এর। Documentation-debug-signature tool বিভ্রান্ত। functools.wraps selected metadata copy করে __wrapped__ original-এ দেয়।

Inner wrapper-এ @wraps(ফাংশন)। এটি validation বা same behavior নিশ্চিত নয়, description আর inspection link রাখে। Argument forward আর result return নিজে ঠিক করবে।

Caller decorated.__wrapped__-এ original পায়, inspection chain ধরতে পারে। তাই decorator access-control barrier নয়। Original freely চালাতে পারা caller-এর বিরুদ্ধে validation wrapper সুরক্ষা নয়।

Metadata রাখলেই সব callable category চলে না। Sync wrapper coroutine ফিরিয়েই async ফাংশন হয় না। Generator wrapper-এ timing-cleanup ভাবতে হয়। এখানে ordinary synchronous ফাংশন।

Setting-এর জন্য outer factory

Argument-সহ decorator সাধারণত তিন layer। Factory configuration নেয়, actual decorator দেয়; সেটি original নেয়; wrapper পরের call-এর argument নেয়।

@minimum(10)-এ definition-এ minimum(10), তার decorator ফাংশন পায়। Wrapper threshold আর original মনে রাখে। পরের কল business argument, নতুন threshold নয়।

Config wrapper-জুড়ে shared, purchase amount per-call। মেশালে numeric result-এর বদলে ফাংশন অবজেক্ট বা decoration-এ original চলে যেতে পারে।

Factory নিজের config তাড়াতাড়ি validate করে। Negative minimum অবৈধ হলে তৈরি করার সময় reject। Wrapper পরে প্রতিটি amount আলাদা দেখে, config error আর business ইনপুট আলাদা।

@outer-এর নিচে @inner মানে outer(inner(ফাংশন))। সংজ্ঞার কাছেরটি আগে, call-এ outer আগে। Before-after message বন্ধনীর মতো nested। ক্রমে validation-cache-log বদলায়।

Wrapper state আর effect বুঝে

Closure-এ call count রাখা যায়। Count ওই decorated ফাংশন-এর, একই decorator-এর সবার নয়। Factory নতুন independent closure দিতে পারে। State lifetime ঠিক করো।

Module-level mutable state সব wrapper share করতে পারে। Closure হলেও same wrapper-এর alias share। কোনোটিই automatic concurrent safety নয়; simple counter thread-safe বলা হয়নি।

Validation original state change-এর আগে fail করবে। Logging default-এ private argument ছাপবে না। Stable result লাগলে আউটপুট আর diagnostic আলাদা। সবসময় print করা reusable API-তে নাও মানাতে পারে।

Decorator-এর আগে explicit helper ভাবো। এক ফাংশন-এ validate(amount) পরিষ্কার। বহু compatible ফাংশন ঘিরে একই policy আর নাম definition-এ অর্থ বললে decorator ভালো।

Interface-এর অংশ হিসেবে wrapper টেস্ট

শুধু successful positional call যথেষ্ট নয়। Keyword, explicit result আর raised exception টেস্ট। প্রথমটি চললেও keyword হারানো বা failure None করা সম্ভব। তিন path-ই contract।

আলাদা setting-এ দুই ফাংশন বানাও। একটি কল অন্য config বদলাবে না। Factory সাধারণত আলাদা রাখে; shared mutable config অবজেক্ট-এ পরে change দুটোতে প্রভাব ফেলে। Closure reference রাখে, snapshot নয়।

অদৃশ্য effect-এর আগে distinct message-এ stacking trace। Outer cache hit-এ inner logger skip, outer logger সব hit-ও দেখে। সর্বজনীন সঠিক order নেই, প্রয়োজন দেখে বাছো।

__wrapped__ সচেতন inspection/টেস্ট-এ নাও। Direct call policy পাশ কাটায়। Original টেস্ট pass public wrapper forwarding প্রমাণ নয়, public name দিয়েও টেস্ট।

প্রতি layer-এ call ধরো

return result বাদ

Original ঠিক হিসাব করেও wrapper None দিতে পারে। ফল রাখার promise হলে explicit return।

Keyword বাদ

শুধু *args valid keyword call বাদ দেয়। Interface সমর্থন করলে **kwargs forward। Positional-এর সঙ্গে named-ও টেস্ট।

ফেরানোর সময় wrapper কল

return wrapper() এখনই চালিয়ে ফল দেয়। পরের decorated call-এর জন্য return wrapper।

Failure-এ normal after-code চলবে ভাবা

Original raise-এ পরের statement বাদ। Guaranteed exit কাজ finally-তে, contract না বললে error চালিয়ে দাও।

wraps মানেই পুরো transparency নয়

ফাংশন, closure, decorator আর functools.wraps Python 3.10–3.12-তে। Copied metadata বদলাতে পারে, তাই stable name-docstring-__wrapped__ দেখা। ParamSpec-সহ generic typing পরে, runtime pattern-এর বাইরে।

Decorator definition-এ দৃশ্যমান policy

Wrapper reusable behavior যোগেও argument-result-error forward করে। wraps metadata, factory config দেয়। পরের context manager call নয়, block ঘিরে entry-exit বলে।
