এক শব্দ নয়, text-এর ধরন বলো

Course code তিন uppercase letter আর তিন digit হতে পারে। এক code মেলালে ধরন যাচাই হয় না। Regular expression বা regex text pattern বলে। Python re তা খোঁজে, অংশ বের করে বা বদলায়।

Pattern নিজস্ব নিয়মের ছোট language। Bracket, dot, repetition sign বিশেষ অর্থ পায়। ব্যাখ্যা না পারা লম্বা expression মুখস্থ নয়, কয়েক construct বুঝে মেলাও। Readable pattern ইনপুট policy বলবে।

Message-এর course লেবেল-এর মতো structured অংশে ভালো, সব text সমস্যায় নয়। Fixed replacement-এ str.replace, whitespace word-এ split, CSV-JSON-এ parser। Pattern domain validation-এর বদলি নয়।

Literal আর special character-এ pattern

re import করে pattern আর text search-এ দাও। r"[A-Z]{3}[0-9]{3}" raw string ভালো। r Python-এর backslash interpretation কমিয়ে regex engine-কে escape দেয়, regex syntax বন্ধ করে না।

Patternঅর্থউদাহরণ
[A-Z]এক ASCII uppercase letterC
[0-9]এক ASCII digit7
{3}ঠিক তিনবার212
+এক বা বেশি[0-9]+
*শূন্য বা বেশি[ ]*
?আগের item optional-?
.Default-এ newline ছাড়া charactera.c
(...)Group capture(CSE)

আসল dot-এ regex escape, যেমন r"a\.b"। বাইরে থেকে literal text এলে re.escape literal pattern করে। Regex আর Python string escaping আলাদা layer, raw string তা স্পষ্ট করে।

আগে matching boundary

re.search যেকোনো জায়গায়, re.match শুধু শুরুতে। কোনোটিই পুরো string চাই না। এক short লেবেল validate-এ re.fullmatch পরিষ্কার।

সফল হলে match অবজেক্ট, ব্যর্থে None। Group-এর আগে দেখো। group(0) পুরো match, span start-end দেয়। End exclusive, slice-এর মতো।

findall match অবজেক্ট ছাড়া ফল জমায়। Capture নেই হলে full string, এক capture-এ সেই group-এর string, কয়েকটিতে captured tuple। Group design-এ result shape বদলায়।

C জানা থাকলে

Python string Unicode, re তাতে চলে। Character ক্লাস-কে C লুপ-এর ASCII byte check ধরো না। Domain ASCII digit চাইলে [0-9]।

Shorthand digit 0..9-এর বাইরের Unicode decimal-ও মেলায়। String pattern-এ word-whitespace-ও default Unicode। ASCII identifier চাইলে range বা flag-এ policy বলো, English-only ধরে নয়।

স্পষ্ট policy-তে search, capture, replace

এক text-এ তিন boundary তুলনা। Extraction-এ full আর group আলাদা। Field reorder-এ replacement ফাংশন বাড়তি backslash rule এড়ায়।

Search, match, fullmatch তুলনা

search বাক্যের ভেতর code পায়। শুরুর T-তে match ব্যর্থ, fullmatch শুধু standalone complete code নেয়।

Named department-number বের করো

Named group CSE আর 212 আলাদা। Span zero থেকে six, six বাদ, slice-এর মতো।

Findall-এর result shape

Capture নেই full match, একটিতে digit string, দুটিতে letter-number tuple।

Substitution-এ field reorder

Replacement ফাংশন match থেকে number-department বানায়। Original immutable string একই।

re.escape-এ literal punctuation

প্রথম search-এ dot-plus literal। আলাদা numeric pattern দুই ASCII digit run বের করে।

Caller-এর দরকারি অংশই capture

বন্ধনী capturing group। (?P<department>[A-Z]{3})-এ number মনে না রেখে group("department")। Department-course number-এর মতো অর্থপূর্ণ অংশে ভালো।

শুধু structure-এ (?:...) noncapturing। এতে findall shape আর numbered group অনিচ্ছায় বদলায় না। Precedence ঠিক করতে bracket যোগ caller-এর ডেটা মডেল নীরবে বদলাবে না।

re.sub nonoverlapping match বদলে নতুন string দেয়, original একই। Replacement fixed text বা match নেওয়া ফাংশন। Capture-নির্ভর বা numeric conversion-এ ফাংশন পরিষ্কার।

re.compile named reuse আর পরিষ্কার code দেয়, search/fullmatch/findall/sub method থাকে। Reuse গুছাতে compile; workload না মেপে বড় speed claim নয়।

External replacement text-এ sub string-এর নিজস্ব escape rule মনে রাখো। ফাংশন text ফেরালে backreference template হয় না। re.escape pattern-এর, সাধারণ replacement escape নয়।

Repetition আর validation scope নিয়ন্ত্রণ

Repetition সাধারণত greedy: পুরো match রেখে যতটা পারে নেয়। +?-এর মতো non-greedy আগে ছোটটি চায়। কোনোটিই নিজে সঠিক নয়, boundary বলে কোন অংশ চাই।

Known field-এ unrestricted dot-এর বদলে precise ক্লাস। Bracketed ASCII identifier-এ allowed interior বলো, পরে কোনো bracket পর্যন্ত arbitrary নয়। Audit সহজ, লম্বা অপ্রত্যাশিত match এড়ায়।

Nested ambiguous repetition কিছু nonmatch-এ বেশি backtrack করে। Untrusted বড় text-এ simple pattern আর ইনপুট bound। এক expression-এ full email, URL বা language parser এই পরিচয়ের কাজ নয়।

Regex shape, সব অর্থ নয়। চার digit-hyphen-দুই digit-আরেক pair অসম্ভব date-ও নিতে পারে। Extract করে datetime বা domain check।

তিন letter তিন digit verify করলেও semester-এ offered course জানে না। Code পরে course table-এ খোঁজো। Syntax আর business rule আলাদা।

Match আর language layer দেখো

বাক্যের ভেতরের code-এ match

match zero-তে শুরু। পরে থাকলে search, পুরো ইনপুট এক code হলে fullmatch।

None-এ group

Failed search None। Group পড়ার আগে দেখো। No match প্রত্যাশিত ফল হতে পারে, exceptional failure নয়।

বন্ধনী findall বদলায় ভুলে যাওয়া

Capture result বদলায়। Structure-এ noncapturing, pattern edit-এর পরে shape টেস্ট।

Fixed text-এ regex বেশি

সব literal comma semicolon করতে str.replace পরিষ্কার। Pattern language কাজে লাগলেই regex।

Shared regex feature-এ থাকো

Pattern Python 3.10–3.12-তে। Atomic group আর possessive quantifier 3.11-এ, দরকার নেই। Raw string invalid Python escape warning এড়ায়, তবু শেষে এক unmatched backslash থাকতে পারে না।

Detail-এর আগে boundary

Text boundary থেকে search/match/fullmatch। অর্থপূর্ণ extraction-এ group, patterned replacement-এ sub। Domain আলাদা validate। পরের টেস্টিং basics known result আর boundary-তে behavior দেখে।
