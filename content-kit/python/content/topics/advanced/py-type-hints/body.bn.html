Caller কী দেবে আর পাবে লিখে দাও

total ফাংশন implementation অনুযায়ী price, mark বা string নিতে পারে। সব type body থেকে আন্দাজ করতে হবে না। Type hint source-এ উদ্দেশ্য বলে, tool run-এর আগেই call মিলিয়ে দেখে।

Project বাড়লে কাজে লাগে। Integer result promise-এ caller numeric কাজ বাছে; None-ও হলে missing handle জানে। পরে অপ্রত্যাশিত failure-এর বদলে boundary দৃশ্যমান।

Python dynamic-ই। Normal run annotation না মিললেই call reject করে না। Static checking আর runtime validation আলাদা। Hint interface, external input-এর rule-এ explicit check।

Parameter, return আর container annotate

Parameter-এর পরে colon-type, list-এর পরে arrow-result। Inferred type স্পষ্ট করতে variable-এর পরেও colon। Useful result ছাড়া action-এ -> None।

def total(prices: list[int]) -> int:
    return sum(prices)

counts: dict[str, int] = {"lab": 2}

list[int] element type, length নয়। dict[str, int] key-value type। Annotation container allocate বা default ভরে না; expression-এ নিজে বানাও।

3.10 থেকে int | None union। typing-এর Optional[int] একই int-or-None। ছোট interface-এ এক রূপ consistent রাখো। কোনোটিই automatic None default নয়।

Static analysis আর execution আলাদা

Static type checker normal কাজ না চালিয়ে source দেখে। Declared-inferred type expression-এ ধরে। int-এর জায়গায় string বা optional-কে definite integer ব্যবহারে জানায়।

Interpreter দেওয়া object দিয়েই body চালায়। double(number: int)-এ body দুই দিয়ে গুণ করলে "a"-তে "aa" হতে পারে। Runtime চললেই declared interface মেলে না; run আর check আলাদা প্রশ্ন।

Hint convert করে না। "75" int করার আগে string। list[int] সব external element inspect নয়। বাইরে parse-validate করে internal interface-মেলা মান পাঠাও।

C জানা থাকলে

C declaration compilation rule আর representation-এর অংশ। Python hint মূলত tool-এর জন্য উদ্দেশ্য। int hint machine-size C integer limit বা automatic conversion নয়।

Static tool সব business rule প্রমাণ করে না। Mark nonnegative চাইতেও int-এ -5 চলে। Alias ভালো নাম দেয়, সাধারণ alias runtime range নয়। Bound আর domain documentation-validation-এ।

আসল মানের পাশে hint পড়ো

Container উদাহরণ declared type মানে। Optional-এ যোগের আগে missing। ইচ্ছাকৃত mismatch runtime enforcement না থাকা দেখায়; Python চালালেও static type error বলা আছে।

Runtime enforcement নেই দেখো

দ্বিতীয় কল interface ভাঙে, static checker ধরার কথা। Interpreter string repeat করে aa দেখায়।

Useful result ছাড়া action

দেওয়া list mutate করে implicit None। Return hint numeric result না রেখে effect ব্যবহার বলে।

ব্যবহারের আগে missing দেখো

Lookup integer mark বা absent-এ None। int | None/Optional[int] দাও। Caller if result is None, অন্য branch-এ অঙ্ক। Static tool তখন int-এ narrow করতে পারে।

Zero valid হলে if result নয়। Zero আর None দুটো false, present zero হারায়। Identity check আসল প্রশ্ন। Practice-এ তাই zero আছে।

Default ছাড়া Optional[int] required। def find(limit: int | None)-এ explicit None চলে, find()-এ argument missing। Omission চাইলে = None। Type আর default আলাদা উত্তর।

উপযুক্ত union-এ isinstance narrowing। isinstance(value, str)-এর পরে string method বোঝে। Condition use-এর কাছে, হঠাৎ narrowed variable অন্য type-এ reassign এড়াও।
