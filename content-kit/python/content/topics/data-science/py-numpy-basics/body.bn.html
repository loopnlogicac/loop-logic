Marks table এক numerical object

প্রতি quiz score-এ দুই mark যোগ চাইলে list-এ comprehension বা loop। NumPy অ্যারে numerical value এক object-এ রেখে entry জুড়ে arithmetic দেয়। একবার হিসাব বলো, library প্রয়োগ করে।

ছোট collection-এ list ভালোই। বড় regular numerical data-তে repeated হিসাবে NumPy সুবিধা। Compiled operation Python loop overhead কমায়, তবে calculation-size-নির্ভর। ছোট list conversion-এর খরচ savings-এর বেশি হতে পারে।

বাছা environment-এ python -m pip install numpy, import numpy as np প্রচলিত। Release-এর Python support মেলাও। এখানে modern release-এর shared feature।

অ্যারে বানিয়ে dimension দেখো

np.array([10, 20, 30]) এক-dimensional। সমান-length nested list rectangle। dtype entry representation, যেমন np.int64/np.float64। Numerical array-তে এক dtype, list-এর মতো unrelated object মেশানো নয়।

marks = np.array([[40, 50, 60], [70, 80, 90]], dtype=np.float64)
row_means = marks.mean(axis=1, keepdims=True)
centered = marks - row_means

Shape প্রতি axis-এর length। (2, 3)-এ দুই student, তিন quiz। ndim দুই, size মোট ছয়। (3,) এক axis length তিন; কমা এক-item tuple।

Fraction চাইলে আগে floating dtype। Integer array-তে fraction assign-এ অংশ হারায়। Fixed-width integer overflow-ও পারে, Python int-এর মতো বাড়ে না। NumPy মানেই বেশি precision বা সব overflow check নয়।

Indexing-arithmetic-এ axis ধরো

a[row, column]-এ index zero থেকে, negative শেষে থেকে। a[:, 1] সব row-এর column এক। Integer selection axis সরায়, shape (2,), (2, 1) নয়।

Length-one column রাখতে a[:, 1:2]। Slice stop বাদ। Reshape একই count নতুনভাবে সাজায়: ছয় entry (2, 3), পাঁচ নয়। Row-এর অর্থ না ভেবে শুধু error চাপতে reshape নয়।

Vectorized operation entry-প্রতি Python loop না লিখে পুরো array-র কাজ বলে। যোগ, তুলনা আর বহু math function এমন। সব operation processor vector instruction ব্যবহার বা memory শূন্য মানে নয়।

Typed block-এর মতো, তবে NumPy shape-stride রাখে। Python lifetime সামলায়। View একই underlying block share করলে একটিতে edit অন্য array-তেও দেখা যায়।

List item repeat করে, NumPy প্রতি সংখ্যা double। tolist সাধারণ Python মান দেয়।

যোগের আগে dimension মেলাও

Broadcasting compatible shape-এ এক হিসাব দেয়। সবার row-তে একই তিন quiz bonus, পুরো bonus table লাগে না। Length-three দুই-বাই-তিন matrix-এর last axis-এ মেলে।

Shape ডান থেকে বামে। সমান dimension বা যেকোনোটি one হলে compatible। না থাকা leading dimension one-এর মতো। (2,3)+(3,) দেয় (2,3); (2,3)+(2,) ব্যর্থ, শেষে three-two অমিল।

Student-পিছু bonus-এ (2,1), এক column তিন quiz জুড়ে ছড়ায়। Flat length-two সেই অর্থ নয়। Broadcast সাধারণত repeated input copy বাঁচায়, result-এ তবু বড় memory লাগে। বড় intermediate-এর আগে shape দেখো।

Row centering নিজের mean নিজের marks থেকে বিয়োগ। Reduced axis রাখলে mean (2,1), নিজের row-তে মেলে। keepdims=True-এর কারণ, শুধু নাম মুখস্থ নয়।

এক entry হাতে মেলাও। [40,50,60]-এ bonus [1,2,3] দিলে [41,52,63], দ্বিতীয় row-তেও একই bonus। পুরো student row-তে এক bonus চাইলে column shape করো।

Selection-এ ownership ভুলো না

marks >= 40 Boolean array। Mask কোন entry condition মানে রাখে। marks[mask] সেগুলো আনে। Flat-এ np.count_nonzero(mask) pass গোনে, none-pass-ও।

Parenthesized comparison-এ & বা |। Python and/or এক truth value চায়। বহু-entry array সব নাকি যেকোনোটি আন্দাজ করে না। এক হ্যাঁ-নায় all()/any()।

Basic slice সাধারণত view, source-এর storage একই। স্বাধীন edit-এ copy()। Boolean আর advanced indexing copy আনে। Python list slice-এর নতুন outer list থেকে নিয়ম আলাদা।
