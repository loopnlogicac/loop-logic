Treat a table of marks as one numerical object

Suppose you need to add two marks to every quiz score. A Python list needs a comprehension or loop. A NumPy array collects numerical values into an object whose arithmetic works across its entries. You can describe the calculation once and let the library apply it.

A list remains the right tool for many small collections. NumPy becomes useful when you repeatedly calculate with large, regular numerical data. Its compiled operations often avoid the overhead of a Python loop. That advantage depends on the calculation and data size; converting a tiny list may cost more than it saves.

Install NumPy in your chosen environment with python -m pip install numpy. Import it as np, a widely used short name. Package releases differ in supported Python versions, so choose a release compatible with your interpreter. This lesson uses features shared by modern NumPy releases.

Build arrays and inspect their dimensions

np.array([10, 20, 30]) builds a one-dimensional array from a list. Nested equal-length lists build a rectangle. A dtype describes how entries are represented, such as np.int64 or np.float64. A numerical array uses one dtype, unlike a list that can freely mix unrelated objects.

marks = np.array([[40, 50, 60], [70, 80, 90]], dtype=np.float64)
row_means = marks.mean(axis=1, keepdims=True)
centered = marks - row_means

The shape gives the length of each axis. Here it is (2, 3): two students and three quizzes. ndim is two, because there are two axes. size is six, the total number of entries. Shape (3,) is a single axis of length three; the comma makes it a one-item tuple.

Choose a floating dtype before calculations that need fractions. Assigning a fraction into an integer array can lose its fractional part. Fixed-width integers can also overflow, unlike Python's growing int values. Do not assume choosing NumPy automatically increases precision or checks every arithmetic overflow.

Follow axes through indexing and arithmetic

Index a matrix with a[row, column]. Both indices start at zero, and negative indices count from the end. A colon selects a slice: a[:, 1] means every row and column one. An integer selection removes an axis, so that result has shape (2,), not (2, 1).

Use a[:, 1:2] when you need to preserve a length-one column axis. Slices exclude their stop index, as Python list slices do. Reshape changes how the same element count is arranged: six entries can become (2, 3), but five cannot. Do not reshape merely to silence an error without checking what rows now mean.

A vectorized operation describes work on a whole array rather than writing a Python loop for each entry. Addition, comparison and many mathematical functions follow this pattern. It does not mean every operation uses a processor's special vector instructions, nor that memory use disappears.

Align dimensions before adding

Broadcasting lets compatible shapes participate in one calculation. Imagine adding the same three quiz bonuses to every student's row. You need not build a full bonus table. A length-three array can align with the last axis of a two-by-three matrix.

Compare shapes from right to left. Two aligned dimensions are compatible when they are equal or either length is one. Missing leading dimensions behave as length one. Shape (2, 3) plus (3,) produces (2, 3). Shape (2, 3) plus (2,) fails because the final lengths three and two disagree.

A bonus per student needs shape (2, 1), so its one column can stretch across three quizzes. A flat length-two array does not express that intent. Broadcasting normally avoids copying repeated inputs, but the computed result may still require substantial memory. Inspect shapes before building very large intermediate results.

Row centering subtracts each student's mean from that student's marks. Keeping the reduced axis gives means of shape (2, 1). Subtracting then aligns each mean with its row. This is a useful reason for keepdims=True, beyond memorizing an argument name.

Check a broadcast by calculating one entry by hand. With row [40, 50, 60] and column bonuses [1, 2, 3], the adjusted row is [41, 52, 63]. The second row receives those same bonuses. If your intended calculation adds one bonus to an entire student's row instead, represent those bonuses as a column before adding.

Choose values without losing track of ownership

A comparison such as marks >= 40 creates a boolean array. Such a mask records which entries satisfy the condition. marks[mask] gathers those entries. For a flat array, you can count passing marks with np.count_nonzero(mask), including the case where none pass.

Combine masks using parenthesized comparisons and & or |. Python's and and or ask for a single truth value. A multi-element array cannot decide whether you mean every entry or any entry. Use mask.all() or mask.any() when one yes-or-no result is actually your goal.

Basic array slicing usually returns a view. The view shares numerical storage with its source. Call copy() when later edits must be independent. Boolean and other advanced indexing gather a copy instead. These ownership rules differ from a Python list slice, which creates a new outer list.

Check meaning before trusting a result

Confusing the axis being reduced

axis=0 removes the row direction, leaving a value for each column. Write the intended result shape before calculating an average. That small step catches many swapped student and subject summaries.

Hiding an incompatible shape with flattening

Flattening removes the row and column meaning. Instead, inspect both shapes and decide whether the adjustment belongs to students or quizzes. Retain the needed axis explicitly.

Expecting printed decimals to be exact mathematics

Binary floating-point approximates many decimals. Format reported means with two decimal places, and use a suitable tolerance for numerical comparisons. Formatting changes the display, not the underlying calculation.

Separate language syntax from library support

The Python syntax here works from 3.10 onward. The tested NumPy release is recorded in the package notes; newer NumPy releases may require newer Python. These examples avoid version-sensitive scalar representations by printing Python lists, integers and explicitly formatted decimal strings.

Read the shape as part of the calculation

NumPy joins typed numerical storage with shape-aware operations. Inspect axes, choose compatible shapes and decide when you need an independent copy. Continue to pandas when labels and mixed table columns matter as much as the numbers.
