লেবেল-সহ table-কে প্রশ্ন

Marks sheet শুধু সংখ্যা নয়, row student-এর, column-এর অর্থ। pandas DataFrame row লেবেল আর named column-এর table দেয়। লেবেল রেখেই student select, category combine আর summary।

Series নিজের index-সহ এক labeled collection, column-এর মতো। DataFrame mixed type: string roll, numeric mark, Boolean attendance। Uniform matrix নয় এমন CSV-তে ভালো।

Project environment-এ python -m pip install pandas, import pandas as pd। ছোট dictionary-ই যথেষ্ট হলে দরকার নাও হতে পারে। Labeled table operation প্রশ্ন পরিষ্কার করলে নাও।

Column বানিয়ে উদ্দেশ্যমতো select

pd.DataFrame dictionary key-কে column name করে। List length মেলাবে। নিজে index না দিলে zero থেকে row লেবেল। দেখতে position হলেও ধারণা আলাদা।

frame = pd.DataFrame({"roll": [11, 12], "mark": [39, 80]})
mask = frame["mark"] >= 40
passed = frame.loc[mask, ["roll", "mark"]]
first_row = frame.iloc[0]

frame["mark"] Series, frame[["mark"]] one-column DataFrame। বাড়তি list table shape রাখে। লেবেল-এ loc, integer position-এ iloc। Filter-sort-এর পরে index visible position নাও মেলে।

loc লেবেল slice final লেবেল থাকলে নেয়, iloc stop বাদ। [10,20,30]-এ loc[10:20] ten-twenty, iloc[0:2] প্রথম দুই position। আগে selection rule।

Alignment, filter আর reduction আলাদা

Series arithmetic index লেবেল মেলায়। Quiz-lab আর lab-quiz ক্রম আলাদা হলেও লেবেল মিলে যোগ। একপাশে লেবেল নেই হলে সাধারণত missing। NumPy-র position যোগ থেকে আলাদা।

Filter আগে comparison-এ Boolean Series, তারপর loc True row নেয়। Parenthesized condition-এ &/|, Python and পুরো Series entry-wise মেলায় না।

Grouped reduction একই key-র row নিয়ে group-পিছু ফল। groupby("category")["taka"].sum() category-তে খরচ যোগ। Numeric column explicit-এ unrelated column বাদ।

ফাইলের অর্থ ঠিক করো

read_csv path বা open stream নেয়, প্রথম row সাধারণত name। CSV quoting field-এর comma সামলায়, হাতে comma split unsafe। Parser-এর পরে column দেখে report।

Inference ID-কে number ভাবতে পারে। 001-এর formatting integer one রাখে না। String dtype দাও। Explicit numeric dtype-ও unexpected text-এ visible failure, column অর্থ নীরবে বদল নয়।

Required column আগে check, parsing-এর পরে range: 150 numeric হলেও percentage mark invalid। to_numeric malformed reject করতে পারে। errors="coerce" missing করে; নিলে conversion গুনে দেখো।

Missing মানে usable observation নেই, zero score নয়। isna missing, count known, বহু reduction unknown skip। Question অনুযায়ী exclude/report/replace।

groupby সাধারণত missing group-key row বাদ দেয়। Unknown category চাইলে dropna=False। All-missing sum default-এ zero লাগতে পারে; min_count=1 missing রাখে। Default-কে অর্থ বানাতে দিও না।

Describe-এর মাপ আলাদা পড়ো

Numeric Series-এ count, mean, sample std, min, quartile,max। Median 50%। Quartile ordered observation ভাগ করে, recorded mark-এর মাঝেও হয়। Distribution summary, নির্দিষ্ট student নয়।

Sample std divisor known count-এর এক কম। এক known-এ missing। NumPy std default population। Library তুলনায় definition মিলিয়ে দেখো।

Full DataFrame display নয়, selected statistic explicit format। Precision, truncation, dtype footer setting-এ বদলায়। বাছা লেবেল লুপ প্রশ্ন-মান পরিষ্কার। Report-এর meaningful precision মেনে দুই decimal।
