Ask questions about labeled tables

A marks sheet contains more than numbers. Each row belongs to a student, and each column has a meaning. pandas provides a DataFrame, a table with row labels and named columns. You can select students, combine categories and summarize measurements while keeping those labels nearby.

A Series is one labeled collection of values, like a column with its own index. A DataFrame combines columns that may have different types. Rolls may be strings, marks may be numbers, and attendance may be boolean. This makes pandas useful for CSV files that do not fit one uniform numerical matrix.

Install pandas with python -m pip install pandas in your project environment, then import pandas as pd. If your work only needs a small dictionary, pandas may be unnecessary. Use the library when labeled selection and table operations make the question clearer.

Construct columns and select with intent

pd.DataFrame accepts a dictionary whose keys become column names. The column lists must have matching lengths. Unless you supply an index, rows receive labels starting at zero. Those default labels resemble positions, but labels and positions remain different ideas.

frame = pd.DataFrame({"roll": [11, 12], "mark": [39, 80]})
mask = frame["mark"] >= 40
passed = frame.loc[mask, ["roll", "mark"]]
first_row = frame.iloc[0]

frame["mark"] selects a Series. frame[["mark"]] selects a one-column DataFrame. That extra list preserves a table shape. Use loc for labels and iloc for integer positions. After filtering or sorting, the index may no longer match the visible row positions.

A label slice with loc includes its final label when present. A position slice with iloc follows Python's excluded stop rule. For an index [10, 20, 30], loc[10:20] selects labels ten and twenty. iloc[0:2] selects the first two positions. Write the selection rule before choosing the accessor.

Separate alignment, filtering and reduction

Series arithmetic aligns entries by index label. If one Series lists quiz then lab and another lists lab then quiz, matching labels still combine. A label missing from one side normally creates a missing result. This differs from adding two NumPy arrays by position.

A filter first calculates a boolean Series from a column comparison. loc then selects the rows whose mask is true. Combining comparisons requires parenthesized conditions with & or |. Python's and cannot combine whole Series in the intended entry-by-entry way.

A grouped reduction collects rows with matching keys and calculates one result for each group. For expenses, groupby("category")["taka"].sum() adds amounts within each category. Choosing the numeric column explicitly prevents unrelated columns from entering the calculation.

Decide what the file means

pd.read_csv reads a path or an open text stream. The first row normally supplies column names. CSV quoting handles commas inside fields, so splitting every line manually on commas is unsafe. Use the CSV parser and inspect the resulting columns before computing a report.

Type inference is convenient, but it can mistake an identifier for a number. A roll written as 001 carries formatting that integer one cannot preserve. Give the roll column a string dtype when those characters matter. Explicit numeric dtypes also make unexpected text fail visibly instead of silently changing a column's meaning.

Check required columns before selecting them. Validate numeric ranges after parsing; a value of 150 may parse as a number while remaining invalid as a percentage mark. For numeric-looking text, pd.to_numeric can reject malformed values. errors="coerce" converts failures to missing values, so count and investigate those conversions if you choose that policy.

A missing value means no usable observation is available. It does not mean the student scored zero. isna identifies missing entries, count counts known entries, and many numerical reductions skip missing entries. Decide whether to exclude, report or replace unknown values based on the question.

groupby normally drops rows whose grouping key is missing. Use dropna=False if an unknown-category group belongs in the report. Likewise, an all-missing sum may look like zero under default settings. min_count=1 can keep such a sum missing. State the policy rather than letting a default invent meaning.

Read describe as several separate measurements

For a numeric Series, describe reports count, mean, sample standard deviation, minimum, quartiles and maximum. The median is labeled 50%. Quartiles divide the ordered observations into parts; their values can fall between recorded marks. They summarize distribution rather than identifying specific students.

The sample standard deviation uses one fewer than the known count as its divisor. With only one known value, that statistic is missing. NumPy's ordinary std instead defaults to a population divisor. If you compare the libraries, align the definition before assuming the numbers disagree.

Print selected statistics with explicit formatting rather than relying on the full DataFrame display. Decimal precision, column truncation and dtype footers can depend on settings. Looping through chosen labels makes both the question and the displayed values clear. Formatting two decimals should follow the precision meaningful for your report.
