দরকারি হিসাবের নাম দাও

ক্যান্টিনের কয়েকবার কেনাকাটায় একই বিলের হিসাব copy করলে ভুল হতে পারে। ফাংশন ধাপগুলোর নাম দেয়। তুমি মান দাও, ফাংশন কাজ করে ফল ফেরাতে পারে।

ফাংশনে একবারে এক কাজ ভাবা যায়। ইনপুট আর প্রিন্টের মধ্যে বারবার গুণের চেয়ে bill নাম সহজে চেনা যায়। দামের নিয়ম বদলালে ভালো একটা সংজ্ঞা সব caller-এর কাজে লাগে।

এক স্পষ্ট প্রশ্নের উত্তর দেয় এমন ছোট ফাংশন দিয়ে শুরু করো। সংখ্যা, Boolean, স্ট্রিং বা কনটেইনার ফেরাতে পারে। Caller ঠিক করে দেখাবে, রাখবে নাকি অন্য হিসাবে নেবে।

প্যারামিটার ঠিক করে ফল ফেরাও

def bill(quantity, unit_price):
    """Return the total price in whole taka."""
    return quantity * unit_price

cost = bill(3, 20)

def দিয়ে সংজ্ঞা শুরু। নামের পরে বন্ধনীতে প্যারামিটারের নাম। Colon-এর পরে indentation-সহ body। প্যারামিটার কলের সময় মান নেওয়ার জন্য স্থানীয় নাম।

আর্গুমেন্ট কল থেকে দেওয়া মান। bill(3, 20)-তে 3 আর 20 যথাক্রমে quantity আর unit_price-এ bind হয়। Body শুরুর আগে আর্গুমেন্টের expression হিসাব হয়।

Body-র শুরুর string literal হলো docstring। উদ্দেশ্য, চাওয়া ইনপুট আর গুরুত্বপূর্ণ বিশেষ ফল বোঝাও। এক line-এও triple quote প্রচলিত। সাধারণ comment-এর বদলে docstring Python-এর documentation tool থেকে পাওয়া যায়।

ইনপুট থেকে ফল পর্যন্ত এক কল ধরো

  1. Python কলের আর্গুমেন্ট হিসাব করে।
  2. নতুন কল স্থানীয় প্যারামিটার নাম ওই মানে bind করে।
  3. return বা body শেষ পর্যন্ত চলে।
  4. Call expression caller-কে ফেরানো অবজেক্ট দেয়।

bill(3, 20)-তে quantity 3, unit_price 20। গুণে 60, return তা ফেরায়। Assignment cost-কে ওই integer-এ bind করে। total-এর মতো স্থানীয় নাম কলের ভেতরে কাজে লাগে, বাইরের ভেরিয়েবল নিজে থেকে হয় না।

return বর্তমান কল সঙ্গে সঙ্গে শেষ করে, ওই পথে পরের statement চলে না। ভুল ইনপুট বা empty collection-এ early return দিলে zero দিয়ে ভাগের মতো বিপদ এড়ানো যায়।

C জানা থাকলে

এই syntax-এ Python return বা parameter type ঘোষণা করে না। শেষে পৌঁছালে None ফেরে, C-তে return না দেওয়া মানের ওপর নির্ভর করার মতো নয়। কমা দিয়ে return-এ টাপল হয়, তাই কয়েকটি ফলের জন্য output pointer parameter লাগে না।

আবার কাজে লাগে এমন ফল ফেরাও

কোন আউটপুট caller, কোনটি ফাংশনের ভেতর থেকে দেখো। একই numeric ফল প্রিন্ট, যোগ বা save করা যায়। শুধু দেখানোর ফাংশন কাজ করে জানায়, সাধারণত None ফেরায়।

ক্যান্টিনের বিল ফেরাও

সংজ্ঞা ফাংশন রাখে, তখনও বিল হিসাব করে না। bill কল দুই parameter bind করে product দেয়। দ্বিতীয় ফল printed text নয়, মান বলে যোগে লাগে।

একাধিক মাপ ফেরাও

কমা দুই মাপ টাপলে রাখে। প্রথম কল low আর high-এ unpack করে। এক-item ইনপুটে minimum-maximum সমান, pair হয় (50, 50)।

প্রিন্ট আর return আলাদা করো

announce Mark: 80 দেখিয়ে return ছাড়া শেষ হয়, তাই ফল None। Printed ফাংশনের ফল save করলে দেখানো text আসে না। Identity check default return নিশ্চিত করে।

হিসাব না হলে আগে ফেরো

Empty list ভাগের আগে early return নেয়। Nonempty list 80.0 ফেরায়। is None দিয়ে অনুপস্থিত ফল আর বৈধ numeric zero আলাদা।

এক কলে দলবদ্ধ ফল বা কাজের ফল না-ও আসতে পারে

একাধিক মান ফেরানো সাধারণত এক টাপল ফেরানো। return low, high pair বানায়। Caller দুই নামে unpack বা এক অবজেক্ট রাখতে পারে। Unpacking target সংখ্যা ফলের shape মেলাবে।

ফাংশন সবসময় return value দেয়। শেষে পৌঁছালে বা bare return-এ None। এটি কাজের মানের অনুপস্থিতি বোঝানো বিশেষ অবজেক্ট, zero, empty string বা empty list থেকে আলাদা।

প্রিন্ট আলাদা কাজ। announce(80) save করলে return value, দেখানো character নয়। পরের হিসাবে mark লাগলে mark ফেরাও। উদ্দেশ্য message দেখানো হলে সেইমতো নাম দাও।

Empty sequence-এর mean-এর মতো optional ফল document করো। Numeric ব্যবহারের আগে caller is None দেখবে। এতে ভুল average বানানো ছাড়াই empty case স্পষ্ট।

ফাংশনের contract পরিষ্কার

কল করতে ভুলে যাওয়া

bill নাম ফাংশন অবজেক্ট, bill(3, 20) কল করে। বন্ধনী জরুরি। ফাংশন অবজেক্ট পরে ব্যবহারের জন্য রাখা যায়, higher-order পাঠে আসবে।

শুধু এক পথে return

এক branch সংখ্যা দেয়, অন্যটি শেষ হলে caller অপ্রত্যাশিত None পেতে পারে। সব পথ পড়ে ফল ঠিক করো। একইরকম documented ফল সহজে ব্যবহার হয়।

Local reassignment-এ caller-এর নাম বদলাবে ভাবা

প্যারামিটার local binding। নতুন মান assign করলে শুধু সেই নাম বদলায়। তার মাধ্যমে shared list edit করলে caller-এর অবজেক্ট বদলাতে পারে। Arguments পাঠে default-এর সঙ্গে এই পার্থক্য আসবে।

সংজ্ঞা আর documentation

def, return আর docstring-এর নিয়ম Python 3.10–3.12-তে স্থির। Type annotation optional, আলাদা শেখানো হবে; এখানে সাধারণ runtime value।

এক কাজের নাম আর ফল বলো

def-এ কাজ জোড়ো, docstring-এ contract, return-এ উত্তর। Empty বা unavailable ফলে কী হবে স্পষ্ট ঠিক করো। পরের ফাংশনের আর্গুমেন্ট contract না লুকিয়ে মান দেওয়ার আরও উপায় দেয়।
