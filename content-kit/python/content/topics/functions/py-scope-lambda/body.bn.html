এক বানানে আলাদা মানের নাম

দুই ক্লাসে roll 12 দুই আলাদা শিক্ষার্থী হতে পারে। Python-এর নামও context-এর। Scope হলো নাম খোঁজার সময় Python যে অঞ্চলের binding বিবেচনা করে।

ফাংশন অস্থায়ী নাম কাজের কাছে রাখে। এতে helper-এর হিসাব অন্য নাম ভুল করে বদলায় না। Nested ফাংশন আরেক layer: inner তার enclosing কলের setting পড়তে পারে।

Scope বোঝায় ভেতরের মান বাইরে প্রিন্টের থেকে আলাদা কেন। কিছু অঙ্কের ভুল মনে হলেও আসলে name-binding error। নামের উৎস অস্পষ্ট হলে চারপাশের scope আঁকো।

দরকার হলেই rebinding-এর জায়গা বদলাও

visits = 0

def record_visit():
    global visits
    visits += 1

সাধারণভাবে ফাংশনে নামে assignment থাকলে পুরো body-তে নাম local। Binding তৈরির আগে পড়লে UnboundLocalError। Local ঠিক করার পরে Python global মানে ফিরে খোঁজে না।

global নামে binding module level-এ পাঠায়। nonlocal enclosing function scope-এর existing binding বাছে। ওই ফাংশনে নাম ব্যবহারের আগেই declaration রাখো।

কোনোটিই argument পাঠায় বা মান ফেরায় না; কোথায় binding হবে বদলায়। অনেক হিসাবে বাইরের state বদলানোর চেয়ে parameter নিয়ে ফল return পরিষ্কার।

LEGB ধরে বাইরে খোঁজো

LEGB সাধারণ খোঁজার ক্রম: Local, Enclosing, Global, Built-in। আগে বর্তমান ফাংশনের parameter-সহ স্থানীয় নাম, তারপর ঘিরে থাকা function scope, তারপর defining module, শেষে Python built-in।

প্রথম প্রোগ্রামে inner-এর নিজের amount আর local_fee। rate local-এ নেই, outer-এ আছে, তাই module-level rate-এর আগে সেটি। কাছে কেউ না ঢাকায় len built-in থেকে।

Nested ফাংশন নিজের defining environment মনে রাখে, পরে যে ফাংশন কল করে তার local variable নয়। এটি lexical scope। make_counter ফিরলেও returned counter count-এ access রাখে, যা closure।

Closure ব্যবহৃত enclosing binding-এ access রাখা ফাংশন। প্রতিটি factory call আলাদা state করতে পারে। তাই আলাদা make_counter কলের counter একই source হলেও একে অন্যে বাধা দেয় না।

C জানা থাকলে

C block scope আর Python function scope হুবহু নয়। Python for আর if সাধারণ নতুন local scope করে না। Returned closure enclosing binding রাখে; মেয়াদ শেষ C stack local-এর pointer ফেরানো নয়।

প্রতিটি ফাংশন কোন binding পড়ে দেখো

প্রিন্ট trace-এর আগে নাম L, E, G বা B দাও। Assignment-এ global বা nonlocal destination বদলায় কি না দেখো। প্রায়ই সব অঙ্ক না চালিয়েই ফল বোঝা যায়।

Local, enclosing, global আর built-in খোঁজো

inner amount আর local_fee local-এ, rate outer-এ, len built-in-এ পায়। ভেতরের হিসাব 33। outer-এর নিজের binding বলে module-level rate 5 থাকে।

এক module-level নাম rebind

global visits-এর assignment module-level-এ করে। দুই কল একই counter বাড়িয়ে 2। global ছাড়া local assignment-এর আগে read-এ UnboundLocalError।

এক enclosing counter রাখো

nonlocal enclosing কলের count বাছে। Returned inner binding access রাখে। প্রতিটি make_counter আলাদা state, তাই first 12 পেলেও second 1-এ শুরু।

ছোট ordering rule হিসেবে lambda

Key ফাংশনের pair-এ negative mark বড় mark আগে, roll tie ভাঙে। নাম দেওয়া lambda নিজের এক expression স্বয়ংক্রিয় ফেরায়। Reusable named হিসাবে lambda assign-এর চেয়ে def সাধারণত পরিষ্কার।

চাওয়া loop value ধরে রাখো

late ফাংশন কলের সময় shared loop name পড়ে, তখন 2। প্রতিটি lambda তৈরিতে default evaluate হওয়ায় fixed আলাদা 0, 1 আর 2 রাখে।

নিয়ম না লুকিয়ে ছোট ফাংশন

Lambda expression parameter আর এক expression দিয়ে ছোট ফাংশন বানায়। Syntax lambda parameters: expression। Expression-এর মান ফল, return লেখা হয় না। sorted-এ ছোট rule পাঠাতে ভালো।

sorted-এর key argument প্রতিটি item-এর comparison key দেওয়া ফাংশন চায়। Key tuple primary-secondary order বলে। Negative mark আর positive roll-এ descending marks, tie-তে ascending roll।

জটিল lambda স্থায়ী নামে assign def-এর চেয়ে কম readable। Named definition docstring আর কয়েকটি পরিষ্কার statement দেয়। আশপাশের কলে পুরো rule আরামে ধরলে lambda নাও।

Closure binding access রাখে, সব মানের frozen snapshot নয়। Loop-এ তৈরি ফাংশন পরে number পড়লে সবাই final binding দেখে। def-এ বানানো inner-এও একই, শুধু lambda নয়।

number=number default ফাংশন তৈরির সময় current object ধরে। Immutable loop value-তে ভালো হতে পারে। Mutable হলে আগের নিয়ম মনে রাখো: reference রাখা independent copy নয়।

সাধারণ if বা for নতুন function-local scope করে না। Executed branch-এর assigned নাম পরে পড়া যায়। Branch না চললে binding তৈরিই নাও হতে পারে। সব পরের পথে দরকার হলে branching-এর আগে result initialize করো।

global মানে defining module, পুরো app-এর shared namespace নয়। দুই module-এ count থাকলে ফাংশন সাধারণত নিজের module-এর binding দেখে। ফাংশন import করলে defining global namespace caller-এর module-এ সরে না।

Nested ফাংশন nonlocal ছাড়াই enclosing নাম পড়ে। ভেতর থেকে ওই নাম rebind করতে declaration লাগে। তাই read-only threshold closure-এ নয়, incrementing counter-এ লাগে।

নাম বদল আর অবজেক্ট বদল আলাদা

সব error সারাতে global

Binding দেখাতে global counter ভালো, কিন্তু বেশি shared state-এ কল বোঝা কঠিন। আগে ভাবো পুরোনো মান নিয়ে নতুন মান ফেরানো উচিত কি না। এতে dependency দেখা যায়।

nonlocal module variable পাবে ভাবা

nonlocal-এ surrounding function binding চাই। না থাকলে definition invalid। ইচ্ছা করা design mutation হলেই module binding-এ global নাও।

Mutation আর reassignment মেশানো

List-এ append নাম পড়ে অবজেক্ট edit করে। একই নামে অন্য list assign rebinding। শুধু rebinding-এ outer scope বাছার declaration লাগে।

দরকারি built-in ঢেকে ফেলা

Local list বা sum সাধারণ lookup-এ built-in ঢাকে। পরে sum কল integer call হতে পারে। দরকারি tool না ঢেকে total বা numbers নাম নাও।

Scope সংজ্ঞা মেনে চলে

LEGB, nonlocal আর lambda এখানে Python 3.10–3.12-তে চলে। সাধারণ loop target binding surrounding scope-এ রাখে; comprehension আলাদা target scope।

LEGB lookup বোঝায়, global আর nonlocal rebinding-এর জায়গা বদলায়। একই scope rule-এ lambda ছোট function expression। পরের রিকার্শন-এ বারবার কলের local state আলাদা trace করবে।
