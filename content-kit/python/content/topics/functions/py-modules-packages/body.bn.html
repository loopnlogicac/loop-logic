এক ফাইলের বাইরে সংজ্ঞা ব্যবহার

Billing ফাংশন কয়েক ছোট প্রোগ্রামে লাগে। প্রতি ফাইলে copy করলে correction কঠিন। Module নিজের namespace-সহ Python কোডের এক unit, যা অন্য কোড import করে।

সরল module .py ফাইল। Package tools.billing-এর মতো dotted name-এ সম্পর্কিত module গুছায়। Standard library Python-এর সঙ্গে, third-party distribution আলাদা install, এক বা একাধিক importable package দিতে পারে।

এভাবে caller পরিষ্কার public interface নেয়, implementation detail একসঙ্গে থাকে। Reusable সংজ্ঞা interactive startup থেকে আলাদা রাখো, যাতে হিসাব import হঠাৎ ইনপুট না চায়।

Import boundary-তে নাম বাছো

import math
import statistics as stats
from math import isqrt

import math module name bind করে, তাই math.factorial। Alias অন্য local name। from import বাছা নাম সরাসরি bind করে। প্রতিটি tool-এর উৎস চেনা যায় এমন explicit রূপ নাও।

Star import কোন নাম এল লুকায়, আগের নাম overwrite করতে পারে। ছোট explicit list search-review সহজ, বিশেষ করে দুই library-তে কাছাকাছি tool name থাকলে।

সাধারণ package-এ __init__.py থাকে। Project root-এর script থেকে __init__.py আর billing.py-সহ tools directory-কে tools.billing import করা যায়। Namespace package-এ __init__.py বাদ চলে, তবে শেখার সময় conventional package পরিষ্কার।

Import initialize করে, guard entry বাছে

সাধারণ প্রথম import-এ Python module খুঁজে namespace বানিয়ে top-level statement চালায়। Definition function object বানায়, body চালায় না। Initialized module সাধারণত cached, পরের import সেটিই নেয়, initialization আবার নয়।

সরাসরি script চালালে __name__ হলো __main__। সাধারণ import-এ import name। তাই if __name__ == "__main__" সরাসরি entry path বাছে।

Interactive কাজ main-এ রেখে guard-এর নিচে কল। Constant আর reusable definition import করা যায়। Unguarded print বা input তখনও import-এ চলে; guard পুরো ফাইলকে জাদুর মতো ঢাকে না।

runpy বাছা নামে source চালিয়ে namespace ফেরাতে পারে। দ্বিতীয় উদাহরণ guard-এর সিদ্ধান্ত দেখায়। এটি execution, ordinary import caching নয়, library import-এর বদলি ভেবো না।

C জানা থাকলে

Import textual #include নয়। Python module initialization চালিয়ে namespace-এ অবজেক্ট bind করে, সাধারণত cache রাখে। C-style linker command লাগে না, তবু search path আর installed environment কী পাওয়া যায় ঠিক করে।

Script চালাও, পাশের ফাইল import

শেষ প্রোগ্রামের পাশে billing.py। total quantity গুণ unit price দেয়, CURRENCY হলো BDT। সরাসরি billing.py চালালে ছোট demonstration, import-এ guarded demonstration চলে না।

পরিষ্কার import বাছো

import math tool math namespace-এ রাখে। from math import isqrt একটিকে সরাসরি bind। stats হলো statistics-এর অন্য নাম। রূপভেদে caller-এর লেখা নাম বদলায়।

এক source আলাদা নামে চালাও

সরাসরি চালালে __main__ হয়ে main চলে। runpy আবার billing_library নামে চালায়। Guard false, তাই entry message ছাড়া সংজ্ঞা load। ফেরত namespace total দেয়।

Active Python environment দেখো

sys.executable active interpreter চেনায়; prefix আর base_prefix environment বোঝায়। Machine-specific path না ছেপে type পরীক্ষা। সাধারণ venv-এ prefix আর base_prefix আলাদা।

Isolated Python-এ আসল পাশের module import

billing.py-তে constant আর documented total। দুই import একই module। Guarded demonstration চলে না, output শুধু BDT আর 60। Explicit folder addition isolated execution-এর জন্য; সাধারণ local script নিজেই sibling খুঁজে পায়।

Project-এর সঙ্গে dependency রাখো

Virtual environment project-কে নিজের installed-package area দেয়। যে interpreter version নেবে সেটি দিয়ে বানাও। সাধারণ Linux/macOS shell-এ:

python3 -m venv .venv
source .venv/bin/activate
python -m pip --version

Windows PowerShell-এ py -m venv .venv, তারপর .venv\Scripts\Activate.ps1। Activation না হলে সরাসরি interpreter: Linux-এ .venv/bin/python, Windows-এ .venv\Scripts\python.exe। Activation shell lookup বদলায়, interpreter ব্যবহারের বাধ্যবাধকতা নয়।

বাছা interpreter দিয়ে দরকারি third-party distribution install, যেমন python -m pip install requests। এই পাঠে external installation লাগে না। python -m pip show requests দিয়ে দেখো, ইচ্ছা করে ওই environment থেকে সরাতে python -m pip uninstall requests।

Project-এর documented version মানো। Requirements file installation requirement রাখে, python -m pip install -r requirements.txt পড়ে। pip freeze installed version দেখায়, তবে maintained direct-dependency list-এর চেয়ে বেশি package থাকতে পারে।

Source project-এ .venv commit কোরো না, documented dependency থেকে আবার বানাও। Activated shell ছাড়তে deactivate। Environment সাধারণ filesystem access আটকায় না, untrusted code-এর সুরক্ষাও নয়।

Distribution আর import name আলাদা হতে পারে। Install interpreter-কে ফাইল দেয়, source-এ import নিজে চালায় না। Install-এর পরেও import fail হলে execution আর pip-এর interpreter মেলাও।

project/
    report.py
    tools/
        __init__.py
        billing.py

এই conventional layout-এ আগের setup থেকে report.py tools.billing import করতে পারে। tools-এর ভেতরে from .billing import total sibling বোঝায়। শুরুর dot package context, যেকোনো filesystem search নয়।

Project root থেকে python -m tools.billing দিয়ে package-এর module চালাও। Relative import-এর package context মেলে। সরাসরি member file path চালালে context হারিয়ে relative import ব্যর্থ হতে পারে।

চাওয়া module আর interpreter খোঁজো

Library-র নামের ফাইল

math.py বা random.py local execution-এ আসল module ঢাকতে পারে। billing.py-এর মতো project-specific নাম নাও। ভুল কোড import হলে একই নামের directory-ও দেখো।

Isolated execution sibling নিজে পাবে ভাবা

-I script directory search path থেকে বাদ দেয়, user environment setting এড়ায়। শেষ উদাহরণ ওই mode-এ পরিচিত source directory নিজে যোগ করে। সাধারণ local script-এ লাগে না।

Import-এ startup code চালানো

Module-level input শুধু ফাংশন চাওয়া caller আটকে দেয়। Startup main আর guard-এর পেছনে রাখো। Initialization-এ বাইরের state লুকিয়ে বদলিও না।

Environment মেশানো

সাধারণ pip চলতি প্রোগ্রাম থেকে অন্য interpreter ধরতে পারে। সমস্যা হলে python -m pip --version আর sys.executable দেখো। System-managed interpreter-এ জোর না করে project environment নাও।

Environment-এর নিজের interpreter নাও

Import, main guard, venv আর pip invocation Python 3.10–3.12-তে প্রযোজ্য। কিছু Linux-এ venv component আলাদা install লাগে; system-wide pip জোর না করে OS-এর নির্দেশ মেনে নাও।

Reuse predictable করো

Explicit import tool চেনায়, main guard startup রক্ষা করে, venv dependency গুছায়। পরের standard library tour Python-এর সঙ্গে আসা module দেখাবে।
