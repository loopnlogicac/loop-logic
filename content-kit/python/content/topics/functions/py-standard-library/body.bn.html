আবার বানানোর আগে পরীক্ষিত tool

শব্দ গোনা, তারিখে দিন যোগ আর কিউ চালানো পরিচিত কাজ। Python-এর standard library, interpreter-এর সঙ্গে দেওয়া collection-এ এর module আছে। Third-party package install ছাড়াই import করা যায়।

সঠিক contract-এর tool বাছাই আসল দক্ষতা। Float square root আর integer square root আলাদা প্রশ্ন। List আর কিউতেও দক্ষ operation আলাদা। ফাংশন নেওয়ার আগে ইনপুট, ফল আর edge case পড়ো।

এই tour পরিচিত structure-কে library tool-এ মেলায়। ফল দেখতে ছোট fixed input। Advanced app-এও validation আর উপযুক্ত resource limit চাই।

Module বা বাছা tool import

import math
from collections import Counter, deque
from datetime import date, timedelta
from pathlib import Path

math.isqrt-এর মতো qualified নাম উৎস দেখায়। Counter-এর মতো ঘনঘন ব্যবহৃত ক্লাসে selected import সুবিধা। দরকারি নামই নাও, একই scope-এ অন্য অর্থে assign কোরো না।

কাজের আগে representation

Integer উত্তর চাইলে exact tool। math.isqrt বড় integer approximate float-এ নেয় না। সাধারণ real হিসাবের sqrt আর trigonometric ফাংশন float। isclose বলা relative-absolute tolerance-এ approximate মান তুলনা করে।

date calendar day, datetime-এ সময়ও। timedelta duration। Aware datetime-এ ব্যবহারযোগ্য timezone, naive-এ নিজের offset জানা যায় না। Naive মানই UTC আন্দাজ কোরো না।

Path-ও অবজেক্ট। Path বানালে location বলা হয়, সেখানে কিছু তৈরি নয়। Read, write, existence check আলাদা কাজ। Pure path class filesystem না ছুঁয়েও syntax parse করে।

C জানা থাকলে

অনেক কাজে C-তে আলাদা library বা custom structure লাগে। Python date, কিউ আর path দেয়, তবু representation-এ খরচ বদলায়। Front removal-এ deque, repeated direct indexing-এ list ভালো।

Fixed data আর bounded কাজ

উদাহরণ current-clock output আর machine-specific absolute path এড়ায়। File উদাহরণের temporary folder নিজে cleanup করে। with resource lifetime সামলায়; ফাইল handling পাঠে text file বিস্তারিত।

Number type অনুযায়ী mathematical tool

isqrt exact integer root, sqrt float। floor negative infinity-র, ceil positive infinity-র দিকে। isclose exact binary equality না চেয়ে tolerance-এ float তুলনা।

Local seeded random generator

Local Random নিজের state রাখে। একই seed-এর দ্বিতীয় generator প্রথম random() মান মেলায়। Draw zero-inclusive থেকে one-exclusive; formatting শুধু display round করে।

Fixed calendar date-এর হিসাব

Date arithmetic February পার হয়। বিয়োগে তিন দিনের timedelta। Aware datetime UTC instant-কে fixed plus-six-hour offset-এ একই instant দেখায়।

মান গোনা আর observation group

Counter frequency mapping বানায়, missing count zero। defaultdict(list)-এ missing room-এ প্রথম bracket access fresh group বানায়। Room A-তে roll 12 আর 25।

কিউর দুই প্রান্তে কাজ

appendleft roll 5-কে সামনে দেয়, popleft সেটি serve। Rotate বাকি কিউর 25 সামনে আনে। Bounded deque capacity পেরোলে শুধু নতুন দুই মান রাখে।

Iterator মেলাও, সীমা দাও

chain input পরপর দেখে, product group-এর সব ordered choice, combinations একই order repeat না করে position group। count unbounded, তাই islice report চার মানে সীমিত করে।

Temporary directory-তে path

Path হাতে separator আন্দাজ ছাড়া component জোড়ে। TemporaryDirectory private working folder বানিয়ে পরে সরায়। পড়ার আগে with ফাইল close করে। শুধু stable filename-content প্রিন্ট, temporary absolute path নয়।

State আর missing value বোঝো

Pseudo-random generator internal state এগিয়ে sequence দেয়। Seed initial state বাছে। Local Random এক experiment-কে অন্যের generator reset করা থেকে বাঁচায়। Fixed seed repeatability দেয়, তবে random-module-এর কিছু algorithm version-এ বদলায়।

random() zero-inclusive one-exclusive float দেয়। অন্য method integer, sample বা shuffled sequence বাছে। এগুলো simulation, password generation নয়; নিরাপত্তার randomness-এ অন্য facility।

Date arithmetic মাস আর leap-year সামলায়। February 27, 2026-এ তিন দিন যোগ March 2। Aware UTC instant fixed plus-six-এ দেখালেও instant এক। Fixed offset historical daylight-saving নয়; named regional zone-এ zoneinfo।

Counter dictionary-র মতো frequency tool। Missing count পড়লে key না যোগ করে zero। most_common-এ equal count first-encounter order রাখে; alphabetic tie চাইলে explicit sort।

defaultdict missing bracket access-এ factory কল করে ফল রাখে। defaultdict(list) independent list দেয়। list-এর বদলে list() ভুল, callable factory চাই। get missing-key factory চালায় না।

deque দুই প্রান্তে efficient append-remove। List front removal পরের reference সরায়, deque.popleft তা এড়ায়। Deque-র মাঝে frequent random indexing ভালো নয়। বারবার কোন কাজ হবে দেখে container নাও।

Combination সীমিত, filename portable রাখো

itertools.chain iterable stream পরপর জোড়ে। product group-পিছু সব combination, combinations position বাছে order repeat ছাড়া। Iterator বলে পুরো output list না বানিয়েও consume করা যায়।

Laziness বিশাল ফল সস্তা করে না। a আর b size-এর product-এ a গুণ b ফল। কিছু itertools tool input pool-ও রাখে। count endless arithmetic sequence, তাই islice বা finite stop দাও।

Path-এর slash path rule-এ component জোড়ে। name শেষ filename, stem শেষ suffix বাদ, suffix সেই অংশ। Absolute component আগের অংশ ফেলে দিতে পারে, location জরুরি হলে বাইরের নাম validate।

os lower-level listdir আর environ দেয়। Directory listing sorted হওয়ার নিশ্চয়তা নেই, উদাহরণ filename sort করে। পরিবেশের সব variable ছাপবে না; প্রোগ্রামের দরকারি setting-ই দেখো।

Temporary উদাহরণ explicit UTF-8-এ পরিচিত text লেখে। পড়ার আগে with close করে। Block শেষে TemporaryDirectory folder সরায়, আগের user file-এ নির্ভর নয়।

Tool-এর exact আচরণ দেখো

Infinite iterator list করা

list(count()) প্রাকৃতিক শেষ ছাড়া চাইতেই থাকে। আগে finite bound। বিশাল finite Cartesian product-এও collect-এর আগে output size গুনো।

Missing group আগেই রাখা ভাবা

Bracket access missing-key machinery ডাকলেই defaultdict insert। Membership বা get group বানায় না। Group count মাপায় পার্থক্য জরুরি।

Path parsing-কে file check ভাবা

ফাইল না থাকলেও নামের .csv suffix হয়। Existence চাইলে is_file বা explicit filesystem operation। Relative path working directory থেকে, যা script directory থেকে আলাদা হতে পারে।

Empty queue-তে ভুল operation

Empty deque-তে popleft IndexError। Empty স্বাভাবিক হলে আগে item আছে দেখো। Bounded deque পুরোনো item নিজে ফেলে, ইচ্ছা করেই হারানো চললে নাও।

Version-sensitive detail স্পষ্ট

সব API Python 3.10–3.12-তে আছে। Compatible seeding-এ seeded random()-এর documented reproducibility আছে, অন্য random algorithm বদলাতে পারে। Path suffix-এ সাধারণ নাম, নতুন version-এর trailing-dot আচরণ নয়।

স্পষ্ট contract-এর ছোট library tool

Standard library বাইরের installation ছাড়াই building block দেয়। Exact-approximate সংখ্যা, bounded-unbounded iteration, lexical-real filesystem কাজ বুঝে বাছো। পরের module-এ ক্লাস আর অবজেক্ট দিয়ে নিজের state-behavior গুছাবে।
