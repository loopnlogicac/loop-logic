Ask a precise question about your values

Before accepting a mark, you may need to ask whether it lies between zero and one hundred. Before dividing, you need to know whether the denominator is nonzero. Operators let you express those questions clearly.

An operator combines or inspects values. Arithmetic operators calculate quantities; comparison operators ask about relationships. Logical operators combine conditions. The goal is not to write the shortest expression, but to make the intended rule visible.

You already know basic arithmetic from Numbers and Arithmetic. This lesson focuses on comparisons, logic, object identity and membership. These expressions become the conditions used by decisions and loops.

Assignment uses one equals sign. Equality uses two. The expression mark == 40 compares without changing mark. When ordinary numeric comparisons succeed, they produce True or False, the Boolean values you met with types.

A comparison chain checks adjacent relationships. The expression 0 <= mark <= 100 means the mark is at least zero and at most one hundred. Python evaluates the middle expression only once. It does not compare a temporary Boolean to the final boundary as a C translation might.

Read logical expressions using comparisons first, then not, then and, then or. Parentheses are useful when a business rule has several groups. For eligibility through either of two routes, make the route boundaries visible even when precedence would already give the desired result.

Stop evaluating when the answer is known

Short-circuit evaluation means skipping an operand when an earlier value already determines the result. For and, a falsey left operand ends the expression. For or, a truthy left operand ends it. Python evaluates left to right.

Truthy and falsey describe whether a value counts as yes or no in a condition. Numeric zero, empty text and None are falsey. Nonzero numbers and nonempty text are usually truthy. The text "0" is nonempty, so it is truthy despite looking like a zero.

and and or return operands, rather than always creating a Boolean result. The expression "" or "Guest" returns Guest. The expression 0 and 99 returns zero without evaluating any further need for 99. Use this behavior only when the returned value matches your purpose.

A fallback using or treats every falsey value as absent. That can be wrong when zero is a valid result. If only None means missing, test specifically for None instead of replacing all falsey values.

The identity example uses lists, groups of values written in square brackets. You only need to know that each list expression creates an object here; Lists develops their operations. The separate lists compare equal but have different identities.

Check whether text contains a part

The membership example asks whether one string occurs within another. Matching is case-sensitive. not in reverses that test. An empty string is considered a substring of every string, which is useful to remember when validating a search term.

Equality, identity and membership have different jobs

Equality asks whether values compare the same. Identity asks whether two references point to the very same object. Use == for ordinary numeric or text value comparisons. Use is when the object itself matters, most commonly in value is None.

Python may reuse some immutable objects internally. An experiment comparing two small numbers with is can therefore appear to work, then fail for another construction. Do not depend on such reuse. The intended question should choose the operator before you inspect an accidental result.

Membership asks whether a container includes an item. For strings, in searches for a substring. Other containers define membership according to their own contents. Do not use membership when you intend equality of the entire string.

If you know C

Python writes and, or and not instead of the C logical symbols. Comparison chains are meaningful Python syntax. The operator is tests object identity, so it is not a replacement for C's numeric equality operator.

Check the expression's actual meaning

Leaving the comparison out of an alternative

The expression course == "CSE" or "EEE" does not compare course with both words. The second operand is nonempty text, so the expression is truthy regardless. Write both comparisons, or use membership in a group when you learn containers.

Using bitwise symbols for ordinary conditions

The symbols & and | have other meanings for numbers and some specialised objects. Use and and or for the ordinary Boolean conditions taught here. Their short-circuit behavior is part of why they are suitable.

Comparing unrelated types by order

Python will not generally order a string and an integer for you. Convert only when the values have compatible meanings. An error from comparing mark text with a numeric boundary often reveals a missing input conversion.

Consistent expression rules

Chaining, short-circuiting, is and in follow these rules in Python 3.10 and later. Exact object reuse is an implementation detail and must not become a program requirement.
