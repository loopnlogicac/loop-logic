What is Python?

Imagine turning a page of lab marks into totals without adding every row by hand. A program can repeat that work for you. Python is a programming language: a way to write instructions that a computer can follow.

You write instructions as text, following rules called syntax. A Python implementation reads that text and carries out its meaning. The computer does not guess what you intended. A missing quote or a mistaken calculation can change what happens.

You do not need to know another language before learning Python. We will begin with displaying a message, then storing values and making decisions. Students who have learned C will also find short comparisons where the languages differ.

Python is useful because many everyday tasks can be expressed with a small amount of readable code. Readable code matters when you return to a lab exercise after several weeks. It also helps another student understand your approach without following every machine-level detail.

From instructions to a running program

A source file contains the instructions you wrote. A runtime is the software that supports their execution. The common Python implementation is CPython. Its name reflects that much of its implementation is written in C.

CPython first checks and compiles source into bytecode, a lower-level set of instructions for its interpreter. The interpreter executes those instructions. This is why calling Python interpreted does not mean that compilation never happens.

In a typical C workflow, you ask a compiler to produce an executable and then run it. With Python, you commonly give the source filename to the interpreter. The translation steps happen as part of starting the program. This difference changes your workflow, but it does not make either language free from errors.

Compiled and interpreted are descriptions of implementation strategies. They are not rigid boxes that every language must stay inside. Other Python implementations can use different execution techniques. Describe the implementation when making a precise performance claim.

Choosing Python for a task

A weekly marks summary

Suppose a department receives marks as rows of text. The job is to calculate totals and identify missing entries. You could write the data-processing steps in Python and use existing tools to read the rows. A library is a collection of reusable tools that saves you from rebuilding common operations.

The important first step is understanding the input. Does a blank mark mean zero or not yet recorded? Python cannot decide that policy for you. A short program with the wrong rule still gives the wrong report.

After choosing the rule, try a tiny record set whose totals you can check yourself. That gives you confidence before working with a whole class. Programming combines instructions with careful checking, rather than replacing careful thought.

A lab data picture

A student measuring temperature every minute might want a graph. Python can organise the readings and pass them to a plotting library. The language is also used for web services, scientific computing, automation and data analysis. Those applications share the same basic ideas of values, decisions and repetition.

A web application usually needs more than Python alone. It may also need a database, a server and rules about access. Learning the language gives you a foundation; it does not automatically teach every surrounding system.

A tight hardware limit

Consider a tiny device with very little memory and strict timing requirements. C may be a better fit for direct hardware control. A desktop tool that prepares the device's data could still use Python. Real projects often combine languages according to their strengths.

If you know C

Keep your problem-solving skills, but learn Python's own forms. You will often visit values directly instead of managing array indexes. You also do not manually free ordinary Python objects. Resource handling still matters, especially for files.

Reading a version number

In Python 3.12.14, 3 is the major version, 12 the minor version and 14 the patch number. These lessons target Python 3.12. Most of their features also work on Python 3.10 and later. That is a compatibility statement, not a claim that 3.12 is the newest release.

Python 2 reached end of life in January 2020. It differs in syntax and behavior, including how printing and division are commonly written. Choose Python 3 for new learning. Check the official documentation for current supported releases instead of relying on an old installation guide.

Ideas that cause trouble early

Assuming readable means automatic

Python may look close to everyday writing, but its syntax remains exact. You must state the steps and their order. Read an error message as useful information about a specific problem, rather than proof that you cannot program.

Assuming Python is always fast enough

Python can reduce writing time, while ordinary Python loops may run slower than compiled C loops. Libraries can move heavy work into optimised code. Measure a real bottleneck before choosing a complicated solution.

Mixing old and new tutorials

An old Python 2 example may fail under Python 3. First check the version named by the source. Do not change random punctuation until the message disappears; you also need to understand any behavioral difference.

Your starting point

Python gives you a readable way to describe work, backed by an implementation and many libraries. You now know why scripts, bytecode and interpreters belong in the same execution picture. Next, prepare an interpreter and try it in Setting Up Python.
