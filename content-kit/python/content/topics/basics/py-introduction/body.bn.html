Python কী?

ভাবো, ল্যাবের এক পাতার নম্বর থেকে মোট বের করবে, কিন্তু প্রতিটি সারি হাতে যোগ করতে হবে না। প্রোগ্রাম তোমার হয়ে একই কাজ বারবার করতে পারে। Python একটি প্রোগ্রামিং ভাষা। এটা দিয়ে কম্পিউটার বুঝতে পারে এমন ইনস্ট্রাকশন লেখো।

এই লেখার নিয়মকে বলে সিনট্যাক্স। Python-এর একটি বাস্তবায়ন তোমার লেখা পড়ে কাজগুলো করে। কম্পিউটার তোমার মনের কথা আন্দাজ করে না। একটা কোটেশন চিহ্ন বাদ পড়লে বা হিসাব ভুল হলে ফল বদলে যেতে পারে।

Python শেখার আগে অন্য ভাষা জানা লাগে না। প্রথমে মেসেজ দেখানো, তারপর মান রাখা আর সিদ্ধান্ত নেওয়া শিখবে। C জানা থাকলে ভাষা দুটির পার্থক্য বোঝার জন্য ছোট তুলনাও পাবে।

অনেক দৈনন্দিন কাজ অল্প, সহজে পড়া যায় এমন কোডে লেখা যায় বলেই Python কাজে লাগে। কয়েক সপ্তাহ পর নিজের ল্যাবের কাজ খুললেও কোড বুঝতে সুবিধা হয়। অন্য শিক্ষার্থীও মেশিনের প্রতিটি খুঁটিনাটি না জেনে তোমার সমাধান ধরতে পারে।

লেখা থেকে প্রোগ্রাম চালানো

তোমার লেখা ইনস্ট্রাকশন থাকে সোর্স ফাইলে। সেগুলো চালাতে সাহায্য করা সফটওয়্যার হলো রানটাইম। Python-এর বহুল ব্যবহৃত বাস্তবায়ন CPython। এর বড় অংশ C দিয়ে লেখা বলে এমন নাম।

CPython প্রথমে সোর্স যাচাই করে bytecode-এ কম্পাইল করে। এগুলো ইন্টারপ্রেটারের জন্য নিচের স্তরের ইনস্ট্রাকশন। ইন্টারপ্রেটার সেগুলো চালায়। তাই Python-কে interpreted বললে কম্পাইল কখনো হয় না, এমন বোঝায় না।

C-তে সাধারণত কম্পাইলার দিয়ে executable বানিয়ে সেটা চালাও। Python-এ সাধারণত ইন্টারপ্রেটারকে সোর্স ফাইলের নাম দাও। প্রোগ্রাম শুরুর ভেতরেই রূপান্তরের ধাপগুলো হয়। কাজের পদ্ধতি আলাদা হলেও দুই ভাষাতেই ভুল হতে পারে।

Compiled আর interpreted হলো ভাষা বাস্তবায়নের কৌশলের বর্ণনা। সব ভাষাকে একটিমাত্র দলে আটকে রাখা যায় না। Python-এর অন্য বাস্তবায়ন অন্যভাবে চলতে পারে। গতি নিয়ে নির্দিষ্ট দাবি করলে কোন বাস্তবায়ন ব্যবহার করছ, সেটাও বলো।

কোন কাজে Python বেছে নেবে?

সপ্তাহের নম্বরের হিসাব

ধরো, বিভাগে টেক্সটের সারি হিসেবে নম্বর এসেছে। মোট বের করতে হবে, আর কোথায় নম্বর নেই খুঁজতে হবে। Python-এ ডেটা সামলানোর ধাপ লিখে সারি পড়ার জন্য তৈরি টুল নিতে পারো। বারবার ব্যবহার করা যায় এমন টুলের সংগ্রহকে বলে লাইব্রেরি। একই সাধারণ কাজ নতুন করে লিখতে হয় না।

আগে ইনপুটের অর্থ বোঝো। ফাঁকা ঘর কি শূন্য নম্বর, নাকি এখনও নম্বর ওঠেনি? Python এই নিয়ম ঠিক করে দেবে না। ছোট কোডেও নিয়ম ভুল হলে রিপোর্ট ভুল হবে।

নিয়ম ঠিক করে অল্প কয়েকটি রেকর্ডে চেষ্টা করো, যেগুলোর মোট নিজে যাচাই করতে পারবে। তারপর পুরো ক্লাসের ডেটা নাও। প্রোগ্রামিংয়ে ইনস্ট্রাকশনের সঙ্গে যাচাইও দরকার। চিন্তা করার কাজ বাদ যায় না।

ল্যাবের ডেটার ছবি

প্রতি মিনিটে তাপমাত্রা মাপলে তার গ্রাফ দরকার হতে পারে। Python রিডিংগুলো সাজিয়ে গ্রাফ আঁকার লাইব্রেরিকে দিতে পারে। ওয়েব সার্ভিস, বৈজ্ঞানিক হিসাব, অটোমেশন আর ডেটা অ্যানালাইসিসেও Python চলে। সবখানেই মান, সিদ্ধান্ত আর একই কাজ বারবার করার ধারণা থাকে।

ওয়েব অ্যাপ বানাতে শুধু Python যথেষ্ট নাও হতে পারে। ডেটাবেস, সার্ভার আর কে কী ব্যবহার করতে পারবে তার নিয়মও লাগে। ভাষা শেখা ভিত্তি তৈরি করে; আশপাশের সব সিস্টেম নিজে থেকে শেখা হয়ে যায় না।

হার্ডওয়্যারের কড়া সীমা

খুব কম মেমরি আর নির্দিষ্ট সময়ের মধ্যে কাজ শেষ করার শর্ত আছে এমন ছোট ডিভাইসে সরাসরি হার্ডওয়্যার নিয়ন্ত্রণের জন্য C ভালো হতে পারে। আবার সেই ডিভাইসের ডেটা প্রস্তুত করার ডেস্কটপ টুল Python-এ হতে পারে। বাস্তব প্রজেক্টে কাজ অনুযায়ী একাধিক ভাষা একসঙ্গে চলে।

C জানা থাকলে

সমস্যা সমাধানের অভ্যাস কাজে লাগাও, সঙ্গে Python-এর নিজস্ব ধরন শেখো। অ্যারের ইনডেক্স সামলানোর বদলে অনেক সময় সরাসরি মানগুলো নিয়ে কাজ করবে। সাধারণ Python অবজেক্টের মেমরি নিজে free করতেও হয় না। তবে ফাইলের মতো রিসোর্স ঠিকমতো সামলাতে হয়।

ভার্সন নম্বর পড়া

Python 3.12.14-এ 3 হলো major, 12 হলো minor, আর 14 হলো patch নম্বর। এই পাঠগুলো Python 3.12 ধরে লেখা। বেশির ভাগ ফিচার 3.10 বা পরেও চলে। এর মানে ওই ভার্সনগুলোতে কাজ মেলে; 3.12-ই সর্বশেষ রিলিজ, এমন দাবি নয়।

Python 2-এর সাপোর্ট জানুয়ারি 2020-এ শেষ হয়েছে। প্রিন্ট আর ভাগ লেখার ধরনসহ এর সিনট্যাক্স ও আচরণে পার্থক্য আছে। নতুন করে শেখার জন্য Python 3 নাও। বর্তমানে কোন রিলিজ সাপোর্ট পায়, তা পুরোনো ইনস্টল গাইডের বদলে অফিসিয়াল ডকুমেন্টেশনে দেখো।

শুরুর কয়েকটি ভুল ধারণা

সহজে পড়া যায় বলে নিজে থেকেই কাজ করবে ভাবা

Python সাধারণ লেখার কাছাকাছি লাগলেও সিনট্যাক্সের নিয়ম নির্দিষ্ট। ধাপ আর তাদের ক্রম তোমাকেই লিখতে হবে। এরর মেসেজকে সমস্যা খোঁজার সূত্র ভাবো। মেসেজ আসা মানে তুমি প্রোগ্রামিং পারো না, এমন নয়।

সব কাজে Python যথেষ্ট দ্রুত ভাবা

Python-এ কোড লিখতে সময় কম লাগতে পারে, কিন্তু সাধারণ লুপ কম্পাইল করা C লুপের চেয়ে ধীরে চলতে পারে। লাইব্রেরি ভারী কাজ দ্রুত কোডে করতে পারে। জটিল সমাধান নেওয়ার আগে কোথায় সময় যাচ্ছে মেপে দেখো।

পুরোনো আর নতুন টিউটোরিয়াল মেশানো

Python 2-এর উদাহরণ Python 3-এ নাও চলতে পারে। আগে টিউটোরিয়ালের ভার্সন দেখো। মেসেজ সরাতে এলোমেলো চিহ্ন বদলাবে না; আচরণের পার্থক্যও বুঝতে হবে।

শেখার শুরু

Python-এ কাজের ধাপ সহজে পড়ার মতো করে লেখা যায়। পেছনে থাকে ভাষার বাস্তবায়ন আর অনেক লাইব্রেরি। স্ক্রিপ্ট, bytecode আর ইন্টারপ্রেটার কীভাবে একসঙ্গে কাজ করে, তা এখন জানো। এবার Python সেটআপ করে ইন্টারপ্রেটার চালিয়ে দেখো।
