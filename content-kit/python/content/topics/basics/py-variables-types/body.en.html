Attach a name to a value

When you label a folder “Lab marks”, the label helps you find its contents. A Python name plays a similar role. You can call a value student_count instead of repeating the number wherever you need it.

A variable is a name that refers to a value. Python represents values as objects. An object is a value with a type and an identity. You can begin using names without knowing how Python stores every object internally.

Names make a calculation readable and allow later input to supply its values. The number 40 alone does not tell a reader whether it means students, taka or a pass threshold. A suitable name records that meaning.

Assignment and meaningful names

student_count = 40
course_title = "Python"
student_count = student_count + 1

The equals sign performs assignment. Python evaluates the expression on its right and binds the name on its left to the result. The last line reads the old count, adds one and rebinds the name. It is an instruction, not an algebraic equation.

A name can contain letters, digits and underscores, but cannot begin with a digit. Python supports Unicode identifiers, although ordinary English letters keep these examples easier to share. Keywords such as if cannot serve as variable names. Uppercase and lowercase letters remain distinct.

Use snake_case: lowercase words separated by underscores. Prefer total_marks over a vague name such as x when the value has a clear purpose. Avoid naming a variable print, input or str, since that hides a useful built-in name in the current scope.

You may assign two names at once with first, second = second, first. Python evaluates the right-hand values before rebinding the left-hand names. This supports swapping without a temporary name. The commas group values; tuples are taught fully in Tuples.

Types belong to values

Dynamic typing means a name is not fixed to a declared type. The same name can first refer to an integer and later to text. The objects still have definite types, and operations must make sense for those types. Python will not allow every possible combination merely because assignment is flexible.

Use int for a number of students and str for a roll label whose leading zeros matter. Use float for measurements where approximation is acceptable. Booleans represent decisions, and their names True and False begin with capitals. None has its own type and is not the string "None".

The built-in function type reports an object's type. The expression type(value).__name__ gives a readable type name for these demonstrations. The dotted part retrieves a named attribute, a piece of information attached to an object. You will meet attributes in more detail with classes.

The function id returns an identity number for an object. That number stays stable during the object's lifetime and differs from those of other live objects. Its actual digits are not portable information. A later object may reuse an identity after the earlier one no longer exists.

After alias is rebound:
course ---------> "Python lab"
alias ----------> "Math lab"

Rebinding changes which object a name refers to. It does not automatically modify another name that referred to the old object. This distinction becomes especially important with mutable containers later; strings and numbers in this lesson cannot be edited in place.

If you know C

You do not write int before a Python variable name. Think of a name as a reference to a typed object. Rebinding the name is different from changing the contents of a fixed C storage location. id is not a portable pointer-arithmetic tool.

Choose meaning before spelling

Using the same word with different case

Student_count and student_count are separate names. A change in case can therefore cause a NameError or use the wrong existing value. Consistent snake_case prevents that confusion.

Confusing absence with zero

A zero mark is a valid recorded result. None can represent a result not yet recorded. Keep those meanings separate so a later report does not count missing work as a real zero.

Expecting identity to mean equal contents

Two objects may hold equal values without being the same object. Ordinary value comparisons use equality. Operators explains equality and identity together, including why small-number identity experiments can mislead you.

Stable beginner type rules

These binding and type rules apply throughout Python 3.10 and later. Exact identity numbers depend on the implementation and the run. Do not record particular id values as facts about a value.

Names carry meaning through a program

Assignment connects names to typed values, and rebinding can change that connection. Choose names that describe the data and types that preserve its meaning. Continue with Numbers and Arithmetic to calculate with numeric values.
