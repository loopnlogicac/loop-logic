Decide what kind of answer you need

If 23 students travel in groups of seven, you need three full groups and two students left over. A decimal quotient alone does not answer that question. Python gives you several arithmetic operators because different problems need different kinds of result.

Use whole-number arithmetic for counts and exact whole units. Use floating-point arithmetic for approximate measurements. Before choosing an operator, ask whether your answer should be a count, a remainder, a power or a fractional quantity.

You learned int and float in Variables and Data Types. Here you will see why their differences matter during calculation. A value that looks correct when printed with two decimals may still be stored approximately.

Parentheses group an expression explicitly. Powers generally come before multiplication and division, which come before addition and subtraction. Operators at the multiplication level normally group from left to right. Powers group from right to left, so 2 ** 3 ** 2 means two raised to the ninth power.

A leading minus has a subtle relationship with powers. The expression -2 ** 2 means the negative of four. To square a negative base, write (-2) ** 2. Do not use ^ for powers: it is a different operator.

The short form total += amount updates an accumulator by adding amount. For the ordinary numeric values here, it has the same effect as calculating total plus amount and assigning the result back. Similar update forms exist for multiplication and subtraction.

Quotients, remainders and signs

Floor division rounds the mathematical quotient down towards negative infinity. For positive inputs this often looks like dropping the fractional part. For negative inputs, dropping that part towards zero would give the wrong Python result.

The quotient of -7 by 3 lies between -3 and -2. Its floor is -3. Python chooses a remainder of 2 so that the original number can be reconstructed. For a nonzero divisor b, the relation is a == (a // b) * b + (a % b).

A nonzero remainder has the divisor's sign. Division, floor division and remainder all reject a zero divisor with ZeroDivisionError. Check that zero cannot reach the operation, or later handle the error deliberately. Do not replace a forbidden zero with one without a rule from the problem.

If you know C

Python / gives a float even for two int operands. Python // rounds down; C integer division truncates towards zero. For negative operands, translate the intended rule rather than replacing one operator by another mechanically.

Import mathematical tools

A module is a named collection of tools. The statement import math makes the standard math module available, and a dot selects one tool. See Modules and Packages for the full import rules. isqrt returns an exact integer square root, sqrt returns a float, and ceil or floor chooses a directional whole-number boundary.

Round with a stated purpose

round can request a rounded value, but its default halfway rule is nearest even. Exactly represented 2.5 rounds to 2, while 3.5 rounds to 4. Decimal inputs such as 2.675 may already be approximate before rounding, so their visible behavior can surprise you.

For approximate comparisons, math.isclose accepts tolerances rather than requiring identical float values. Pick tolerances that make sense for the units and measurement scale. Near zero, an absolute tolerance may be necessary. A tolerance is part of the problem's meaning, not a universal magic constant.

For simple exact money tasks, store whole taka or integer poisha instead of approximate fractions of taka. More advanced decimal calculations have dedicated tools. Choose those tools when needed instead of assuming that formatting changes how addition works.

Keep the numeric model clear

Expecting // to truncate towards zero

Test a negative example before using floor division for signed data. If your algorithm requires another rounding rule, express it explicitly. A positive-only test cannot reveal this difference.

Using float for an exact large square root

Converting a huge integer to float can lose low digits or exceed its range. math.isqrt avoids that conversion for a nonnegative integer. Its result r satisfies r squared at most n and the next square greater than n.

Assuming unlimited integers mean unlimited work

A power with millions of digits still costs resources. Keep meaningful input bounds. In modern Python, conversion between huge integers and decimal strings can also have a safety limit, even though arithmetic itself has no fixed-width overflow.

Arithmetic across supported versions

These operators and math.isqrt are available on Python 3.10 and later. The examples run on Python 3.12. Floating-point representation depends on the implementation, so reason about approximation rather than assuming every decimal is exact.
