টেক্সটকে ক্রম হিসেবে দেখো

কোর্স কোডে অক্ষরের ক্রম আছে। প্রথম আর শেষ অক্ষরের জায়গা এক নয়। Python-এ সেই ক্রম পড়তে, অংশ নিতে আর নতুন টেক্সট বানাতে পারো। Unicode টেক্সট রাখার str মানকে বলে স্ট্রিং।

টেক্সটে অক্ষর, সংখ্যা, স্পেস আর যতিচিহ্ন থাকে। 0017 রোল হলে শুরুর শূন্য দরকার হতে পারে। সংখ্যায় বদলালে তা হারাবে। দেখতে সংখ্যা বলেই হিসাবের মান ধরে নেবে না; অর্থ আগে ভাবো।

Python স্ট্রিং Unicode code point-এর ক্রম। Code point হলো Unicode-এ নম্বর দেওয়া একটি টেক্সট একক। কয়েকটি code point মিলে একটিমাত্র দৃশ্যমান অক্ষর হতে পারে। বাংলা টেক্সট গুনতে বা অবস্থান ধরে পড়তে এটা মনে রাখতে হবে।

কোটেশন, escape আর টেক্সটের কাজ

Single আর double quote দুটো দিয়েই স্ট্রিং হয়। যেটিতে লেখা সহজ হয় সেটি নাও। double quote-এর ভেতরে apostrophe সরাসরি চলে। স্ট্রিং ঘেরা একই কোটেশন ভেতরে লাগলে escape করো, বা অন্য কোটেশন নাও।

দরকারি escape sequence
সোর্সে লেখাটেক্সটে অর্থ
\nনতুন লাইন
\tTab
\\একটি backslash
\"একটি double quote

Escape sequence-এ backslash দিয়ে বিশেষ অক্ষর বোঝানো হয়। তাই সোর্সের বানান আর দেখানো টেক্সটের দৈর্ঘ্য আলাদা হতে পারে। tab একটি অক্ষর, যদিও টার্মিনালে কয়েক কলাম জুড়ে দেখা যায়। triple quote-এ সরাসরি লাইন ভাঙা যায়, তবে ইনডেন্টেশনও টেক্সটে ঢুকতে পারে।

+ দিয়ে স্ট্রিং জোড়া দাও। অঋণাত্মক পূর্ণসংখ্যা দিয়ে গুণ করলে বারবার একই স্ট্রিং পাও। দুটোতেই নতুন স্ট্রিং হয়; আগের কোনো স্ট্রিংয়ের অক্ষর বদলায় না।

ইনডেক্স আর শেষ বাদ দেওয়া slice

একটি আইটেমের অবস্থান বোঝায় ইনডেক্স। প্রথম অক্ষরের ইনডেক্স শূন্য। দৈর্ঘ্য n হলে শেষ অঋণাত্মক ইনডেক্স n minus one। ঋণাত্মক ইনডেক্স শেষ থেকে গোনে: -1 শেষ অক্ষর, -2 তার আগেরটি।

টেক্সট:      P  Y  T  H  O  N
ইনডেক্স:     0  1  2  3  4  5
শেষ থেকে:  -6 -5 -4 -3 -2 -1

Slice দিয়ে start, stop আর চাইলে step ধরে অংশ নাও: text[start:stop:step]। start নেওয়া হয়, stop নেওয়া হয় না। সামনের দিকে গেলে start না দিলে শুরু, stop না দিলে শেষ পর্যন্ত।

PYTHON-এ 1:4 নিলে YTH আসে: ইনডেক্স 1, 2, 3। :2 দেয় PY, আর 2: দেয় THON। step দুই হলে এক অবস্থান পরপর নেয়। step -1 হলে উল্টো দিকে চলে; দুই সীমানা ফাঁকা রাখলে পুরো ক্রম উল্টায়।

একটি ইনডেক্স আর slice-এ সীমা পেরোনোর নিয়ম আলাদা। অবৈধ একক ইনডেক্সে IndexError হয়। slice-এর সীমানা টেক্সটের বাইরে হলে যতটুকু আছে ততটুকু নেওয়া হয়। তাই ফাঁকা slice এরর নয়। ফাঁকা স্ট্রিংয়ে কোনো বৈধ একক ইনডেক্স নেই।

টেক্সট পড়ো, অংশ নাও, রূপ বদলাও

বিশেষ অক্ষর দেখো

প্রথম প্রোগ্রামে স্ট্রিংয়ের ভেতর কোটেশন, tab আর newline আছে। newline-এর জন্য এক স্ট্রিং দুই লাইনে দেখা যায়। সোর্সে কিন্তু একটি print কলই আছে।

দরকারি অবস্থান পড়ো

ইনডেক্সের প্রোগ্রামে ছবির ছয় অক্ষরের শব্দ আছে। প্রথম আর শেষ অক্ষর দেখো, তারপর মাঝের slice আন্দাজ করো। শব্দ উল্টাতে হাতে লুপ ছাড়াই ঋণাত্মক step কাজে লাগে।

মেথড বদলানো মান ফেরত দেয়

মানের পরে ডট দিয়ে কল করা টুল হলো মেথড। strip দুই পাশের whitespace সরায়, upper বড় হাতের করে, replace মেলা টেক্সট বদলায়। পরে লাগলে ফেরত পাওয়া ফল রাখো। মূল অবজেক্ট একই থাকে।

Code point ভেবে গোনো

চতুর্থ উদাহরণের বাংলা শহরের নামে চারটি code point আছে। তার মানে চারটি আলাদা দৃশ্যমান অক্ষর নয়। দ্বিতীয় print-এ শেষের বাইরের ফাঁকা slice আছে, তাই ফাঁকা লাইন আসে। ফাঁকা ফলও ইচ্ছাকৃত স্ট্রিং হতে পারে।

বদলাতে নতুন স্ট্রিং বানাও

Immutability মানে অবজেক্টের মান একই জায়গায় বদলানো যায় না। str immutable। একই নামকে নতুন স্ট্রিং দেওয়া যায়, কিন্তু তার একটি অক্ষরের জায়গায় অ্যাসাইন করা যায় না।

দ্বিতীয় অক্ষর বদলাতে প্রথম অক্ষরের slice, নতুন অংশ আর ইনডেক্স দুই থেকে বাকি অংশ জুড়ে দাও। এতে নতুন মান তৈরি হয়। তারপর অ্যাসাইনমেন্টে নামটি সেই ফলের সঙ্গে যুক্ত হয়।

lower, upper, strip, replace আর startswith পরিচিত মেথড। শেষটি টেক্সট নির্দিষ্ট অংশ দিয়ে শুরু কি না জানায়। বানানের case ঠিক রাখো। কল করতে বন্ধনী লাগে। text.upper লিখলে মেথডটিকে পাও; বদলানো টেক্সট পেতে কল করতে হবে।

C জানা থাকলে

str বদলানো যায় এমন char array নয়। শেষের zero character নিজে সামলাতে হয় না। len code point গোনে, encoded byte নয়। C-এর character array-এর মতো text[0] বদলাতে পারবে না।

টেক্সটের সীমা আর চেহারা আলাদা

দৈর্ঘ্যকে শেষ ইনডেক্স ধরা

ছয় অক্ষর হলে ইনডেক্স ছয় তাদের পরে। শেষ অক্ষর থাকলে -1 বা দৈর্ঘ্য minus one নাও। ইনডেক্স নেওয়ার আগে ফাঁকা টেক্সট আলাদা সামলাও।

মেথড পুরোনো মান পাল্টাবে ভাবা

ফল না রেখে strip কল করলে পুরোনো স্ট্রিংয়ের স্পেস যায় না। ফেরত স্ট্রিং একটি নামে রাখো। এটা immutability-এর নিয়ম, শুধু strip-এর ব্যতিক্রম নয়।

শুধু len দিয়ে দৃশ্যমান অক্ষর গোনা

যুক্ত হওয়া চিহ্নেরও নিজস্ব code point থাকতে পারে। তাই বাংলা বা emoji-এর দৈর্ঘ্য আর দৃশ্যমান অক্ষরের সংখ্যা এক নাও হতে পারে। এই সাধারণ ইনডেক্স দিয়ে ব্যবহারকারীর দেখা অক্ষর সম্পাদনার সব কাজ হয় না।

খোঁজার সময় case ভুলে যাওয়া

CSE আর cse আলাদা টেক্সট। case উপেক্ষা করা দরকার হলে বুঝে এক রকম করো। মূল বানান পরিচয়ের অংশ হলে বদলাবে না।

Python 3-এর Unicode স্ট্রিং

সাপোর্ট করা ভার্সনে str Unicode টেক্সট রাখে। byte-এর ক্রম আলাদা টাইপ। উদাহরণ Python 3.12-এ চলে, টার্মিনালের কলামের প্রস্থের ওপর নির্ভর করে না।

মূল টেক্সট রেখে অংশ নাও

এখন অবস্থান আর slice নিতে, পরিচিত মেথড কল করতে আর নতুন মান কেন হয় বুঝতে পারো। code point-এর দৈর্ঘ্য আর চোখে দেখা প্রস্থ আলাদা রাখো। এবার ইনপুট আর আউটপুট-এ মানুষের টেক্সট পড়ে ফল দেখাও।
