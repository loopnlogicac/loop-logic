Treat text as a sequence

A course code has an order: the first character is different from the final one. Python lets you inspect that order, select part of it and build new text. A string is the str value used to represent Unicode text.

Text may contain letters, digits, spaces and punctuation. The label 0017 should often stay text because its leading zeros identify a roll. Arithmetic conversion would remove that formatting. Think about the meaning before deciding that every digit belongs in a number.

A Python string is a sequence of Unicode code points. A code point is a numbered text unit in Unicode. Several code points may combine into one visible character. This matters when counting Bangla text or moving through it by position.

Quotes, escapes and text operations

Single and double quotes both delimit strings. Choose whichever makes the text easier to write. An apostrophe can sit naturally inside double quotes. To include the same quote that delimits the string, escape it or choose the other delimiter.

An escape sequence uses a backslash to describe a special character. The source spelling and displayed text can therefore have different lengths. A tab is one character even though it can occupy several terminal columns. Triple-quoted strings can contain line breaks directly, but their indentation may also become part of the text.

Use + to concatenate, meaning join, strings. Use multiplication by a nonnegative integer to repeat a string. These operations produce new strings. They do not edit characters in either original operand.

Indexes and half-open slices

An index selects one sequence item. The first character has index zero. For text with length n, the final nonnegative index is n minus one. Negative indexes count backwards: -1 selects the last character, -2 the one before it.

Text:        P  Y  T  H  O  N
Index:       0  1  2  3  4  5
From end:   -6 -5 -4 -3 -2 -1

A slice selects a range using start, stop and an optional step. The form is text[start:stop:step]. The start is included and the stop is excluded. With a forward step, omitting start means the beginning and omitting stop means the end.

For PYTHON, the slice 1:4 selects YTH. It includes indexes 1, 2 and 3. The slice :2 selects PY, while 2: selects THON. A step of two skips alternate positions. A step of negative one walks backwards; leaving both boundaries empty reverses the sequence.

Single indexing and slicing handle missing positions differently. An invalid single index raises IndexError. A slice boundary beyond the end is clipped to the available text. A slice can therefore be empty without being an error. Empty strings have no valid single-character index.

Methods return transformed values

A method is a tool called through a value using a dot. strip removes surrounding whitespace, upper changes case and replace substitutes matching text. Save the returned result if you need it later. The original object remains unchanged.

Build a new string to make a change

Immutability means an object's value cannot be changed in place. A str is immutable. Assigning a new string to the same name is allowed, but assigning into one character position is not.

To replace the second character, take the first-character slice, join the replacement, then join the suffix starting at index two. The expression builds a new value. Only after that does assignment bind your chosen name to the result.

Common methods include lower, upper, strip, replace and startswith. The last reports whether text begins with a specified prefix. Method names are case-sensitive, and parentheses perform the call. Writing text.upper without parentheses refers to the tool rather than the transformed text.

If you know C

A str is not a writable char array and has no terminating zero character for you to manage. len counts code points, not encoded bytes. You cannot change text[0] as you might change an element of a C character array.

Separate text boundaries from appearance

Using the length as a final index

If a string contains six characters, index six lies after them. Use -1 or length minus one when a final character exists. Handle empty text separately before indexing.

Expecting a method to edit the old value

Calling strip without saving its result does not remove spaces from an existing string. Assign the returned string to a name. This follows directly from immutability rather than being a special strip rule.

Counting visible letters with len alone

A combining mark can have its own code point. Bangla text and emoji can therefore have lengths that differ from their visual character counts. These basic indexing operations are not a full solution for editing user-perceived letters.

Forgetting that searches are case-sensitive

CSE and cse are different text. If a task calls for case-insensitive handling, normalise case deliberately. Do not change case when the original spelling is part of an identifier.
