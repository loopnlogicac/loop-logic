Prepare a place to run Python

An editor is like a notebook: it holds your instructions. An interpreter is like the person who follows them. You need a Python interpreter before a saved program can run. You also need to know which window is asking for which kind of instruction.

A terminal is a window for entering system commands. A REPL is Python's interactive conversation: read, evaluate, print and repeat. The terminal starts Python; the Python prompt then accepts Python code.

Use Python 3.12 for the examples here. A compatible supported Python 3 release can also be useful, but check which interpreter your editor selects. Having several installations is common and can explain confusing differences between two windows.

Install and identify the interpreter

On Windows, use an official Python installer or installation manager. Choose Python 3 and follow its instructions about command-line access. Older installer screens offer an option to add Python to PATH. PATH is the set of locations the terminal searches for commands.

On macOS, the official installer provides a separate Python 3 installation. Do not remove a Python installation used by the operating system. On Linux, use your distribution's package manager for Python 3 and, if needed, its pip and venv packages. Package names and permissions depend on the distribution.

Open a new terminal after installation so it receives updated settings. The executable may be called python3, python or selected through the Windows py launcher. Check before assuming that a short command points to the version you intended.

python3 --version
python3

On a Windows setup with the launcher, the corresponding commands may be py -3 --version and py -3. Use the command that selects your intended installation. Do not type a displayed shell prompt such as a dollar sign as part of the command.

Move from the prompt to a file

Start Python interactively and enter a small expression such as 2 + 3. The REPL shows its result. The >>> characters mark the prompt and are not part of your program. Use exit() to return to the terminal.

A script is a saved file of instructions. Create a folder for your learning work and save a plain-text file named lesson.py there. Confirm that the editor has not added .txt after .py. Saving a file and running a file are separate steps.

python3 lesson.py

Run that command from the folder containing the file, or provide its correct path. Python reads the saved contents, so save your edits before running again. A bare arithmetic expression in a script is not automatically displayed as it is in the REPL. Use print when you want to see a result.

In VS Code, install the Python extension if needed, then select the interpreter you installed. Open a folder, create the script and use the editor's run action or its terminal. If the editor and terminal behave differently, compare their interpreter selections first.

Notebooks and package installation

Jupyter presents work as cells in a notebook. A kernel is the process that executes those cells. The browser displays the notebook, while the selected kernel determines which Python and packages run. Notebook support can be installed separately or supplied by a teaching environment.

Notebook cells remember previous results. Running a lower cell before an upper one can fail or use an older value. Restart the kernel and run cells in order when checking whether a notebook is reproducible. Saved visible results do not prove that the current cell order works.

pip installs additional Python packages. Prefer python3 -m pip so pip belongs to the interpreter you chose; on Windows the launcher form can be py -3 -m pip. Most examples here need only the standard library, which comes with Python. Later, Modules, Packages and pip explains project environments that keep dependencies separate. Respect an operating system's managed-environment warning rather than forcing changes to its Python.

If you know C

There is usually no separate compile command before each Python run. The interpreter performs its own translation steps. Your editor still does not execute the text by itself; its run button starts an interpreter for you.

Fix the location before the program

Entering a terminal command at the Python prompt

A command such as python3 lesson.py is not a Python statement. If you see >>>, leave the REPL first. Then enter the command in the system terminal.

Running a different file

Two folders can contain files with the same name. Check the working directory and the path passed to Python. Add a temporary distinctive message if you need to confirm which file is running.

Installing into another interpreter

A package installed for one environment may be absent in another. Check the editor interpreter and notebook kernel. Repeating a pip command without checking its Python may repeat the same mistake.
