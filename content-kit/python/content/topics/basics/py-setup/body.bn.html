Python চালানোর জায়গা তৈরি করো

এডিটরকে খাতা ভাবতে পারো: সেখানে ইনস্ট্রাকশন লেখো। ইন্টারপ্রেটার সেগুলো অনুসরণ করে। সেভ করা প্রোগ্রাম চালাতে Python ইন্টারপ্রেটার লাগবে। কোন উইন্ডোতে কী লিখতে হয়, সেটাও জানতে হবে।

সিস্টেমের কমান্ড লেখার উইন্ডো হলো টার্মিনাল। Python-এর সঙ্গে সরাসরি কোড লিখে ফল দেখার ব্যবস্থা হলো REPL: read, evaluate, print, repeat। টার্মিনাল থেকে Python চালু করো; তারপর Python-এর প্রম্পটে Python কোড লেখো।

এখানকার উদাহরণে Python 3.12 নাও। কোড চলে এমন অন্য সাপোর্ট পাওয়া Python 3 রিলিজও কাজে আসতে পারে। এডিটর কোন ইন্টারপ্রেটার নিচ্ছে দেখো। একাধিক ইনস্টল থাকলে দুই উইন্ডোতে আলাদা ফল পাওয়ার কারণ সেটাও হতে পারে।

ইনস্টল করে ইন্টারপ্রেটার চিনে নাও

Windows-এ অফিসিয়াল Python installer বা installation manager ব্যবহার করো। Python 3 বেছে কমান্ড লাইন থেকে চালানোর ধাপগুলো অনুসরণ করো। পুরোনো installer-এ PATH-এ Python যোগ করার অপশন থাকে। টার্মিনাল কমান্ড খুঁজতে যেসব জায়গায় দেখে, তাদের তালিকা হলো PATH।

macOS-এর অফিসিয়াল installer আলাদা Python 3 ইনস্টল করে। অপারেটিং সিস্টেমের ব্যবহৃত Python সরাবে না। Linux-এ ডিস্ট্রিবিউশনের প্যাকেজ ম্যানেজার দিয়ে Python 3 এবং দরকার হলে pip ও venv নাও। প্যাকেজের নাম আর অনুমতির নিয়ম ডিস্ট্রিবিউশন অনুযায়ী বদলায়।

ইনস্টলের পর নতুন টার্মিনাল খোলো, যেন নতুন সেটিং পায়। কমান্ডের নাম python3 বা python হতে পারে; Windows-এ py launcher-ও থাকতে পারে। ছোট কমান্ডটি ঠিক কোন ভার্সন চালায়, আগে দেখো।

প্রম্পট থেকে ফাইলে যাও

ইন্টারঅ্যাকটিভ Python চালিয়ে 2 + 3 লিখে দেখো। REPL ফল দেখায়। >>> হলো প্রম্পট, কোডের অংশ নয়। টার্মিনালে ফিরতে exit() দাও।

ইনস্ট্রাকশন সেভ করে রাখা ফাইল হলো স্ক্রিপ্ট। শেখার কাজের জন্য ফোল্ডার বানিয়ে সেখানে lesson.py নামে plain-text ফাইল রাখো। এডিটর যেন .py-এর পরে .txt না যোগ করে। ফাইল সেভ করা আর চালানো আলাদা ধাপ।

ফাইলের ফোল্ডার থেকে কমান্ড দাও, অথবা সঠিক path দাও। Python সেভ করা লেখা পড়ে, তাই বদলানোর পর আবার সেভ করো। স্ক্রিপ্টে শুধু অঙ্ক লিখলে REPL-এর মতো ফল দেখায় না। ফল দেখতে print ব্যবহার করো।

VS Code-এ দরকার হলে Python extension ইনস্টল করে তোমার ইন্টারপ্রেটার বেছে নাও। ফোল্ডার খুলে স্ক্রিপ্ট বানাও, তারপর run বা টার্মিনাল ব্যবহার করো। এডিটর আর টার্মিনালে আচরণ আলাদা হলে আগে কোন ইন্টারপ্রেটার চলছে মেলাও।

একটি সংখ্যার পরে লেবেল

পরের স্ক্রিপ্ট গুণ করে, তারপর একটি শব্দ দেখায়। প্রথম লাইনে 60, দ্বিতীয় লাইনে taka। হিসাব আর সরাসরি লেখা টেক্সটের পার্থক্য বোঝো।

কোন Python চলছে দেখো

sys হলো ইন্টারপ্রেটারের তথ্যের বিল্ট-ইন মডিউল। import লাইন দিয়ে সেটি নামে ব্যবহার করা যায়। পরে মডিউল আর প্যাকেজ পড়বে। এখানে ইনস্টল ফোল্ডার বা অপারেটিং সিস্টেমের নামের ওপর নির্ভর না করে ভার্সনের একটি বৈশিষ্ট্য দেখা হয়েছে।

নোটবুক আর প্যাকেজ ইনস্টল

Jupyter-এ নোটবুকের সেল ধরে কাজ করো। সেল চালায় যে প্রসেস, সেটি kernel। ব্রাউজার নোটবুক দেখায়; কোন Python আর প্যাকেজ চলবে তা ঠিক করে kernel। নোটবুকের ব্যবস্থা আলাদা করে ইনস্টল করা বা শেখার পরিবেশে দেওয়া থাকতে পারে।

নোটবুক আগের ফল মনে রাখে। ওপরের সেলের আগে নিচের সেল চালালে এরর বা পুরোনো মান আসতে পারে। কাজ আবার একইভাবে হয় কি না দেখতে kernel restart করে ক্রমানুসারে সেল চালাও। সেভ করা ফল দেখেই বর্তমান ক্রম ঠিক ধরে নেবে না।

বাড়তি প্যাকেজ ইনস্টল করে pip। python3 -m pip ব্যবহার করলে নির্বাচিত Python-এর pip চলে। Windows-এ py -3 -m pip হতে পারে। এখানকার বেশির ভাগ উদাহরণে Python-এর সঙ্গে আসা standard library যথেষ্ট। পরে মডিউল, প্যাকেজ আর pip-এ আলাদা প্রজেক্ট পরিবেশ শিখবে। অপারেটিং সিস্টেম managed-environment warning দিলে তার নিয়ম মেনে চলো; জোর করে সিস্টেমের Python বদলাবে না।

python3 lesson.py কোনো Python স্টেটমেন্ট নয়। >>> দেখলে আগে REPL থেকে বের হও। তারপর সিস্টেম টার্মিনালে কমান্ড দাও।

অন্য ফাইল চালানো

দুই ফোল্ডারে একই নামের ফাইল থাকতে পারে। কাজের ফোল্ডার আর Python-কে দেওয়া path দেখো। কোন ফাইল চলছে বুঝতে অস্থায়ী আলাদা মেসেজ যোগ করতে পারো।

অন্য ইন্টারপ্রেটারে প্যাকেজ ইনস্টল

এক পরিবেশের প্যাকেজ অন্যটিতে নাও থাকতে পারে। এডিটরের ইন্টারপ্রেটার আর নোটবুকের kernel দেখো। কোন Python-এর pip তা না দেখে কমান্ড বারবার দিলে একই ভুল হবে।

ভার্সন দেখে নাও

Installer-এর চেহারা বদলালেও ইন্টারপ্রেটারের ভার্সন দেখা কাজে লাগে। এই কোড Python 3.10 বা পরের ভার্সনে চলে। পাঠের নির্দিষ্ট পরিবেশ অনুসরণ করলে 3.12 নাও।

নির্ভরযোগ্য প্রথম রান

এখন টার্মিনাল, REPL, সেভ করা স্ক্রিপ্ট আর নোটবুক kernel আলাদা করতে পারো। শেখার সময় একটি পরিচিত ইন্টারপ্রেটার বেছে রাখো। স্ক্রিপ্টের ভেতরের কোড বুঝতে তোমার প্রথম Python প্রোগ্রাম পড়ো।
