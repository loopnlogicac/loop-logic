ছোট উত্তরও নির্ভুল হোক

Interview-তে উত্তর অন্যকে behavior predict করতে সাহায্য করবে। নিয়ম, ছোট example, useful limit বলো। নিচের পঞ্চাশ প্রশ্ন অবজেক্ট, collection, ফাংশন, iteration আর design নিয়ে। Worked answer শুরুর ব্যাখ্যা, মুখস্থ script নয়।

পড়ার আগে নিজের ভাষায় বলো। Absolute claim হলে শর্ত খোঁজো। Dictionary insertion order Python নিশ্চয়তা, reference counting সাধারণ CPython behavior। পার্থক্য জানলে আত্মবিশ্বাসী উত্তরও ভুল হবে না।

প্রশ্ন 1–20: কী shared বোঝাও

প্রথম দশে name, identity, copy, hash, lifetime। Mutation-এ reference আঁকো। Tuple-এ mutable list থাকে, immutable outer মানে deep নয়। Shallow copy নতুন container, nested reference একই।

এগারো-বিশে collection choice। List order-duplicate, set unique hashable value, dictionary unique key-value রাখে। Expected lookup সাহায্য করে, construction-মেমরি-ও ধরো।

dict.fromkeys idiom-এ hashability বলো। zip-এ default shortest-ইনপুট আর strict আলাদা। দরকারি assumption দিলে ছোট উত্তর বেশি কাজে লাগে।

প্রশ্ন 21–40: সংজ্ঞা আর কল

এবার scope,argument,closure,decoration। মান কখন evaluate: definition,call নাকি iteration? Timeline-এ shared default আর লুপ-এর পরে binding দেখা closure বোঝা যায়।

Iterable-iterator, generator definition আর advancement আলাদা। ফাংশন কল suspended অবজেক্ট, consume state বদলায়। দ্বিতীয় list conversion consumed মান ফেরায় না।

Design-এ duck typing,composition,dataclass। অদরকারি hierarchy নয়, ছোট behavior contract। Generated initializer কাজ বাঁচায়, সব validation নয়। Frozen field referenced অবজেক্ট recursively freeze করে না।

প্রশ্ন 41–50: চলার শর্ত বলো

শেষ দশে exception,ফাইল,annotation,টেস্ট,concurrency,ডেটা tool। Handler কোন failure আশা করে, cleanup কী নিশ্চিত আর কী নয় বলো। Successful parse valid record-এর এক ধাপ।

Concurrency-তে implementation-build বলো। সাধারণ GIL-enabled CPython thread অপেক্ষাবেশি কাজে সাহায্য করে, Python bytecode একইসঙ্গে চলা সীমিত। Extension আর optional free-threaded build বদলায়। এক detail সব Python-এর rule নয়।

Library-র আগে কাজ: numerical অ্যারে, labeled table নাকি figure। পরিচিত dependency মানেই সঠিক নয়। কী capability চাই বলো; standard library পরিষ্কার হলে সেটি রাখো।

দেখানো example-এ উত্তর সমর্থন

পনেরো quiz-এ পাঁচ runnable trace। আগে predict, পরে চালিয়ে tempting ভুল কেন বলো। list.sort-sorted গুলালে return দুটো দেখাও। Shallow-deep গুলালে nested list mutate।

বড় practice-এ সঙ্গীকে প্রতি উত্তরে এক শর্ত বদলাতে বলো। Unhashable,empty বা exhausted generator হলে? মুখস্থ বাক্যের বাইরে contract বোঝা যাচাই।

Intro track শেষ। Expense tracker-এ ফিরে money representation, validation আর save order মুখে বোঝাও। চলা example ছোট উত্তরকে বাস্তব ভিত্তি দেয়।
