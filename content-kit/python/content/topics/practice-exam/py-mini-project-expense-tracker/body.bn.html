Persistent state-এর ছোট tool

কোথায় টাকা গেল? Expense tracker-এ menu CLI দিয়ে expense add, category summary আর CSV export। JSON পরের run-এ রাখে। এক user-এর ছোট local learning project।

বড় class hierarchy নয়, function-dictionary। Parsing, validation, storage, aggregation, interaction আলাদা দায়। Menu ছাড়া হিসাব, সব command না টাইপ করেও file handling check সহজ।

ছোট দরকারি record

ঠিক দুই field: category আর paisa। Category strip-casefold-এ normalize, Food-food এক group। পরে এক থেকে চল্লিশ printable character। Space-comma চলে, তাই CSV quoting দরকার।

paisa positive integer 1..1000000000, প্রতি expense দশ million BDT সীমা। Smallest unit রাখায় যোগে decimal approximation নেই। Display integer division আর দুই-digit remainder-এ 1050 paisa-কে 10.50 করে।

Amount text digit, optional এক/দুই decimal। 10,10.5,10.50 এক amount। Negative,zero,scientific notation,nonfinite word,fractional paisa reject। Refund ইচ্ছা করে নেই, চাইলে contract বদল।

Command আর হিসাব আলাদা

চার choice: add,summary,export,quit। Add category-amount validate। Summary paisa group করে sorted category। Export JSON-এর পাশে expenses.csv-তে category আর amount_bdt।

Unknown choice message দিয়ে menu আবার। অসমাপ্ত add-সহ EOF clean exit। পুরো valid record না হলে storage নয়। Expected input-file error ধরে, programming bug দৃশ্যমান।

Default current folder-এর expenses.json। --path-এ অন্যটি, যেমন পূর্ণ program tracker.py হলে python tracker.py --path records.json। Parent folder আগেই চাই। Export fixed sibling expenses.csv বদলায়, তাই dedicated project folder।

Total থেকে পুরো interface

Exact paisa summary

দশ টাকা পঞ্চাশ আর উনিশ টাকা পঁচাত্তর মিলে 30.25 BDT। Integer-এ প্রতি paisa থাকে।

JSON round-trip আর CSV category quote

JSON integer paisa রাখে। CSV comma-সহ category quote করে, ফিরে এক field।

পুরো menu, প্রতি add persist

Food-travel যোগ, summary, CSV export, quit। Default file current folder-এ।

Saved list বদলানোর আগে validate

Startup missing file আর unreadable-invalid আলাদা। Missing empty list। Invalid existing-এ failure print করে stop, তদন্তে bytes থাকে। Corrupt-কে নীরবে empty করলে problem লুকায়, record হারায়।

JSON decode শুধু syntax। validate_records top-level list, item dictionary, exact দুই key দেখে। Category normalization আর exact integer paisa bound-ও।

bool int-এর subclass, isinstance(True,int) true। Stored true এক-paisa নয়। type(paisa) is int precise contract দেয়। Domain-specific exact-check কারণ; সাধারণ interface-এ compatible behavior নেওয়াই ভালো।

Add-এ candidate = records + [new_record], live-এ আগে append নয়। save_records সফল ফেরার পরে records candidate-এ bind। Failed save-এ পুরোনো list summary চালায়।

save_records destination folder-এই temporary তৈরি। Write-close শেষে replace। পাশে রাখায় সাধারণত cross-filesystem move এড়ায়। Replace না হলে finally leftover সরায়।

Partial rewritten destination-এর risk কমায়। Concurrent writer coordination বা power-loss survival নিশ্চিত নয়। fsync/transaction নেই। দরকার হলে database আর শক্ত design।

Field বোঝে এমন parser-writer

JSON authoritative state, CSV spreadsheet/report export। Line split বা extension পাল্টে interchangeable নয়। প্রতিটির নিজস্ব parser-quote।

csv.writer food, campus পুরো field quote করে। newline="" module-কে ending দেয়, UTF-8 text রাখে। amount_bdt reader-এর formatted string, JSON-এ exact paisa।

Empty tracker header export পারে। Export failure file-message দেয়, JSON বদলায় না। Direct write বলে partial CSV হতে পারে। আবার export চলে, authoritative state বদলায় না।

আলাদা run-এ transition

Empty folder-এ summary No expenses, Total 0.00। Food 10.50 আর 19.75 যোগ, total 30.25; quit-restart-এও।

1.001,zero,negative reject, record নয়। Empty category আলাদা, amount চাওয়ার আগেই reject। Comma category export csv.reader-এ পড়ে boundary মিলাও।

Corruption পরীক্ষা আগে disposable folder-এ JSON copy। List-এর বদলে object, missing key বা true amount-এ startup error আর file preserved। Controlled replace failure-এ Added কখনো যেন না আসে।

সফল command-এর অর্থ রাখো

Persistence-এর আগে success

Write fail হলেও stored promise হয়। save_records সফল হলেই new list আর success।

Decimal text float-এ নেওয়া

Binary float paisa conversion-এর আগে approximate। Decimal-এ parse, সর্বোচ্চ দুই decimal enforce করে integer।

Broad handler-এ storage reset

Read failure empty history চাওয়ার প্রমাণ নয়। File রেখে issue বলো। শুধু FileNotFoundError empty start।
