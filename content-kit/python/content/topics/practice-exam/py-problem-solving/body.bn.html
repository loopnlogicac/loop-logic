গল্প থেকে নির্দিষ্ট হিসাব

Contest-এ ticket, mark, booking-এর গল্প আসে। আগে ডেটা, allowed operation আর required answer চেনো। এই বিশটি মৌলিক সমস্যা arithmetic থেকে reusable scan-এ যায়, নির্দিষ্ট judge-এ নির্ভর নয়।

প্রথম আট runnable example, নয়-ষোলো solution পড়ার আগে চেষ্টা। সতেরো-বিশ exam answer-এ পুরো program। প্রতিটিতে explicit input contract, valid input ধরে solution কাজটিতে মন দেয়।

Whitespace token নাকি পুরো line

sys.stdin.buffer.read().split() সব byte পড়ে whitespace token করে। int numeric byte সরাসরি নেয়। Arbitrary line-এ input হলে সুবিধা, তবে input-token memory-তে, size ভাবো।

tokens = iter(map(int, sys.stdin.buffer.read().split()))
count = next(tokens)
values = [next(tokens) for _ in range(count)]

Line-shaped input-এ readline grouping রাখে। Blank line আর EOF আলাদা, যদিও strip line ending সরায়। Field-এর space অর্থপূর্ণ হলে split নয়। Text-byte বুঝে নাও, মিশিয়ে compare নয়।

Print বা answer line join করে stdout.write। Output format correctness-এর অংশ। এখানে শুধু requested answer; extra prompt contract বদলায়। Expense project পরে আলাদা interactive interface।

Pattern বেছে state-এর কারণ

ছোট হাতে হিসাব দিয়ে শুরু। ধাপ-পেরিয়ে কী থাকবে? Total accumulator, earlier value set, unmatched opening stack। State নাম দিলে ছোট solution বোঝা যায়।

Invariant loop-এ সত্য থাকা কথা। Repeated scan-এ seen ঠিক আগের মান, attendance-এ current এই character-এ শেষ run। Syntax নয়, update কেন বৈধ বোঝায়।

Bound-এ খরচ দেখো। 100000-এ quadratic সাধারণত নয়। Sort O(n log n), পরের two-pointer O(n)। Python int fixed overflow এড়ালেও বিরাট সংখ্যা representation-মাফিক সময়-মেমরি নেয়।

C জানা থাকলে

বড় int আর ready collection থাকলেও algorithm cost জরুরি। Comprehension quadratic-কে linear করে না। Buffered input parsing overhead কমায়, pair comparison count নয়।

সমস্যা 1–8: arithmetic, scan, boundary

1. Signed adjustment যোগ

n (0–100000), তারপর ঠিক n integer -1000000..1000000। Sum প্রিন্ট। Whitespace কয়েক line হতে পারে।

যোগের identity zero। Empty sum চলে, negative-এ extra branch নয়। O(n) সময়, O(n) মেমরি।

2. Shuttle fare ভাগ

Passenger n (0–1000000000), positive capacity k (1–1000000000)। Minimum shuttle count দাও।

Integer ceiling division-এ ভাগের আগে capacity minus one যোগ। Partial group-এও shuttle, zero people-এ none। O(1) arithmetic operation।

3. Duration ভাগ

Nonnegative second s সর্বোচ্চ 1000000000। Hour, remaining minute-second তিন space-separated integer।

divmod quotient-remainder দেয়। প্রতিবার original নয়, remainder convert। O(1) arithmetic।

4. তিন stick যাচাই

-1000000..1000000 তিন integer। Nondegenerate triangle side হলে VALID, নইলে INVALID।

Positive side sort করে ছোট দুটির sum বড়টির চেয়ে বড় চাই। Equal মানে flat। O(1) সময়-মেমরি।

5. লম্বা receipt code-এর digit sum

Nonempty decimal digit string, length সর্বোচ্চ 100000। Digit sum, leading zero চলে।

Identifier text-এ length-zero থাকে। Huge integer না করে character loop। O(d) সময়, O(d) মেমরি।

6. সবচেয়ে বড় equal packet

Nonnegative a,b সর্বোচ্চ 1000000000। GCD, 0 আর 0-তে 0 সংজ্ঞা।

a,b-কে b,remainder করলে common divisor থাকে। দ্বিতীয়টি zero পর্যন্ত কমে। O(log(max(a,b)+1)) division step।

7. Prime roll candidate

n 0–1000000000। Prime হলে PRIME, নইলে NOT PRIME।

Composite-এর factor square root-এর বেশি না এমন একটি থাকে। Inclusive bound 49 ধরে। O(sqrt(n)) সময়, extra O(1)।

8. Mirror token

Nonempty lowercase ASCII token সর্বোচ্চ 100000। উল্টো পড়ে এক হলে YES, নইলে NO।

Reverse slice সহজ। Memory জরুরি হলে ভেতরে আসা দুই index reverse string বাঁচায়। দেখানো O(n) সময়, extra O(n)।

সমস্যা 9–16: collection আর efficient search

9. সবচেয়ে frequent score

n (1–100000), তারপর n integer 0–100। Most frequent score আর count। Tie-তে ছোট score।

Counter frequency রাখে। Tuple আগে বড় count, পরে ছোট value, insertion order নয়। O(n) সময়, O(n) input memory। পুরো solution p-1।

10. Distinct badge number

n (0–100000), n integer 0–1000000000। Increasing distinct মান space-এ, n zero হলে EMPTY।

Set duplicate বাদ, sort display promise দেয়। Set iteration একা increasing নয়। u distinct-এ O(n + u log u) সময়, O(n) মেমরি। Solution p-2।

11. প্রথম repeated scanner মান

n (0–100000), n integer 0–1000000000। বাম থেকে scan-এ যার দ্বিতীয় appearance আগে, সেটি; না হলে NONE।

প্রতি iteration-এর আগে seen ঠিক আগের মান। Membership repetition বলে। Expected O(n) সময়, O(n) মেমরি। Solution p-3।

12. Attendance streak

এক line-এ binary string length 0–100000। Longest contiguous 1-run, empty line-এ 0।

current এখানে শেষ run, best সব prefix-এর সেরা। Zero current reset, আগের best নয়। O(n) সময়-input memory। Solution p-4।

13. Repeated inclusive range total

n,q দুটো 1–100000, n integer absolute সর্বোচ্চ 1000000, q pair l r যেখানে 1 ≤ l ≤ r ≤ n। প্রতি line inclusive sum।

prefix[k] প্রথম k যোগ। r পর্যন্ত থেকে l-এর আগের prefix বাদ। Rescan বাঁচে। O(n+q) সময়-মেমরি। Solution p-5।

14. Target মোটের দুই আলাদা ticket

n (0–100000), target -2000000000..2000000000, n integer -1000000000..1000000000। দুই distinct position sum target হলে YES, নইলে NO।

Sort। Smallest+largest ছোট হলে smallest আর কারও সঙ্গে হবে না, এগোও; বেশি হলে উল্টো যুক্তি। O(n log n) সময়, O(n) মেমরি। Solution p-6।

15. ছোঁয়া booking interval merge

n (0–100000), n closed l r, 0 ≤ l ≤ r ≤ 1000000000। Overlap বা touching merge। Count, তারপর increasing merged l r প্রতি line।

Sort-এ start বাড়ে, শুধু last merged পরেরটির সঙ্গে overlap করতে পারে। Touching মানে equal endpoint, adjacent integer নয়। O(n log n) সময়, O(n) মেমরি। Solution p-7।

16. Round-square bracket nesting

শুধু ()[]-এর এক line, length 0–100000। ঠিক nested হলে YES, নইলে NO। Empty valid।

Stack unmatched opening রাখে। Closing সর্বশেষটির সঙ্গে মিলবে। শুধু count crossed nesting ধরবে না। O(n) সময়-মেমরি। Solution p-8।

সমস্যা 17–20: count, optimize, locate

17. Factorial-এর trailing zero

n 0–1000000000। n factorial-এর শেষে decimal zero count। Zero factorial one। পুরো solution exam question 1।

প্রতি zero-তে factor ten। Two যথেষ্ট, তাই five গুনো, 25,125 ও পরের power-এর extra-সহ। Input '25' দেয় '6', '0' দেয় '0', '5' দেয় '1'।

18. সেরা nonempty earning segment

n (1–100000), n signed integer absolute সর্বোচ্চ 1000000। Nonempty contiguous segment-এর greatest sum। Solution exam question 2।

ending এখানে শেষ best nonempty segment। আগেরটি extend বা এখান থেকে restart। All-negative রাখতে আসল entry দিয়ে শুরু। '5\n-2 4 -1 3 -5' দেয় '6', '3\n-8 -2 -5' দেয় '-2'।

19. প্রথম eligible sorted value

n (0–100000), target, n nondecreasing signed integer; সব absolute সর্বোচ্চ 1000000000। অন্তত target এমন প্রথম zero-based position, নেই হলে n। Solution exam question 3।

bisect_left ছোট আর eligible-এর boundary। Length-সমানও হতে পারে, index-এর আগে check। '5 4\n1 4 4 8 9' দেয় '1', '0 7' দেয় '0', '2 9\n1 2' দেয় '2'।

20. ছোট grid-এ route count

Row-column 1–30। Top-left থেকে শুধু right/down, bottom-right-এর route count। এক cell-এ এক route। Solution exam question 4।

Inner cell ওপর-বাম থেকে route পায়। Column update-এর আগে মান previous row-এর, বাম neighbor current row-এর। '3 3' দেয় '6', '1 1' আর '1 4' দেয় '1'।

তোমার শর্তকে আঘাত করে এমন case

Empty answer-কে zero

Zero valid sum-score। Missing repeat-এ specified NONE। বিশেষ করে allowed range-এ zero থাকলে absence আলাদা।

এক index দুইবার

Two-ticket-এ দুই position। এক three target six করে না, আলাদা দুই three পারে। Value-এর সঙ্গে index ভাবো।

Task পড়ার আগেই order হারানো

Set distinct গোনে, streak বা first repeat-এর sequence হারায়। Sort position বদলায়। তথ্য হারানো অনুমতি থাকলেই নাও।
