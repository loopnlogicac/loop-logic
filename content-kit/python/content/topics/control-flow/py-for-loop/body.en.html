Take the next item rather than manage every step

When reading a short course code aloud, you take its characters in order. You do not need to keep asking which numeric position comes next. Python for loops let you process values in that direct way.

An iterable is an object that can supply items one at a time. Strings supply characters, ranges supply integers and many containers supply their stored values. A for loop asks for each next item and runs its body with that item.

Use while when a condition controls ongoing work. Use for when an iterable already describes the values to visit. Counted repetition is a special case where range supplies the numbers for you.

Loop over values or a range

for item in sequence:
    process_item

for number in range(start, stop, step):
    process_number

The body descriptions above stand for your statements. The loop binds the target name to each supplied value. You do not initialise that target before a nonempty for loop. When the iterable is empty, no assignment by the loop takes place.

The range constructor accepts a stop alone, a start and stop, or all three values. Its default start is zero and default step is one. The stop is always excluded. For an inclusive positive upper endpoint n, a common choice is stop n plus one.

A negative step moves towards smaller values. The start must therefore be above the excluded stop for a nonempty descending range. A zero step raises ValueError. It is not a shortcut for an open-ended repetition.

The iterable controls the next value

For a string CSE, the loop first binds letter to C, then S, then E. After the final item, iteration finishes. The loop machinery handles the request for another item, so you do not manually update a character index.

Assigning a different value to the target inside the body does not change the iterable's next supplied item. Avoid treating it as a C-style counter update. If you need a different sequence of numbers, express that sequence in range or choose while for condition-driven updates.

A range represents its arithmetic sequence compactly. It does not create a stored list of every integer merely to loop over them. Visiting a billion values still takes a billion iterations, though the range object itself stays small. Representation cost and execution time are different questions.

Keep an index beside the item

The function enumerate supplies an index-value pair. The two target names unpack that pair on each iteration. start=1 changes the numbering for display, while the first supplied character remains L. Use this when position is part of the result.

Pair corresponding values

The function zip combines iterables into corresponding pairs. The example uses tuples, fixed groups of values; Tuples explains them fully. The course group has three items but the marks group has two, so normal zip supplies two pairs.

Report that a search finished

The search scans a word for Z and would break on a match. No character matches, so the loop reaches exhaustion and runs else. The else is aligned with for, rather than with the if inside its body.

Know when information is discarded

Normal zip stops at its shortest input. This can be useful, but it can also silently omit unmatched values. When equal lengths are required, Python 3.10 and later offers zip(first, second, strict=True). A mismatch then raises ValueError during iteration instead of disappearing unnoticed.

The loop else runs after the iterable is exhausted without break. It also runs for an empty iterable, since no early break occurred. In a search, this means you do not need a separate found flag solely to remember whether the search ended early.

break exits the nearest loop. continue skips the remaining body and asks for the next item. Because a for loop obtains that next item automatically, continue does not skip a manual range update as it might skip a while counter update.

When loops are nested, break affects only the innermost active loop. The outer loop can continue with its next item. Write out the two sequences on paper if you need to predict how many total body actions occur.

If you know C

Python for has no initializer-condition-update header. Use range for arithmetic counting, enumerate for positions and zip for paired streams. Direct value iteration often expresses the intention more clearly than translating an index loop line by line.

Choose the values before the body

Including the stop accidentally

range(1, 10) ends at nine. Write the desired first and last visited values, then choose the excluded stop. Check a zero-length and a one-item case when the boundary comes from input.

Counting down with a positive step

range(5, 0) is empty because its default step moves upwards. Use a negative step for a countdown. Python does not infer direction from the endpoints.

Using indexes where items are enough

A loop over range(len(text)) can work, but it makes you retrieve each character separately. Prefer direct iteration when the index has no purpose. Choose enumerate when both are needed.

Assuming a loop target always exists afterwards

A nonempty loop leaves its final target binding available, but an empty loop never creates that binding. Avoid depending on it for a result. Keep the result in a deliberately initialised accumulator instead.

Use strict pairing when required
