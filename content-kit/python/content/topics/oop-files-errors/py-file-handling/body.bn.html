প্রোগ্রাম শেষেও ডেটা রাখো

Process শেষ হলে ভেরিয়েবল হারায়। ফাইলে marks বা expense পরের run-এর জন্য থাকে। দুই দায়: ডেটা format আর open resource সঠিকভাবে সামলানো। Format পরে পড়া সহজ করে, close leak ঠেকায়।

Path ফাইলের জায়গা বোঝায়। pathlib string-slash হাতে জোড়ার বদলে অবজেক্ট। নেই এমন ফাইলও Path বোঝাতে পারে; বানালেই create বা open হয় না।

উদাহরণ নিজের temporary directory করে, ব্যক্তিগত ফাইল ছাড়া read-write-cleanup শেখায়। বাস্তব app-এ location বেছে existing ডেটা কখন বদলাবে বলো। Inspect করতে write mode নিরীহ নয়।

খোলার আগে mode বাছো

open ফাইল অবজেক্ট দেয়। Text ফাইল encoding-এ disk byte আর Python string বদলায়। এখানে encoding="utf-8"। Block শেষ বা exception-এ বেরোলে close করতে with।

from pathlib import Path

path = Path("marks.txt")
with path.open("r", encoding="utf-8") as stream:
    for line in stream:
        print(line.rstrip("\n"))
Modeঅর্থআগের ডেটা
rText readথাকে; নেই হলে failure
wText writeখোলাতেই truncate
aText appendথাকে; শেষে নতুন write
xশুধু নতুন text ফাইলআগে থাকলে failure
rb / wbByte read/writeText encoding argument নেই

Relative path process working directory থেকে, script folder নাও হতে পারে। App-এ configured base নাও। Path("ডেটা") / "marks.txt" portable join; slash pathlib operator, সংখ্যার ভাগ নয়।

Position, buffering আর lifetime

ফাইল অবজেক্ট current position রাখে। read() বাকি সব নেয়, শেষে আবার নিলে empty string। readline() সাধারণত newline-সহ এক line, শেষে empty string। Blank line আলাদা, newline character থাকে।

Stream iteration পরের line পড়ে। পুরো ফাইল list-এ নয়, তবে processing-এ প্রতিটি line মেমরি-তে। readlines() সব remaining line-এর list। Size আর হিসাব দেখে বাছো।

Text write OS-এ যাওয়ার আগে buffered হতে পারে। Close Python buffer flush করে। Sudden power failure টেকার নিশ্চয়তা নয়, durability-তে আরও লাগে। with প্রধানত নির্ভরযোগ্য lifetime।

Block-এর পরে closed stream read-write সাধারণত ValueError। Processing ভেতরে বা দরকারি value আগে রাখো। অন্য with একই path নতুন independent read-এর জন্য খুলতে পারে।

C জানা থাকলে

Python stream ফাইলের মতো, তবে string ফেরায় আর অনেক failure-এ exception। with exit-এ close। এখানে text encoding explicit, binary-তে Unicode decode ছাড়া byte read-write।

লেখো, আবার খোলো, structured ডেটা পড়ো

Text-এ replacement, append আর line iteration। CSV-JSON delimiter নিজের না বানিয়ে reader নেয়। Reopen-এর আগে writer close, তাই completed Python write পড়ে।

Text লিখে append আর line read

প্রথম open create, append 75 রেখে 80 যোগ। Iteration দুই line পড়ে integer করে।

EOF আর blank line আলাদা

প্রথম line A আর newline। দ্বিতীয় blank-এ newline। শুধু তৃতীয় read-এ EOF-এর empty string।

Comma room field-এর ভেতর। DictReader seats text দেয়, তাই পাঁচ যোগের আগে convert।

JSON-এ Unicode আর সংখ্যা

UTF-8 Bangla লেবেল রাখে, JSON integer marks সংখ্যায়। Loaded list যোগে 155।

Exclusive creation-এ overwrite আটকাও

x আগের content বদলানোর আগেই raise। শেষ read-এ keep অক্ষত।

CSV-কে comma আর quote সামলাতে দাও

CSV row-তে field রাখে। Field-এর comma quote চায়, তাই line comma-তে split নির্ভরযোগ্য নয়। csv.reader-writer format মানে, Lab, East এক field থাকে।

Encoding-এর সঙ্গে newline="" নাও। csv নিজে newline মানে, কিছু platform-এ extra blank line এড়ায়। Quoted field-এ newline থাকলেও দরকার। Reader-এ দেওয়ার আগে physical line strip কোরো না।

DictWriter column name আর row dictionary মেলায়। একবার header, তারপর named column-এর row। DictReader header ধরে dictionary দেয়। CSV value string, তাই marks-এ int আর উপযুক্ত boundary-তে invalid ডেটা handle।

Required column আর empty field-এর অর্থ বলো। Missing marks অনুপস্থিত ডেটা, zero নাও হতে পারে। Reader syntax জানে, grading rule নয়। Parsing আর domain validation আলাদা।

সংখ্যা আর nested value-র format

JSON অবজেক্ট, অ্যারে, string, number, Boolean, null রাখে। json.dump text stream-এ Python value লেখে, json.load পড়ে। dumps-loads string-এ, ফাইল অবজেক্ট নয়। জোড়া মেশানো পরিচিত ভুল।

অবজেক্ট dictionary, অ্যারে list হয়। true,false,null হয় True,False,None। Tuple অ্যারে হয়ে list-এ ফেরে, সব Python type থাকে না। Set আর custom instance-এ explicit conversion policy।

Predictable অবজেক্ট-এ string key। Numeric key string হয়ে loaded result বদলায়। Readable Bangla-তে ensure_ascii=False text-এ Unicode রাখে, encoding বাছে না; তবু UTF-8-এ open।

Invalid JSON-এ JSONDecodeError। Syntax ঠিক হলেও missing field বা wrong domain থাকতে পারে। Trusted marks ধরার আগে structure check। একই path-এ w পুরোনো document বদলায়, আরেক valid document append করে না।

গুরুত্বপূর্ণ ডেটা-তে temporary sibling লিখে destination replace partial-update risk কমাতে পারে। Deliberate error handling আর filesystem assumption লাগে। শুরুর উদাহরণ temporary disposable ডেটা, transaction-এর নিশ্চয়তা নেই।
