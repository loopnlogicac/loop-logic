Routine method না লিখে record বোঝাও

Course record-এ code, credits আর readable display চাই। Ordinary ক্লাস-এ initializer-repr পরিচিত pattern বারবার। ডেটা ক্লাস declared field থেকে তা বানায়। সংজ্ঞা ছোট, সাধারণ method-ও থাকে।

dataclasses standard library-তে, নতুন install নয়। সংজ্ঞার ওপরে @dataclass। এটি ক্লাস process করা decorator; decorator পাঠে notation বিস্তারিত।

Named value-তে অর্থ এমন record-এ মানায়। সব ক্লাস-এর বদলি বা database নয়। Network connection-এ field equality-র বদলে নিয়ন্ত্রিত আচরণ লাগতে পারে। অবজেক্ট-এর অর্থ দেখে নাও।

Field আর optional default

credits: int = 3 annotated assignment default-সহ field। Default নেই মানে initializer-এ required argument। সাধারণ initializer-এ required আগে default পরে, তাই Course("CSE212") স্পষ্ট।

from dataclasses import dataclass, field

@dataclass
class Course:
    code: str
    credits: int = 3
    rolls: list[int] = field(default_factory=list)

Generated __init__ code, credits, rolls নেয়। credits বাদে 3, rolls বাদে list কল করে fresh empty list। Explicit rolls দিলে সেই reference, automatic copy নয়। Ownership তখনও জরুরি।

Annotation intended type, string integer করে না বা construction-এ wrong type বাদ দেয় না। Static tool usage দেখে, যেমন type hint পাঠে। Domain-এ লাগলে explicit runtime validation।

কী তৈরি হয় জানো

Default-এ initializer, readable repr আর equality বানায়। Repr-এ ক্লাস-field name। Equality declaration order-এ participating field মেলায়, matching concrete ক্লাস চায়। আলাদা matching record equal, একই অবজেক্ট না হলেও।

Ordering default off; order=True-তে generated order। Field order tuple-like key। roll আগে marks দিলে উল্টো declaration থেকে ভিন্ন sort। এক report-এর order চাইলে sorted(records, key=...) পরিষ্কার হতে পারে।

সাধারণ total() বা passed(), custom __str__ লিখতে পারো। Generated routine অংশ, নিজের method domain behavior। পড়ে caller-এর operation বোঝা চাই।

C জানা থাকলে

Generated initialization-comparison helper-সহ struct-এর মতো। Field এখনও Python অবজেক্ট reference। Annotation fixed C integer slot allocate বা C-style convert করে না।

repr=False generated display-তে field লুকায়, access control নয়। compare=False generated comparison বাদ দেয়। Helper cache যেন logical identity না হয়, তখন কাজে লাগে।

Record আর independent default দেখো

Generated initializer-display, তারপর আলাদা record তুলনা। Roster-এ factory callable কেন দেখো। Frozen-এ assignment বাদ, কিন্তু ভেতরের list mutation চলে।

Initializer আর representation বানাও

Course generated initializer আর repr পায়। credits না দিলে default তিন।

প্রতি roster-এ আলাদা list

Factory a আর b-তে আলাদা চলে। a append-এ b empty, identity-তেও list আলাদা।

ডেটা record তুলনা আর order

Declaration-এ marks প্রথম key, roll tie-breaker। Matching field equal।

Frozen-এর shallow সীমা

Generated rule লেবেল assignment বাদ দেয়। Existing list-এ append field binding না বদলে contained list বদলায়, তাই চলে।

Initialization-এর পরে validate

Generated initializer marks বসায়, __post_init__ domain দেখে। Zero valid, 101-এ explicit ValueError।

ঠিক সময়ে mutable default

ক্লাস definition-এ বানানো mutable list সাধারণত shared হতো। Dataclass list-সহ প্রচলিত unhashable default reject করে। প্রতি instance-এ fresh চাইলে field(default_factory=list)। list নিজে, list() নয়, callable চাই।

Factory dictionary, set বা custom helper-ও বানায়। Zero-argument ফাংশন বিশেষ শুরুর মান দিতে পারে। Construction-এ default দরকার হলেই চলে; caller value দিলে সেটি।

Generated initializer field বসানোর পরে __post_init__। Mark validate বা derived field হিসাব চলে। 0..100-এর বাইরে ValueError domain rule স্পষ্ট করে; int annotation এই পরীক্ষা করে বলবে না।

Validation predictable রাখো। ইনপুট list সরাসরি রাখলে caller পরে বদলে check পাশ কাটায়। Initialization-এ copy alias কমায়, তবে outer list copy deep নয়। Record কোন অবজেক্ট own করে বোঝাও।

Frozen-এর boundary বোঝো

frozen=True initialization-এর পরে normal field assignment reject। point.x = 9-এ AttributeError-এর subclass FrozenInstanceError। Value-like record-এর সাধারণ attribute স্থির রাখে; API rule, absolute security barrier নয়।

Frozen shallow। List field-এর append নতুন field assign না করে list বদলায়। উদাহরণ ইচ্ছা করে দেখায়। Deeply stable record চাইলে immutable element-এর tuple-এর মতো মান।

Equality-সহ frozen সাধারণত generated hash পায়, সব field hashable করে না। List-সহ record hash করলে participating field-এর hash ব্যর্থ। Error সরাতে unsafe_hash নেবে না।

Frozen value update-এ dataclasses.replace(record, field=new_value) নতুন record। না বদলানো field reference একই, deep copy নয়। পুরোনো রেখে course plan-এর নতুন version-এ মানায়।

সুবিধা আর নিশ্চয়তা আলাদা

default_factory=list() লেখা

ফাংশন-এর বদলে বানানো list যায়। বন্ধনী ছাড়া list। Factory construction-এ fresh অবজেক্ট দেয়।

Annotation text reject করবে ভাবা

Explicit validation ছাড়া Course("CSE212", "three") তৈরি হতে পারে। Runtime correctness type-range চাইলে __post_init__ বা ইনপুট boundary check।

Frozen মানে nested সব স্থির

Frozen wrapper-এ mutable অবজেক্ট থাকে। Logical stability চাইলে immutable field। Nested mutation আর reassignment আলাদা টেস্ট।

ভুল field order-এ sort

Generated order declaration মেনে। order=True-এর আগে পড়ো বা sorted-এ explicit key। দরকারে non-identity helper comparison বাদ দাও।

Supported field option বুঝে নাও

Dataclass Python 3.7-এ এসেছে। এখানে 3.10–3.12, পরের-only option নেই। Mutable-default rejection 3.11-এ বিস্তৃত, তবে পুরো range-এ field(default_factory=list) intended portable pattern। Generated repr persistent interchange format নয়।

Record সংজ্ঞা সৎ রাখো

ডেটা ক্লাস routine method কমায়, ordinary behavior থাকে। Independent mutable default-এ factory; frozen shallow assignment rule। পরের exception-এ invalid operation reject আর উপযুক্ত boundary-তে recovery।
