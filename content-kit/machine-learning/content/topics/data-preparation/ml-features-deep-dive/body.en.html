What can Tuktuk know in time?

Mina wants Tuktuk to guess whether tomorrow's practice game will finish before sunset. She writes down the starting time, team size and yesterday's rain. Then Nana adds tomorrow's final whistle time. Mina pauses. That answer arrives after the game. Tuktuk would be cheating if it used it today.

A useful prediction starts with a clear question and a clear moment. List what you will know at that moment. A column can look impressive and still be unavailable when the prediction matters.

You will choose sensible inputs, spot answer clues that arrive too late, and build a new measurement from two existing ones. Better inputs can help more than a more complicated model.

Choose clues with a clock beside them

A feature is a measurable clue supplied to a model. A target is the answer you want it to predict. Leakage means information sneaks into learning or evaluation that would not be available for an honest prediction.

Useless and harmful are different. A random identifier usually adds noise. A private identifier can also expose people or help memorise them. A feature available only at a well-funded school may exclude other schools.

Domain knowledge means understanding the activity that generated the data. A housing expert may suggest distance to a transport stop. A teacher may explain why attendance changed when a register system broke. A column name cannot provide that context.

Strong clues can be dishonest clues

  • Keeping final marks while predicting passing leaks the defining answer. Remove that column before fitting or selecting features.
  • Trying hundreds of feature combinations against the final test score turns the test set into advice. Select using validation data.
  • Adding every possible ratio creates noise and unstable denominators. Propose a reason, validate it, and check zero values.
  • Dropping a district because its name has no numeric meaning loses potential location information. Encode nominal names appropriately.

Optional: dimension and sample size

With n records and d features, the input matrix has shape n by d. Adding features increases the space a model can use. With few records, accidental patterns become easier to fit. There is no universal maximum d: useful signal, redundancy, regularisation and the model all matter.

A derived feature can reveal a relationship without adding new measured information. BMI is determined by height and weight. For a model limited to straight combinations, that nonlinear ratio may change what it can represent. Compare a small, justified baseline against additions on validation data.

For an exam answer, distinguish prediction-time availability from statistical association. A feature can be strongly associated with the target yet leak it. Document who measures each field, when it arrives, and whether the same process will exist in deployment.

Choose clues that survive real use

  • Define the prediction moment before choosing inputs.
  • Separate the requested answer from its candidate clues.
  • Reject fields that arrive after the decision.
  • Check units and denominators for derived features.
  • Use domain knowledge to explain a proposed input.
  • Validate additions without consulting the final test set.
