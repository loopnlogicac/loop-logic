A room number is not a room count

Nana brings Mina a notebook of homes for rent. One page says three rooms. Another says room 302. Tuktuk adds the numbers and announces 305 rooms. Mina draws a box around 302. That number names a room; it does not count rooms.

Computers store symbols and numbers, but storage does not explain meaning. The same integer can be a count, a category code or part of an identifier.

You will classify measurements, names, ranks, text, images and dates. You will also inspect pandas storage types without mistaking them for a full description of the data.

Ask what comparisons are meaningful

Numerical data describes quantities for which arithmetic has meaning. Categorical data describes membership in a named group. A dtype tells you how a column's values are stored and which operations its software supports.

The area gap between A and B is meaningful. The code gap between districts 1 and 3 has no distance meaning unless someone explicitly defined such a measurement. Relabelling districts must not change their geography.

Numerical quantities can be discrete or continuous. Rooms are discrete counts: two and three rooms, not 2.4 actual rooms. Area is continuous in meaning, even if a form rounds every measurement to a whole square foot.

Nominal categories have names but no built-in order: Mirpur, Badda and Uttara. Ordinal categories have a meaningful order: low, medium and high service levels. An order does not promise equal gaps. Moving from low to medium need not equal moving from medium to high.

Dates need calendar-aware operations. From January 1 to January 3 is two elapsed days. Sorting text dates such as 02/11/2026 can be misleading when the day/month convention is unclear. Prefer an explicit year-month-day format and record the timezone when clock times matter.

Text starts as characters, not a ready-made measure of similarity. A later text model may count words or encode tokens. An image is a grid of pixel values, often with three colour channels. Turning pixels into numbers still leaves questions about resolution, brightness and what the scene means.

Codes printed on a mobile receipt deserve the same care. Leading zeros may be part of an identifier. Converting that field to an integer can lose information even if pandas accepts the operation.

Use head to inspect representative rows, dtypes for storage, and value counts for categories. Pandas info combines column counts with non-missing counts. A numeric dtype containing only 0 and 1 may represent a class label, a switch or a measured proportion; ask which one.

Conversion can change a question

  • Averaging numeric district codes invents geography. Keep their category meanings and encode them later.
  • Sorting low, medium and high alphabetically loses their intended order. Supply the category order explicitly.
  • Converting a price containing a currency word without inspecting failures hides a parsing problem. Separate units from numbers first.
  • Subtracting local clock strings across timezones gives misleading durations. Parse dates and document timezone rules.

Optional: storage, measurement and information

Measurement type constrains valid transformations. Relabelling nominal categories should preserve category membership. An ordinal transformation must preserve order, but can change spacing. Quantitative units allow meaningful differences or ratios according to the measurement definition.

Pandas may store an integer-like column with missing values as float64 because ordinary NumPy integer storage has no NaN. Nullable Int64 can retain integer semantics with missing entries. That capital I identifies a pandas extension dtype. Software storage is a representation choice, not a discovery about the world.

Meaning comes before dtype

  • Counts and continuous measurements are different numerical meanings.
  • Nominal names do not acquire order from integer codes.
  • Ordinal levels have order without guaranteed equal spacing.
  • Dates and times require explicit parsing conventions.
  • Text and image representations need documented transformations.
  • Inspect values and field descriptions alongside pandas dtypes.
