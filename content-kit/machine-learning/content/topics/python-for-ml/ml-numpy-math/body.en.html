One instruction for every tray

Mina draws five rows of two boxes. She wants to add 10 to each left box and 20 to each right box. Tuktuk starts copying the same instruction five times. Nana lays one instruction strip across the top. “Can every row borrow this?” Mina asks. NumPy can, when the shapes fit.

Array arithmetic lets one expression act on many numeric entries. Broadcasting reuses a smaller arrangement across compatible dimensions. Reductions then combine entries into totals or means. These operations are the building blocks inside many later learning methods.

You will follow every addition before using NumPy’s shorter expression. You will also distinguish an element-wise product from a weighted sum. Both involve multiplication, but they answer different questions and often produce different shapes.

A row strip and a column strip

Broadcasting reuses entries along compatible dimensions without requiring you to write a repeated matrix. An axis names a dimension along which a calculation combines entries. A dot product multiplies matching vector entries and adds the products.

Follow the source of each number

In row mode, choose the offset by column: offsets[c]. Begin at row 0, column 0. Read 2, borrow offset 10 and write 12. Move right, read 3, borrow offset 20 and write 23. Row 1 starts with 3, so its first result is 13. Continue until every result cell is written.

The lab restricts X to five rows and two columns so all ten additions remain visible. You can edit every entry. The first two sliders control row-mode offsets; column mode uses the separate five-entry list. In column mode [1,2,3,4,5], the first row becomes [3,4], the second [5,4] and the fifth [12,13]. Both modes perform ordinary exact additions on your supplied integers.

NumPy checks shapes from the right. Two dimension lengths are compatible if they match or either is one. Missing leading dimensions act as one. Therefore (5,2) plus (2,) acts like (5,2) plus (1,2). A (5,1) column also fits. A (5,) vector does not fit because its final length 5 conflicts with the matrix’s final length 2.

Element-wise +, -, * and / operate on matching broadcast entries. Division can produce fractional results. Neither * nor + automatically combines feature columns into one answer. For a reduction, name the axis. X.sum(axis=0) removes the row dimension, giving [22,23]. Divide by five to get column means [4.4,4.6]. X.sum(axis=1) combines columns within each row, giving [5,5,7,13,15]. Adding different physical units may have no practical meaning even when the arithmetic is valid.

To form one illustrative weighted sum per fruit, use weights [2,1]. The first dot product is 2×2 + 3×1 = 7. X @ weights produces [7,8,11,19,22]. In contrast, X * weights leaves two products per row. For a matrix W with shape (2,k), X @ W has shape (5,k); the inner lengths must match.

Compatible does not always mean intended

Broadcasting along the wrong direction

A two-entry row affects columns; a five-by-one column affects rows. Check the result’s shape and two hand-computed cells. A square matrix can hide directional mistakes because both alternatives may fit.

Calling every product a dot product

The expression X * weights retains products rather than summing them. Use @ when you intend weighted sums, and verify the inner dimensions first.

Restarting randomness inside a loop

Repeatedly creating default_rng(0) repeats its first draw. Create one generator before the loop for successive draws. A seed helps reproduce a chosen experiment; it does not make the data representative.

Optional: a weighted combination

For row r and weights w, the weighted sum is s[r] = Σ over c of X[r,c]w[c]. Here r selects a fruit and c selects a feature; w[c] is its chosen multiplier. Dense multiplication of an n-by-d matrix by a length-d vector takes work proportional to n×d. Broadcasting can avoid explicitly storing repeated offsets, but the full addition result still has n×d entries. NumPy speed comes from numeric storage and compiled loops, not from eliminating the arithmetic.

Name both the operation and the shape

  • Broadcasting compares dimension lengths from the right.
  • A singleton dimension can reuse one entry across many positions.
  • axis=0 combines rows; axis=1 combines columns.
  • Use * for entrywise products and @ for matrix products.
  • Keep random seeds and package versions for reproducible experiments.
  • Validate both result shapes and small known values.
