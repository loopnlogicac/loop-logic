A tray with numbered spaces

Tuktuk doubles Mina’s list of fruit sizes. Instead of larger measurements, it prints the same list twice. Nana laughs: the robot has brought two copies of the shopping list. Rafi gives it a numeric tray instead. Now doubling means changing each number, rather than repeating the container.

NumPy arrays organise numeric values so arithmetic can act on many entries together. The arrangement matters as much as the values. A table of five fruits with two measurements is different from a single row of ten unrelated numbers.

You will describe an array’s dimensions, choose entries and keep selected labels aligned. You will also reshape a flat collection into a feature table. Later learning methods will expect that table to have examples in rows.

Rows hold examples

An array is a collection with a regular arrangement of entries. Its shape lists the length along each dimension. Its dtype describes how values are represented, such as whole numbers or floating-point numbers.

The shape is (5,2): five rows followed by two columns. The property ndim is 2 because the matrix has two dimensions. The five-entry size vector alone has shape (5,) and ndim 1. The comma in (5,) is Python’s spelling for a one-entry tuple; it does not add a dimension.

NumPy’s usual numeric arrays use one dtype for all cells. That enables compact storage and numeric operations. Keep text labels in a separate array rather than mixing fruit names into the numeric matrix. Units still need column documentation; float64 does not tell you whether an entry is centimetres or sweetness.

Find the intended entries

Construct the matrix with np.array from a list of equal-length rows. NumPy is usually imported as np. You may request dtype=np.float64 when fractional measurements are expected. An integer array can discard a fractional part if you later assign a decimal into its existing integer storage, so choose the representation deliberately.

Indexing starts at zero. In the pictured matrix, X[2, 0] is 4: row 2 is the third fruit, and column 0 is its size. X[-1, 1] finds the last row’s sweetness, 8. A negative index counts from the end; it does not describe a negative measurement.

A slice selects a range. Its stop is excluded, so X[:2] keeps rows 0 and 1. X[:, 0] takes all rows but selects only their size entries, producing a vector of shape (5,). Use X[:, 0:1] when you want a table of shape (5,1). The numeric values agree, but their dimensions differ.

A Boolean mask is a row-by-row yes/no selection. For sizes at least 4, compare the entire size column with 4. You get [False,False,True,True,True]. Applying that mask to X retains [4,3], [6,7] and [7,8]. Applying it to the original label vector retains apple, mango and mango in the same order.

Reshape rearranges the indexing of the same number of entries. The sequence [2,3,3,2,4,3,6,7,7,8] can become five rows of two entries. Read left to right across each row to recover that original sequence. A requested six-by-two shape would require twelve entries and fails. One dimension may be -1, allowing NumPy to infer its length from the others.

Reshape is not transpose. Turning a five-by-two matrix into a two-by-five arrangement by reshape changes which values share a row. It does not automatically swap the scientific roles of examples and features. Decide what the rows mean before changing the layout.

Values can be right while shapes are wrong

Dropping the feature dimension

A length-five vector and a five-row column table have different shapes. Many estimator APIs require the latter for a single feature. Inspect shape immediately before passing the data onward.

Editing a shared slice

Basic NumPy slicing commonly returns a view of the same storage. Editing that view can change the original array. Use copy when independent editing is intended. Boolean indexing produces a separate selection, so do not assume all indexing behaves identically.

Masking only the measurements

If you remove two rows from X but keep every entry in y, labels no longer match examples. Create the mask once and reuse it for both selections.

Optional: dimensions and storage

For n examples and d features, a dense X has shape (n,d) and n×d entries. With float64, the numeric payload uses eight bytes per entry, excluding array metadata. Thus a five-by-two matrix needs 80 payload bytes. Reshape may share the original storage or require a copy depending on layout. It must preserve the element count regardless of whether storage is shared.

Read shape as a sentence

  • A numeric matrix keeps one example in each row.
  • shape gives dimension lengths; ndim counts dimensions.
  • dtype describes representation rather than physical units.
  • Integer indices can remove dimensions.
  • Apply identical masks to features and labels.
  • Reshape preserves entry count but not every interpretation.
