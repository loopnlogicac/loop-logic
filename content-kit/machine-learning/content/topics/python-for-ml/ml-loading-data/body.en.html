Data exploration asks what each row means, which values are present and whether the measurements are plausible. pandas can read the course files and provide useful summaries. Your judgement connects those numbers to their units and collection story.

You will read fruit and study CSVs, count labels, summarise groups and sort complete records. Finally, you will make the feature matrix X and label vector y expected by many scikit-learn estimators. Model fitting comes in later modules.

Read the header as a promise

A missing value is an absent measurement, not a recorded zero. A group gathers rows that share a chosen key, such as fruit label. A target is the answer you want a model to predict.

Explore before separating X and y

Place fruits.csv beside the script and read it with pd.read_csv("fruits.csv"). Relative paths are resolved from the current working directory, which can differ from the script’s directory. Check the directory if the file is not found. Keep the header and default comma separator for these supplied files.

Inspect shape, head and dtypes. fruits.csv has 120 rows and five columns: size_cm, weight_g, sweetness, colour_score and label. Four columns are numeric measurements; label is text. pandas may display text dtype differently across releases. Use the column’s meaning and a numeric-type check rather than assuming every text column must have one exact dtype name.

Count missing values with isna().sum(). In pandas numeric columns, an empty CSV cell commonly becomes NaN, a marker for missing numeric data. count excludes missing cells, while len counts rows. Many numeric summaries skip missingness by default; check how many values contributed before interpreting a mean.

Count labels with value_counts. The shared fruits table contains forty apples, forty mangoes and forty lychees. Sort the resulting index when a stable alphabetical display is useful. Equal counts tell you that this invented table is balanced by label. They do not prove equal representation across seasons, farms or fruit varieties.

To understand grouping by hand, consider five labelled weights: apple 2, mango 6, apple 4, mango 8, apple 3. Put the three apple cards together: their sum is 9 and their mean is 3. The two mango cards sum to 14 and average 7. groupby("label")["weight_g"].mean() performs that gathering before the arithmetic.

A summary can hide its assumptions

Replacing missing with zero automatically

A blank study-time cell means the measurement is absent. Zero means a measured absence of study time. Decide and document a cleaning strategy rather than quietly merging these meanings.

Sorting a label vector on its own

Alphabetical labels no longer describe the original feature rows. Sort the combined frame or carry one shared row permutation through every array.

Using an answer as an input

Exclude final marks when the intended prediction happens before marks exist. Ask when each measurement becomes available, not merely whether it is numeric.

Optional: weighted group summaries

Suppose one group has three observed weights averaging 3 and another has two averaging 7. The overall mean is (3×3 + 2×7)/(3+2) = 4.6, not the unweighted mean of group means, 5. Group counts matter. With missing cells, use the number of present measurements for the particular column being summarised. A group difference remains descriptive; it does not establish a causal explanation.
