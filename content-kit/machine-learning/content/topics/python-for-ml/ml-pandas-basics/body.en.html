pandas adds labels to tabular data. You can ask for size_cm instead of remembering a column position. You can also select rows, inspect types and create a calculated column while keeping related measurements together.

Labels live beside positions

A DataFrame is a table with named columns and row labels. A Series is one labelled sequence, often a single column. An index supplies the row labels. Labels need not equal zero-based row positions.

Selecting frame["size_cm"] returns a Series. Selecting frame[["size_cm"]] uses a list of column names and returns a DataFrame with one column. The outer brackets select; the inner brackets make the Python list.

Inspect, select and derive

Construct a DataFrame from a dictionary whose keys are column names and whose values have equal lengths. Supply the five row labels with index when creating it. Otherwise pandas normally creates default labels beginning at zero. Default labels can make label and position selections look interchangeable until a filter or reorder changes the table.

Three inspection methods answer different questions. head shows the first five rows by default; head(2) shows only two. info lists column types and present-value counts. describe summarises numeric columns with count, mean, spread and selected percentiles. None of them proves the measurements are correct. For this size column, count is five, minimum is 2, maximum is 7 and the mean is 22/5 = 4.4.

Use loc for labels and iloc for positions. Read frame.loc[20, "size_cm"] as the size in the row labelled 20: it is 3. Read frame.iloc[2, 0] as row position 2, column position 0: it is 4. For the ordered unique labels here, loc[20:40] includes both endpoint labels and retains 20, 30 and 40. iloc[1:3] excludes stop position 3, retaining labels 20 and 30.

A row filter produces a Boolean Series. Size at least 4 gives false, false, true, true, true. Sweetness at least 7 gives false, false, false, true, true. Combine them with & and parentheses around each comparison. The result keeps only labels 40 and 50.

The conversion adds 60 mm for label 40 and 70 mm for label 50. It changes neither the physical fruit nor the original centimetre column. Give derived columns names that state their units. Copying the selection before assignment makes the intended destination clear and avoids depending on version-specific chained-assignment behaviour.

pandas also aligns labelled Series by their index when combining them. Two Series with the same length but different row labels may not add by position. Preserve the index when deriving columns from the same frame. If you intentionally need positional arithmetic, convert or reset labels deliberately and explain why.

Choose the destination deliberately

Using and between Series

Python and asks for one truth value from each operand. A Boolean Series contains several values, so this request is ambiguous. Use parenthesised comparisons joined with & for rowwise conjunction.

Guessing whether 20 means a label

The method answers that question: loc uses labels and iloc uses positions. Do not rely on an index that happens to match positions in the current table.

Chaining selection and assignment

A filtered expression followed by another bracket assignment can obscure which object you intend to edit. Either make a named copy for separate work or use one loc assignment on the original DataFrame.

Optional: labelled alignment

For Series a labelled [10,20] with values [2,3], and b labelled [20,10] with values [7,8], a+b pairs by label. Label 10 gets 2+8=10; label 20 gets 3+7=10. Raw positional addition would give [9,11] instead. Index alignment helps prevent accidental row mismatches, but only when labels themselves are meaningful and correctly maintained.

Names carry meaning

  • A DataFrame holds a labelled table.
  • A Series represents one labelled sequence.
  • head previews; info reports structure; describe summarises numbers.
  • loc selects labels and iloc selects positions.
  • Combine rowwise conditions with & and parentheses.
  • Add derived columns to an explicit destination.
