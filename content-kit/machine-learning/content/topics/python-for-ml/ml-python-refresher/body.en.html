Keep the cards together

Nana writes fruit names on one page and sizes on another. A gust blows both pages off the stall. Mina finds the size list, but cannot tell which number belongs to which mango. She proposes one card per fruit, with all its details kept together. Tuktuk needs the same care inside a program.

Python containers let you keep measurements and labels organised. Loops visit the records, and functions turn repeated calculations into named tools. You do not need every Python feature before starting ML, but these few habits will follow you through the course.

You will store fruit records, select a few of them and compute a summary. You will also read the shared ten-fruit CSV using Python’s built-in csv module. No additional data library is needed for that first read.

Three containers, three useful jobs

A list is an ordered collection that can change. A tuple groups values in a fixed sequence whose positions cannot be reassigned. A dictionary connects names or keys to values. Think of a list as a stack of cards, a tuple as the fields on one card, and a dictionary as labelled drawers.

Visit, select and return

A for loop visits each record once in order. You can unpack a tuple into names such as label, size and sweetness. Keep that order consistent with how the tuple was created. The first program uses label first, while the picture places size first; the code documents its own tuple order explicitly.

To count labels, begin with an empty dictionary. The first apple has no entry, so counts.get("apple", 0) supplies zero; add one and store one. The next apple changes its count to two. With the five pictured records, the finished dictionary has apple:3 and mango:2. No fruit measurement has been moved to a different label.

A list comprehension is a compact way to create a list from another collection. For the pictured size column [2,3,4,6,7], test whether each entry is at least 4. The tests are false, false, true, true, true. Keeping the passing entries gives [4,6,7]. To preserve complete fruit records, return the record itself after testing its size.

selected = empty list
for each fruit record:
    if its size reaches the cutoff:
        append the whole record to selected
return selected

A function gives a calculation a name and receives its input through parameters. A mean function first handles an empty collection. Otherwise it adds the values and divides by their count. For the pictured sizes the sum is 22 and the count is five, so the mean is 4.4 cm. Returning that number lets another function compare it or draw it. Printing alone would only show text to a person.

Use an f-string when mixing text and numbers. Inside f"Mean: {value:.2f}", the colon introduces formatting and .2f requests two digits after the decimal point. This changes the displayed text, not the measurement stored in value. Label the unit so a reader knows whether the number means centimetres or grams.

A CSV is a text table with a header and separated fields. Open it with an explicit UTF-8 encoding and newline="" for the csv module. DictReader takes names from the header and gives one dictionary per row. Even size cells arrive as strings. Convert known numeric fields with float or int before arithmetic, and keep labels as text.

Small syntax, large consequences

Text that looks numeric

The expression "6" * 2 repeats text to make "66". Convert the CSV cell before doubling a size. If conversion fails, inspect the cell rather than silently treating it as zero.

Only printing a function result

A function that prints a mean but has no return statement returns None. Keep calculation and display separate when another part of your program needs the numeric answer.

Losing record alignment

Sorting sizes alone separates them from labels and sweetness. Sort or filter complete records. If separate lists are necessary, apply exactly the same row decisions to every list.

Optional: count the work

For n records, one loop that counts labels makes n visits, so its time grows proportionally to n. A new selected list can contain as many as n records. An accumulator for the mean needs only a running sum and count, but returning the full selection uses space proportional to its length. These costs help explain why numeric libraries become useful for larger tables.

Records before models

  • Use a list for an ordered collection of fruit cards.
  • Document tuple field positions or name them with dictionary keys.
  • Filter complete records to preserve their meaning.
  • Return results from reusable functions.
  • Format numbers when displaying them.
  • Convert numeric CSV strings before calculating.
