A number for Nana's notebook

Mina helps Nana price baskets before the morning market opens. A large basket usually costs more than a small one. Yet two baskets of the same size can have different prices. Tuktuk offers to guess a price from yesterday's notebook. Nana wants a number in taka, with room for mistakes.

Predicting a quantity is called regression. The answer might be a price, an exam mark or tomorrow's temperature. You need to name the quantity and its unit before choosing a model.

A useful prediction helps someone plan. Nana can prepare change, and a school can estimate how much support students may need. A prediction is still a guess drawn from past examples. It does not replace measuring the real outcome.

You already know how to separate training rows from held-out rows. Now you will use that separation to judge numeric predictions. Start by reading a picture of measured values and a candidate trend.

Each dot pairs one measured input with one known answer. A regressor predicts a numeric answer from inputs. A residual is the observed answer minus the predicted answer. A baseline is a basic prediction rule that a more complicated model should improve upon.

Lay a ruler through the cloud. It follows the general upward movement without touching every dot. The ruler can help you guess between observed inputs. A flexible curve could touch more dots, but it might bend around accidents in the measurements.

Regression and classification differ in the requested answer. Predicting a student's mark is regression; predicting pass or fail is classification. Both can use study hours as an input. The feature alone does not decide which learning task you have.

The line uses prediction = 1.2 times x plus 1.4. At x=4 it predicts 6.2, while the observation is 4. That residual is 4-6.2=-2.2. The negative sign tells you the line guessed too high. At x=5 the positive residual means the line guessed too low.

To obtain a line, training chooses its slope and starting height using known targets. Prediction then keeps those choices fixed. A new row supplies an input; it does not supply its future answer. These are different jobs even when one program performs both.

A mean baseline ignores x and predicts the training target average for every row. Our five targets average 5. That rule is worth checking before adding features. A model that cannot beat a useful basic rule may not justify its complexity.

Make predictions with a paper ruler

Draw the five dots on squared paper. Ask a friend to place a ruler through them. Read its height at each x and draw vertical pencil gaps to the dots. Compare which ruler gives a smaller overall pattern of gaps. Keep the same observations when comparing rulers.

Hide one target and predict it from the remaining cards. Reveal it only after recording the guess. With five cards the result changes a lot depending on the hidden row. Larger evaluations help, but only if those rows represent the situations where predictions will be used.

Learn a line and use it

Follow the arithmetic

The first program computes a slope and intercept from the five rows. The next topic derives the calculation. For now, compare its predictions with the hand table and notice that some residuals remain.

Fit with a library

LinearRegression receives a two-dimensional input table with one column. Its fit method sees known answers; predict receives only inputs. Both implementations report slope 1.2, intercept 1.4 and MSE 1.52.

Move to a larger collection

The study example reads invented records and predicts marks from daily study hours. It reserves one fifth of the valid records. Missing inputs are replaced using a training-fitted median, so held-out information cannot influence that replacement.

The reported MAE is an average absolute error in marks. It is a useful scale for a teacher, but it does not say every student has that exact error. Nor does the invented relationship establish what would happen if a real child studied longer.

Keep the requested answer clear

  • Treating numeric codes as quantities: district code 3 is a name represented by a number. It is not three times district 1. Ask what arithmetic means for the target.
  • Calling a line a guarantee: an average trend leaves residuals. Report typical errors alongside estimates.
  • Using the final mark as an input: the answer is unavailable before the exam. Choose measurements known at the prediction time.
  • Reporting only training fit: the model has already seen those answers. Use a reserved evaluation set to assess unfamiliar rows.

Optional: a model of a conditional average

Write the prediction as y_hat = w x + b. Here x is the input, w is the slope and b is the intercept. The observed answer y can differ from y_hat. Least squares chooses w,b to reduce the sum of squared residuals; the next lessons make that objective explicit.

Under squared-error loss, the population-optimal prediction at a given input is its conditional mean, when that mean exists. A straight-line model restricts how that mean can depend on x. This explains why a fitted trend can be useful without describing every observation exactly.

One-feature prediction takes constant arithmetic per row after fitting. Its scientific reliability depends on measurement quality and coverage, not only execution speed. A random-row score can fail to represent a new school, a future year or an unseen neighbourhood.

Predict a quantity and measure the gaps

  • Regression asks for a quantity with a meaningful unit.
  • Classification asks for a category instead.
  • A straight line can summarise an upward or downward trend.
  • Residual signs show whether a guess was too high or low.
  • A training-mean baseline gives a useful first comparison.
  • Unseen rows test whether the learned trend travels.
