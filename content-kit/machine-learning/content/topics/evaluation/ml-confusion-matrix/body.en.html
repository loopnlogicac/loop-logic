Two mistakes can have different meanings

Mina uses pretend COVID-test cards in a classroom exercise. Each card has a known reference answer and a test decision. One negative card receives a positive decision; one positive card is missed. Tuktuk first calls both wrong, but Nana asks what happened in each case.

A confusion matrix keeps those error types separate. It counts the actual category against the predicted category. In a binary task, four cells distinguish correct positives, correct negatives and the two different mistakes. The same counting idea extends to more than two categories.

You will read the matrix axes, count fixed-score decisions and move a threshold. The lesson's cards and scores are invented examples for understanding evaluation; their purpose is to explain the counting rule, not to estimate a real test's reliability.

A true positive correctly predicts the designated positive class. A false positive predicts positive for an actual negative. A false negative misses an actual positive. True negatives are the remaining correct negative cases.

Positive is a declared label, not a synonym for good or bad. If class one means unwanted message, a false positive flags a normal message. If class one instead means benign tissue, the same words refer to that target definition. Name the class before discussing which mistake matters.

This course uses rows for actual labels and columns for predictions. Other presentations may transpose them, so read the headings rather than memorising a cell location without its axes. The diagonal contains exact matches under this convention.

Apply the inclusive threshold to each score. The first two cards enter true negative. The 0.45 positive enters false negative, while the 0.60 negative enters false positive. The last two cards enter true positive. Counts are therefore TN two, FP one, FN one and TP two.

The four counts sum to six because every evaluated example belongs to exactly one cell. Accuracy combines the diagonal: four correct out of six, about 0.667. That number does not show whether the errors were missed positives or unnecessary flags.

The plot sorts scores horizontally and places known classes on separate rows. Only the horizontal score and class label enter the calculation; vertical placement is a display aid, not a second predictive feature. Each step highlights a card and its matrix cell before adding its count.

Raise the threshold to 0.8 without refitting. The 0.60 negative becomes a true negative. The 0.80 and 0.90 positives still pass, so FP becomes zero while TP stays two. Raising a threshold need not change every error count, but it cannot create extra predicted positives under the same fixed inclusive rule.

Rebuild the counts after one policy change

Predict the first preset's four counts before playing. Move the threshold to 0.8 and explain which single card changes cell. Then use a very low threshold and identify which row supplies the extra false positives.

Draw a two-by-two grid on paper. Give six classmates one scored card each. Let each choose a row from the known label and a column from the threshold decision. Count each card once, then move only the threshold and repeat.

Try scores exactly equal to the threshold. A different equality convention can change those cases, so the rule belongs in the evaluation description. Do not round scores before applying the decision unless the deployed policy also rounds them.

More categories add specific confusion routes

For three target categories, use a three-by-three table with the same explicit label order on both axes. A class-one example predicted as class two enters row one, column two. The mirrored cell counts the reverse confusion and need not match it.

The iris example reserves flowers before fitting and reports all nine cells. Similar species may be confused while another species is classified well. A single accuracy number can hide that pattern. Read row totals to see how many actual examples of each category were evaluated.

One-versus-rest summaries can treat each class as positive in turn, but they answer a chosen binary view of the multiclass problem. Keep that view explicit before computing precision, recall or averaging across classes. The next lesson develops those ratios and their denominators.

In the six-card binary example, both actual row totals are three. The predicted column totals also happen to be three each, yet the model still made two mistakes. Matching category totals therefore do not establish correct individual assignments. Check the diagonal and both error cells, not only the margins. When comparing policies, keep the evaluated cohort fixed or explain a changed population; raw counts grow with sample size and cannot be compared as if every report used the same number of cases.

Keep labels, decisions and consequences separate

Swapping false positives with false negatives

Read actual first and predicted second. A missed actual positive is false negative; a predicted positive on an actual negative is false positive.

Treating a threshold change as retraining

The scores can stay fixed while their hard labels change. Report the threshold with the matrix so another reader can reconstruct the decision policy.

Ignoring class counts behind a percentage

A high overall accuracy can coexist with poor handling of a rare class. Keep the raw matrix and class totals available before drawing a conclusion.

Declaring one error always worse

The cost depends on the action and context. Define the positive class, the downstream decision and the evidence needed to choose a policy.

Optional: a count table before any ratio

A confusion matrix is a discrete count table, not automatically a probability table. You may normalise rows to inspect recall-like class proportions, columns to inspect prediction composition or the whole table for joint frequencies. Those normalisations have different meanings and should be labelled.

A matrix summarises the evaluated sample under one policy. It does not by itself describe uncertainty in estimates, sampling representativeness or probability calibration. Preserve the threshold, label order and evaluated population when comparing reports.
