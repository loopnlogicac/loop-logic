Choose the question that leaves less confusion

Mina proposes asking whether a fruit is small. Nana proposes asking whether it is sweet. Both questions divide the cards, but their groups mix labels differently. Tuktuk needs a fair way to compare the questions instead of choosing the one with the nicest wording.

A decision tree measures mixing inside a node, then asks which candidate question reduces that mixing most. Gini impurity and entropy are two common measures. Both give zero to a pure group, but their numeric scales differ.

You will calculate each measure, weight the two child groups by their sizes and inspect every numeric threshold. The winning question should follow from the full comparison, not from a favourite hand-picked cut.

Impurity measures how mixed a group's labels are. Entropy is one way to measure label uncertainty, here using base-two logarithms. Gain is the reduction from a parent node's impurity to its size-weighted children.

A split is useful when the children are collectively less mixed than the parent. One tiny pure child does not automatically make the whole split good. The remaining large child still contains most of the examples and must receive most of the weight.

Work through the eight-card root

The tree dataset has three class-zero cards and five class-one cards. Its parent Gini is one minus three-eighths squared minus five-eighths squared, giving 0.46875. Gini uses class proportions, so doubling every count without changing those proportions leaves the impurity unchanged.

The size-three question gives four cards on each side. The left labels are zero, zero, zero and one, giving Gini 0.375. The right labels are all one, giving zero. Weight by sizes: four-eighths times 0.375 plus four-eighths times zero equals 0.1875.

Subtract child impurity from parent impurity to obtain gain 0.28125. In this particular split, the two child sizes are equal, so a plain average happens to agree. That shortcut fails when the groups have different sizes. A two-card pure child and eight-card child with impurity 0.5 have weighted impurity 0.4, not 0.25.

Rounding is for reading the table, not a reason to replace the stated numerical tie tolerance. Exact gain ties retain feature order and then smaller midpoint order, while no positive improvement means no split.

A constant feature has no adjacent distinct values and therefore no midpoint candidate. Duplicate values stay together on one side. Trying several thresholds between the same adjacent values would repeat the same partition rather than add a new possibility.

Both criteria receive the same train/test partition and depth limit. A score difference on one split does not establish a universal best criterion; compare choices with suitable validation before a final evaluation.

Compare pure, balanced and three-to-one groups

A pure group has zero mixing under both measures. The balanced binary group has Gini one-half and entropy one bit. The three-to-one group lies between those extremes; the two scales are not interchangeable.

Read information gain in its own units

Entropy is minus the sum of each class proportion times its base-two logarithm. The zero-probability contribution is defined by a limit as zero; skip that term in code instead of computing log2(0). A pure group then has zero bits and a balanced binary group has one bit.

Information gain uses parent entropy minus size-weighted child entropy. Its logic is the same comparison as Gini reduction, but its values are not numerically interchangeable. Both criteria often choose similar useful questions, while particular datasets can give different rankings.

A criterion measures training-label separation, not the cost of an error in the intended application. A pure split around a tiny accidental exception may overfit. Depth limits, minimum samples, pruning and held-out evaluation remain relevant after you have chosen a mathematically correct split.

Do not let one clean child hide the rest

Averaging children without their sizes

Every example should have equal influence in the weighted result. Multiply each child impurity by its count, add and divide by the parent count.

Using raw counts where proportions are required

Gini and entropy use fractions within the current node. Normalise by that node's total, not the full dataset when evaluating a child.

Choosing the first acceptable threshold

The search compares all distinct-value midpoints. Stop early only when a justified algorithmic rule permits it, rather than because one candidate looks plausible.

Logging a zero proportion

Skip its entropy term. A pure group is a valid low-uncertainty case, not a numerical exception that should be hidden with warning suppression.

Optional: greedy improvement and its limits

Gini is 1−sum(p_c²). Entropy is −sum(p_c log2 p_c). A split gain is I(parent)−(n_left I(left)+n_right I(right))/n_parent. These formulas use the current node's class proportions and give larger groups their appropriate influence.

The displayed algorithm greedily chooses the best immediate positive gain. It does not search all possible future trees for a globally optimal structure. Some interaction patterns need an initially zero-gain cut, which this explicitly positive-gain teaching solver declines. That stopping convention is visible rather than silently presented as every possible CART implementation.

A complete comparison before a chosen question

  • Impurity measures the class mixture within one node.
  • Gini and entropy are different scales for related mixing ideas.
  • A split gain subtracts size-weighted child impurity from the parent.
  • Try every distinct-value midpoint before choosing the best candidate.
  • Tie rules and positive-gain stopping must be explicit.
