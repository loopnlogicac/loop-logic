Two turns through the market

Mina draws Nana's market on squared paper. She walks two stalls east and one stall north. Nana then sends her one stall east and three stalls north. Tuktuk wants one direct instruction home from the starting gate. Mina joins the gate to her final stall with an arrow. The two errands now fit into one picture.

A pair of measurements can also be a place on paper. A fruit with a measured size and sweetness becomes one dot. You can compare several fruits without losing which two measurements belong together.

This lesson connects dots with arrows. You will add movements, stretch them and store the same coordinates in NumPy. Keep the axis meanings beside your drawing: a number alone cannot tell you whether it measures distance, sweetness or weight.

A dot is a place; an arrow is a change

A coordinate tells you how far to travel along one named axis. A vector is an ordered set of numbers; in this picture, its numbers describe an arrow's movement. The origin is the reference point where both coordinates are zero.

Point C is three across and four up. The arrow from the origin to C has the same pair of numbers. An arrow from A to C has a different pair because its starting place is A. A position and a displacement can share a storage format while describing different things.

Add matching directions

Call the first walk a=(2,1) and the second b=(1,3). The across movements combine to 2+1=3. The upward movements combine to 1+3=4. Therefore a+b=(3,4). Draw the answer from the original gate, rather than adding arrow lengths and guessing a direction.

To scale an arrow by two, double every coordinate. Twice the combined walk is (6,8). Scaling by zero produces no displacement. Scaling by a negative number reverses the arrow; scaling by -1 preserves its length while reversing direction.

Vector addition is commutative: walking b and then a reaches the same final position. The intermediate corner differs. Scaling by two after addition gives the same endpoint as doubling both original arrows and then adding them.

To move from point A=(2,1) to C=(3,4), subtract start from finish: C-A=(1,3). This displacement is b. Reversing the trip gives (-1,-3). Subtraction therefore describes direction as well as how each coordinate changes.

The fruit collection has four numeric features. A row is still one vector, even though a single flat drawing cannot show all four axes independently. The mean vector has one entry per feature; subtracting it shifts the reference point of every row.

Inspect the column list before trusting the numbers. A centred weight remains in grams, and a centred size remains in centimetres. Centring alone does not make their numeric magnitudes comparable.

Coordinates carry meaning

  • Joining Python lists instead of adding values: list addition concatenates entries. Add individual positions or use numeric arrays.
  • Scaling only one coordinate: that stretches one axis, which can turn the arrow. Multiply all coordinates for ordinary vector scaling.
  • Mixing feature order: reorder both records to the same documented column list before doing arithmetic.
  • Treating the drawing as a literal map: sweetness is not northward travel. The arrow picture explains coordinate arithmetic, not physical fruit motion.

Optional: the same rules in many dimensions

Rafi writes a vector as x=(x₁,…,xd), where d is the feature count and xj is its jth entry. Addition is defined by (a+b)j=aj+bj. Scalar multiplication is (sa)j=s aj. Each rule applies independently at every coordinate.

Adding two length-d vectors uses d additions, so time and result storage are O(d). A point cloud with n examples has n such rows. A two-axis projection drops other coordinates; points that overlap on that projection can still differ elsewhere.

A useful algebra check is s(a+b)=sa+sb. Substitute the tiny walk numbers on both sides to see the distributive law. This law is about compatible quantities. An array can accept nonsensical unit combinations unless your program checks their meaning.

Read the start and the finish

  • One feature pair gives one point.
  • An arrow describes an ordered displacement.
  • Add corresponding coordinates head to tail.
  • Scale every entry together.
  • Negative scaling reverses a nonzero arrow.
  • Extra features add coordinates, even when drawings cannot show them all.
