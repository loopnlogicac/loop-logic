Mina builds three pretend snack boxes for Tuktuk. The first adds a fixed number of biscuits for each token. The second arranges biscuits in a square. The third doubles a display after every tap. The same token count produces different amounts in the boxes. Tuktuk learns to ask which rule a box follows before predicting its answer.

A function is an input-to-output rule. Its picture lets you see whether changes stay steady, speed up, reverse direction or flatten out. Those shapes appear throughout machine learning.

You will compare a line, a square, an exponential, a logarithm and a sigmoid. Read their shapes first. Then connect each curve with the operation that produces its values.

Follow one input to one output

A function assigns one output to each allowed input. Its domain is the set of allowed inputs. A sigmoid is an S-shaped function that changes gradually from values near zero to values near one.

Give every curve its own instruction

The line rule is f(x)=2x+1. Increase x by one and its output increases by two. The square rule is f(x)=x². It makes a parabola: a bowl with a bottom at zero. Squaring -2 or 2 gives four, so the bowl is symmetric.

The exponential rule exp(x) uses the natural base e, approximately 2.718. Equal increases in input multiply its output by a fixed factor. At inputs zero, one and two it gives about 1,2.718,7.389. It stays positive even at negative inputs.

The natural logarithm log(x) reverses exp. It asks which exponent produces a positive input. log(1)=0, log(e)=1 and log(exp(2))=2. For real-number arithmetic, log accepts only positive inputs. A positive fraction can have a negative logarithm.

The sigmoid rule is 1/(1+exp(-x)). At zero, the exponential term is one, so the output is one half. At -2 and 2, outputs are about 0.119 and 0.881. It behaves like a soft switch, rather than abruptly jumping at one threshold.

The rule has a domain and a scale

  • Using log on zero or a negative real input: validate the domain before calling it.
  • Confusing multiplication with exponentiation: Python x**2 squares x; 2*x doubles it.
  • Reading equal-looking slopes across different axes: check the displayed scale before comparing curves.
  • Calling every sigmoid output a trustworthy probability: shape alone does not establish calibration on real data.
  • Feeding enormous values into exp: finite computer numbers can overflow. These examples intentionally use a small safe interval.

Optional: inverses and smooth changes

Function notation f(x) names the output of rule f at input x. Composition f(g(x)) applies g first, then f. Natural log and exp satisfy log(exp(x))=x for real x; exp(log(x))=x requires x>0.

The sigmoid approaches zero as x becomes very negative and one as x becomes very positive. Those are limits: at finite mathematical x it reaches neither endpoint. Floating-point arithmetic may round to an endpoint for very large magnitudes.

Rafi also notices that sigmoid(-x)=1-sigmoid(x). Substituting -x into the formula and multiplying numerator and denominator by exp(-x) proves it. This symmetry explains the equal distance of its two tails from one half.

Read growth from the picture

  • A function gives one output per allowed input.
  • A line changes at a steady rate.
  • A square makes a symmetric bowl.
  • Exponential growth multiplies across equal input steps.
  • Natural logarithm reverses exp on positive values.
  • Sigmoid is a gradual switch between zero and one.
