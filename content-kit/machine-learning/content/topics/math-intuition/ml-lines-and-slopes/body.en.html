A straight line turns a measured input into a prediction using two chosen numbers. One controls the starting height; the other controls how fast the prediction changes.

You will steer that line, read vertical gaps to observations, and make a prediction at a new input. The lab lets you choose a rule. A later regression lesson will teach how data can choose its parameters.

A steady rise above a starting height

The slope is how much the line's output changes for one unit of input. The intercept is its output at input zero. A residual is an observed output minus the prediction at the same input.

The predictions rise by two each time the input rises by one. Observations need not sit exactly on the line. The point at input two is above it; the point at input three is below it. Both differences matter when judging the rule.

Keep the slope fixed while changing the intercept. The whole line shifts up or down. Then keep the intercept fixed while changing the slope. The line turns around its starting point.

Apply one rule at every input

Write a straight-line prediction as y=m·x+c. Here x is the input, y is the predicted output, m is slope and c is intercept. For m=2,c=1, multiply input by two and add one. At x=6, the prediction is thirteen.

The five table predictions are 1,3,5,7,9. Subtract each from its observation to get residuals 0,0,1,-1,0. Their signed sum is zero, although two predictions are wrong. Squaring gives 0,0,1,1,0, whose mean is 2/5=0.4. This mean squared error measures vertical prediction gaps.

To recover a line through two different input positions, divide rise by run. Between (1,3) and (4,9), the rise is six and the run three. Slope is two. Substitute either point into the rule to find intercept one. Two points with equal input cannot determine a finite slope this way.

A negative slope predicts a decrease. With slope -2 and intercept eight, inputs zero through four give 8,6,4,2,0. A zero slope predicts the same output at every input. Both are valid straight-line rules.

Turn a ruler before turning a slider

Choose the flat-line preset and inspect its query prediction. Move the query input without moving the line. Why does the prediction stay fixed? Return to the rising line and predict the change when the intercept rises by three.

Put the five observed points on squared paper. Lay a ruler through the predictions at zero and four. Draw short vertical segments to the observations. Move the ruler up without tilting it, then tilt it while keeping the starting height. Explain which parameter changed in each movement.

Try a query beyond the largest observed input. Label it as extrapolation: using a pattern outside the range where observations support it. A displayed prediction is not a promise about that unseen region.

From chosen parameters to a fitted line

The first program evaluates the exact rule shown in the default lab. Its residual list explains why mean squared error is positive even though signed errors cancel.

The array version uses the same five rows. Squaring operates on every residual before the average is taken, so it matches the loop rather than squaring the average residual.

The optional study-data program previews a fitted line. scikit-learn chooses slope and intercept from training rows. Its fitting method comes later; here, inspect the meaning and units of its two parameters. Missing inputs are removed before this small demonstration.

The test error uses held-out observations. The study collection is invented, so its relationship is a teaching example rather than a finding about actual students. Other influences on marks are absent from this single-input rule.

Keep parameter meaning and error meaning apart

  • Calling the intercept a slope: read the output at zero for intercept; compare output changes for slope.
  • Measuring slanted gaps: regression residuals here are vertical because x is treated as the given input.
  • Averaging before squaring: positive and negative residuals can cancel. Square each residual first.
  • Assuming a rising prediction proves a cause: association in observed data does not establish the effect of changing one input.
  • Trusting distant extrapolation: check whether the pattern could reasonably continue outside observed values.

Optional: a two-parameter model

Rafi writes prediction ŷi=m xi+c for row i, where the hat distinguishes a prediction from its observed yi. With n rows, MSE=(1/n)Σ(yi-ŷi)². There are two adjustable parameters, regardless of the number of rows.

If x measures hours and y measures marks, m has units marks per hour and c has units marks. MSE then has squared-mark units. Mean absolute error, used in the real-data example, averages absolute gaps and keeps the original mark unit.

Evaluating a fixed line for n inputs takes O(n) arithmetic. Training is a different task: choose m,c to reduce an objective on training data. The sliders expose that parameter space without claiming that your chosen line is optimal.

One starting height and one rate of change

  • A line predicts with slope times input plus intercept.
  • Slope has output-per-input units.
  • Intercept is the prediction at input zero.
  • Residuals compare observations at the same input.
  • Mean squared error averages squared residuals.
  • Unseen input ranges need extra caution.
