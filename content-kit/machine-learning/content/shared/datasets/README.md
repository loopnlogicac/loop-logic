# Invented course datasets

These six CSVs contain fictional measurements and messages for teaching, not records of people, homes or customers. They require no downloads. UTF-8 text, comma separators, decimal points and LF newlines are used. An empty cell means a missing measurement; it never means zero.

Rebuild from any working directory:

```sh
python3 -I -X utf8 path/to/shared/datasets/make_datasets.py
```

The generator uses one `numpy.random.default_rng(2026)` in a fixed order. `tiny_fruits.csv` is a fixed hand-sized table; all other tables include seeded variation. Run twice and compare SHA-256 hashes to confirm identical bytes. `make_datasets.out` records its real console output. The generator needs NumPy 2.0 or newer and Python 3.10 or newer. The delivered toolchain is recorded in the package manifest.

| File | Rows | Columns and units | Construction and use |
| --- | ---: | --- | --- |
| tiny_fruits.csv | 10 | `size_cm`: illustrative size in centimetres; `sweetness`: made-up 0–10 tasting score; `label`: apple or mango | Five small apples and five larger mangoes, with two features that fit on squared paper. The miniature apples are deliberately schematic, not a horticultural reference. Used in Module 1 cards and rules, Module 3 distance activities, and Module 6 classification. The cards and threshold labs start with these exact ten rows. |
| fruits.csv | 120 | `size_cm`: cm; `weight_g`: grams; `sweetness`: 0–10; `colour_score`: invented 0–10 colour scale, not a universal fruit colour; `label`: apple, mango or lychee | Forty invented examples per fruit, perturbed around class-specific centres, clipped to the stated ranges and shuffled. Used in loading/EDA, KNN, trees, multiclass classification and the fruit project. Labels describe the invented fruit, not whether it is safe to eat. |
| study.csv | 200 | `hours_studied`: hours per day; `attendance_pct`: 0–100 percent; `past_marks`: 0–100; `sleep_hours`: hours per night; `passed`: 0/1; `marks`: 0–100 | Hours, attendance, past marks and sleep influence a noisy score. `passed` is 1 when marks reach 50. Six feature cells are missing. Row 200 deliberately records impossible study time of 30 hours per day: investigate it during cleaning. Used in cleaning, regression, logistic regression, evaluation and the student project. Do not use `marks` to predict `passed`: that leaks the answer. Relationships are invented; they establish no causes and support no real student decisions. No protected-group or identifying information is supplied; fairness examples must discuss missing representation rather than invent group measurements. |
| rent.csv | 250 | `area_sqft`: square feet; `rooms`: count; `floor`: 0 means ground; `distance_km`: km from an invented common reference point; `district`: Mirpur, Dhanmondi, Uttara, Mohammadpur or Badda; `rent_bdt`: BDT per month | A noisy invented price combines size, rooms, floor, distance and a district adjustment. Six feature cells are missing. The final rent is an obvious 500,000 BDT outlier; ask whether it is an error or an unusual home before removing it. Used in cleaning, encoding, regression and the rent project. These are not current Dhaka market estimates. |
| sms.csv | 160 | `text`: fictional short English or Bangla message; `label`: spam or ham (ordinary message) | Eight original sentence stems per language and class are combined with five time phrases. Eighty spam and eighty ham messages, half in each language, then shuffled. No phone numbers, actual offers or brands. Used in word counts, naive Bayes and the SMS project. Repeated stems can make a random row split too optimistic: group by message stem when measuring transfer to new wording. Keywords overlap labels intentionally; 'free' and 'পুরস্কার' do not prove spam. |
| shop.csv | 180 | `customer_id`: arbitrary C001–C180 identifier; `visits_per_month`: count; `avg_spend_bdt`: BDT per visit; `items_per_visit`: average count; `online_share`: fraction 0–1 | Three overlapping invented shopping patterns, with seeded noise. The last customer's 18,000 BDT spending is an outlier. Used in scaling, clustering, anomaly detection and the customer project. Group labels are intentionally absent. Exclude the identifier when computing distance. |

The ten-fruit table is visible in both language versions of the first module. Only the cards and rule labs use it directly; the train/test lab uses a separately documented ten-card counterexample with a noisy label. Shared `verify_content.py` checks row counts, missingness, units, lab agreement and exact regeneration.
