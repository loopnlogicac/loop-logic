Language আর server চেনো

প্রতি student record না খুলে তিন department code চাই। SQL-এ অনুরোধ বলো। MySQL তা নিয়ে যাচাই করে মেলা ডেটা খোঁজে।

SQL relational data সংজ্ঞা, পড়া আর বদলানোর language। MySQL নিজস্ব feature-সহ SQL চালানো database management system। Workbench graphical client, mysql command-line program আরেক client। কোনোটিই চলতে থাকা database server নয়।

SQL মূলত declarative: কী ফল বা change চাই বলো, record কীভাবে পাবে server বাছে। Access tuning-এর আগে logical অর্থ। Intended প্রশ্নের উত্তর দিলেই fast query কাজে লাগে।

কিছু course SELECT-কে আলাদা DQL বলে। নাম আলাদা হলেও কাজ data read। Command-line-এ semicolon statement শেষ। Readability-তে keyword uppercase, table-column নাম consistent রাখো।

SELECT column_name
FROM table_name
ORDER BY column_name;

এখানকার নাম actual object-এর placeholder। SELECT expression বাছে, FROM source, ORDER BY result order চায়। Table-এর guaranteed first row নেই।

Connection আর type বাছাই

Server install, client ব্যবহার

MySQL Community Server 8.0.16+ install। Service চালিয়ে local account configure। Supported Ubuntu-তে mysql-server package server দেয়। OS-এ package-service আলাদা, installed product-version নিশ্চিত করো।

Terminal client-এ host,account,password দিয়ে connect। -p interactively password চায়; production password command-এ সরাসরি নয়। Workbench একই host-port-এ graphical connection। সাধারণ TCP port 3306।

XAMPP local-এ সুবিধা, তবে কিছু version MySQL নয় MariaDB দেয়। Package name দেখে নয়, server identity দেখো। SQL মেলে অনেক, feature-version আলাদা। পাঠ Oracle MySQL-এর।

Database সম্পর্কিত table গুছায়। CREATE DATABASE বানায়, USE default বাছে, SHOW DATABASES account-এর visible নাম। SHOW TABLES selected database-এর table। Local নাম-permission-এ display অন্যজন থেকে আলাদা হতে পারে।

Connection refused সাধারণত listening server পৌঁছায়নি। Access denied service পেয়েও authentication-permission failed। Missing table selected schema বা নাম। Diagnosis-এ stage আলাদা।

অর্থ দেখে data type

INT numeric identifier আর whole count। VARCHAR name-course code-এর variable text। DATE সময় ছাড়া calendar date। DECIMAL fixed-scale exact taka, FLOAT-DOUBLE approximate binary।

তথ্যউপযুক্ত typeকারণ

Course codeVARCHARCSE 212-এ letter আর space

Digit আছে বলেই numeric নয়। Phone-এ leading zero আর country prefix, text ভালো। Zero জরুরি ID-ও text। Arithmetic অর্থ, format আর range দেখে বাছো।

Bangla-সহ text-এ utf8mb4। Character set কোন character, collation তুলনা-sort rule। Database-table-connection সব setting লাগে। Unicode ঠিক রাখলেই comparison case-sensitive নয়।

পড়ো আর ফিরিয়ে নেওয়া change

Department ID-code দেখাও

University catalogue-এর named column পড়ে, department-number ক্রমে তিন row চায়।

Money-date নির্ভুল

Shop-এ fixed date পাশে দুই price। Literal বলা report day, current clock নয়।

Table column description পড়ো

information_schema metadata, database object-এর data। Loan column-type definition order-এ নেয়।

Uncommitted stock change বাতিল

Transaction row change গুছায়। Lamp stock ভেতরে five, rollback-এ zero ফেরে।

সঠিক setup সমস্যা সারাও

Server ছাড়া Workbench

Client নিজে query উত্তর পারে না। Server install-running নিশ্চিত, তারপর host-port-account। Graphical editor খুললেই missing service শুরু নয়।

Exact price-এ binary float

Decimal fraction-এ representation পার্থক্য হতে পারে। Fixed-scale BDT-তে DECIMAL ভালো। তবু constraint-rounding policy চাই, type সব financial কাজ validate নয়।

সব SQL system একই syntax

মূল language মেলেও function,type,version আলাদা। সন্দেহে MySQL manual। অন্য database-এ চলা এখানকার support proof নয়।

এখানকার baseline

MySQL 8.0.16+, কারণ তখন থেকে CHECK enforced। 8.4-তেও query চলে। পরের পাঠে নতুন minimum লাগলে বলা আছে।

Query-র আগে connect

SQL request বলে, MySQL চালায়, client পাঠায়। Database বেছে family আর type-এর অর্থ জানো। পরের table আর constraint তৈরি-তে নির্ভরযোগ্য structure।
