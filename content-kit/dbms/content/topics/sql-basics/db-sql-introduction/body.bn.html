Language আর সার্ভার চেনো

প্রতি শিক্ষার্থী রেকর্ড না খুলে তিন বিভাগ কোড চাই। SQL-এ অনুরোধ বলো। MySQL তা নিয়ে যাচাই করে মেলা ডেটা খোঁজে।

SQL relational ডেটা সংজ্ঞা, পড়া আর বদলানোর language। MySQL নিজস্ব ফিচার-সহ SQL চালানো ডেটাবেস management system। Workbench graphical ক্লায়েন্ট, mysql কমান্ড-line প্রোগ্রাম আরেক ক্লায়েন্ট। কোনোটিই চলতে থাকা ডেটাবেস সার্ভার নয়।

SQL মূলত declarative: কী ফল বা change চাই বলো, রেকর্ড কীভাবে পাবে সার্ভার বাছে। Access tuning-এর আগে logical অর্থ। Intended প্রশ্নের উত্তর দিলেই fast কোয়েরি কাজে লাগে।

কিছু কোর্স SELECT-কে আলাদা DQL বলে। নাম আলাদা হলেও কাজ ডেটা read। কমান্ড-line-এ semicolon স্টেটমেন্ট শেষ। Readability-তে keyword uppercase, টেবিল-কলাম নাম consistent রাখো।

SELECT column_name
FROM table_name
ORDER BY column_name;

এখানকার নাম actual object-এর placeholder। SELECT expression বাছে, FROM source, ORDER BY ফল অর্ডার চায়। টেবিলের guaranteed first রো নেই।

কানেকশন আর type বাছাই

সার্ভার install, ক্লায়েন্ট ব্যবহার

MySQL Community সার্ভার 8.0.16+ install। সার্ভিস চালিয়ে local অ্যাকাউন্ট configure। Supported Ubuntu-তে mysql-সার্ভার package সার্ভার দেয়। OS-এ package-সার্ভিস আলাদা, installed পণ্য-ভার্সন নিশ্চিত করো।

Terminal ক্লায়েন্ট-এ host,অ্যাকাউন্ট,পাসওয়ার্ড দিয়ে connect। -p interactively পাসওয়ার্ড চায়; production পাসওয়ার্ড কমান্ড-এ সরাসরি নয়। Workbench একই host-পোর্ট-এ graphical কানেকশন। সাধারণ TCP পোর্ট 3306।

XAMPP local-এ সুবিধা, তবে কিছু ভার্সন MySQL নয় MariaDB দেয়। Package নাম দেখে নয়, সার্ভার পরিচয় দেখো। SQL মেলে অনেক, ফিচার-ভার্সন আলাদা। পাঠ Oracle MySQL-এর।

ডেটাবেস সম্পর্কিত টেবিল গুছায়। CREATE DATABASE বানায়, USE ডিফল্ট বাছে, SHOW DATABASES অ্যাকাউন্ট-এর visible নাম। SHOW TABLES selected ডেটাবেস-এর টেবিল। Local নাম-পারমিশন-এ display অন্যজন থেকে আলাদা হতে পারে।

কানেকশন refused সাধারণত listening সার্ভার পৌঁছায়নি। Access denied সার্ভিস পেয়েও authentication-পারমিশন failed। Missing টেবিল selected schema বা নাম। Diagnosis-এ stage আলাদা।

অর্থ দেখে ডেটা type

INT numeric identifier আর whole সংখ্যা। VARCHAR নাম-কোর্স কোড-এর variable টেক্সট। DATE সময় ছাড়া calendar তারিখ। DECIMAL fixed-scale exact taka, FLOAT-DOUBLE approximate binary।

Shared রেকর্ড-এর type
তথ্যউপযুক্ত typeকারণ
Student IDINTএই শিক্ষার ID পূর্ণসংখ্যা
Course কোডVARCHARCSE 212-এ letter আর space
BDT unit priceDECIMAL(10,2)দুই decimal-এ exact
Return তারিখNullable DATEবই ফেরত নাও আসতে পারে

Digit আছে বলেই numeric নয়। Phone-এ leading zero আর country prefix, টেক্সট ভালো। Zero জরুরি ID-ও টেক্সট। Arithmetic অর্থ, format আর রেঞ্জ দেখে বাছো।

Bangla-সহ টেক্সট-এ utf8mb4। Character set কোন character, collation তুলনা-সর্ট rule। ডেটাবেস-টেবিল-কানেকশন সব সেটিং লাগে। Unicode ঠিক রাখলেই comparison case-sensitive নয়।

information_schema metadata, ডেটাবেস object-এর ডেটা। Loan কলাম-type definition অর্ডার-এ নেয়।

সার্ভার ছাড়া Workbench

ক্লায়েন্ট নিজে কোয়েরি উত্তর পারে না। সার্ভার install-running নিশ্চিত, তারপর host-পোর্ট-অ্যাকাউন্ট। Graphical editor খুললেই missing সার্ভিস শুরু নয়।

Exact price-এ binary float

Decimal fraction-এ representation পার্থক্য হতে পারে। Fixed-scale BDT-তে DECIMAL ভালো। তবু কনস্ট্রেইন্ট-rounding policy চাই, type সব financial কাজ validate নয়।

সব SQL system একই সিনট্যাক্স

মূল language মেলেও ফাংশন,type,ভার্সন আলাদা। সন্দেহে MySQL manual। অন্য ডেটাবেস-এ চলা এখানকার support proof নয়।

এখানকার baseline

MySQL 8.0.16+, কারণ তখন থেকে CHECK enforced। 8.4-তেও কোয়েরি চলে। পরের পাঠে নতুন minimum লাগলে বলা আছে।
