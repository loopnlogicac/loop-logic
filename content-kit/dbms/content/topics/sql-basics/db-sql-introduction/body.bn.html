Language আর সার্ভার চেনো

প্রতি শিক্ষার্থীর রেকর্ড না খুলে তিনটি বিভাগ কোড চাই। SQL দিয়ে সেই অনুরোধ বলো। MySQL অনুরোধ পেয়ে যাচাই করে matching ডেটা খুঁজে আনে।

SQL relational ডেটা সংজ্ঞা, পড়া ও বদলানোর ভাষা। MySQL নিজস্ব ফিচারসহ SQL চালানো ডেটাবেস management system। Workbench graphical ক্লায়েন্ট, কমান্ড-line mysql আরেক ক্লায়েন্ট। কোনোটিই চলমান ডেটাবেস সার্ভার নয়।

SQL মূলত declarative: কী ফল বা পরিবর্তন চাই বলো, stored রেকর্ড কীভাবে পাবে সার্ভার বাছে। Access tuning-এর আগে logical অর্থ শেখো। উদ্দেশ্যের প্রশ্নের উত্তর দিলেই fast কোয়েরি কাজে লাগে।

কিছু কোর্স SELECT-কে আলাদা ডেটা কোয়েরি language বা DQL বলে। নাম বদলালেও কাজ ডেটা read। কমান্ড-line ক্লায়েন্ট-এ semicolon স্টেটমেন্ট শেষ করে। পড়ার সুবিধায় keyword uppercase রাখা হয়; টেবিল-কলাম নামে একটি consistent নিয়ম নাও।

SELECT column_name
FROM table_name
ORDER BY column_name;

ওপরের নামগুলো আসল object-এর placeholder। SELECT দেখানোর expression বাছে, FROM source বলে, ORDER BY ফলের ক্রম চায়। টেবিলের নিজের guaranteed প্রথম রো নেই।

কানেকশন আর type বাছাই

সার্ভার install, ক্লায়েন্ট ব্যবহার

এই পাঠের জন্য MySQL Community সার্ভার 8.0.16 বা নতুন install করো। সার্ভিস চালিয়ে local অ্যাকাউন্ট configure করো। Supported Ubuntu-তে mysql-সার্ভার package সার্ভার দেয়। OS অনুযায়ী package ও সার্ভিস management বদলায়; আসল পণ্য ও ভার্সন নিশ্চিত করো।

Terminal-এ mysql ক্লায়েন্ট দিয়ে host, অ্যাকাউন্ট ও পাসওয়ার্ড নিয়ে connect করো। -p দিলে interactively পাসওয়ার্ড চায়; production পাসওয়ার্ড সরাসরি কমান্ড-এ দেবে না। Workbench graphical interface-এ একই host-পোর্ট-এ connect করে। সাধারণ TCP পোর্ট 3306।

Local development-এ XAMPP সুবিধাজনক, তবে কিছু ভার্সন-এ MySQL-এর বদলে MariaDB থাকে। Package নাম দেখে ধরে না নিয়ে সার্ভার পরিচয় দেখো। অনেক সিনট্যাক্স মিললেও ফিচার ও ভার্সন আলাদা। এই পাঠ Oracle MySQL-এর জন্য।

ডেটাবেস সম্পর্কিত টেবিল গুছিয়ে রাখে। CREATE DATABASE বানায়, USE কানেকশন-এর ডিফল্ট বাছে, SHOW DATABASES অ্যাকাউন্ট-এর visible ডেটাবেস দেখায়। SHOW TABLES নির্বাচিত ডেটাবেস-এর টেবিল দেখায়। Local নাম ও পারমিশন-এ list অন্যজনের থেকে আলাদা হতে পারে।

কানেকশন refused সাধারণত listening সার্ভার পৌঁছানো যায়নি বোঝায়। Access denied-এ সার্ভিস পৌঁছেও authentication বা পারমিশন ব্যর্থ। Missing টেবিল নির্বাচিত schema বা নামের সমস্যা। Diagnosis-এ ধাপগুলো আলাদা করো।

অর্থ দেখে ডেটা type

INT অনেক numeric identifier ও পূর্ণসংখ্যার সংখ্যা-এ মানায়। VARCHAR নাম বা কোর্স কোড-এর variable টেক্সট রাখে। DATE সময় ছাড়া calendar তারিখ। DECIMAL fixed-scale দশমিক, exact টাকার জন্য উপযুক্ত। FLOAT ও DOUBLE approximate binary floating-point।

শুধু digit আছে বলে numeric type নেবে না। Phone number-এ leading zero ও country prefix থাকে, তাই টেক্সট সাধারণত ভালো। Leading zero গুরুত্বপূর্ণ এমন identifier-ও টেক্সট হবে। Arithmetic অর্থ, format ও রেঞ্জ দেখে বাছো।

Bangla-সহ টেক্সট-এ utf8mb4 নাও। Character set কোন অক্ষর রাখা যায় বলে; collation তুলনা ও সর্টিং ঠিক করে। ডেটাবেস, টেবিল ও কানেকশন সেটিং সবই গুরুত্বপূর্ণ। Unicode ঠিক রাখলেই সব comparison case-sensitive হয় না।

পড়ো আর ফিরিয়ে নেওয়া change

Department ID-কোড দেখাও

প্রথম কোয়েরি university catalogue-এর নির্দিষ্ট কলাম পড়ে। Department number-এর ক্রমে তিনটি রো চায়।

Money-তারিখ নির্ভুল

Shop উদাহরণে নির্দিষ্ট তারিখের পাশে দুই দাম দেখায়। তারিখ literal রিপোর্টের বলা দিন, বর্তমান ঘড়ি নয়।

টেবিল কলাম description পড়ো

MySQL information_schema-তে metadata থাকে, অর্থাৎ ডেটাবেস object বর্ণনার ডেটা। কোয়েরি loan কলাম ও type সংজ্ঞার ক্রমে নেয়।

Uncommitted stock change বাতিল

ট্রানজ্যাকশন রো change এক করে। ভেতরে lamp stock পাঁচ হয়; rollback-এ শূন্য ফেরে।

সঠিক setup সমস্যা সারাও

সার্ভার ছাড়া Workbench

ক্লায়েন্ট একা কোয়েরি-এর উত্তর দিতে পারে না। MySQL সার্ভার install ও চালু আছে নিশ্চিত করো, তারপর host-পোর্ট-অ্যাকাউন্ট দেখো। Graphical editor খুললেই অনুপস্থিত ডেটাবেস সার্ভিস চালু হয় না।

Exact price-এ binary float

Approximate সংখ্যায় দশমিক ভগ্নাংশের ছোট representation difference হতে পারে। Fixed-scale BDT-তে DECIMAL বেশি মানায়। তবু কনস্ট্রেইন্ট ও rounding policy চাই; শুধু type সব financial operation যাচাই করে না।

সব SQL system একই সিনট্যাক্স

মূল ভাষা মিললেও পণ্য-এর ফাংশন, type ও ভার্সন support আলাদা। সন্দেহ হলে MySQL manual দেখো। অন্য ডেটাবেস-এ কোয়েরি চলেছে বলে এই সার্ভার-এও চলবে ধরে নিও না।

এখানকার baseline

উদাহরণগুলো MySQL 8.0.16 বা নতুনে চলে। এই baseline দরকার, কারণ 8.0.16 থেকে CHECK enforced হয়। MySQL 8.4-তেও চলে। পরে নতুন minimum লাগা ফিচার আলাদা করে বলা আছে।

কোয়েরির আগে connect

SQL অনুরোধ বলে, MySQL চালায়, ক্লায়েন্ট পাঠানোর উপায় দেয়। ডেটাবেস বাছো, কমান্ড family বোঝো এবং অর্থ অনুযায়ী type নাও। এরপর টেবিল ও কনস্ট্রেইন্ট তৈরি শেখো।
