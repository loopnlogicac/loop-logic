Meet the language and the server

You want the three department codes without opening every student record. SQL lets you describe that request. MySQL receives the request, checks it and finds the matching data.

SQL is a language for defining, reading and changing relational data. MySQL is a database management system that implements SQL with its own features. Workbench is a graphical client. The command-line mysql program is another client. Neither client should be confused with the running database server.

SQL is mostly declarative: you describe the result or change you want. The server chooses how to access stored records. Learning the logical meaning comes before tuning that access. A fast query is useful only when it answers the intended question.

Some courses call SELECT a separate data query language, or DQL. The classification label varies, but SELECT’s role remains reading data. A semicolon ends a statement in the command-line client. Keywords are commonly uppercase for readability; column and table names should follow one consistent convention.

SELECT column_name
FROM table_name
ORDER BY column_name;

The names above are placeholders for actual objects. SELECT chooses the displayed expressions, FROM names their source and ORDER BY requests a result order. Tables themselves do not have a guaranteed first row.

Set up a connection and choose types

Install the server and use a client

Install MySQL Community Server 8.0.16 or newer for these lessons. Start its service and configure a local account. On a supported Ubuntu setup, the mysql-server package provides the server. Package names and service management vary by operating system, so confirm the actual installed product and version.

Connect from a terminal with the mysql client using host, account and password. The -p option requests a password interactively; avoid putting a production password directly into a command. Workbench connects to the same host and port through a graphical interface. The usual MySQL TCP port is 3306.

XAMPP can be convenient for local development, but some versions bundle MariaDB rather than MySQL. Check the server identity instead of assuming the package name guarantees it. MariaDB shares much SQL syntax but differs in features and version numbers. These lessons target Oracle MySQL.

A database groups related tables. CREATE DATABASE defines a database, USE chooses the connection’s default database, and SHOW DATABASES lists databases visible to the account. SHOW TABLES lists tables in the selected database. Those administrative displays depend on local names and permissions, so your list may differ from someone else’s.

A connection-refused error usually means the client cannot reach a listening server. An access-denied error means authentication or permission checking failed after reaching the service. A missing-table error concerns the selected schema or table name. Separate these stages when diagnosing a problem.

Choose data types from meaning

INT suits many numeric identifiers and whole-number counts. VARCHAR holds variable-length text such as names or course codes. DATE holds calendar dates without time-of-day. DECIMAL stores fixed-scale decimal values and is suitable for exact taka amounts. FLOAT and DOUBLE use approximate binary floating-point.

Do not choose a numeric type merely because a value contains digits. Telephone numbers can include leading zeros and a country prefix, so text is usually appropriate. An identifier whose leading zeros matter also belongs in text. Arithmetic meaning, allowed format and range should guide the choice.

Use utf8mb4 for text that may include Bangla. Character set describes available characters; collation controls comparison and sorting rules. The database, table and connection settings can all matter. Storing Unicode correctly does not make every text comparison case-sensitive.

Solve the right setup problem

Installing Workbench without a server

A client cannot answer queries on its own. Confirm that MySQL Server is installed and running. Then verify host, port and account details. Opening a graphical editor does not start a missing database service.

Using binary floating-point for exact prices

Approximate numbers can introduce small representation differences for decimal fractions. DECIMAL is a better match for fixed-scale BDT. It still needs constraints and a clear rounding policy; selecting a type alone does not validate every financial operation.

Assuming all SQL systems accept identical syntax

The broad language is shared, but products differ in functions, types and supported versions. Check the MySQL manual when a feature is uncertain. Do not treat a query working on another database as proof that this server supports it.

The baseline used here

The examples use MySQL 8.0.16 or later. That baseline matters because CHECK constraints are enforced from 8.0.16. MySQL 8.4 also supports these queries. Later lessons mark features that need a newer minimum version.
