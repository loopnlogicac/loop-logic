জমা তথ্য না বদলে আরও প্রশ্ন করো

Library চায় due date পেরিয়েও ফেরত না আসা বই। Student office চায় অজানা hometown-এর পড়তে সুবিধা হয় এমন label। Operator আর ফাংশনে দুই অনুরোধ বলা যায়, আসল রেকর্ড না বদলিয়েই।

Operator যোগ বা সমান কি না-র মতো মান মেলায় বা তুলনা করে। ফাংশন argument থেকে মান হিসাব করে, যেমন দুই date-এর দিনের ফারাক। SELECT expression নতুন label-মাপ হিসাব করতে পারে, original column update ছাড়া।

Filtering আর দেখানো আলাদা। Condition বলে row ফলের অংশ হবে কি না। Display expression বলে বাছা row-তে কী দেখাবে। Report-এ NULL-কে Unknown বললেই hometown জানা হয় না।

প্রচলিত expression চেনো

value BETWEEN lower_bound AND upper_bound
value IN (choice_a, choice_b)
text_value LIKE 'prefix%'
COALESCE(first_choice, fallback)
CASE
    WHEN condition_a THEN label_a
    WHEN condition_b THEN label_b
    ELSE other_label
END

Expression SELECT আর উপযুক্ত condition-এ থাকে। CASE মান ফেরায়, আলাদা row-change command নয়। Text literal quote-এ রাখো। AND-OR মেলালে বন্ধনী দিয়ে শর্ত পরিষ্কার করো।

Range, pattern, string আর date

সীমা আর তালিকার বিকল্প

BETWEEN দুই প্রান্তই নেয়। 75 থেকে 80-তে ঠিক 75 বা 80-ও চলে। প্রান্ত উল্টো দিলে MySQL নিজে অদলবদল করে না। Numeric/date অর্থে তুলনার উপযুক্ত type নাও, ভুল করে text order নয়।

IN তালিকার সদস্য কি না দেখে। Department (1,3)-তে হলে এক বা তিন, মাঝের সব মান নয়। তালিকায় NULL বিশেষ করে NOT IN-এ সাবধান: unknown তুলনায় condition TRUE নাও হতে পারে। Absence query-তে স্পষ্ট NULL policy দরকার।

Text pattern মেলাও

LIKE-এ percent শূন্য বা বেশি character, underscore ঠিক এক। Active collation-এ A% নামের শুরু A চায়, _a% দ্বিতীয় character a চায়। Wildcard নিজে digit বা whole word নয়।

আসল percent বা underscore মেলাতে escaping বা অন্য সচেতন matching পদ্ধতি লাগে। Backslash SQL mode-এ নির্ভর করতে পারে, অন্য language দেখে আন্দাজ নয়। Case-accent collation ঠিক করে; LIKE নিজে case-sensitive নয়।

Report-এর text বদলে দেখাও

UPPER-LOWER letter case, CONCAT roll label-এর মতো text জোড়ে। CHAR_LENGTH character, LENGTH byte গোনে। সাধারণ English-এ মেলে, utf8mb4 Bangla-তে আলাদা হতে পারে।

Unicode character count পাঠকের দেখা grapheme cluster-এর সংখ্যা সবসময় নয়। Combining mark আলাদা character হতে পারে। SQL character গুনতে CHAR_LENGTH নাও, হাতে লেখা অক্ষর বা display width ঠিক গোনে বলবে না।

CONCAT-এর কোনো argument NULL হলে ফল NULL। Readable fallback চাইলে বুঝে replacement। TRIM চারপাশের space সরায়, SUBSTRING অংশ আনে। সবার নামে একইসংখ্যক শব্দ ধরে নয়, আসল requirement-এ validate করো।

Fixed report date-এ হিসাব

DATEDIFF(first_date, second_date) দিনের ফারাক; ক্রম উল্টালে sign উল্টায়। DATE_ADD interval যোগ, YEAR-MONTH অংশ বের করে। Local text আন্দাজ নয়, DATE আর স্পষ্ট year-month-day literal নাও।

Overdue report-এ বলা reporting date আর open-loan condition চাই। returned_on IS NULL এখনও বাইরে থাকা বই রাখে; due_on report date-এর আগের হলে overdue। আজ due হলে zero late, এই সংজ্ঞায় strictly overdue নয়।

Missing মান আর category

IFNULL দুই argument-এ প্রথম NULL হলে দ্বিতীয়। COALESCE কয়েক বিকল্প থেকে প্রথম non-NULL। Zero আর empty string known, নিজে fallback ঘটায় না।

Searched CASE ক্রমে দেখে প্রথম TRUE branch দেয়। Excellent-Pass দিতে আগে mark অন্তত 80, পরে অন্তত 40। উল্টো হলে high mark-ও আগে Pass। বাকি case স্পষ্ট করতে ELSE।

Expression কী করল পড়ো

Prefix বা দুই hometown-এর একটি

প্রথম query LIKE আর IN-কে OR দিয়ে মেলায়। নাম বা town যেকোনো শর্তে row আসতে পারে।

সীমায় আর ভেতরের marks

Range-এ 75,78,80 আসে। Grading rule তুলনায় নিতে দুই প্রান্ত জরুরি।

Name, character count আর roll label

String ফাংশন নতুন displayed column করে। Original নাম-ID আগের মতো জমা।

1 March-এ overdue open loan

Fixed দিনে loan 402 দশ দিন overdue। পুরোনো due date পার হলেও returned loan বাদ।

Fallback আর grade band

দুই result set missing-town label আর ordered CASE দেখায়। এগুলো report-এর পছন্দ, stored fact replacement নয়।

সীমা আর missing দেখো

BETWEEN-কে exclusive ভাবা

Strictly above 75 আর below 80 হলে BETWEEN বেশি নেয়, প্রান্তও আসে। তখন strict comparison লেখো। Operator বাছার আগে প্রশ্নের boundary শব্দ পড়ো।

Unknown-কে আসল category করা

COALESCE পড়তে সাহায্য করে, কিন্তু fallback আর সত্যিই রাখা একই label group করলে ভিন্ন অর্থ মিশে যায়। দরকার হলে missingness আলাদা রাখো। সুন্দর display যেন data quality না লুকায়।

ঐতিহাসিক প্রশ্নে আজকের clock

1 March-এর report মাস পরে চালালেও 1 March নেবে। Current date অন্য প্রশ্ন। As-of date বলো, due-today,overdue,returned আলাদা।

ফাংশন আর setting দুটোই জরুরি

MySQL 8.0.16+-এ চলে। utf8mb4 Bangla রাখে, collation match-sort ঠিক করে। Literal wildcard escape ধরার আগে SQL mode স্পষ্ট দেখো।

অর্থ থেকে expression

Range-pattern row বাছে, ফাংশন মান হিসাব, CASE সচেতন category দেয়। NULL,Unicode count,report date সাবধানে ধরো। পরের aggregate আর GROUP BY-তে row মিলিয়ে summary।
