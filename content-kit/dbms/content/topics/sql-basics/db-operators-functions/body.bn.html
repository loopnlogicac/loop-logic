জমা তথ্য না বদলে আরও প্রশ্ন করো

Library চায় due তারিখ পেরিয়েও ফেরত না আসা বই। Student office চায় অজানা hometown-এর পড়তে সুবিধা হয় এমন লেবেল। অপারেটর আর ফাংশনে দুই অনুরোধ বলা যায়, আসল রেকর্ড না বদলিয়েই।

অপারেটর যোগ বা সমান কি না-র মতো মান মেলায় বা তুলনা করে। ফাংশন argument থেকে মান হিসাব করে, যেমন দুই তারিখ-এর দিনের ফারাক। SELECT expression নতুন লেবেল-মাপ হিসাব করতে পারে, original কলাম আপডেট ছাড়া।

ফিল্টারিং আর দেখানো আলাদা। শর্ত বলে রো ফলের অংশ হবে কি না। Display expression বলে বাছা রো-তে কী দেখাবে। রিপোর্ট-এ NULL-কে Unknown বললেই hometown জানা হয় না।

প্রচলিত expression চেনো

value BETWEEN lower_bound AND upper_bound
value IN (choice_a, choice_b)
text_value LIKE 'prefix%'
COALESCE(first_choice, fallback)
CASE
    WHEN condition_a THEN label_a
    WHEN condition_b THEN label_b
    ELSE other_label
END

Expression SELECT আর উপযুক্ত শর্ত-এ থাকে। CASE মান ফেরায়, আলাদা রো-change কমান্ড নয়। টেক্সট literal quote-এ রাখো। AND-OR মেলালে বন্ধনী দিয়ে শর্ত পরিষ্কার করো।

রেঞ্জ, pattern, স্ট্রিং আর তারিখ

সীমা আর তালিকার বিকল্প

BETWEEN দুই প্রান্তই নেয়। 75 থেকে 80-তে ঠিক 75 বা 80-ও চলে। প্রান্ত উল্টো দিলে MySQL নিজে অদলবদল করে না। Numeric/তারিখ অর্থে তুলনার উপযুক্ত type নাও, ভুল করে টেক্সট অর্ডার নয়।

IN তালিকার সদস্য কি না দেখে। Department (1,3)-তে হলে এক বা তিন, মাঝের সব মান নয়। তালিকায় NULL বিশেষ করে NOT IN-এ সাবধান: unknown তুলনায় শর্ত TRUE নাও হতে পারে। Absence কোয়েরি-তে স্পষ্ট NULL policy দরকার।

টেক্সট pattern মেলাও

LIKE-এ percent শূন্য বা বেশি character, underscore ঠিক এক। Active collation-এ A% নামের শুরু A চায়, _a% দ্বিতীয় character a চায়। Wildcard নিজে digit বা whole word নয়।

আসল percent বা underscore মেলাতে escaping বা অন্য সচেতন matching পদ্ধতি লাগে। Backslash SQL mode-এ নির্ভর করতে পারে, অন্য language দেখে আন্দাজ নয়। Case-accent collation ঠিক করে; LIKE নিজে case-sensitive নয়।

রিপোর্ট-এর টেক্সট বদলে দেখাও

UPPER-LOWER letter case, CONCAT roll লেবেল-এর মতো টেক্সট জোড়ে। CHAR_LENGTH character, LENGTH byte গোনে। সাধারণ English-এ মেলে, utf8mb4 Bangla-তে আলাদা হতে পারে।

Unicode character সংখ্যা পাঠকের দেখা grapheme cluster-এর সংখ্যা সবসময় নয়। Combining mark আলাদা character হতে পারে। SQL character গুনতে CHAR_LENGTH নাও, হাতে লেখা অক্ষর বা display width ঠিক গোনে বলবে না।

CONCAT-এর কোনো argument NULL হলে ফল NULL। Readable fallback চাইলে বুঝে replacement। TRIM চারপাশের space সরায়, SUBSTRING অংশ আনে। সবার নামে একইসংখ্যক শব্দ ধরে নয়, আসল requirement-এ validate করো।

Fixed রিপোর্ট তারিখ-এ হিসাব

DATEDIFF(first_date, second_date) দিনের ফারাক; ক্রম উল্টালে sign উল্টায়। DATE_ADD interval যোগ, YEAR-MONTH অংশ বের করে। Local টেক্সট আন্দাজ নয়, DATE আর স্পষ্ট year-month-day literal নাও।

Overdue রিপোর্ট-এ বলা reporting তারিখ আর open-loan শর্ত চাই। returned_on IS NULL এখনও বাইরে থাকা বই রাখে; due_on রিপোর্ট তারিখ-এর আগের হলে overdue। আজ due হলে zero late, এই সংজ্ঞায় strictly overdue নয়।

Missing মান আর category

IFNULL দুই argument-এ প্রথম NULL হলে দ্বিতীয়। COALESCE কয়েক বিকল্প থেকে প্রথম non-NULL। Zero আর empty স্ট্রিং known, নিজে fallback ঘটায় না।

Searched CASE ক্রমে দেখে প্রথম TRUE branch দেয়। Excellent-Pass দিতে আগে mark অন্তত 80, পরে অন্তত 40। উল্টো হলে high mark-ও আগে Pass। বাকি case স্পষ্ট করতে ELSE।

Expression কী করল পড়ো

Prefix বা দুই hometown-এর একটি

প্রথম কোয়েরি LIKE আর IN-কে OR দিয়ে মেলায়। নাম বা town যেকোনো শর্তে রো আসতে পারে।

সীমায় আর ভেতরের marks

রেঞ্জ-এ 75,78,80 আসে। Grading rule তুলনায় নিতে দুই প্রান্ত জরুরি।

নাম, character সংখ্যা আর roll লেবেল

স্ট্রিং ফাংশন নতুন displayed কলাম করে। Original নাম-ID আগের মতো জমা।

Fallback আর grade band

দুই ফল set missing-town লেবেল আর ordered CASE দেখায়। এগুলো রিপোর্ট-এর পছন্দ, stored fact replacement নয়।

সীমা আর missing দেখো

BETWEEN-কে exclusive ভাবা

Strictly above 75 আর below 80 হলে BETWEEN বেশি নেয়, প্রান্তও আসে। তখন strict comparison লেখো। অপারেটর বাছার আগে প্রশ্নের boundary শব্দ পড়ো।

Unknown-কে আসল category করা

COALESCE পড়তে সাহায্য করে, কিন্তু fallback আর সত্যিই রাখা একই লেবেল গ্রুপ করলে ভিন্ন অর্থ মিশে যায়। দরকার হলে missingness আলাদা রাখো। সুন্দর display যেন ডেটা quality না লুকায়।

ঐতিহাসিক প্রশ্নে আজকের clock

1 March-এর রিপোর্ট মাস পরে চালালেও 1 March নেবে। Current তারিখ অন্য প্রশ্ন। As-of তারিখ বলো, due-today,overdue,returned আলাদা।

ফাংশন আর সেটিং দুটোই জরুরি

MySQL 8.0.16+-এ চলে। utf8mb4 Bangla রাখে, collation match-সর্ট ঠিক করে। Literal wildcard escape ধরার আগে SQL mode স্পষ্ট দেখো।

অর্থ থেকে expression

রেঞ্জ-pattern রো বাছে, ফাংশন মান হিসাব, CASE সচেতন category দেয়। NULL,Unicode সংখ্যা,রিপোর্ট তারিখ সাবধানে ধরো। পরের aggregate আর GROUP BY-তে রো মিলিয়ে সারাংশ।
