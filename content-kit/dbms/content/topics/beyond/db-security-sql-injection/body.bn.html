নাম যেন কমান্ড না হয়

Search-এ শিক্ষার্থী apostrophe-সহ নাম লিখতে পারবে,WHERE rewrite নয়। SQL injection-এ untrusted ইনপুট SQL টেক্সট-এ মেশে,DB সেটিকে কমান্ড-এর অংশ ভাবে।

Quoted ইনপুট জুড়ে SELECT student_id FROM students WHERE student_name = বানাও ধরি। ইনপুট quote বন্ধ করে always-true শর্ত দিলে unrelated রো আসে। সমস্যা special character থাকা নয়,কোড-ডেটা boundary।

Example fictional university-তে read-only unsafe-safe তুলনা। আসল login-এ পাসওয়ার্ড hash,অ্যাকাউন্ট check,rate limit,authentication চাই। নাম search login design নয়। Binding SQL স্ট্রাকচার রক্ষা করে,কে কার ফল পড়বে বাছে না।

স্ট্রাকচার prepare,value bind

SET @student = 101;
PREPARE lookup FROM
    'SELECT student_name FROM students WHERE student_id = ? ORDER BY student_id';
EXECUTE lookup USING @student;
DEALLOCATE PREPARE lookup;

? value placeholder। PREPARE স্ট্রাকচার parse,EXECUTE value দেয়। App driver-এর native binding API নাও,নিজে quote বানিও না। SQL-level interface অন্য language ছাড়াই একই boundary দেখায়।

Trust boundary খোঁজো

Form,URL,upload,queue,আগে stored value—কোয়েরি-তে আসা সব পথ ধরো। Save হলেই trusted নয়। Stored ইনপুট পরে concat হলে second-অর্ডার injection।

Binding quote,space,OR-কে এক value-তেই রাখে,parser extra predicate করে না। Business validation-ও চাই,mark numeric রেঞ্জ-এ। দুটো আলাদা সমস্যা,একসঙ্গে কাজ করে।

Placeholder value,টেবিল-কলাম-keyword নয়। ORDER BY ? bound constant সর্ট করে,user-named কলাম নয়। User সর্ট লেবেল known fixed identifier-এ map,ASC-DESC trusted set থেকে।

IN (?) এক parameter,list token নয়। “101,102” স্ট্রিং দিলে দুই integer নয়। Driver list expansion বা validated bounded length-এ তত placeholder বানিয়ে প্রত্যেকটি bind। Maximum কোয়েরি cost-ও বাঁধে।

Procedure নিজে immune নয়;dynamic SQL concat-এ same flaw। Static parameter safer,unavoidable identifier trusted map। Escape charset-mode-নির্ভর,hand escaping supported API-এর fragile বদলি।

Authority কমাও,recovery রেখো

ফল viewer selected read চায়,CREATE USER,DROP,broad আপডেট নয়। Dedicated narrow app অ্যাকাউন্ট,migration আলাদা। Additive broad scope-role review,target পরিচয়-তে allowed-denied test।

Least privilege injected/compromised app-এর ক্ষতি কমায়,read-only-ও private রো ফাঁস করে। App ownership-role আর প্রযোজ্য ভিউ দাও। অন্য শিক্ষার্থী-এর bound ID-তে marks দিলে এখনও authorization flaw।

পাসওয়ার্ড repo/ক্লায়েন্ট কোড-এ নয়। Protected deployment secret-এ,exposure-এrotate,reader সীমিত। Network-এপ্রয়োজনীয় transport protection। User এরর useful হবে,full SQL,credential,internal schema নয়।

Backup sensitive,app রো-screen পাশ কাটায়। Reader,transit,at-rest,keys,retention রক্ষা। Isolated restore drill-এtable,routine,trigger,পারমিশন validate। RPO কত loss,RTO কত সময় বলো।

Snapshot logical dump tool rule-এ InnoDB consistent। Concurrent DDL assumption ভাঙে,nontransactional আলাদা। PITR-এ corresponding binlog-position রাখো। Recovery-তে log-backup ফারাক।

Unexpected privilege,repeated failure,unusual export monitor। Raw parameter-এ personal ডেটা থাকতে পারে,log-ও protect। Alert তদন্তের evidence,সফল attack-এর proof নয়। Security explicit,tested boundary,কানেকশন স্ট্রিং-এর শব্দ নয়।
