Subquery অন্য statement-এর ভেতর SELECT। এক value,row,set বা temporary relation দেয়। এক mean-এর তুলনা আর কোনো registration আছে কি না আলাদা, উপযুক্ত রূপ নাও।

Comparison-এর সঙ্গে subquery shape

Scalar subquery সর্বোচ্চ এক row-এর এক column। এক value চাইলে বন্ধনীতে। GROUP BY ছাড়া AVG এক aggregate row দেয়, input না থাকলে তাতে NULL।

Scalar-এ no row-ও NULL, দুই row-এ একই মান হলেও error। LIMIT 1 ভুল লুকিয়ে arbitrary row নিতে পারে। সত্যিই এক row চাইলে unique predicate বা অর্থপূর্ণ ordered selection।

Row subquery tuple comparison-এ কয়েক column। Enrollment identity student_id-section_id। Left tuple আর result-এর count-position মিলবে। আলাদা IN list-এ আলাদা enrollment-এর ভুয়ো combination হতে পারে।

Table subquery FROM-এ, MySQL-এ alias চাই। Surrounding query-তে temporary relation। Grouped payment এক total/order দিয়ে original payment multiply ছাড়া join করে।

SELECT <outer_columns>
FROM <outer_table> AS o
WHERE EXISTS (
    SELECT 1 FROM <inner_table> AS i WHERE <correlation>
)
ORDER BY <outer_keys>;

Membership, witness আর universal test

Value/tuple result set-এ আছে চাইলে IN। ভেতরে duplicate outer row বাড়ায় না। Enrollment-এ Ayesha কয়েকবার হলেও students membership একবার দেয়।

যেকোনো qualifying row যথেষ্ট হলে EXISTS। Selected expression অর্থহীন; SELECT 1 readable convention, one গুনতে নয়। NULL-সহ row-ও true, empty false।

Correlated subquery outer value পড়ে। Missing-enrollment-এ inner WHERE current student-এর সঙ্গে enrollment.student_id মেলায়। Student-পিছু প্রশ্ন ভাবো; optimizer বদলাতে পারে, execution strategy promise নয়।

Correlated average নিজের section mean-এ তুলনা। 31-এ 85 আর 65, mean 75, শুধু 85। Overall mean অন্য প্রশ্ন, অন্য student আসতে পারে।

ANY-তে অন্তত এক true। Study price-এর ANY-এর বড় হতে সস্তাটির বড় হলেই চলে। ALL-তে সব true, সবচেয়ে দামিরও বড় চাই। Strict greater-এ equal যথেষ্ট নয়।

Empty-তে ANY false, success দেখানোর candidate নেই। ALL true, ভাঙার candidate নেই। এটি vacuous truth। Business প্রশ্নে মানায় কি না আগে বোঝো।

NULL-এর পাশে অর্থ রক্ষা

Nullable exclusion-এ policy

NOT IN সহজ লাগে, কিন্তু nullable-এ বিপদ। 101 NOT IN (102, NULL)-এ প্রথম inequality true, NULL comparison unknown। মিলিয়ে unknown বলে WHERE বাদ, confirmed non-member নয়।

Missing-related-row-তে NOT EXISTS পরিষ্কার। ভেতরে identity মেলিয়ে existence উল্টাও। Outer NULL key-তেও policy চাই; equality match পায় না। NULL-NULL মিলবে চাইলে null-safe comparison বুঝে।

চাওয়া column-এই correlation

ANY-ALL candidate-এ NULL থাকলেও সতর্ক। এক true ANY প্রতিষ্ঠা, এক false ALL ভাঙে; নইলে unknown থাকতে পারে। Empty rule সত্যিকারের empty-তে, এক NULL row-তে নয়।

Unqualified correlation এড়াও। student_id = student_id inner-কে নিজের সঙ্গে মেলাতে পারে। Alias দিয়ে দুই owner লেখো। Syntax ঠিক self-comparison এক inner row থাকলেই সবার EXISTS true করে।

Tuning-এর আগে readable equivalent

Join rewrite-এ uniqueness দেখো। Unique department key-তে এক match/student, enrollment-এ বহু। শুধু existence হলে EXISTS রাখো বা dedup requirement বলো। Plan-এর আগে semantics।

ছোট group হাতে দেখো, missing আর repeated match-সহ, তারপর empty inner। Ordinary data-তে এক লাগা query আলাদা হয়। পরে index আর EXPLAIN-এ performance দেখো, প্রশ্ন না বদলে।
