Marksheet-এ mark-এর পাশে সেকশন position চাই। GROUP BY বহু ফল এক করে, তাই একা পারে না। Window ফাংশন related রো-তে হিসাব করেও পৃথক mark রাখে।

Window ফাংশন বর্তমান রো-র মান নির্ধারিত related রো দিয়ে করে। সেই দল window। Section ভাগ,mark-এ অর্ডার,প্রতি ফল-এ rank; ইনপুট-পিছু আউটপুট এক রো।

Leaderboard,running পেমেন্ট,পাশের রেকর্ড তুলনায় ভালো। Related মানে কী ঠিক করাই চ্যালেঞ্জ। Partition,অর্ডার,moving frame আলাদা কাজ, মেশালে believable ভুল সংখ্যা।

Seed-এ একই সেকশন-এ equal mark নেই, তাই tie example এক mark local বদলায়। Tie ছাড়া তিন ranking এক লাগে। নিয়ম আলাদা হয় এমন ডেটা দেখাতেই হবে।

OVER তিন অংশে

PARTITION BY independent দল, ভেতরের ORDER BY sequence/peer অর্ডার। Optional frame SUM-AVG-র relevant subset।

Section position-এ PARTITION BY section_id, প্রত্যেকে restart। Overall-এ partition বাদ। পরে display সেকশন-এ সাজালেও calculation population বদলে গেছে।

Window অর্ডার calculation, final কোয়েরি অর্ডার display। Descending rank হিসাব করে ID-তে print চলে, তবে trace কঠিন। Teaching-এ মিলিয়ে দাও।

Tie-এর অর্থ বাছো

ROW_NUMBER 1,2,3 দেয়। Equal mark-এ student_id-র মতো unique tie-breaker repeatable। না থাকলে দুই internal অর্ডার চলে, final display সর্ট আগে ambiguous assigned number সারায় না।

RANK peer-এ same, পরে gap। 80,80,60-তে 1,1,3; প্রথম স্থান দুই রো দখল করে। Current mark-level-এর আগে কত রো আছে ভিত্তিতে ভালো।

DENSE_RANK gap রাখে না: 1,1,2। Distinct mark level গোনে। Best দুই level prize চাইলে dense rank ≤2-এ তিনজনই।

Equal mark tie রাখতে RANK অর্ডার-এ ID দিও না। Peer-কে সব ordering expression মেলাতে হয়; unique ID-তে সবাই আলাদা, রো position হয়ে যায়। ID final display-তে দাও।

পেমেন্ট running মোট-এ partition আর chronology। order_id-তে আলাদা অর্ডার balance, বাদে সব এক। Same তারিখ-এ তারিখ+payment_id deterministic।

Explicit ROWS এক রো করে। 180-এর পরে 1000-এ 1180,380-এ1560,20-এ1580। Original আর cumulative amount পাশে, ধাপ দেখা যায়।

Ordered aggregate-এ explicit frame না দিলে ডিফল্ট RANGE current peer গ্রুপ পর্যন্ত। Same তারিখ-এর দুই পেমেন্ট-এ দুটোসহ মোট হতে পারে। তারিখ পর্যন্ত মোট-এ সঠিক, পেমেন্ট-পিছু ledger থেকে আলাদা।
