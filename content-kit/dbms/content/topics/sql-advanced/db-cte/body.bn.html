সাধারণ নাম আর recursive self-reference

Nonrecursive WITH-এ name,AS,parenthesized SELECT, তারপর main। কয়েক definition এক WITH-এ comma-য়। পরেরটি আগের ওপর হতে পারে, stage-এর অর্থে নাম দাও, লেখা-ক্রমে নয়।

item_totals order_items-কে order_id-তে, payment_totals payment স্বাধীনভাবে group। Final orders-এ summary join। সর্বোচ্চ এক row/order বলেই multiplication ঠেকে। Name-এ cardinality দেখা যায়।

WITH RECURSIVE-এ প্রথম anchor নিজের CTE না পড়ে start row দেয়। Recursive member আগের round expand। Example-এ UNION ALL সব round মেলায়।

দুই member-এর column count-compatible type মেলে। Name আর গুরুত্বপূর্ণ width nonrecursive থেকে। Growing path-এ anchor cast যথেষ্ট চওড়া চাই। শুরু ছোট বলেই পরে সীমাহীন নয়।

Recursive member-এ aggregate,window,GROUP BY,ORDER BY,DISTINCT চলে না; recursive reference placement-ও সীমিত। ভেতরে expansion, বাইরে completed result sort-aggregate-rank।
