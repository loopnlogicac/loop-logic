দুই office department ID list দিল, একটি student থেকে, অন্যটি teacher। সব occurrence,প্রতি ID একবার,শুধু shared ID বা দ্বিতীয়তে নেই এমন ID চাইতে পারো। একই input-এ চার আলাদা প্রশ্ন।

Set operation corresponding position-এর column মিলিয়ে পুরো result মেলায়। Join-এর মতো related record পাশে নয়, একই shape-এর row যোগ,ছেদ বা বিয়োগ। Compatible list স্তরে রাখার পরে repeat-এর আচরণ ভাবো।

SQL result-এ duplicate সাধারণত চলে, একে bag বা multiset বলে। Mathematical set-এ প্রতি value একবার। Attendance,মানুষের count বা আর্থিক event-এ কোন model নাও জরুরি।

আট student চার teacher মিলে বারো department occurrence, distinct মাত্র তিন। বারো আর তিন দুটোই অর্থপূর্ণ, record নাকি department identity গুনছ বলো।

Operator-এর আগে column মেলাও

দুই query-তে column count এক, position-পিছু compatible type চাই। Name matching চালায় না। প্রথমে student_id তারপর section_id হলে দ্বিতীয়তেও একই অর্থের ক্রম।

Output name প্রথম block থেকে। ভালো alias দিয়ে final ORDER BY-তে নাও। শেষ sort পুরো result-এর; input block sort final order promise নয়।

ALL না বললে UNION DISTINCT। দুই input জুড়ে complete duplicate বাদ। UNION ALL সব occurrence রাখে। Student-এ department চারবার teacher-এ দুবার হলে UNION এক, ALL ছয়।

INTERSECT দুইপাশে থাকা row, EXCEPT left-এ আছে right-এ নেই। Default DISTINCT। ALL count-rule-এ multiplicity রাখে, arbitrary duplicate copy নয়।

Mixed operator-এ বন্ধনীতে grouping বলো। MySQL-এ INTERSECT-এর precedence UNION-EXCEPT-এর বেশি। গুরুত্বপূর্ণ eligibility rule বুঝতে পাঠকের precedence মুখস্থ লাগবে না; port করতেও ভালো।

Complete row আর occurrence গুনো

INTERSECT DISTINCT দুই input-এ থাকা প্রতিটি complete row একবার। Registered আর recorded result-এ একই student থাকলে আসে; বহু result হলেও distinct intersection-এ এক ID।

EXCEPT DISTINCT distinct left থেকে right member বাদ। Enrollment minus result-এ Sadia 107। Fahim enrollment-এই নেই, তাই candidate নয়। Students minus enrollment অন্য প্রশ্ন, Fahim পায়।

INTERSECT ALL দুই count-এর ছোটটি। Dept 1 student-এ চার teacher-এ দুই, থাকে দুই। 2 আর 3 student-এ দুই teacher-এ এক, থাকে এক করে। মোট চার row।

EXCEPT ALL left count থেকে right বাদ, minimum zero। Left তিন CSE right দুই হলে এক; উল্টে কিছু নেই। Difference directional, compatible union-intersection membership symmetric।

Set duplicate comparison দুই NULL equal ধরে। সাধারণ NULL = NULL এখনও unknown। Town উদাহরণে missing আর Dhaka দিয়ে shared NULL intersection-এ একবার দেখায়।

সব projected column মেলে। Department-এর পাশে student_name দিলে dedup identity বদলায়। দুই CSE student-এর নাম আলাদা হলে complete row আলাদা। আগে projection, তারপর operation; wide-row DISTINCT নিজে narrow identity প্রশ্ন নয়।

Duplicate removal অর্থের পছন্দ

বড় output ছোট করতে ALL-কে UNION কোরো না। একই displayed field-এর দুই আসল transaction দুটোই চাইতে পারে। আবার এক town একবার directory-তে ALL ভুল। Cost-এর আগে অর্থ।

Population আর repetition বলো

প্রতি input-এর filter-projection এক বাক্যে, তারপর repeat জরুরি কি না। Eligibility-তে membership, event accounting-এ প্রতিটি occurrence সাধারণত জরুরি। Long result-এর আগেই ভুল ধরা যায়।
