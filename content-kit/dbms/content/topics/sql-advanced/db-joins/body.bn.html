Pair rule আর কোন পাশ থাকবে বাছো

INNER JOIN ON true pair নেয়। LEFT JOIN partner না পাওয়া left রো-ও রাখে, right কলাম NULL হয়। RIGHT JOIN right ইনপুট-কে একইভাবে রাখে।

students AS s LEFT JOIN enrollments AS e ON e.student_id = s.student_id বাম থেকে পড়ো। Students রাখার population, enrollment optional match। ON বর্তমান শিক্ষার্থী-এর registration চেনায়। ছোট alias-এ কলামের owner স্পষ্ট।

CROSS JOIN সব possible pair। আট শিক্ষার্থী ছয় সেকশন-এ 48, কখনো না হওয়া registration-ও। Self join এক টেবিল দুই alias-এ, যেমন প্রথম-দ্বিতীয় classmate-এর role।

MySQL native FULL OUTER JOIN নেই। Left জয়েন-এর সঙ্গে শুধু unmatched right রো-এর branch মেলাও। Legitimate duplicate রাখতে UNION ALL। দ্বিতীয় branch-এ left-এর non-null কী পরীক্ষা, optional description নয়; নইলে matched-ও missing মনে হয়।

SELECT <columns>
FROM <left_table> AS l
LEFT JOIN <right_table> AS r ON <matching_condition>
WHERE <result_filter>
ORDER BY <display_keys>;
