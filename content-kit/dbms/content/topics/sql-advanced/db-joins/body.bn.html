শুধু table নয়, সম্পর্ক জোড়ো

Department noticeboard-এ code, student register-এ প্রত্যেকের department ID। Join-এ নাম প্রতি student row-তে না রেখেও একসঙ্গে পড়ো। কোন pair মেলে আর একপাশে না মিললে কী হবে, তুমি বাছো।

Join condition মেনে row মেলায়। পরিচিত নিয়ম foreign key-কে referenced key-তে মেলানো, যাতে সঠিক department আসে। অন্য column-ও তুলনা চলে; নাম কাছাকাছি বলেই SQL সম্পর্ক বাছে না।

আগে বলো এক output row কী: student,enrollment নাকি payment? একে result-এর grain বলে। অপ্রত্যাশিত grain বদলালে syntax ঠিক report-ও ভুল প্রশ্নের উত্তর দেয়।

University-তে আট student, বারো enrollment। Fahim 108-এর enrollment নেই, Sadia 107-এর enrollment আছে result নেই। মানুষ রাখা আর recorded activity রাখার ফারাক দেখায়।

Pair rule আর কোন পাশ থাকবে বাছো

INNER JOIN ON true pair নেয়। LEFT JOIN partner না পাওয়া left row-ও রাখে, right column NULL হয়। RIGHT JOIN right input-কে একইভাবে রাখে।

students AS s LEFT JOIN enrollments AS e ON e.student_id = s.student_id বাম থেকে পড়ো। Students রাখার population, enrollment optional match। ON বর্তমান student-এর registration চেনায়। ছোট alias-এ column-এর owner স্পষ্ট।

CROSS JOIN সব possible pair। আট student ছয় section-এ 48, কখনো না হওয়া registration-ও। Self join এক table দুই alias-এ, যেমন প্রথম-দ্বিতীয় classmate-এর role।

MySQL native FULL OUTER JOIN নেই। Left join-এর সঙ্গে শুধু unmatched right row-এর branch মেলাও। Legitimate duplicate রাখতে UNION ALL। দ্বিতীয় branch-এ left-এর non-null key পরীক্ষা, optional description নয়; নইলে matched-ও missing মনে হয়।

SELECT <columns>
FROM <left_table> AS l
LEFT JOIN <right_table> AS r ON <matching_condition>
WHERE <result_filter>
ORDER BY <display_keys>;

সম্পর্কের শর্ত দেখাও

Explicit ON আর shared column qualify। NATURAL JOIN schema-তে নতুন matching column পেলে নীরবে বদলায়, সাধারণ JOIN ভালো। Promised column-ই নাও, grain দেখা সহজ।

জটিল report-এর আগে count আন্দাজ। নতুন সম্পর্ক one-to-one,many নাকি optional? Row অপ্রত্যাশিত বাড়লে DISTINCT-এর আগে match দেখো। Dedup ভুল condition লুকাতে পারে।

MySQL outer-join সীমা

8.0 আর 8.4-তে চলে, FULL OUTER এখনও emulation। Shared schema-য় enforced CHECK 8.0.16+। পুরো result-এর ORDER BY display ঠিক করে, index বা branch order নয়।

Report population স্পষ্ট

কাকে রাখবে, matching key আর row-পিছু partner count ঠিক করো। Missing data আর duplicate total বোঝা সহজ। পরের subquery-তে সব pair নয়, comparison,membership বা existence প্রশ্ন করবে।
