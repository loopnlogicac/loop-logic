৪০. Department 1-এ আছে অথবা অন্তত 80 নম্বর পেয়েছে এমন শিক্ষার্থী identifier একবার করে দাও। কঠিন। UNION দুই source-এর duplicate membership সরায়।

সমাধান ৩১–৪০

ওপরের একই নম্বরের প্রশ্নের সঙ্গে কোয়েরি মেলাও। কোয়েরির ক্রমে ফল টেবিল পড়ো। শুধু সংখ্যা মেলায় সন্তুষ্ট না হয়ে পরিচয়, অনুপস্থিত সম্পর্ক ও tie যাচাই করো।

কাজ ৪১–৫০: window ও কয়েক ধাপের রিপোর্ট

৪১. প্রতি সেকশন-এ নম্বরের rank করো; সমান নম্বরে rank সমান রাখো। কঠিন। শুধু নম্বর tie ঠিক করলে RANK-এর ordering-এ student_id দেবে না।

৪২. প্রতি শিক্ষার্থী-এর ফল বেশি নম্বর আগে রেখে সাজাও; tie-তে সেকশন-id নাও। কঠিন। নির্দিষ্ট individual অর্ডার পেতে ROW_NUMBER-এ unique tie-breaker লাগে।

৪৩. প্রতিটি ফল ও সেকশন গড় থেকে তার পার্থক্য দুই দশমিকে দেখাও। কঠিন। Window ফল রো রেখে সেকশন aggregate যোগ করে।

৪৪. CTE দিয়ে অন্তত তিন enrollment-এর সেকশন সংখ্যা দেখাও। কঠিন। বাইরের কোয়েরি নাম দেওয়া সংখ্যা stage ছাঁকে।

৪৫. প্রতি ভর্তি শিক্ষার্থী-এর সর্বশেষ registration দেখাও; তারিখ tie হলে বড় সেকশন id নাও। কঠিন। Window হিসাব করা কোয়েরির বাইরে তার মান ফিল্টার করো।

৪৬. প্রতি সেকশন-এর সর্বোচ্চ দুই distinct নম্বর দেখাও, dense rank দুইয়ের tie-সহ। কঠিন। DENSE_RANK আলাদা mark level গোনে; দুইয়ের বেশি শিক্ষার্থী আসতে পারে।

৪৭. তারিখ ও id ক্রমে ভর্তি শিক্ষার্থীর running সংখ্যা দেখাও। কঠিন। স্পষ্ট ROWS frame একই admission তারিখ-এর রো-ও একে একে গোনে।

৪৮. খালি সেকশন-সহ প্রতিটির enrollment সংখ্যা সব সেকশন-এর গড় সংখ্যা-এর সঙ্গে তুলনা করো। কঠিন। আগে সেকশন অনুযায়ী aggregate করো, তারপর ছয়টি সংখ্যা-এর ওপর window নাও।

৪৯. রেকর্ড করা ফল আছে এমন শিক্ষার্থী-এর credit-weighted grade point বের করো। কঠিন। Grade point-কে credit দিয়ে weight দাও; অপেক্ষমাণ ফল বাদ। Retake replacement এই ডেটাসেটের বাইরে।

৫০. Enrollment নেই এমন CSE কোর্স-সহ catalogue-এর সব CSE কোর্স নেওয়া শিক্ষার্থী দেখাও। কঠিন। CSE 121-এ কেউ ভর্তি নয়, তাই ঠিক উত্তর খালি। Required কোর্স set-ই খালি হলে division vacuously true হতো।

সমাধান ৪১–৫০

ওপরের একই নম্বরের প্রশ্নের সঙ্গে কোয়েরি মেলাও। কোয়েরির ক্রমে ফল টেবিল পড়ো। শুধু সংখ্যা মেলায় সন্তুষ্ট না হয়ে পরিচয়, অনুপস্থিত সম্পর্ক ও tie যাচাই করো।

সিনট্যাক্স বদলানোর আগে প্রশ্নের অর্থ পরীক্ষা করো

NULL-দিয়ে বাড়ানো রো গোনা

LEFT JOIN-এর পরে COUNT(*) child-হীন শিক্ষার্থী-এর জন্যও এক গুনতে পারে। COUNT(e.section_id) প্রকৃত enrollment match গোনে। শূন্যসহ enrollment সংখ্যা চাইলে child কী নাও।

ফল জয়েন-এ কী-এর একটি কলাম নেওয়া

এক শিক্ষার্থীর একাধিক সেকশন-এ নম্বর থাকতে পারে। Enrollment-এর সঙ্গে ফল দুই identifier দিয়েই জয়েন করো, নইলে অন্য ফল ভুল registration-এ জুড়বে। রিপোর্ট-এর সব ধাপে composite পরিচয় রাখতে হবে।

একই WHERE-এ rank ছাঁকা

নিজের কোয়েরি block-এর window value তৈরি হওয়ার আগেই WHERE চলে। CTE বা derived টেবিলে rank বের করে বাইরে ফিল্টার করো। Tie-এর নীতি অনুযায়ী RANK, DENSE_RANK বা ROW_NUMBER নাও।

Shared MySQL baseline ব্যবহার করো

উত্তরগুলো MySQL 8-এর window ও CTE নেয়; native INTERSECT বা EXCEPT লাগে না। স্কিমার CHECK কনস্ট্রেইন্ট-এর জন্য MySQL 8.0.16 বা নতুন লাগে। কোয়েরি shared রো বদলায় না, তাই বারবার চেষ্টার ফল তুলনা করা যায়।

প্রতি রো কেন রইল বোঝাও
