Give the program a route

A class routine can resemble a campus notice board: some instructions apply only to certain students, while others repeat for everyone. Control flow is the order in which statements run. Branches choose a route; loops repeat a route until a condition says to stop.

Java keeps much of the if, switch and loop structure you know from C. The crucial starting rule is that conditions must be boolean. Java will not treat an arbitrary integer as true or false. An explicit comparison makes the intended decision clear.

This lesson adds convenient ways to visit array values and choose a result with switch. An array is an ordered group of values, introduced fully in Arrays in Java. For now, read an array initializer as a short list and its length as the number of elements.

Choose statements or values

Use if when a decision depends on a boolean expression. A traditional switch statement is useful when one value selects among cases. An arrow switch avoids accidental fall-through. A switch expression goes further by supplying a value for an assignment.

if (mark >= 40) {
    // Handle a passing mark.
} else {
    // Handle a lower mark.
}
String label = switch (day) {
    case 5, 6 -> "Weekend";
    default -> "Class day";
};

The expression's arms must cover its possible inputs. The default arm handles unlisted values here. A block arm can contain several statements and use yield to supply its result. An arrow arm does not need break to prevent fall-through.

Trace the check, body and update

A normal for loop performs its initialization once. It checks its condition before each body execution, then performs its update. continue skips the remaining body statements but still reaches the for update. A while loop checks before entering its body; a do-while loop checks after it.

An enhanced for loop reads elements in sequence without exposing an index. Its syntax gives an element type, local variable, colon and array. For an int array, the variable receives a copy of each int value. Assigning that local does not replace the stored element.

A labelled break names an enclosing statement to leave. Place a clear label immediately before the outer loop you want to exit. An unlabelled break would leave only the nearest loop or switch. Use a label for a specific nested search rather than treating it as a general jump.

For a row search, choose what first means before writing code. Row order means finishing columns in row zero before moving to row one. Save the coordinates when a match appears, then leave both search loops. If no match appears, keep the initial missing-result coordinates.

Empty work, boundaries and nested exits

A loop whose initial condition is false runs zero times. This is useful for an empty list or a count of zero. Do not add a special body execution unless the task requires one. A do-while is different because its first execution occurs before any check.

Boundary comparisons should match the problem wording. At least 40 includes 40, so use >=. Below 40 excludes it, so use <. When counting indices from zero, the usual upper condition is index < length. Using <= would try one position beyond the array.

Traditional colon-style switch cases can fall through unless control leaves the switch. Arrow cases do not. If you read older Java code, inspect the case syntax before assuming which behaviour applies. Mixing up the two styles can change both printed text and accumulated totals.

An enhanced for variable can also hold an object reference. Reassigning that variable still does not replace an array element. A method called through it may change the shared object, however. The distinction is the same reference-value rule explained in Methods.

A labelled break ends the labelled loop but does not end the method. Statements after the loop still run. This makes it useful for a search followed by one reporting step. Choose a meaningful label such as search rather than a vague letter.

Keep the intended route visible

Using an integer as a condition

Writing while (count) does not compile when count is int. State the test, such as count > 0. The comparison tells a reader what progress the loop expects.

Replacing elements through a copied loop variable

In for (int mark : marks), assigning mark changes only that local variable. Use an indexed loop when your task is to write marks[index]. Enhanced for is clearer for totals and read-only visits.

Leaving only the inner search

A plain break stops the current inner loop. The next outer iteration can continue searching or overwrite your saved answer. A labelled break can leave the whole nested search at the first match.

Recognise the newer switch form

Enhanced for was introduced in Java 5. Switch expressions became a permanent feature in Java 14. They work under Java 17 without preview flags. The older statement forms remain useful when you need actions rather than a computed result.

Choose the clearest route for the task

Use explicit boolean conditions, ordinary loops for indexed changes, and enhanced for for visiting values. A switch expression can name a result directly, while a labelled break can finish a nested search. Continue by grouping repeated work into methods.
