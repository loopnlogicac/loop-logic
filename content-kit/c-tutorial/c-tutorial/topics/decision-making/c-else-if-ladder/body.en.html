Introduction

A result sheet needs more than Pass or Fail. Different marks belong to different grade bands. An else-if ladder asks a sequence of questions until one succeeds. Only the first matching branch runs.

If none succeeds, a final else can handle the remaining case.

Picture checking labeled shelves from top to bottom. Once you place the result on its matching shelf, you stop looking. The order of the shelves therefore matters. A broad condition placed too early can catch a mark before its more specific grade is considered.

Syntax and reading guide

if (marks >= 80) {
    puts("A+");
} else if (marks >= 75) {
    puts("A");
} else {
    puts("Lower band");
}

Follow the values and decisions

Begin with a validated mark from zero to one hundred. Ask whether it is at least eighty. If true, print A+ and leave the chain. If false, you already know the mark is below eighty.

The next question can ask only whether it is at least seventy-five; it does not need to repeat the upper bound.

For seventy-seven, the first comparison fails and the second succeeds, selecting A. For eighty, the first succeeds and the second is never evaluated. For seventy-four, both fail. These cases show why the boundaries and order must agree.

Validate the input before assigning a grade so an impossible value does not silently enter the highest or lowest band.

A ladder differs from several independent if statements. Independent comparisons can print many grades for a high mark. A ladder's earlier false conditions provide context for each later branch, and the first true branch ends the choice. This helps avoid duplicate output and makes the decision easier to trace.

Examples

Select a high grade

Seventy-seven fails the eighty threshold and passes seventy-five. The first matching branch prints A. It needs no explicit upper limit because reaching it already means the first test failed.

Classify a signed difference

Zero fails both strict sign comparisons, so the final else handles it. These three categories cover every permitted integer. The output illustrates a final case whose meaning follows directly from the earlier failures.

Use ascending size limits

Twenty-five exceeds the small-room limit but fits the medium-room limit. The ascending upper bounds must be ordered from smallest to largest. Reversing them would hide the small category inside the broader first condition.

You can also build a ladder from ascending upper limits. In that design, test the smallest upper limit first. Do not mix descending lower limits with ascending ordering. Write a trace row for each threshold and the value immediately below it.

Common mistakes

Testing mark >= 40 first in a descending grade chain

That branch captures every passing mark, including ninety. Put the most restrictive high threshold first, or redesign the whole chain around ascending upper limits.

Leaving the final case unexplained

A final else is useful when prior branches cover all but one valid category. Validate impossible inputs separately. Do not use the final grade as an accidental error handler for a mark outside zero to one hundred.

Questions to ask while reading

QuestionRule and reason
How many matching branches does a ladder run?Only the first. The rest of the chain is skipped after a match.
For descending lower-bound grade tests, which threshold belongs first?The highest threshold. A broad low threshold would hide higher categories.
What is already known when the mark >= 75 branch follows a failed mark >= 80 test?The mark is below 80. The earlier false condition supplies the upper limit.
Which keyword token is else-if in C?It is two keywords, else and if. The else controls another if statement.
What should happen before grading an input mark?Check that it belongs to the valid range. An impossible mark should not receive a normal grade.
How should ascending upper limits be ordered?Smallest first. A larger first upper limit would capture smaller bands.
Which values best reveal a grade boundary error?The threshold and neighboring values. Neighbors show which side owns equality.

Walk the edge of each grade band

Seventy-nine belongs to A, while eighty belongs to A+. Seventy-four belongs to A-, while seventy-five belongs to A. These neighboring pairs expose both ordering and equality mistakes. For every threshold in the table, compare the threshold with one less than it.

Zero and one hundred then verify the overall valid interval.

In an exam explanation, list the false tests before the selected branch. For a mark of sixty-seven, the checks for eighty, seventy-five and seventy fail, then sixty-five succeeds. The output B+ follows from that path. Writing only the final label misses the reason the surrounding bands do not apply.

A final else can name the lowest valid band only after earlier input validation has excluded impossible marks.

Version notes

else if is an else whose controlled statement is another if; it is not a separate C keyword. The structure works across C89 to C23. These examples use C17 and explicitly braced branches.
