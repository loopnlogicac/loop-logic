Reuse a tool after reading its label

You already use printf without writing a terminal driver. The standard library offers many other reusable tools: convert text, sort arrays, search sorted data, generate pseudo-random values and work with time. Each tool saves implementation effort, but only when you respect the job its interface actually promises.

A kitchen measuring cup is useful because its markings have a meaning. Passing the wrong element width to qsort is like measuring with an unlabelled cup: the tool may run, but the result cannot be trusted. Before calling a library function, identify the input representation, the success result and the assumptions that remain your responsibility.

This tour groups related functions so you can choose a starting point. It is not a claim that every function in a header is interchangeable. Conversion, sorting and time each have different failure and portability rules. Use the references when an application needs details beyond the small examples here.

Include the correct header rather than writing an improvised prototype. A wrong declaration can make a call invalid even when the linker finds a similarly named function. Some mathematical functions also need the platform's documented linking option, commonly -lm with GCC on Unix-like systems. A header declaration and a linked implementation are different requirements.

Convert, compare and locate deliberately

atoi converts a decimal prefix to int but does not provide the diagnostics needed for robust arbitrary-input validation. strtol supplies an end pointer and a documented range indication. Clear errno before conversion, require at least one converted digit, inspect remaining characters and reject ERANGE. Apply any narrower application range afterwards. The earlier argument lesson develops that sequence in full.

qsort receives an array base, an element count, an element width in bytes and a comparator. The library calls the comparator with pointers to elements. The comparator must return only a meaningful sign; its exact magnitude is irrelevant. Returning a minus b can overflow, so the example combines relational results instead.

bsearch needs an array already ordered by a compatible comparator. It returns a pointer to a matching element or null. Check for null before dereferencing. For duplicate keys, do not assume that it chooses the earliest match. qsort likewise does not promise to preserve the original order among equal elements. Add a tie-break rule when the application needs one.

Keep size calculations attached to the actual array where its full type is known. sizeof array divided by sizeof array[0] counts local array elements, but the same expression on a pointer parameter does not recover the caller's array length. Pass the count explicitly across a function interface.

Pseudo-random values and process control

rand produces a nonnegative pseudo-random integer no larger than RAND_MAX. srand selects a starting seed. Reusing a seed repeats the sequence within the implementation, which is useful when debugging. The standard does not prescribe one numeric sequence for every C library, and the generator is not appropriate for secrets or security decisions.

The expression rand() % 6 creates values from zero through five, but may introduce modulo bias when the generator range does not divide evenly into six groups. A production simulation should choose an appropriate generator and sampling method for its accuracy requirements. Seeding from changing time also makes an example harder to reproduce; the demonstration uses a fixed seed and prints repeatability instead.

abs returns an int absolute value only when the result is representable. INT_MIN may have no positive int counterpart, so abs(INT_MIN) is not a safe general magnitude operation. Wider variants have the same representability concern for their own most-negative value. Choose a representation and precondition that match the range you actually need.

exit ends the whole program, not just the current helper. EXIT_SUCCESS and EXIT_FAILURE express portable success and failure statuses. Returning a status from a helper lets its caller decide what to do; calling exit there removes that choice. Keep process termination near the application boundary when writing reusable modules.

Ask whether you need a date or CPU work

time obtains a calendar-time representation when the environment can provide it. Check for (time_t)-1 before using the result. Do not assume time_t is an integer number of Unix seconds on every implementation. Use difftime to obtain a seconds difference between valid calendar-time values.

localtime and gmtime convert calendar time to broken-down fields in struct tm, using local time or UTC respectively. They can return null, and their returned storage may be reused by later time conversions. Copy fields if you need to retain them. tm_year counts from 1900; tm_mon counts from zero. Those offsets are easy to overlook when constructing a date.

strftime formats fields into a bounded character buffer. Check its return value before printing the result. Locale and timezone can change some formatted text, so this example constructs a numeric date rather than printing the current local date. clock addresses processor time, with CLOCKS_PER_SEC giving its scale and (clock_t)-1 indicating unavailability; processor time is not the same as wall elapsed time.

Keep hidden assumptions out of utility calls

Searching before sorting

bsearch is not a replacement for a general linear scan of arbitrary data. Sort with a compatible ordering first, preserve an already sorted invariant, or choose another search. The element width must describe the actual object type.

Assuming library success validates application meaning

A converted long can still be an invalid mark. A matching roll can still belong to an inactive record. Treat library results as one stage in the application's validation, not proof of every business rule.

Printing changing measurements as fixed answers

The current date, elapsed duration and implementation-specific random sequence do not have a universal fixed output. Teach their contracts with stable comparisons or clearly state environmental dependence. Avoid confusing a reproducible example with a promise that every host has the same clock or generator.

A C17 tour with long-established interfaces

The selected functions are available under C17 and mostly come from much earlier C standards. Exact time representation, locale details and pseudo-random sequences remain implementation choices. Newer standards add facilities, but existing calls still require correct ranges, object sizes and failure handling.

Choose the operation and check its contract

Use declared interfaces, validate complete conversions, agree on array ordering and distinguish calendar time from processor work. Keep process termination separate from reusable helpers. Next, error handling brings these success and failure decisions into one consistent application design.
