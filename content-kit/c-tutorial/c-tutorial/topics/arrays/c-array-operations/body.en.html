An array has storage and a used portion

A classroom mark list may reserve space for sixty students while containing only forty marks today. The reserved space is the capacity. The number currently used is the logical length. Many array operations change the length without changing the capacity.

A traversal reads each used element for a total, average or comparison. Insertion and deletion additionally move values to preserve their order. The direction of movement matters because a write can overwrite a value that another step still needs.

You already know how to select one array element. This lesson combines that access with accumulators, comparisons and shifts. Before each operation, decide whether an empty range is meaningful and whether enough storage exists for the result.

Use one loop for one traversal

int sum = 0;
for (int i = 0; i < n; i++) {
    sum += values[i];
}
double average = (double)sum / n;

The sum starts at zero because zero is the additive identity. The average expression requires n greater than zero. Casting sum before division preserves a fractional result. Casting an already-truncated integer quotient would not repair it.

For a nonempty range, initialize minimum and maximum from values[0]. Then compare the remaining elements. Starting maximum at zero fails for an all-negative list. Starting minimum at zero fails for an all-positive list unless zero actually occurs.

Shift in the direction that preserves unread values

To insert at position p, first check that n is less than capacity and p lies from zero through n. Move elements from the old last element backward toward p. Each old element goes one slot to its right. Then store the new value at p and increase n.

Insert 30 at position 2, capacity 6
before: [10][20][40][50][  ][  ]   n=4
shift:  [10][20][40][50][50][  ]
shift:  [10][20][40][40][50][  ]
store:  [10][20][30][40][50][  ]   n=5

If shifting started at p and moved forward, copying 40 onto 50 would destroy the old 50 before it could move. The backward loop avoids that data loss. The unused destination at index n is valid only because spare capacity was checked first.

Deletion uses the opposite direction. Replace the deleted slot with its successor, then keep moving left through the suffix. Decrease n after the shift. A leftover value outside the new logical range need not be erased for an ordinary int list.

Find the second distinct largest

The frequency example has a domain from zero to four. A five-element counter array therefore has a valid position for each possible input value. With arbitrary negative values or huge integers, this direct indexing would be unsafe and wasteful.

The second-largest helper returns a success flag separately from its output. A one-element list and an all-equal list have no second distinct value. The helper does not invent a numeric sentinel that might also be legitimate input.

Define what second largest means

For the values 9, 9, 7 and 4, the second distinct largest value is 7. If duplicates occupied separate ranking positions, a different task might answer 9. Read the wording before choosing an algorithm. Here equal maxima are deliberately excluded.

Maintain the largest seen value, a candidate second value and a flag saying whether that candidate exists. A new largest moves the previous largest into second place. A smaller distinct value can improve second place. The flag prevents reading an uninitialized candidate.

Reversal uses two indices that move inward. Swap the endpoints, then move left forward and right backward. Stop when left meets or passes right. An odd-length list leaves its central element untouched. An empty range performs no swaps when the signed right index starts at minus one.

Inserting into an empty range is valid at position zero if capacity exists. Inserting at position n appends a value and requires no element shifts. Deleting from an empty range is invalid, while deleting the only element leaves a zero logical length.

The statistics example restricts marks to zero through one hundred and length to twenty. Its int sum therefore remains small. General integer arrays may need a wider accumulator or checked addition. Choosing a wide type does not remove every possible overflow risk.

Count the work of each operation

A total, minimum, maximum or reversal visits at most a constant number of times per element. Each takes O(n) time. Reversal needs O(1) extra working storage because one temporary holds a swapped value.

Insertion and deletion can shift almost n elements near the front, so their worst-case time is O(n). Appending into spare capacity can take O(1) time. A direct frequency table takes O(n+k) time to count and report k possible values, with O(k) counter storage.

The second-distinct-largest scan takes O(n) time and constant extra storage. Sorting first would also reveal the answer, but sorting does more work than this single requested statistic needs. Choose an operation that matches the actual question.

Check the used range before reading

Dividing an empty total by zero

Zero is a valid sum for an empty range, but its average is not defined by this task. Require at least one element before calculating an average, or report an explicit empty result.

Using the wrong shift endpoint

Insertion writes the new last slot at old index n. Deletion reads only through old index n minus one. Trace the first and final copy to check that neither loop steps outside the available storage.

Counting frequency without validating values

A value used as a counter index must fit the counter array. Reject out-of-domain input before incrementing. The frequency table's length depends on the value domain, not just the number of input items.

Separate movement from reporting

Finish an operation before printing its final list. Mixing prints with shifts can show temporary duplicate values that are not the intended result. Keep n updated exactly once after successful insertion or deletion.

Try a front position, an end position and a one-element list. Include all-equal and all-negative data for the runner-up task. These cases check the meaning of the operation more directly than another long random list.

No automatic array growth

The fixed-capacity algorithms here work in C17 without variable-length arrays. C arrays do not grow when an insertion needs another slot. Dynamic resizing requires a separate allocation strategy, introduced in later memory-management lessons.
