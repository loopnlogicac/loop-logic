Introduction

Suppose thirteen students need transport, with five seats in each row. Division tells you how many complete rows are filled; remainder tells you how many students remain. Arithmetic operators express calculations such as these. C provides addition, subtraction, multiplication, division and integer remainder.

The symbols look familiar, but the operand types control the answer. Integer division keeps a whole-number quotient. Floating division can keep a fraction. You should decide which meaning the task needs before writing the expression.

A double variable on the left cannot restore a fraction already lost by integer division.

Syntax and reading guide

sum = a + b;
difference = a - b;
product = a * b;
quotient = a / b;
remainder = a % b;

Percent is the remainder operator in an expression. Inside a printf format it begins a conversion instead. The multiplication sign is a star, not the letter x.

Follow the values and decisions

For integers in C17, division truncates toward zero. Thus 13 / 5 gives 2 and -13 / 5 gives -2. Remainder fits the identity a == (a / b) * b + a % b whenever the quotient is representable. For negative thirteen, the identity becomes negative thirteen equals negative two times five plus negative three.

A nonzero remainder has the same sign as the dividend, the value before percent. Changing the divisor's sign changes the quotient's sign, but not that remainder sign. Try all four sign combinations on paper. You will see that C remainder is not always the nonnegative modulo operation used in mathematics.

The percent operator accepts integer operands only. For a floating remainder, include math.h and use fmod. A function is a named operation; this one returns a floating remainder with the dividend's sign. On many Unix toolchains you link the mathematics library with -lm.

The floating example compares fmod with ordinary integer percent so their separate types remain visible.

Examples

Complete rows and remaining students

Thirteen divided by five fills two complete groups. Three students remain because two times five plus three is thirteen. The quotient is useful for complete rows; the remainder describes the unfinished row. Both operands are int, so no fractional quotient is produced.

Negative quotients and remainders

Both quotients are negative two, but the remainders differ. Negative thirteen leaves negative three; positive thirteen leaves positive three. The dividend controls the remainder sign. Substituting each pair into the quotient-remainder identity verifies the result without guessing a sign rule.

Keep a fractional average

The first division computes two. The second converts total to double before dividing, producing 2.60 in the report. Two decimal places describe output formatting. They do not force the first integer division to preserve its missing fraction.

Remainder for a measured quantity

fmod removes three whole multiples of two from seven and a half, leaving one and a half. This is a library function for double operands, not an overloaded percent operator. The source includes math.h and the build links with the mathematics library.

Boundaries and alternatives

A zero divisor is invalid for integer division and remainder. The signed minimum divided by negative one is another dangerous case when the positive result cannot fit. Signed overflow is undefined behavior: C promises no resulting wrapped value. Bound inputs before the calculation, and choose a suitable type for intermediate products.

For a marks average, compare (double)total / count with (double)(total / count). The first changes an operand before division; the second converts a whole quotient afterward. See casting for the conversion rules. Keep price calculations in whole small units when exact integer amounts are sufficient.

Common mistakes

Using percent with a double

An expression such as 5.5 % 2.0 violates the operand rule. Use fmod for floating operands. Converting both operands to int would change the problem by discarding their fractions.

Widening only the destination

A long long destination does not force an int multiplication to use long long. Convert an operand first, then check that the wider product fits. The important type is the type at the operation itself.

Questions to ask while reading

QuestionRule and reason
What is the type rule for the % operator?Both operands must have integer type. Remainder is an integer operator; fmod is the floating alternative.
In C17, which direction does -13 / 5 truncate?Toward zero. The quotient is -2.
Which sign does a nonzero integer remainder have?The dividend sign. The quotient-remainder identity determines that sign with truncation toward zero.
Which expression retains 13 divided by 5 as a fractional value?(double)13 / 5. Changing an operand makes the division floating-point.
Which library function gives a double remainder?fmod. fmod is declared in math.h.
What must you do before integer division by a variable?Ensure the divisor is nonzero and the quotient fits. Zero division and an unrepresentable signed quotient are invalid.
What does ordinary signed integer overflow guarantee?No result is prescribed by C. Its behavior is undefined, even if one machine appears to wrap.

When a remainder changes the final task

The transport task asks for complete rows, but a booking task may ask for enough rows to seat everyone. For thirteen students and five seats, two complete rows are insufficient. Add one extra row when the remainder is nonzero. For zero students, no extra row is needed.

This distinction comes from the task's meaning, not a different division operator. State whether the required answer is a quotient, a remainder, or a rounded-up capacity before writing code.

Version notes

C99 specified truncation toward zero for signed integer division. The examples use that rule in C17. Earlier C editions allowed more variation for negative quotients; do not generalize an old textbook remainder table.
