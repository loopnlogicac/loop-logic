Introduction

A balance changes after you pay a fare. In C, assignment stores a new value in an existing object. The expression on the right is evaluated, converted to the destination type, and stored on the left. The equals sign means an action, not a claim that two values are equal.

Often the new value depends on the old value. Compound assignments provide a shorter form for these updates. You will use them to add deposits, deduct fares and change flag bits. Keep each update readable enough that you can follow the balance by hand.

Syntax and reading guide

balance = 100;
balance += 20;
balance -= 5;
/* Other forms: *= /= %= &= |= ^= <<= >>= */

The left operand must identify a modifiable object. A literal or the result of ordinary addition cannot be the destination. A const-qualified object cannot be reassigned after initialization.

Follow the values and decisions

For an ordinary integer variable, balance += 20 adds twenty to its old value and stores the sum back. You can understand it like balance = balance + 20. The compound form evaluates its left operand only once, which matters for more complex destinations introduced later.

Follow a starting balance of one hundred. Adding twenty produces one hundred twenty. Deducting five leaves one hundred fifteen. Multiplying by two doubles that current value, not the original balance.

Each completed statement changes what the next statement reads.

An assignment is also an expression. It supplies the value after storing and conversion. Thus saved = (balance = 25) stores twenty-five in balance and then in saved. Assignment associates from right to left, so a = b = 7 groups as a = (b = 7).

This is valid, but separate statements are often clearer when the variables have different meanings.

Compound assignment still follows arithmetic and conversion rules. For an int, x /= 2 performs integer division. An unsigned destination can wrap, while a signed arithmetic overflow remains undefined. A shorter symbol does not add a safety check or preserve missing fractions.

Examples

Update a taka balance

Each statement reads the latest balance and replaces it. The deposit takes the balance to one hundred twenty; the fare leaves one hundred fifteen. The original one hundred is no longer stored in balance unless you saved another copy.

Trace chained assignment

The right assignment stores seven in b and supplies seven to the assignment into a. Both become seven. This is right association of the grammar, not a general rule that every C expression executes from right to left.

Update flag bits

OR adds the bit with value four, giving five. XOR removes the existing low bit, leaving four. Shifting left once gives eight. The unsigned values and small shift count keep the bit operations well-defined.

Boundaries and alternatives

The bitwise compound forms use integer bit patterns. OR-assignment can set selected flags; AND-assignment can keep selected flags; XOR-assignment toggles selected bits. Shift-assignment moves the bits subject to the same shift restrictions as the ordinary shift operators. See bitwise operators for masks and valid shift counts.

When the right-hand result has a different type, conversion occurs before the destination stores it. For example, assigning a finite in-range 3.9 to int stores three. A chained assignment through that int would propagate the stored integer value. Avoid chains across different types unless this conversion is exactly what you intend.

Common mistakes

Using = where a question is intended

Assignment can produce a nonzero value that looks true in a condition. Use == to compare. Read the left side as a destination whenever you see a single equals sign.

Assuming += avoids overflow

The addition must still have a valid result for its calculation type. Choose bounds that fit before updating the object. Inspect long sequences of updates as carefully as one large formula.

Questions to ask while reading

QuestionRule and reason
Which operand of assignment names the destination?The left operand. The right-hand value is stored into the left object.
What is the ordinary-variable meaning of x += 3?Add 3 to x and store the result in x. It combines addition with storage.
How does a = b = 7 group?a = (b = 7). Assignment associates right to left.
What value does an assignment expression supply?The value after storage conversion. A later assignment can receive the newly stored value.
For an int x, what arithmetic does x /= 2 use?Integer division. The compound form retains the integer operand rules.
Which compound operator toggles selected flag bits?^=. XOR flips positions where the mask contains ones.
Can a compound assignment destination be a const int?No. The destination must be modifiable.

This is why the order of compound assignments belongs to the problem's logic.

Try exchanging the deposit and fare updates. Addition and subtraction produce the same final small balance here, but an intermediate minimum-balance check could change the outcome. Update order matters whenever another action observes the state between changes.

Version notes

The assignment forms shown are supported in C89 and remain in C17. They do not introduce automatic range validation in newer editions. The lesson uses separate full expressions to make each stored update visible.
