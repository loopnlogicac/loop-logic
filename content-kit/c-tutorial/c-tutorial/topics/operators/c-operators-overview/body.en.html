Introduction

Think of a shop receipt. You add item prices, compare the bill with your budget, and choose a message. C uses different symbols for those jobs. An operator asks for an operation on one or more values.

The values it uses are its operands. In price + fee, the plus sign is the operator; price and fee are operands.

Operators connect the variables and literals you already know into useful calculations. You can read an expression as a small instruction tree. First identify its pieces, then ask what value it produces and whether it changes a variable. Printing a value is a separate action from calculating it.

Syntax and reading guide

int total = price + fee;
int affordable = total <= budget;
const char *message = affordable ? "Within budget" : "Over budget";

The last line uses a pointer to text: a value referring to the chosen string. See pointers later. For now, concentrate on how the question mark chooses one of two messages.

Follow the values and decisions

Arity means the number of operands an operator needs. Unary minus uses one operand: -debt changes the sign of a value. Binary subtraction uses two: cash - fare finds a difference. The conditional operator uses three parts: a condition and two alternatives. Count operands rather than symbol characters; <= is one operator.

An expression computes a value or identifies an object, and it may also have a side effect. A side effect is a change such as storing a new balance. An expression statement ends with a semicolon, for example balance = balance - fare;. The expression computes and stores; the semicolon makes it a complete statement.

Follow a receipt with price 40 and fee 5. Addition produces 45. Comparing 45 with a budget of 50 produces integer 1, which means true. The conditional operator can select a message from that result.

An assignment stores the result for later use. The sequence is easier to understand as several named steps than as one long line.

Examples

Build a small receipt

The two operands of plus are price and fee. Their sum is 45, which initializes total. The equals sign belongs to initialization in the declaration. The printed label lets you connect the arithmetic result with its purpose on a receipt.

Unary minus and binary subtraction

Unary minus produces negative twelve without modifying debt. Binary subtraction then uses cash and the unchanged debt, leaving thirty-eight. The same minus symbol has different operand counts. Neither expression assigns a new value to cash.

A comparison chooses a message

The comparison produces 1 because forty-five is at most fifty. The conditional expression selects Ready from that nonzero value. It does not print both alternatives. Percent s prints the selected string; the choice and its display are separate steps.

Boundaries and alternatives

C groups operators by their jobs. Arithmetic uses + - * / %. Comparisons use < > <= >= == !=. Logical operators combine questions with && || !.

Bitwise operators work on integer bits with & | ^ ~ << >>. Assignment uses = and forms such as +=. Increment and decrement use ++ --. The conditional operator is ?:; comma and sizeof have separate roles.

The same symbol can have different meanings in different positions. A star multiplies two numbers, but a unary star accesses an object through a pointer. Do not decide an operator's meaning from its appearance alone. The types and surrounding grammar matter.

Common mistakes

Assuming every operator changes a variable

The expression marks + 5 computes a new value without replacing marks. Store the result if you need the update. Assignment and increment have side effects; ordinary addition does not.

Reading a long expression only left to right

Multiplication groups more tightly than addition. Read 2 + 3 * 4 as two plus the product, giving fourteen. Parentheses can instead request the sum first. The precedence lesson gives the full grouping rules.

Questions to ask while reading

QuestionRule and reason
In price + fee, what are price and fee called?Operands. They are the two values on which addition acts.
How many operands does unary minus use?One. Its sign change applies to one value.
Which category contains == and <=?Relational and equality comparisons. These ask questions about values and produce 0 or 1.
What turns balance = 5 into an expression statement?A following semicolon. The semicolon completes the expression statement.
Which operator can select between two alternatives??:. Its condition selects one of two expressions.
If marks is 70, does evaluating marks + 5 replace marks?No, it only computes a value. An assignment is needed to store the computed result.
Which operator category works on individual integer bits?Bitwise. Bitwise operators combine or shift the binary digits of integer values.

For a new task, choose the category before choosing its spelling. A program can need several categories in separate statements. That separation also gives intermediate values useful names, making a mistake easier to locate.

An operator expression can become part of a larger expression. Name useful intermediate results, such as subtotal, when that larger expression hides the task steps.

Version notes

The core categories here exist in C89. The examples use C17; newer editions add facilities without changing what ordinary addition, comparison and assignment mean.
