Introduction

At a lab desk, you might display Ready when enough seats remain and Full otherwise. The program needs one of two values. The conditional operator, also called the ternary operator, makes that choice inside an expression. It has a condition, a true alternative and a false alternative.

Unlike an if statement, the conditional expression supplies a value that can initialize a variable or become a function argument. Use it when the alternatives are short and have a clear shared meaning. If the alternatives perform several actions, an if-else statement usually explains the decision better.

Syntax and reading guide

result = condition ? true_value : false_value;
maximum = a > b ? a : b;

The question mark follows the condition. A colon separates the two alternatives. There is one question mark and one matching colon per conditional operator. The statement ends with its own semicolon.

Follow the values and decisions

First evaluate the condition. Zero chooses the expression after the colon. A nonzero value chooses the expression between the question mark and colon. C evaluates only the chosen alternative.

This allows a guard such as count != 0 ? total / count : 0 to skip division when count is zero.

Take a equal to seven and b equal to twelve. The condition a > b is false, so the maximum expression supplies b. Equal inputs also select b in this form, but the numeric maximum remains correct. If you instead choose a label identifying the winning student, ties require an explicit policy.

The conditional operator can also select strings. The two alternatives in the room example refer to string literals; the selected reference is printed with percent s. You do not need to print both strings and then remove the unwanted one. The decision happens before the output call.

For three numbers, find the maximum of the first two, then compare that candidate with the third. This uses two small conditional expressions. A nested form is legal, but it takes more care to pair each question mark with its colon. Conditional expressions associate to the right.

Parenthesize and indent nested choices so their structure is visible.

Examples

Choose a larger mark

Seventy exceeds eighty-five is false. The expression selects b, so maximum becomes eighty-five. The comparison itself does not change either mark. The chosen value is stored before it is printed.

Skip zero division

The false condition chooses the fallback zero. The division alternative is not evaluated, so a zero divisor is never used. A real application should choose a fallback meaningfully; zero average and no data may need different labels.

Maximum of three scores

The first comparison selects ninety-one from the first pair. The second compares that candidate with the third score, also ninety-one. Choosing either tied value gives the same numeric maximum. A separate winner label would require a tie rule.

Boundaries and alternatives

Arithmetic alternatives may be converted to a common type. If one is int and the other double, the conditional result can be double even when the integer alternative is chosen. The condition selects evaluation, while type rules determine the expression type from both alternatives.

Do not place several counter updates inside a compact choice merely to save lines. The operator already contains three roles, and side effects make each harder to trace. Assign a clearly named result, then print or store it in another statement. Treat the shorter form as a way to express a small choice, not as a requirement to avoid if-else.

Common mistakes

Reversing the two alternatives

Read the expression aloud as if condition, use first; otherwise, use second. Test one false case, one true case and a boundary tie. This catches a swapped label quickly.

Hiding a three-way decision in a long line

Find a first candidate and update it with another comparison. Two assignments are easier to trace than several nested question marks, especially when ties have special meaning.

Questions to ask while reading

QuestionRule and reason
How many operands does ?: have?Three. The condition and two alternatives are its three operands.
Which alternative follows a zero condition?The expression after the colon. Zero is false.
How many alternatives are evaluated?Exactly the selected one. The other alternative is skipped.
How do nested conditional expressions associate?Right to left. Explicit parentheses can make the grouping clearer.
Which design is clearest for finding a maximum of three beginners can trace?Compare a pair, then compare its winner with the third. Two named steps expose the candidate value.
What happens to an int and double pair of arithmetic alternatives?A common arithmetic type is determined. Both operand types participate even though only one value is evaluated.
When is if-else usually clearer than ?:?When a choice needs several statements. A statement block better expresses several actions.

Separate a maximum value from a winner label

For marks eighty and eighty, either operand supplies the correct numeric maximum. A label such as First student or Second student asks a different question: who should receive credit for the tie? Write a tie rule explicitly before choosing the alternatives. The expression a > b ? a : b handles a numeric tie safely, but using the same strict comparison to choose a winner silently favors the second alternative.

Equality boundaries deserve a deliberate policy whenever the result carries meaning beyond the numeric value.

Version notes

The conditional operator is available in C89 through C23. These examples use its C17 arithmetic and pointer rules. The chosen operand alone is evaluated, but both operand types participate in determining the result type.
