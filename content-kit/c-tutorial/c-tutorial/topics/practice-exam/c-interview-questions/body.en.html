Answer with a rule and a consequence

These fifty short questions revisit the language behind the projects. A useful answer names the rule, gives its practical consequence and states any boundary or implementation assumption. Avoid slogans such as “arrays are pointers” or “volatile is thread-safe,” which erase the detail that makes the answer correct.

Try answering aloud before reading the explanation. If an answer depends on a target width or language revision, say so. For an invalid program, identifying the violated rule is a complete and more accurate response than guessing a familiar compiler output.

Basics

What does sizeof(char) guarantee?

It is exactly one C byte. A byte need not contain exactly eight bits; CHAR_BIT states the implementation width. Do not confuse a C byte with an assumed octet.

Does int always have four bytes?

No. C specifies minimum ranges, while the implementation chooses widths and representations within its rules. Use limits.h and the documented target assumptions when a range matters.

Why use %zu for sizeof results?

sizeof produces size_t, an unsigned integer type chosen by the implementation. The z length modifier matches that type. Passing it to an incompatible format is not repaired by a familiar-looking result.

How do integer and floating division differ?

If both operands are integer types after the usual conversions, division produces an integer quotient, truncating toward zero for signed values in C17. Converting the result afterwards cannot restore the lost fraction. Convert an operand before division when a floating quotient is intended.

What does main return communicate?

The result of the initial main invocation communicates termination status to the host. Use EXIT_SUCCESS or zero for success and EXIT_FAILURE for unsuccessful termination. A helper return normally resumes its caller instead.

Why check scanf assignment counts?

A failed conversion may leave a destination unchanged or never assigned. Process only values whose required assignments succeeded. A format count is not the same as the number of characters consumed.

What is the scope of a for-initialiser variable?

A variable declared in a for initialiser belongs to that loop scope under C99 and later. It is not available as the same local name after the loop. This keeps a small index lifetime close to its use.

Does const make an object a C17 integer constant expression?

Not automatically. A const-qualified object supplies a read-only access rule, while integer constant expressions have specific language forms. Use an appropriate enum or macro where a compile-time integer constant is required.

Pointers

What is a pointer value used for?

A pointer can identify an object or function, or represent a null value, subject to its type and validity rules. It is not an ordinary integer array index. Dereferencing requires a suitable live object.

How does an array differ from a pointer?

An array contains its elements; a pointer is a separate object holding a pointer value. Many array expressions convert to a pointer to the first element, but sizeof on an actual array still measures the array. A pointer parameter does not retain the caller’s array bound.

May a one-past pointer be dereferenced?

No. It can be formed as a boundary for its array and used in permitted comparisons or subtraction within that array. Move back to an actual element before dereferencing.

What is a null pointer?

It is a pointer value guaranteed not to identify a valid object or function for dereference. Use a null pointer constant or supported nullptr form rather than guessing an address representation. Dereferencing null has undefined behavior.

What is a dangling pointer?

It points to storage whose object lifetime has ended. Returning a local object’s address or retaining an alias after free can create one. Nulling another alias does not repair it.

Why pass a pointer to a pointer?

An operation may need to replace the caller’s pointer, such as inserting a new linked-list head. Passing the pointer by value would only replace a local copy. State ownership and failure behavior before publishing the new pointer.

What does const int * permit?

The pointer can be reassigned, but the int cannot be modified through that access path. Another valid alias may change an originally mutable object. An object actually defined const must not be modified by casting the qualifier away.

When is pointer subtraction meaningful?

The pointers must refer to elements of the same array or its permitted one-past boundary, and the difference must be representable. The result counts elements and has type ptrdiff_t. Subtracting unrelated allocations is not a portable distance operation.

Memory

What does malloc initialise?

malloc allocates suitably aligned storage of the requested size when successful, but does not initialise its contents to application values. Check for null and initialise before reading. Use sizeof on the pointed-to type to keep allocation size consistent.

How does calloc differ from malloc?

calloc allocates space for a count of elements and initialises all bits to zero. That is not a universal promise about every possible pointer or floating representation. Both calls can fail and require a valid ownership policy.

Why use a temporary for realloc?

On failure for a positive requested size, the original allocation remains owned by the caller. Assigning the result directly to the only owner can lose that address. Use a temporary, check success and then replace the owner.

What happens to old aliases after successful realloc?

Treat the old allocation and its pointers as invalidated by successful reallocation, even if the numerical address happens to match. Use the returned pointer for the resized storage. Rebuild any required interior views within its new valid bounds.

Is free(NULL) permitted?

Yes, it has no effect. This helps cleanup when null consistently means no owned allocation. It does not make freeing a dangling nonnull pointer or freeing the same allocation twice valid.

What is a memory leak?

An owned allocation becomes unreachable or is never released when no longer needed. The program may still display correct output while accumulating leaked storage. Review failure paths as well as ordinary completion.

Why save next before freeing a linked node?

The node’s lifetime ends when it is freed. Its next member can no longer be read legally afterwards. Save the successor while the node is live, free the node and then advance.

Are automatic objects always on a hardware stack?

C specifies storage duration and lifetime rather than requiring a particular hardware placement. Automatic objects normally cease to exist when their block invocation ends. Do not base portability or lifetime arguments solely on a guessed memory diagram.

Structures

Can a structure contain a pointer to its own type?

Yes, a pointer member has a known size even while the structure type is being completed. A structure cannot recursively contain a complete instance of itself by value. This distinction permits linked nodes.

Does structure assignment copy pointed-to allocations?

It copies member values, including pointer values. It does not clone separately allocated objects that those pointers name. Decide whether copying creates borrowing, shared ownership or an explicit deep copy.

Is sizeof(struct) the sum of member sizes?

Not necessarily. Padding may appear between members and at the end to satisfy alignment requirements. Do not infer a portable file layout from the visible member declarations.

Why avoid raw structure dumps as portable file formats?

Padding, integer widths, byte order and representations can differ across implementations. Pointers have no portable meaning after reload in another process. Encode fields explicitly and define a versioned format.

How do dot and arrow differ?

Dot selects a member from a structure or union expression. Arrow selects through a pointer to such an object and corresponds to dereferencing then selecting. The pointer must still identify a valid live object.

What does a union share?

Its members overlap storage rather than each receiving separate structure-like storage. Interpreting a different member has representation-sensitive rules and may encounter invalid representations. Do not treat a union as automatic portable serialisation.

Why retain a record index when finding a maximum score?

The index identifies the full matching record, including its roll and other fields. A maximum numeric score alone can lose that association. State how equal scores choose among records.

What does typedef create for a structure?

It creates an alias for an existing type name, not a new allocation or a distinct runtime object. The alias can improve readability, but must not obscure pointer ownership. The underlying structure layout rules remain unchanged.

Preprocessor

When does macro expansion happen?

During preprocessing before ordinary C compilation of the resulting translation unit. It substitutes tokens rather than calling a runtime function. Inspect the expanded expression when precedence or repeated evaluation matters.

Why parenthesise macro parameters and replacements?

Expression operands may contain operators with lower precedence. Parentheses preserve grouping at each occurrence and around the whole replacement. They do not prevent repeated evaluation of an argument with side effects.

Why is SQUARE(i++) unsafe in a repeated-argument square macro?

Expansion can modify the same scalar more than once without required sequencing. Parentheses do not supply that sequencing. Prefer a function so the argument is evaluated once.

What does a header guard prevent?

Repeated header content within one translation unit. Each separately compiled source starts preprocessing independently. A guard does not legalise multiple external definitions placed in the header.

How does #if differ from if?

#if selects source during preprocessing, so an excluded branch is not ordinary compiled runtime code. if chooses behavior while the program runs. Use the right stage for feature availability versus user data.

Why avoid a semicolon inside an expression macro replacement?

A replacement ending with a semicolon can break the surrounding expression or control-flow syntax. Let the caller supply statement punctuation in an appropriate interface. A small function often communicates types and evaluation better.

What does __STDC_VERSION__ tell you?

It advertises the selected standard mode’s version for relevant C implementations. It is not a complete checklist of every optional or newly implemented feature. Consult version-specific feature support and compile tests.

Why should a public header be self-contained?

A caller should not need an undocumented include order to obtain required type declarations. Include the headers that define types used by the interface. Keep private helpers out of the public promise.

Undefined behavior and boundaries

Why is signed overflow not a wraparound algorithm?

C17 imposes no required result for an overflowing signed operation. Checking a wrapped-looking value afterwards is too late. Validate representable bounds before evaluating the operation.

Does unsigned arithmetic permit every shift?

No. Unsigned addition has defined modular behavior, but shift counts must still be nonnegative and below the promoted left operand width. Use a valid unsigned mask and a checked bit index.

What is wrong with i = i++ in C17?

The modifications of i are unsequenced relative to one another. There is no portable numeric output to trace. Separate the intended read and update into explicit full expressions.

Is an uninitialised automatic int useful random input?

No. Reading an indeterminate value is not a valid randomness technique and can invoke undefined behavior. Initialise the object and use an appropriate documented generator when randomness is required.

When does division require more than a nonzero divisor?

Signed INT_MIN divided by -1 is invalid if the quotient cannot be represented. The same representability concern applies to the corresponding remainder operation. Guard both exceptional cases before evaluation.

Why must character classification cast a possibly negative char?

ctype functions require EOF or a value representable as unsigned char. A negative plain-char value outside EOF violates the interface. Preserve EOF as int when reading, and cast actual character bytes appropriately.

What does a successful sanitizer run prove?

It shows no enabled diagnosis on the paths and inputs executed. It does not prove every possible path or every library contract. Combine dynamic checking with boundary tests and code review.

Does volatile make shared-thread updates atomic?

No. It does not establish a general thread synchronisation protocol or make a read-modify-write indivisible. Use suitable atomic operations or locks with the required ordering.

How do unspecified and implementation-defined choices differ?

Unspecified behavior permits alternatives without requiring documentation of each selection. Implementation-defined behavior requires a documented choice. Neither category should be confused with undefined behavior’s lack of requirements.

What is the first question before predicting a tricky output?

Ask whether all operations have valid bounds, lifetimes, arithmetic, sequencing and library arguments. If not, explain the violated rule instead of inventing output. A meaningful trace belongs to a defined execution.

Connect the rules to your own programs

Revisit one project and identify its bounds, ownership, failure and persistence contracts. Explain how its functions preserve those rules at each transition. That habit matters more than memorising fifty isolated answers, and it is the bridge from first-year exercises to larger C programs.
