Practise complete solutions, not memorised fragments

These twenty-five programs cover common first-year C tasks. Each states its input domain, shows a complete implementation and includes a real sample run. Use the marking guidance to identify the algorithmic decisions that deserve explanation in an exam, rather than treating every line as equally important.

All decimal input tokens must be representable in the scanned type. The programs reject missing values and the application bounds they state; they are not unrestricted hostile-text parsers. For arbitrary numeric strings, use the strtol pattern from the argument lesson. The string tasks work on explicitly bounded byte or ASCII input rather than claiming Unicode text processing.

Before running a solution, write its invariant or main update rule. Then choose one ordinary input and one boundary input that could expose an incorrect initial value or loop bound. A correct sample alone does not prove every path. Rewrite the program from that explanation after you understand it.

Twenty-five worked exam solutions

Sum the first n natural numbers

n is from 0 to 1000. The cast widens the multiplication before it occurs. Zero gives the empty sum.

Marking guide: 1 mark for validation, 2 for the formula and safe type, 1 for output.

Compute a bounded factorial

n is from 0 to 12. Start at one so both zero factorial and one factorial are one. Twelve factorial fits the minimum standard range of unsigned long.

Marking guide: 1 for the domain, 2 for initialisation and loop, 1 for the correct format.

Test primality without squaring a divisor

n is from 0 to 30000. Only divisors through the square-root boundary are needed. The quotient comparison avoids computing d*d.

Marking guide: 1 for treating zero and one, 2 for divisibility and bounds, 1 for output.

Find an indexed Fibonacci value

Use F0 = 0, F1 = 1 and n from 0 to 20. The pair holds consecutive values. After n updates, a is Fn; a temporary prevents losing the old pair.

Marking guide: 1 for indexing convention, 2 for updates, 1 for the bounded result.

Compute the Euclidean greatest common divisor

Both inputs are from 0 to 10000; this exercise defines gcd(0,0) as zero. Each remainder preserves the common divisors and decreases the second operand until zero.

Marking guide: 1 for input checks, 2 for the remainder update, 1 for zero cases.

Compute an LCM after reducing by the GCD

Both inputs are positive and no larger than 1000. Compute gcd first, divide before multiplying and use long for the bounded product.

Marking guide: 1 for positive domain, 2 for gcd and reduction, 1 for the wide result.

Sum decimal digits of a nonnegative number

The input token is nonnegative decimal and no larger than one billion. Remainder extracts the final digit and division removes it. Zero requires no special nonzero digit.

Marking guide: 1 for bounds, 2 for extraction and progress, 1 for zero.

Reverse a bounded decimal integer

n is from 0 to 999999. Appending each extracted digit reverses the order. Leading zeroes in the reversed decimal representation are not preserved as digits.

Recognise a numeric palindrome

n is from 0 to 999999. Save the original before consuming its digits. Compare the final reverse with the saved value.

Test a three-digit Armstrong number

n is exactly a three-digit positive integer. This task uses cubes because the domain has three digits; it is not a general arbitrary-digit Armstrong test.

Apply the Gregorian leap-year rule

Use Gregorian arithmetic for years 1 through 9999. Century years need divisibility by four hundred, while other multiples of four qualify.

Convert Celsius to Fahrenheit with floating division

The value is finite and between -100 and 100. Floating constants avoid the integer quotient 9/5. The explicit inclusive comparison also rejects NaN.

Find an array maximum including all-negative data

n is 1–10 and all values are -100–100. Initialise from the first actual element rather than zero, which would fail for all-negative input.

Return the first linear-search match

A bounded array is followed by a key in the same range. The break makes the first zero-based match the result. Minus one represents missing because it is not a valid index.

Marking guide: 1 for input, 2 for matching and early exit, 1 for missing.

Search an already sorted array by halving

n is 1–10, array values are -100–100 and the array must be nondecreasing; the key fits int. Check the ordering precondition. Each nonmatching step excludes mid and keeps only the possible half; duplicate keys may return any matching index.

Marking guide: 1 for sortedness, 2 for shrinking bounds, 1 for result and missing.

Sort a small array with bubble passes

n is 1–10 and all values are -100–100. Each pass moves the largest remaining element to its final suffix position. Strict comparison leaves equal values unswapped.

Marking guide: 1 for input, 2 for both loop bounds and swap, 1 for duplicates.

Add two two-by-two matrices

Read all four cells of A, then all four of B; cells are -100–100. Addition pairs cells with the same row and column. The bounded sums fit even the minimum int range.

Marking guide: 1 for input layout, 2 for matching indices, 1 for row output.

Transpose a two-by-three matrix

Read six representable int values row by row. Output rows correspond to original columns. The result has three rows and two columns.

Measure a bounded input line

One line has at most 80 bytes before its newline and no embedded null. fgets preserves spaces. Remove the newline before measuring content; this is a byte length, not a Unicode character count.

Marking guide: 1 for bounded input, 2 for newline removal and length, 1 for spaces.

Reverse the bytes of a line

Use a line of at most 80 ASCII bytes. Count down from length while positive, then access index i−1. This avoids unsigned underflow at index zero and is not a Unicode reversal algorithm.

Marking guide: 1 for line input, 2 for safe reverse traversal, 1 for a blank line.

Check an exact case-sensitive string palindrome

Use at most 80 ASCII bytes; spaces and case are significant. Compare mirrored positions only through half the string. A blank string passes because there is no mismatching pair.

Marking guide: 1 for stated matching policy, 2 for mirror indices, 1 for odd/even lengths.

Count English vowels without changing the line

Use at most 80 ASCII bytes; count English vowels in either case. Each nonterminator byte is searched in the explicit vowel set. The loop never tests the null terminator as a vowel.

Marking guide: 1 for policy and input, 2 for membership test, 1 for mixed case.

Swap caller variables through pointers

Both decimal input values are representable as int. The helper receives addresses of the actual caller objects. A saved temporary preserves the first value; arithmetic swapping would introduce avoidable overflow risk.

Marking guide: 1 for pointer parameters, 2 for three-step swap, 1 for caller use.

Select the highest-scoring structure record

Read three roll/score pairs; rolls are 1–999 and scores 0–100. Keep the record index rather than just the maximum score. Strict comparison retains the first record in a tie.

Marking guide: 1 for structure use, 2 for record-preserving selection, 1 for tie policy.

Write and reread a temporary text file

The program generates its own bounded well-formed records in a temporary stream. The positioning call switches from writing to reading. A conversion-driven loop prints only complete pairs, then the code checks I/O and close outcomes.

Marking guide: 1 for open/check, 2 for write/position/read, 1 for cleanup.
