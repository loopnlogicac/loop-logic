Introduction to Strings

Think of a label on a laboratory drawer. You want to store letters together and later print the whole label. A C string is a sequence of characters ending with a zero-valued character. You normally keep those characters in a char array.

The end marker matters because the array itself does not announce where meaningful text stops. A room-label array might reserve twenty positions while holding only three letters. String operations follow the characters until they meet the first null terminator, written '\0'.

You already know arrays and indices. Strings add a stopping rule to that familiar storage. The first string below uses the campus abbreviation DIU so you can inspect every element.

Declarations and call rules

Write char campus[] = "DIU"; to create a writable array whose size is inferred from the initializer. C includes a fourth element for the final zero. The initializer {'D', 'I', 'U', '\0'} describes the same four character values explicitly.

A string literal is the quoted text in source code. In this declaration, its contents initialize a separate array. Changing the array later does not change the literal. A pointer can instead select the literal itself, but that selected literal must never be modified.

A fixed declaration such as char campus[12] = "DIU"; reserves twelve elements. The first three contain the visible letters, and the remaining initialized elements are zero. You can later store a longer label, provided the visible bytes and final zero still fit.

Follow the storage and operations

Follow the DIU diagram from left to right. campus[0] is D, campus[1] is I and campus[2] is U. The fourth element is not the digit zero; it is a character whose numeric value is zero. The digit '0' is a different character.

When puts(campus) prints the array, it reads D, I and U, then stops at the null. It does not print the null itself. puts adds an output newline after the text; that newline is separate from the stored terminator.

The length is the number of bytes before the first zero. The capacity is the total number of available array elements. DIU has length three and capacity four in the inferred array. Its terminator occupies index equal to its length, not the preceding index.

Insert a zero at index one and the visible string becomes D. The U byte can still remain later in the array. String length changes because the stopping point changes; the array does not shrink. Code that needs a later suffix must track that suffix deliberately.

An empty string has its zero in the first position. It therefore needs at least one char element even though it has no visible bytes. Do not invent a zero-element array to represent empty text.

Choose the right behavior

A char array is not automatically a string. Three explicit elements D, I and U form a useful character sequence, but there is no terminator. You may access those three elements by index. You may not hand that sequence to an operation that searches for a final zero.

C allows a special initializer such as char exact[3] = "DIU"; with no space for the literal's terminator. That declaration does not create a valid terminated string. Prefer an inferred bound or reserve one extra position so a later reader cannot mistake raw characters for text.

For a known array in its declaring scope, sizeof campus measures all its char storage. A char occupies one C byte by definition. The library function strlen, introduced shortly, measures the visible prefix instead. Neither measurement should be guessed from the appearance of printed text.

These examples use basic Latin characters, each represented as one byte on the recorded system. UTF-8 Bangla text may use several bytes per visible character. Counting char elements is therefore not a general way to count Bangla letters. Keep that distinction when designing a name or message field.

Mistakes and repairs

Missing termination can make a print operation read beyond the array. Finding an accidental zero in nearby memory does not make the read valid. Add the terminator within owned storage rather than depending on surrounding bytes.

Do not confuse '\0' with "\0". The first is a character constant suitable for one array element. The second is a string literal containing a zero plus its own terminator. Assign a character when ending an existing string.

A newline does not end a C string in memory. A stored '\n' changes how output appears but leaves following characters part of the string until a zero is reached.

A nonterminated array is not a string

The result is undefined: puts searches past the three valid elements for a null character. Add a fourth element containing '\0'.

Working habits

Reserve a separate position for termination when choosing capacities. Inspect the empty, one-character and full-capacity cases by index. Use array storage when the label must be edited, and keep its maximum visible length in mind.

Standard and portability notes

Character arrays and null-terminated strings have the same central rules in C89 through C23. The examples use C17 and C99-style loop declarations. No newer standard makes a nonterminated character array acceptable to string-reading functions.
