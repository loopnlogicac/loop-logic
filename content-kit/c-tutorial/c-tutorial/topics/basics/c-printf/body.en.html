Introduction

printf writes formatted text to standard output. A format string combines literal text with conversions that describe how later arguments should be displayed. It lets a program show a roll number, marks and a CGPA without constructing each digit manually.

Think of a marks-sheet row: the data values are separate from the printed layout. You might store a double value of 3.75 but display it with two fractional digits in one report and more digits in a diagnostic trace. Formatting controls presentation rather than changing the stored object.

Include stdio.h so the compiler can check the declared interface. Use literal format strings in beginner code, because warning-enabled compilers can then detect many type and argument-count mistakes before the program runs.

A pointer is a value referring to an object or other permitted target; see Introduction to Pointers. For string output, it identifies the character data to read until the null terminator.

Syntax and vocabulary

The first argument supplies the format string. Each ordinary conversion consumes a corresponding later argument in order. The special sequence %% emits a percent sign without consuming a value.

printf("Roll=%d CGPA=%.2f\n", roll, cgpa);

A conversion specifier is the final letter selecting the conversion. The optional pieces before it refine width, precision, flags or length. A detailed type-based table appears in Format Specifiers Reference.

How it works

printf scans the format string from left to right. It copies ordinary characters, interprets each conversion, obtains the next matching argument and writes the resulting text. The format does not dynamically convert any arbitrary supplied type into the expected one.

In the student-row example, %d consumes roll and %.2f consumes cgpa. Supplying the values in the opposite order would be a type mismatch rather than an automatic rearrangement. The compiler can warn because it sees a constant format string and the argument expressions.

A field width is a minimum number of output characters for the field. %5d pads a short integer on the left, while %-5d pads on the right. A value needing more than five characters is not truncated to five.

Details and comparisons

Precision depends on the conversion

For %f, precision gives the number of digits after the decimal point. %.2f therefore formats a value to two fractional digits, rounding the displayed representation as required. It does not change the double object or make binary floating arithmetic exact.

For an integer conversion, precision has a different role: it sets a minimum digit count rather than fractional places. For %s, precision can limit the number of characters written from a string. Consult the conversion's rule rather than assuming a dot always means decimal places.

The output call also returns a result

On success, printf returns the number of characters written. The count includes spaces, punctuation and newline characters, not only visible digits. The Lab example writes three letters and one newline, so its returned count is four.

A negative return value signals an output or encoding error. In a real reporting tool, checking that value can help detect failure to write a result. In these small terminal examples the successful result is captured and printed by a separate call so you can observe the count directly.

The return value belongs to one call, not the whole output history. The practice task counting a Roll line must not include the earlier Input prompt in its count. This is the same separation between a function result and emitted text that you saw with main's return status.

When puts or putchar fits

puts writes a string and appends a newline. Use it for a plain message when you do not need format conversions. A percent sign in a string passed to puts has no formatting role.

putchar writes one character supplied as an int value representing an unsigned char value, and returns the written character or EOF on error. A character literal such as 'A' is useful here because it avoids guessing an encoding-specific number. The final normal example uses putchar for a character and a separate newline.

These functions are not interchangeable in return-value questions. puts returns a nonnegative value on success, not a guaranteed character count like printf. Choose a function by its contract, then reason about its result using that function's own rules.

Common mistakes

The marked mistake example is supplied for compiler diagnostics. Repair the stated cause before running it; it has no expected stdout transcript.

Trying to print a percent with one percent sign

A lone percent begins a conversion, so write %% when the message needs a literal percent. It consumes no argument. Adding an unused argument does not repair an invalid format sequence.

Treating width as a maximum

%3d can print four digits when the value requires them. Width pads short results rather than clipping long numbers. If a task requires a bounded roll, validate the range independently from the output format.

Mistake: too few format arguments

The second %d has no matching argument, so the compiler warns; running the call would have undefined behavior.

Best practices

  • Match each conversion against the actual promoted argument type.
  • Use literal format strings and keep compiler warnings enabled.
  • Choose width and precision separately.
  • Use %% for a percent and a newline for each completed report line.
  • Use puts for a plain line when formatting is unnecessary.

Version notes

printf, puts and putchar predate C99. C99 added length modifiers such as z for size_t and ll for long long. In the C17 baseline, float is promoted to double in printf calls, and %lf is equivalent to %f for output. Input rules differ.

Summary

printf converts matching typed arguments into controlled text and returns a count of characters written. Width, precision and flags shape the report without changing the stored data. Next, receive values safely in Input with scanf.
