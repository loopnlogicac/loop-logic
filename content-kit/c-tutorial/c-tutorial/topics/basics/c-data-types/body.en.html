Introduction

A marks sheet uses different kinds of entries: whole marks, a grade letter and a fractional CGPA. C gives you different data types for those jobs. A type describes which values fit and which operations apply. Choose it from the meaning and range of your data before choosing how to print it.

A marks sheet stores whole-number marks and may also show a fractional average. C distinguishes integer arithmetic from floating-point arithmetic. Using a floating type does not automatically make every earlier operation floating-point. The operand types still matter.

This lesson measures sizes on GCC on 64-bit Linux. A typical 64-bit computer is a helpful example, not a replacement for the C standard's minimum guarantees. Code should state when a displayed size is specific to its implementation.

Syntax and vocabulary

The common basic choices here are char for a character value, int for a bounded whole number, float or double for approximate real arithmetic, and _Bool for a Boolean truth value. In C17, stdbool.h provides bool as a convenient macro name for _Bool.

int marks = 85;

A byte in C is the unit measured by sizeof, and sizeof(char) is always one. CHAR_BIT from limits.h gives the number of bits per byte, which is at least eight. Four C bytes therefore mean thirty-two bits only on an implementation with eight-bit bytes.

How it works

The first example keeps each field in a suitable type and passes matching arguments to printf. %c prints the grade as a character, %d prints the integer and %.2f formats the double to two fractional digits. Formatting changes the displayed text rather than the stored value.

The sizeof operator yields a size_t value, an unsigned integer type used for object sizes. Use %zu to print it instead of assuming size_t is int. The second example reports the actual sizes for this build and can differ on another target.

Boolean conversion maps scalar zero to false and nonzero to true. The example initializes bool ready from 7 and prints 1, showing normalization rather than preservation of seven. A Boolean flag is suitable for a yes-or-no state, not for storing an arbitrary count.

  1. Decide whether the value is a character, count, measurement or flag.
  2. Choose a type with the needed range and precision.
  3. Initialize it with an appropriate value.
  4. Use a matching output conversion.
  5. Inspect limits or sizeof when a platform assumption matters.

Details and comparisons

Range and precision answer different questions

Range describes how small or large a representable value can be. Precision describes how finely distinct values are represented. A floating type can cover very large magnitudes while losing the ability to distinguish neighboring large integers.

Within its range, an integer type represents whole numbers exactly. A binary floating type represents a finite set of fractions and exponents, so many decimal fractions require approximation. A decimal value looking short on paper does not imply an exact binary representation.

The last normal example prints 0.1 + 0.2 with seventeen fractional digits. On the recorded binary64 implementation it reveals 0.30000000000000004. This is not a broken addition instruction: the decimal constants and the result are represented using nearby binary values.

Printing two decimal places can hide that approximation in the displayed result, but it does not make the stored arithmetic exact. For whole taka or small fixed-unit counts, an integer model may be more appropriate. For measured quantities, choose a suitable floating type and define the tolerance the task permits.

Characters and Boolean flags are not counts

char is an integer type used to store character codes, but plain char can be signed or unsigned depending on the implementation. Do not assume a byte read as char is always nonnegative. When numeric byte ranges matter, later lessons introduce explicitly unsigned or fixed-width choices.

In printf calls, float undergoes promotion to double, and small integer types generally undergo integer promotion. That is why a float value can be printed with %f and a Boolean can be printed as an integer with %d. Input functions have different destination rules, covered in Input with scanf.

An integer promotion converts smaller integer types to int when its range is sufficient, otherwise to unsigned int. See Type Conversion and Casting. Promotion rules depend on types, not on whether you wrote a short variable name.

Common mistakes

Assuming every int is four bytes

Use the table as a labeled example, not an absolute language rule. Consult limits.h for integer ranges and sizeof for storage size. Portable decisions follow the required value range rather than an operating-system marketing label.

Choosing output by appearance alone

A double holding 3.0 still requires a floating output conversion. It is not an int merely because the value has no visible fraction. A format mismatch can be undefined behavior. Match the expression's type before deciding how many digits to display.

Mistake: format and type disagree

The compiler warns that %d expects int, while cgpa supplies double. A format mismatch can cause undefined behavior if run.

Best practices

  • Prefer int for bounded whole-number tasks and double for ordinary decimal measurements.
  • Use size_t with %zu when working with sizes.
  • Label observed sizes as implementation facts.
  • Keep flags separate from counts.
  • Do not confuse display precision with exact stored arithmetic.

Version notes

_Bool and stdbool.h were added in C99. In C17, bool, true and false are header macros. In C23 they are language keywords. The course's Boolean example uses the C17 header form.

Basic integer and floating type sizes remain implementation-dependent.
