Introduction

A classroom has eight seats in each row. Giving eight the name seats_per_row makes the calculation easier to understand and update. A literal writes a value directly in source. A named constant gives a fixed value a useful name.

You will compare several ways of naming values, because they have different language rules.

For a lab capacity calculation, seats_per_row explains what the fixed number eight means. Repeating eight throughout a program makes later changes harder to review. Naming it keeps the assumption visible while preserving the distinction between source substitution and a typed object.

This lesson compares const objects, macros and enum constants, then reads literal bases and suffixes. Keep the C17 baseline in mind: a compiler extension accepting a new literal form does not make that form portable C17.

Syntax and vocabulary

A const-qualified object cannot be modified through that object after initialization. A macro substitutes preprocessing tokens before compilation. An enum constant names an integer constant. Enumerations are developed in Enumerations.

const int seats_per_row = 8;
#define LAB_FEE 5
enum { LAB_DAYS = 2 };

A constant expression is an expression meeting language rules for places needing translation-time values. C17 does not generally treat a const int variable like an enum constant for that purpose. The word const expresses nonmodifiability, not every possible compile-time property.

How it works

The seats example reads rows from a typed const object and uses a macro for seats per row. Both contribute to the result 24, but they arrive through different mechanisms. The macro disappears through substitution, while the object belongs to the ordinary type and object model.

Integer literal prefixes select the written number base. Decimal uses ordinary digits without a leading base marker. A leading zero gives octal, and 0x or 0X gives hexadecimal. The base example writes the same value twenty-six in three forms.

A suffix follows a literal to help select its type. U requests an unsigned integer family, L a long family, and LL a long long family. Combinations such as ULL are available. For floating literals, F selects float, no suffix normally gives double, and L selects long double.

Details and comparisons

Literal type depends on more than one character

An integer literal's type depends on its value, base and suffix according to the standard's candidate-type rules. Do not assume every unsuffixed integer fits int. Write a suitable suffix when a large value or signedness requirement would otherwise be unclear.

The minus sign is normally a unary operator applied to a numeric literal, rather than part of the literal token itself. This matters near signed minimum limits because the positive magnitude may not fit the intended signed type. Prefer the appropriate limits.h macro when you need the implementation's exact boundary.

Character constants and string literals

An ordinary character constant such as 'A' has type int in C. You can use it to initialize a char when the value is representable. A string literal such as "A" has array type and includes a terminating null character, so it is not interchangeable with that single character constant.

A null character has value zero and marks the end of a C string. See Introduction to Strings. The string "lab" therefore has four array elements: three visible characters and a terminator. A string literal must not be modified, even though its ordinary C array type is not spelled with const.

The mixed example prints a grade with %c, a string with %s and an enum constant with %d. Matching the categories matters more than matching how short the text looks. A one-character string still needs a string-compatible use rather than a character conversion.

Choose the mechanism for the job

Use a const object when a typed value with ordinary scope is appropriate. Use a small enum constant when a C17 integer constant expression is needed and the enum model fits. Macros remain useful for preprocessing decisions, but they lack ordinary object typing and must be designed carefully.

A function-like macro can duplicate expressions or interact with operator precedence. Those risks are covered in Macros. This lesson uses only object-like macros holding fixed literals. Avoid adding a semicolon to a macro value, because the semicolon would become part of every replacement.

Try a small change

In the fare exercise, separate the changing passenger count from the fixed fare. The count needs a variable. The fare needs a clear name and unit. scanf stores the typed count through its address, while an if checks success.

A macro substitutes source tokens before those runtime steps. A const object is instead a typed part of your program. Try finding all uses of the fixed fare when the amount changes. If you must edit several unrelated numeric literals, the original name has not captured the rule well enough.

Common mistakes

Adding a leading zero for appearance

Writing 010 means octal eight in C17, not decimal ten. Use output width formatting when you want leading zeroes in a displayed roll number. A literal's source base and a formatted number's appearance are separate choices.

Treating every const object as an enum

A const int remains an object and is not generally an integer constant expression in C17. Select the correct mechanism for a context needing a constant expression. Do not infer the rule from another language that uses the same const spelling.

Mistake: assigning to a const object

A const-qualified object cannot be assigned after initialization. Initialize a new value or use a modifiable variable.

Best practices

  • Name fixed assumptions such as units, prices and capacities.
  • Choose const, macros and enums for their actual roles.
  • Check a literal's base and suffix before tracing arithmetic.
  • Use straight single quotes for a character and double quotes for a string.
  • Keep C23-only literal syntax explicitly marked.

Version notes

C17 supports decimal, octal and hexadecimal integer literals. Binary literals with 0b became standard in C23, so the binary example is built with GCC option -std=c2x. C23 also adds constexpr. That feature is separate from the C17 const object rules taught here.

Summary

Literals describe written values, while named constants express fixed assumptions through different language mechanisms. Read bases, suffixes and quote forms carefully. Next, control how values become text in Output with printf.
