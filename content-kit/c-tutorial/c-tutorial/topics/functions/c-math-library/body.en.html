Use a library for familiar mathematics

A calculator has separate keys for a square root, a power and a sine. C provides similar operations through functions declared in math.h. You can use these functions for geometry, measurements, rounding and scientific calculations.

The header describes how to call each function. It does not turn every mathematical input into a meaningful real answer. A square root of a negative real number needs a different number system. A useful program checks that an input belongs to the function's intended domain.

Domain means the set of allowed inputs for an operation. Floating-point calculations also have limited precision. A displayed decimal answer is a rounded representation, so numerical reasoning matters alongside correct function names.

Include the declarations and link the implementation

gcc -std=c17 -Wall -Wextra -Wpedantic -Werror main.c -o main -lm

Include #include <math.h> in a source file that calls these functions. On this GCC/Linux toolchain, place -lm after the source or object files when linking. The option requests the mathematical library.

A missing header and a missing library are different problems. Without the declaration, the compiler may reject the call. Without the implementation at link time, the linker may report an undefined reference. Optimization can hide some missing-library mistakes for constant expressions, so use the explicit link option consistently.

Separate the function result from its display

sqrt, pow and the other table entries normally operate on double and return double. The rounding functions return integer-valued floating results, not an int type. Printing floor(2.8) with %.1f is therefore appropriate; printing it with %d is not.

Use fabs for double magnitudes. abs, declared in stdlib.h, accepts int instead. Passing a fractional reading to abs would first require an integer conversion and lose information. Function names and parameter types tell you which operation preserves the intended value.

The rounding example is deliberately negative. Upward means toward positive infinity, so ceil(-2.5) gives -2. Downward means toward negative infinity, so floor gives -3. Truncation toward zero would instead give -2; it is a different rounding rule.

Inspect roots, rounding and angles

Roots, powers and magnitude

sqrt gives 9, pow gives 81 and fabs gives 2.5. The result formats retain one digit after the decimal point.

Rounding negative numbers

ceil moves toward positive infinity to -2. floor moves to -3. round sends the halfway value away from zero, also to -3.

Convert degrees to radians

The sine is displayed as 0.500000. acos computes a usable pi value without depending on the nonstandard M_PI name.

Compare a computed root with a tolerance

A small rounding error is allowed in the squared result. Exact equality is unnecessary for this numerical check.

The trigonometry example converts degrees to radians using degrees times pi divided by 180. It computes pi with acos(-1.0). A right angle is pi divided by two radians, rather than ninety radians. Passing degrees directly gives a valid but unintended angle.

The tolerance example squares an approximate square root. The mathematical result is two, but the stored floating value may differ slightly. fabs measures the magnitude of that difference without caring which side of two it lands on.

Check domain, range and precision

sqrt expects a nonnegative input for a real result. pow with a negative base and a noninteger exponent can have a domain error. Zero raised to a negative exponent also needs attention. Large powers can exceed the representable floating range even when their input domain is otherwise acceptable.

The practice programs use isfinite to reject infinities and NaN values before calculating. NaN means not a number. Comparisons involving NaN do not behave like an ordinary ordered reading. For broader applications, the library also provides error-reporting mechanisms described by math_errhandling.

Floating-point values approximate many decimal fractions. Avoid assuming that a printed 0.50 means the stored value is exactly one half in every calculation. The chosen decimal places control the display, while the underlying representation controls subsequent arithmetic.

A tolerance should fit the problem's scale. An absolute tolerance of 1e-12 works for the small identity checks here. Comparing large measurements may need a relative tolerance based on their magnitudes. Monetary calculations often need an integer minor-unit design instead of unrestricted floating rounding.

pow is a floating operation, even when the mathematical result is an integer. For exact bounded integer powers, a checked integer loop or recursive helper can be a better choice. Do not convert an out-of-range double to int and expect a safe exact answer.

Watch units and return types

Using degrees as radians

The sine of thirty degrees is about one half. The sine of thirty radians is a different value. Convert units at the input boundary and give the converted variable a name such as radians.

Assuming M_PI is portable C17

Some implementations provide M_PI as an extension. Standard C17 does not require that macro. Use a clearly stated constant or calculate a suitable pi with acos(-1.0).

Using equality for every numerical check

Exact equality can reject a useful computed result after rounding. Choose a tolerance from the task's accuracy requirement. Conversely, do not add a large tolerance that hides a real algorithmic error.

Check the smallest meaningful numeric case

Try a zero distance, a perfect square and a non-square. For rounding, include positive and negative halfway values. For angles, begin with zero and a familiar angle before trying an arbitrary reading.

Keep units in names and explanations. A distance formula requires matching coordinate units. Restrict inputs enough to avoid overflow in intermediate squares; use hypot for larger-scale work when its range behavior is useful.

Choose an explicit numerical baseline

sqrt, pow, fabs, ceil, floor, sin and cos are longstanding C library functions. round and isfinite were added in C99. These programs use C17 with -lm on GCC/Linux; other toolchains may link the mathematical functions without that option.
