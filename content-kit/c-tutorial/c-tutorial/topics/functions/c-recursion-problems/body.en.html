Choose a reduction that matches the problem

A recursive solution begins by deciding what a smaller problem means. For digits, remove the last digit. For a text range, remove both endpoints after handling them. For a sorted search interval, discard the half that cannot contain the key.

These reductions are different, but each needs a stopping condition and preserved information. Do not memorize a recursive call without understanding which part of the original task remains. A short equation or range diagram often reveals the correct arguments.

Some examples here preview arrays and strings because the problems naturally use them. An array stores indexed elements, starting at zero. A C string is a character array ending with a zero character. Later lessons in Arrays and Strings develop these details.

Write the mathematical reduction first

power(b, 0) = 1
power(b, e) = b * power(b, e - 1), e > 0

digit_sum(n) = n, n < 10
digit_sum(n) = n % 10 + digit_sum(n / 10), n >= 10

gcd(a, 0) = a
gcd(a, b) = gcd(b, a % b), b > 0

The power helper reduces the exponent rather than the base. The digit helper reduces the number of decimal digits. Euclid's GCD helper replaces a pair with another pair whose second value is smaller. Each equation points to its own base case.

The classroom power task defines every zero-exponent answer as one, including zero to the zero power. State that convention because different mathematical contexts treat that expression differently. The numeric bounds also keep all products representable.

A common divisor of a and b also divides a modulo b. Replacing the pair therefore preserves the greatest common divisor. The remainder is smaller than a positive divisor, so the second argument eventually becomes zero. This gives both a correctness reason and a termination reason.

The digit recursion takes O(d) time and depth for d digits. The simple power helper takes O(e) time and depth for exponent e. Euclid's reduction takes O(log min(a,b)) remainder steps for positive inputs, with zero cases handled before division.

The reversal helper uses a writable array, not a pointer to a string literal. The indices begin at zero and length minus one. It swaps those endpoint characters, then moves left inward and right inward. When the indices meet or cross, there is nothing left to exchange.

The pattern helper uses two recursive layers. triangle handles rows; stars handles one row's repeated character. Printing the shorter triangle before the current row gives increasing lengths. Reversing those two actions would print decreasing lengths instead.

Understand the Tower of Hanoi plan

Hanoi has three pegs and n disks of different sizes. Move one disk at a time, and never place a larger disk on a smaller one. To move n disks from source to target, first move n minus one disks to spare. Then move the largest disk to target, and finally move the smaller group from spare to target.

The peg roles change between recursive calls. The first smaller move uses the old target as spare. The second smaller move begins at the old spare and uses the old source as spare. Copying the same three peg arguments into both calls would describe the wrong moves.

For three disks, the move count is seven. The recurrence is T(n) = 2T(n minus one) + 1 with T(0) = 0. It gives 2^n minus one moves. The running time is exponential because the output itself contains exponentially many move lines.

The maximum active call depth is O(n), even though the move count is much larger. A completed first branch returns before the second branch begins. Restricting the practice task to five disks keeps both the trace and the output manageable.

Binary search must shrink past its midpoint

The recursive search example uses an inclusive interval from left through right. An interval with left greater than right is empty and returns minus one. Otherwise calculate the middle index as left plus half the difference, avoiding the potentially overflowing left-plus-right formula.

If the middle value is too large, search left through middle minus one. If too small, search middle plus one through right. The already-tested midpoint is excluded. Reusing middle as an unchanged endpoint can leave a one-element interval that recurses forever.

The input must be sorted under the same comparison used by the search. An unsorted array can send the search away from a key that is actually present. The iterative search lesson later compares this requirement with linear search.

A string of length zero or one needs no reversal swap. The practice reads a nonempty ASCII word with a width-limited %s conversion. Its character array has one extra element for the terminating zero. Byte-by-byte reversal is not a correct method for general UTF-8 Bangla text.

Preserve the problem's meaning in every call

Applying remainder before checking zero

Euclid's base case must be checked before a modulo b. Remainder with a zero divisor is undefined. The zero second argument means the answer is already the first argument.

Multiplying outside the promised numeric domain

Recursion does not provide unlimited integer precision. A power result can overflow long long. Follow the stated base and exponent bounds instead of assuming a smaller exponent always means a safe product.

Reversing the terminator into the word

The final character position is length minus one. Position length holds the terminating zero and must stay at the end. Moving it to the front would make printing stop immediately.

Underestimating recursive output

Hanoi cannot become fast merely by shortening its function body. Every legal plan still needs exponentially many moves. Pattern output also costs time for each printed character, even when recursion organizes the rows neatly.

Name the decreasing measure

Before coding, write whether digits, exponent, disk count or interval length decreases. Then check the smallest input and the first recursive input. These two cases often expose an incorrect boundary before a long trace does.

Use separate names for a problem's roles: source, spare and target; left and right; base and exponent. The names help you verify argument permutations. Compare small results with an independent calculation, such as a loop power or a known GCD.

Keep recursive storage bounded

These recursive reductions require no feature beyond C17. The unsigned helpers accept nonnegative inputs and guard their base cases before subtraction or remainder. Available call storage remains an implementation limit, regardless of whether the mathematical recurrence terminates.
