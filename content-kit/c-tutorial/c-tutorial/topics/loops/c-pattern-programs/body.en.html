Introduction

A pattern on paper is a set of rows. Each row contains leading spaces and visible symbols. A pattern program turns those counts into nested loops. You do not need to memorize a separate long program for every shape.

Derive the row rules first, then translate them into counters.

Draw a small shape with height four. Number the rows from one to four and count its spaces and symbols. The resulting table is the algorithm. This approach helps you explain a pattern in an exam, adjust its size, and diagnose a shifted row without guessing where to add another print.

Syntax and reading guide

for (int row = 1; row <= height; row++) {
    /* print the spaces belonging to this row */
    /* print the symbols belonging to this row */
    puts("");
}

Follow the values and decisions

A left-aligned growing star triangle has row stars on row number row. An inverted triangle has one fewer star on every later row. You can count the outer row downward from height to one and let that row value also be the number of stars.

A centered pyramid has height minus row leading spaces and twice row minus one stars. The spaces decrease by one while the stars increase by two, keeping the center fixed. Use separate loops for spaces and stars. The newline comes after both loops, once for the whole row.

A diamond combines a growing pyramid with a shrinking lower half. Start the lower half at height minus one so the widest middle row is not duplicated. Its total row count is twice height minus one. For height one, the lower half is empty and the diamond is a single star.

Number patterns change the value printed per cell. Printing column numbers resets the visible sequence at every row. Floyd's triangle instead keeps a value outside both loops and increments it after each cell. Alphabet rows can index a fixed string of letters; this avoids assuming that the character codes for letters are consecutive on every C implementation.

Pascal's triangle contains binomial coefficients. Each row begins with one. From column c to c+1, multiply the current coefficient by row-c and divide by c+1. These integer operations are exact for the coefficients, but intermediate products must still fit.

The example and exercises limit the number of rows to ten.

Examples

A growing star triangle

Row one prints one star, row two prints two, and so on through four. The inner counter restarts at one for each row. A newline after the inner loop creates a separate line for each row. The total number of stars is ten.

An inverted star triangle

The outer counter decreases from four to one. Using that value as the inner limit gives row lengths four, three, two and one. The downward signed counter stops safely after reaching zero; an unsigned count with a nonnegative condition would need different care.

Reset number labels by column

The printed value is the column number. Each row therefore begins at one and grows to its row number. Compare the row lengths with the star triangle: the control structure is the same, while the symbol changes to a changing numeric value.

Alphabet rows with a lookup string

The string stores the desired alphabet order explicitly. Array indexing selects its first row letters, producing A, AB, ABC and ABCD. An array is a sequence of elements; see arrays later. The small bound keeps every index inside the letter sequence.

A centered pyramid

The first row has three spaces and one star. Each later row removes a space and adds two stars. The base has seven stars and no leading space. The row table predicts every output line before the program runs.

A diamond without a repeated center

The upper half prints rows of one, three and five stars. The lower half starts at row two and prints three then one. There are five lines in total. Starting the lower half at three would incorrectly duplicate the widest row.

Floyd numbering across rows

The sequence counter lives outside the outer loop, so row two begins at two rather than restarting at one. Ten cells print values one through ten. The conditional separator avoids a trailing space at the end of each row.

Pascal coefficients by a recurrence

Row zero is one. The later rows follow the exact coefficient recurrence, reaching one four six four one on row four. The update is skipped after the last printed coefficient. The small row count keeps every multiply-before-divide intermediate safely inside unsigned long long.

Boundaries and alternatives

Separate algorithmic spaces from display formatting. A leading space is part of the shape; an accidental trailing space may be invisible on screen but still belong to the emitted text. The numeric Pascal example places a separator only before nonfirst columns, avoiding a trailing separator.

A pattern's dimensions also control running cost. A star triangle prints a total of n*(n+1)/2 stars. A pyramid prints n*n stars across its rows, plus leading spaces. Small teaching bounds keep both output volume and arithmetic manageable.

Do not remove bounds merely because each individual loop looks short.

Common mistakes

Repeating the diamond middle row

Use height for the last upper row and height-1 for the first lower row. Trace height one and height two to see whether the center appears once.

Resetting the Floyd counter every row

The sequence must continue across row boundaries. Declare the next value before the outer loop, while the column counter still resets inside each row.

Questions to ask while reading

QuestionRule and reason
What should you derive first for a new pattern?The counts and values in one row. Row rules translate directly into loop bounds.
How many stars belong to pyramid row r?2*r - 1. The odd widths keep the center aligned.
How many leading spaces belong to pyramid row r of height n?n - r. The indentation decreases by one each row.
Where should the diamond lower half begin?At height - 1. The widest row has already printed.
Where does a Floyd sequence counter belong?Outside the outer loop. It must continue across rows.
Why use a string for alphabet lookup?It records the letter order without assuming consecutive codes. The lookup expresses the desired sequence directly.
Why bound Pascal triangle rows?Intermediate products can overflow. Even a multiply later divided must fit its calculation type.

Version notes

The pattern algorithms use ordinary C17 loops. Header-local counters need C99 or later. The alphabet example uses a string lookup rather than depending on a specific numeric encoding for consecutive letters.
