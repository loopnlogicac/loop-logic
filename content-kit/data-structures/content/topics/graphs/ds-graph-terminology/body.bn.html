কোড বাছার আগে সংযোগ বোঝাও

ক্যাম্পাসের মানচিত্রে ভবন বিন্দু আর হাঁটার পথ রেখা দিয়ে দেখানো যায়। বিন্দু জায়গা, রেখা সরাসরি সংযোগ বোঝায়। Graph vertex আর edge দিয়ে এই ধরন মডেল করে। Vertex বাস্তব জায়গাই হতে হবে না: course, account বা program state-ও যুক্ত হতে পারে।

Graph প্রায়ই G=(V,E) লেখা হয়; V vertex set, E edge set। কোনো edge না ছুঁলেও isolated vertex V-তে থাকে। শুধু edge record-এর নাম গুনলে বিচ্ছিন্ন ভবন হারাবে। তাই উদাহরণে vertex count আর edge count আলাদা পড়ে।

শব্দের অর্থ জরুরি, কারণ model একটু বদলালেই কোন algorithm চলবে বদলায়। একমুখী পথে directed edge, travel time-এ weight লাগে। গন্তব্যে পৌঁছানো, hop কমানো আর মোট সময় কমানো আলাদা তিন প্রশ্ন, একই vertex হলেও।

প্রতিটি edge-এর অর্থ বেছে নাও

Undirected edge দুই vertex-এ দুই দিকেই সংযোগ দেয়। {u,v} এক সংযোগ, কোন endpoint আগে বললে কিছু বদলায় না। Directed edge বা arc u থেকে v যায়; উল্টো যেতে আলাদা arc চাই। Directed graph-এ দুই দিকই থাকতে পারে, তবু এক edge ধরা হয় না।

Weighted graph edge-এ distance, time বা fee-এর মতো সংখ্যা দেয়। Weight সংযোগের, endpoint ID-র নয়। শূন্য weight-ও অর্থপূর্ণ। Unweighted graph শুধু সংযোগ রাখে, সাধারণ path length-এ edge গোনা হয়।

Input-এ simple undirected graph: self-loop বা repeated endpoint pair নেই। তাই matrix presence শূন্য বা এক। সাধারণ graph-এ parallel edge বা loop চলতে পারে। Counting formula-র আগে নিয়ম বলো, boolean matrix একাধিক parallel edge আলাদা করতে পারে না।

Undirected vertex-এর degree হলো ছোঁয়া edge end-এর সংখ্যা। Loop-free নিয়মে এটি neighbor count। প্রতি edge দুই endpoint-এ এক করে দেয়, তাই degree sum 2E। Directed graph-এ indegree incoming, outdegree outgoing arc গোনে; দুই মোটই E। Undirected self-loop অনুমোদিত হলে degree-তে দুই যোগ করে।

Path, cycle আর component পড়ো

Walk পরপর edge ধরে, vertex repeat হতে পারে। এখানে path-এ vertex repeat নেই। Cycle অন্য vertex repeat না করে শুরুতে ফেরে। কিছু সংজ্ঞায় path ঢিলাভাবে ব্যবহৃত হয়, তাই repetition উত্তরে প্রভাব ফেললে তোমার নিয়ম বলো।

পরের BFS আর DFS-এর সাত-vertex উদাহরণ ধরো। Vertex 0 থেকে 6। Edge 0-1,0-2,1-3,1-4,2-4,3-5,4-5, সব undirected। Vertex ছয়ে কোনো edge নেই, তবু graph-এর অংশ।

সংযোগ যোগের আগে:               Edge 2-4 যোগের পরে:
0 -- 1 -- 3 -- 5                0 -- 1 -- 3 -- 5
|    |         |               |    |         |
2    4 --------+               2 -- 4 --------+
6 বিচ্ছিন্ন                    6 বিচ্ছিন্ন

0,1,3,5 path-এর দৈর্ঘ্য তিন। 0,1,4,2,0 cycle-ও আছে। শূন্য থেকে পাঁচ এক connected component, ছয় আরেকটি। Connected component সর্বোচ্চ এমন দল যেখানে প্রতিটি জোড়ার মধ্যে undirected path আছে। সর্বোচ্চ মানে বৈশিষ্ট্য না ভেঙে আর vertex যোগ হয় না।

Directed graph-এ reachability দুইদিকে নাও হতে পারে। 0 থেকে 1, 1 থেকে 2 গেলে শূন্য দুইয়ে যায়, কিন্তু দুই শূন্যে নাও যেতে পারে। Strong connectivity-তে প্রতি জোড়ায় দুইদিকে directed path চাই। Weak connectivity তিরের দিক উপেক্ষা করে। কোন অর্থ চাই না বলে undirected component-এর সংজ্ঞা directed graph-এ বসিও না।

Degree গুনে graph family যাচাই

Simple undirected graph-এ degree মিলাও

Vertex চারের degree শূন্য। প্রতি pair দুই endpoint-এ এক করে যোগ করে, তাই degree sum আট।

DAG-এ incoming আর outgoing আলাদা

দুটি directed path vertex তিনে পৌঁছায়। আগের layer-এ কোনো তির ফেরে না, তাই graph acyclic।

সব edge দুই দলের মাঝে রাখা যায় কি না দেখো

তৃতীয় edge odd cycle বন্ধ করে। তখন পাশাপাশি দুই vertex-এ একই color লাগে, graph bipartite নয়।

কাজের graph family চেনো

Complete simple undirected graph-এ প্রতিটি distinct vertex pair-এ edge। n vertex-এ n*(n-1)/2 edge, কারণ unordered pair একবার গোনা। প্রতিটি degree n-1। K7 সাত-vertex complete graph বোঝায়, যা পরে dense preset-এ আছে।

Bipartite graph vertex দুই দলে ভাগ করে, সব edge দল পার হয়। একই দলের মধ্যে edge নেই, তবে সম্ভাব্য সব crossing edge থাকতেই হবে না। Odd cycle না থাকলেই graph bipartite। তৃতীয় প্রোগ্রাম দুই color দিয়ে নতুন neighbor-কে উল্টো color দেয়।

Coloring প্রোগ্রামে array queue পাঠের কিউ আছে। Disconnected অংশও দেখতে প্রতিটি uncolored vertex থেকে আবার শুরু। Edge সমান color জুড়লে test ব্যর্থ। Triangle ব্যর্থ, চার-cycle সফল। Isolated vertex যেকোনো দলে যেতে পারে।

Directed acyclic graph বা DAG-এ তির আছে, directed cycle নেই। Prerequisite বোঝায়, যেখানে dependency ধরে শুরুর course-এ ফিরে আসা চলবে না। Undirected tree connected আর acyclic। Nonempty n-vertex tree-তে n-1 edge, যেকোনো দুই vertex-এর মধ্যে ঠিক এক simple path।

Tree সবসময় bipartite: যেকোনো root থেকে depth জোড়-বিজোড় দিয়ে দল দাও। DAG-র underlying undirected graph bipartite নাও হতে পারে। যেমন 0 থেকে 1, 1 থেকে 2, 0 থেকে 2 তিরে DAG, কিন্তু তির উপেক্ষা করলে triangle। Family-গুলো আলাদা শর্ত বোঝায়।

না থাকা সংযোগও ধরো

প্রোগ্রামের empty graph-এ vertex আর edge শূন্য। Component শূন্য, two-color শর্ত খালি ক্ষেত্রেও সত্য। এক-vertex graph-এ এক component, degree শূন্য, cycle নেই। Nonempty-tree নিয়মে connected আর acyclic বলে এটিও tree।

Disconnected graph-এ n-1 edge থাকলেও tree নাও হতে পারে। Triangle আর isolated vertex মিলে চার vertex তিন edge, কিন্তু cycle আছে, connected নয়। উপযুক্ত connectedness বা acyclicity শর্তের সঙ্গে মিললেই edge count tree test হয়।

Matrix থেকে degree গুনতে n row-এর n cell scan, সময় O(V squared), storage-এর বাইরে কাজের জায়গা O(1)। Two-color প্রোগ্রামও পুরো row দেখে O(V squared) সময় আর O(V) queue/color space নেয়। Adjacency list-এ একই coloring O(V+E)।

এক simple undirected edge যোগে দুই endpoint degree এক করে, E এক বাড়ে। সরালে উল্টো। Matrix-এর দুই symmetric cell একসঙ্গে বদলাবে। Complete graph-এ বৈধ নতুন distinct pair নেই; loop বা repeated pair নীরবে degree-র অর্থ না বদলে reject হয়।

Model একই রাখো

Undirected pair দুবার গুনে দুই edge

দুই symmetric matrix cell এক সংযোগ। Endpoint pair থেকে E গুনে degree sum দিয়ে মিলাও।

কম hop-কে কম weight বলা

সরাসরি দামি edge সস্তা দুই-edge পথের চেয়ে কম hop নিতে পারে। Traversal বাছার আগে কোনটি কমাতে চাই বলো।

Degree শূন্য vertex বাদ

কিছু vertex edge list-এ না এলেও vertex list graph ঠিক করে। Component আর reachability-তে সেগুলো রাখো।

C17 graph counter

বলা আট-vertex সীমায় ID, degree আর queue index int। Graph ধারণায় নতুন C feature লাগে না; এখানকার array আর control flow C17 দেয়।

Graph model বৈধ প্রশ্ন ঠিক করে

Vertex জিনিস চেনায়, edge সংযোগ, দিক আর weight অর্থ যোগ করে। Path আর component reachability বলে, family দরকারি শর্ত দেয়। এবার কাজের উপযুক্ত memory representation বেছে নাও।
