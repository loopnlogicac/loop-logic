উত্তর পড়ার আগে বোঝানোর চর্চা

পরীক্ষার উত্তর ছোট ব্যাখ্যা ভাবো, যা অন্য কেউ অনুসরণ করতে পারে। আগে representation, তারপর চাওয়া state change, শেষে ফল আর খরচ। শুধু সঠিক final array দিলে movement-এর tracing প্রশ্নের উত্তর সম্পূর্ণ নাও হতে পারে।

নিচে array ও address, linked list, stack, queue, tree, hashing আর graph আছে। প্রতিটি প্রশ্নে পুরো উত্তর। আগে কাগজে চেষ্টা করে শুধু final number নয়, মাঝের state মেলাও। Address হিসাবের element width বলা আছে; সব মেশিনে int সমান size ধরে না।

সময় ধরে practice-এ একটা array, একটা pointer, একটা tree trace আর একটা graph প্রশ্ন নাও। Diagram label আর empty বা missing-element case দেখার সময় রাখো। Complexity-তে worst case, expected নাকি amortized বলো। কোন representation-এ সীমা সত্য ব্যাখ্যা করো।

অ্যারে

1. অ্যারে (5 নম্বর): A[3][4] row-major, base address 1000, width চার byte, index শূন্য থেকে। A[2][1] খোঁজো।

Element offset 2*4+1=9। Byte offset 9*4=36। Address তাই 1036। বারো element-এর array-তে index বৈধ। Column-major হলে 1*3+2=5 element, address 1020 হতো।

2. অ্যারে আর complexity (5 নম্বর): spare capacity-সহ [4,8,12,16]-এর position 1-এ insert। Movement আর খরচ দেখাও।

16 index 3 থেকে 4, 12 দুই থেকে তিন, 8 এক থেকে দুইয়ে সরাও। নতুন মান, যেমন 6, index 1-এ লেখো। ফল [4,6,8,12,16]। ডান থেকে বামে সরালে না পড়া মান overwrite হয় না। এখানে তিন shift; সাধারণ worst-case insertion O(n) সময়, বাড়তি O(1) জায়গা।

লিস্ট

3. Linked list (6 নম্বর): head দেখায় 5 -&gt; 9 -&gt; 12। 9 মুছে দরকারি pointer action লেখো।

prev-এ node 5, cur-এ 9 খোঁজো। cur next রেখে prev next-এ node 12 বসাও, তারপর cur free। ফল 5 -> 12 -> NULL। cur head হলে head বদলাও; pointer-to-pointer loop দুটো case পারে। Search O(n), জানা incoming link থেকে unlink O(1)।

স্ট্যাক

4. স্ট্যাক (5 নম্বর): push 3, push 7, pop, push 2, peek। সব state আর returned value দাও।

[] থেকে push 3-এ [3], push 7-এ [3,7], pop 7 ফেরায় আর [3] রাখে, push 2-এ [3,2], peek না বদলে 2 ফেরায়। ডান প্রান্ত top। Capacity থাকলে প্রতিটি array operation O(1); শুরুর empty stack-এ pop হলে underflow।

কিউ

5. কিউ (6 নম্বর): capacity চার, count শূন্য, front শূন্য। 10,20,30 enqueue; দুবার dequeue; 40,50,60 enqueue। শেষ physical cell আর logical order দাও।

Cell হয় [50,60,30,40]। Front 2, count 4। Active logical order [30,40,50,60], index 2,3,0,1 ঘুরে। Next-insertion index front-এর সঙ্গে মিললেও count full আর empty আলাদা করে। দুই dequeue 10 আর 20 ফেরায়।

ট্রি

6. ট্রি (6 নম্বর): BST-তে 8,3,10,1,6,9,14 insert, successor দিয়ে 8 delete। নতুন tree আর traversal দাও।

Successor right subtree-র minimum 9। Root-এ 9 copy করে node 10-এর নিচের পুরোনো leaf 9 সরাও। Root 9-এর left 3, তার child 1 আর 6; right 10, তার right child 14। Inorder 1,3,6,9,10,14। Preorder 9,3,1,6,10,14।

হিপ

7. হিপ (5 নম্বর): max-heap [10,7,8,3,5]-এ 12 insert। Swap দেখাও।

Index 5-এ 12 append, parent index 2-তে 8। Swap-এ [10,7,12,3,5,8]। নতুন parent index 0-তে 10; আবার swap-এ [12,7,10,3,5,8]। Complete গঠন বৈধ, প্রতিটি parent child-এর সমান বা বড়। Sift-up O(log n)।

হ্যাশিং

8. হ্যাশিং (6 নম্বর): modulus সাত, chained table-এ সামনে 1,8,15 insert। 8 delete। Linear probing-এর সঙ্গে তুলনা।

Chaining-এ bucket 1 হয় 15 -> 8 -> 1। 8 মুছলে 15 সরাসরি 1-এ জুড়ে, 8 free। Linear probing-এ key slot 1,2,3 নেয়। 8 মুছলে slot 2-তে tombstone চাই, যাতে 15 search পেরোতে পারে। দুই scheme-এই worst-case search O(n)।

গ্রাফ

9. গ্রাফ (6 নম্বর): undirected edge 0-1,0-2,1-3,1-4,2-4,3-5,4-5 আর isolated 6। Ascending neighbor-এ 0 থেকে BFS দাও।

Queue expansion order 0,1,2,3,4,5। Distance [0,1,1,2,2,3,-1]। Parent [-1,0,0,1,1,3,-1]। 5-এর parent path 0,1,3,5। Vertex 6 BFS tree-র বাইরে। একবার neighbor list দেখায় traversal O(V+E)।

10. গ্রাফ (5 নম্বর): minimum-hop route আর সব component পেতে BFS-DFS তুলনা।

Queue layer ধরে বলে unweighted minimum-hop route-এ BFS উপযুক্ত। DFS minimum hop নিশ্চিত করে না। প্রতিটি unseen vertex-এ নতুন search করে দুটোই undirected component গুনতে পারে। Adjacency list-এ দুইটি O(V+E); queue বা DFS stack বাড়তি O(V) নিতে পারে।

Union-Find

11. Union-find (5 নম্বর): size আর first-root tie-তে union(0,1), union(2,3), union(0,2), find(3)।

Parent [0,0,2,2], তারপর [0,0,0,2]। শেষ find 3 থেকে 2 থেকে 0 গিয়ে parent[3] শূন্য করে। Final parent [0,0,0,0], root size চার। আবার union(1,3)-এ size বা component count বদলায় না।

ডিজাইন

12. ডিজাইন (8 নম্বর): sparse city connection রাখো, road যোগে বারবার connectivity দেখো, কখনো shortest-hop route উদ্ধার করো।

আসল road neighbor রাখতে O(V+E) record-এর adjacency list নাও। প্রতিটি undirected road দুই list-এ যোগ। Road আসলে repeated same-component query-তে union-find রাখো। Route-এর জন্য list-এ parent-সহ BFS। শুধু union-find route reconstruction-এর edge history রাখে না। Deletion-এ অন্য strategy বা connectivity rebuild লাগে।

ফল বলার আগে শর্ত দেখো

Complexity label-এ representation আর operation চাই। Matrix traversal absent connection-ও scan করে, adjacency list করে না। BST chain হতে পারে, hash অনেক key এক bucket-এ পাঠাতে পারে। দ্রুত average বা amortized দাবির শর্ত বলো।

Pointer trace-এ allocated record আর তার owner link আলাদা করো। Release-এর আগে incoming link মেরামত, freed node কখনো পরের traversal step নয়। Graph trace-এ source আর neighbor order বলো; route বানিয়ে না দিয়ে আলাদা unreachable marker রাখো।

মুখস্থ তথ্যের কারণ বোঝাও

প্রতিটি উত্তরের পরে এক শর্ত বদলে ফল ভাবো। Full queue, duplicate key, missing contact বা disconnected vertex নাও। দুই উত্তরে একই cost word দিয়ে আলাদা নিশ্চয়তা বোঝালে complexity basics আবার দেখো।
