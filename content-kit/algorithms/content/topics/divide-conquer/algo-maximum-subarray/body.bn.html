সিউডোকোড ও ব্যবহারের নিয়ম

ending = values[0]; best = ending
for i = 1 to n - 1
    ending = max(values[i], ending + values[i])
    best = max(best, ending)
return best

Ending মানে current index-এ শেষ হওয়া nonempty interval-এর greatest sum। Best মানে processed prefix-এর যেকোনো জায়গার greatest sum। আলাদা অর্থ:আজ ending negative হলেও আগের profitable interval best থাকতে পারে।

দুই variable a[0] থেকে,loop indexone থেকে। Negative infinity ছাড়া nonempty শর্ত প্রতিষ্ঠিত। Caller অন্তত একটি value দেবে। Empty dataset হলে আলাদা response ঠিক করো,a[0] পড়বে না।

পদ্ধতিটি কেন সঠিক

i-এর আগে ending হলো i-1-এ best-ending,best হলো [0,i)-এর optimum। i-তে শেষ interval শুধু a[i] বা আগের-ending-এর extension। Exhaustive দুই possibility-র ভালোটি recurrence নেয়। তারপর best পুরোনো winner ও নতুন ending মেলায়।

শুরুর prefix-এ একটিমাত্র nonempty interval প্রথম value,তাই invariant সত্য। প্রতিটি iteration দুই অর্থ রাখে। শেষে সব interval কোনো processed index-এ শেষ হয়েছে,best সব দেখে। i n-এর দিকে বাড়ায়,তাই stop।

Divide-conquer-এর তিন location exhaustive। Crossing left suffix+right prefix হবেই। Choice স্বাধীন,প্রতিটির maximum যোগেই best। Nonempty base এক value;length induction-এ recursive result সঠিক।

সময় ও মেমরির হিসাব

Brute-force extension n+(n-1)+…+1,তাই Θ(n²),extra Θ(1)। Recursive দুই half+linear crossing-এ2T(n/2)+Θ(n),তাই Θ(n log n),active stack Θ(log n)।

Kadane প্রতি value একবার,fixed arithmetic-comparison,তাই Θ(n),দুই total Θ(1) extra। Boundary-তে অল্প index। প্রতি candidate copy করলে constant space নষ্ট;boundary রাখো,দরকারে শুধু final copy।

Positive,negative,mixed-এ bound linear;sort বা early exit নেই। Arithmetic width আলাদা:বড় অনেক change int overflow করতে পারে। এখানে16 value,-99..99-এ brute force ও crossing-সহ intermediate sum নিরাপদ।

Boundary ও সমান sum সামলাও

Boundary পেতে ending-এর tentative start ও best-এর final boundary রাখো। Restart strictly ভালো হলে start=i;ending strictly best ছাড়ালে start,i+1 save। Earliest start tie চাইলে equal-এ extend করো,পুরোনো start ফেলে দিও না।

Single negative নিজেকে,all-positive পুরো sum ফেরায়। All-zero-তে অনেক optimum;exercise earliest start তারপর earliest end নেয়। আলাদা contract অংশ test করে,recurrence বদল বা empty answer লাগে না।

Maximum subsequence গুলিও না;তাতে position skip করে বিচ্ছিন্ন positive যোগ করা যায়। Sum ও length-ও আলাদা। One-length interval জিততে পারে;longer tie শুধু বলা থাকলেই ভালো।
