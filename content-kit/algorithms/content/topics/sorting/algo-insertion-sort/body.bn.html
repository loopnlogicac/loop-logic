শুরু করা যাক

হাতে তাস সাজাতে পরের card আগেরগুলোর ঠিক জায়গায় ঢোকাও। Insertion sort-ও এভাবে কাজ করে। প্রতি outer iteration-এ sorted prefix এক key বাড়ে।

ছোট array ও nearly ordered data-তে উপকারী। Order যাই হোক সব pair scan না করে সত্যিই নড়তে হবে এমন value-এ কাজ করে। সহজ movement-এ stability বোঝানোও সহজ।

সিউডোকোড ও ব্যবহারের নিয়ম

for i = 1 to n - 1
    key = a[i]; j = i - 1
    while j >= 0 and a[j] > key
        a[j + 1] = a[j]; j = j - 1
    a[j + 1] = key
    a[0..i] is sorted

ধাপে ধাপে বোঝো

Shift-এর আগে key বাঁচাও

প্রথম value length-one sorted prefix। Index i-তে a[i] key হিসেবে save। j=i-1 থেকে আগের value তুলনা। a[j] বড় থাকলে এক cell ডানে copy,j কমাও। Original cell overwrite হলেও key আলাদা variable-এ নিরাপদ।

থামলে key a[j+1]-এ বসাও। হয় j=-1,মানে সব আগেরটির চেয়ে ছোট;নয়তো a[j]≤key। দুই ক্ষেত্রেই j-এর পর ঠিক জায়গা। এখানে shift-based;adjacent-swap variant-ও আছে।

[7,3,5,3,1]-এ i1-এর key3 save করে7 ডানে,ফল [3,7,5,3,1]। পরের key5 আবার7 সরিয়ে3 ও7-এর মাঝে। নিজের key insert-এর আগে suffix sorted ধরা হয় না।

Guard নিরাপদ ক্রমে পড়ো

C guard j≥0 ও a[j]>key,short-circuit &&-এ লেখা। Left আগে;false হলে right বাদ। তাই negative j-তে access নেই। Operand উল্টালে invalid বোঝার আগেই array-র বাইরে পড়তে পারে।

Signed j=-1 সুবিধার stopping state। Unsigned zero থেকে এক কমলে বড় মানে wrap,negative নয়। তখন hole position zero-র ওপরে রেখে অন্য design চাই। Redesign ছাড়া signed condition copy করবে না।

Shift-এর মাঝে array-তে একই value repeat দেখা যেতে পারে। Key হারায়নি,আলাদা আছে। Trace-এ saved key দেখলে সব value হিসাব মেলে। Reinsertion-এর পরই original multiset তুলনা করো।

Nearly sorted-এ movement কম

Ascending-এ নতুন key-র condition সঙ্গে সঙ্গে false:n-1 check,zero shift,Θ(n)। Reverse-এ key i আগের i value পেরোয়;1+2+…+n-1 shift,Θ(n²)।

Inversion হলো p<q অথচ a[p]>a[q]। প্রতি shift একটি এমন pair পার করে। Total shift input inversion count। I inversion-এ সাধারণ implementation Θ(n+I)। “প্রায় sorted” বলার চেয়ে অল্প inversion-এর লাভ নির্দিষ্ট করে।

প্রায় ascending list-এর শেষে একটি ছোট value-ও অনেক position পার হয়। Linear extra কাজ,তবু quadratic থেকে কম হতে পারে। Performance দাবিতে আসল disorder বা inversion count বলো।

Equal key arrival order রাখো

Strictly বড় predecessor-ই shift। আগের equal record পেলে থামে,তাই পরের3B আগের3A-এর পরে থাকে। এই shift implementation stable।

Greater-than-or-equal দিলে নতুন key আগের equal-এর আগে। সংখ্যা sorted,record order বদলায়। এক field-এ sort করে আরেক field-এ stable sort-এ আগের order tie rule হিসেবে কাজে লাগে।

Key ও index ছাড়া extra নেই,তাই in-place constant workspace। বড় random array-তে quadratic worst খারাপ। Practical sort-এ ছোট subarray-তে অল্প overhead-এর জন্য ব্যবহৃত হয়।

Keyboard-এর সংখ্যা sort করো

Signed মানেও সরাসরি shift। Strict comparison দুই -2-এর আগের order রাখে।

Sorted neighbor থেকে distinct mark

Sort equal key একত্র করে। Group শুরুর count তিন distinct score।

Shift ও inversion মেলাও

শুধু3,2 pair inverted। একটি shift সেটি সরায়;near-order-এ কম কাজ বোঝা যায়।

ছোট ইনপুটে ধাপ দেখো

ধাপঅবস্থাকেন এমন হয়
i = 1, key = 3[3,7,5,3,1]7 ডানে সরিয়ে 3 বসাও।
i = 2, key = 5[3,5,7,3,1]শুধু 7 key-এর চেয়ে বড়।
i = 3, key = 3[3,3,5,7,1]আগের সমান 3-এর পরে থামো।
i = 4, key = 1[1,3,3,5,7]আগের চার value-ই সরাও।

পদ্ধতিটি কেন সঠিক

Outer i-এর আগে a[0..i) sorted,মূল প্রথম i value আছে। Next key save। ডানে shift হওয়া সবাই key-এর চেয়ে বড় ও sorted। বড় predecessor শেষ হলে j+1-এ key দিয়ে length i+1 sorted prefix।

Outer n পর্যন্ত বাড়ে। Inner ordered predecessor বা left boundary না-পাওয়া পর্যন্ত কমে। তাই দুটোই থামে। প্রতিটি shift শেষে key ফেরে,তাই completed iteration সব record রাখে।

সময় ও মেমরির হিসাব

Best Θ(n),reverse worst Θ(n²)। Uniform random distinct permutation-এ expected inversion n(n-1)/4,তাই average quadratic। সাধারণ Θ(n+I),auxiliary Θ(1),strict shift stable। এই routine-এর জন্য,শুধু prefix বাড়ানো যেকোনো algorithm-এর নয়।

প্রচলিত ভুল

প্রথম shift-এ key হারানো

Predecessor সরানোর আগে a[i] save করো। নইলে বড় value প্রথম key overwrite করতে পারে।

j যাচাইয়ের আগে a[j] পড়া

&&-এ আগে boundary test রাখো;short-circuit array access বাঁচাবে।

j+1-এর বদলে j-তে বসানো

থামা j acceptable predecessor বা -1। খালি cell তার ঠিক পরে।

C17-এর খুঁটিনাটি

C17 &&-এ left-to-right short-circuit নিশ্চিত। আগে j>=0 দিলে negative-এ a[j] evaluate হয় না।
