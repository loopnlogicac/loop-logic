শুরু করা যাক

উচ্চতা অনুযায়ী student সাজাবে ভাবো। পাশাপাশি ভুল order-এ থাকা দুজনকে বদলে পুরো row হাঁটো। একবার শেষে সবচেয়ে লম্বা ডানে। Bubble sort বাকি row-তে এই local repair করে।

Pass,comparison,invariant শেখায় bubble sort ভালো। সিদ্ধান্ত দেখা সহজ, কিন্তু worst কাজ quadratic। ছোট example-এ প্রতিটি swap বোঝাও। বড় dataset-এর speed এর মূল শক্তি নয়।

সিউডোকোড ও ব্যবহারের নিয়ম

for pass = 0 to n - 2
    swapped = false
    for j = 0 to n - 2 - pass
        if a[j] > a[j + 1]
            swap a[j] and a[j + 1]
            swapped = true
    a[n - 1 - pass] is now in place
    if not swapped: stop early

ধাপে ধাপে বোঝো

এক pass maximum ডানে ঠেলে

Ascending-এ a[j],a[j+1] তুলনা; বাঁটি বড় হলেই swap। দুইটির বড় ডানে যায়। পরের comparison-এ carried maximum আবার পরেরটির সঙ্গে মেলে। তাই বড় value এক pass-এ অনেক cell যেতে পারে।

[7,3,5,3,1]-এ 7 প্রথমে 3,পরে5,3,1 পেরিয়ে [3,5,3,1,7]। Maximum final। পরের pass-এ final7 নয়, unsorted prefix দেখো।

ছোট value আলাদা চলে। শেষের1 প্রথম pass-এ মাত্র এক cell বামে, কারণ আগের pair দেখা হয়ে গেছে। Reverse order-এ বহু pass লাগে কেন বোঝা যায়। Local repair-এ দুজনই final হয় না।

Unfinished prefix ছোট করো

Pass zero থেকে। j zero থেকে n-2-pass পর্যন্ত, j+1 তুলনা। শেষ right index n-1-pass। শেষে বৃহত্তম remaining value ওইখানে final suffix-এ যায়।

সর্বোচ্চ n-1 pass। এতগুলো maximum বসলে প্রথমটিও ঠিক। Singleton-এ pass নেই,empty-তে access নেই। ছোট case-এ signed index দিয়ে n-1 expression সামলানো সহজ।

Pass মানে unfinished prefix জুড়ে sweep; comparison এক pair check; swap শুধু ভুল order-এ data movement। আলাদা গোনো। Same size-এ প্রথম pass comparison এক হলেও swap অনেক আলাদা হতে পারে।

পুরো pass বদল না হলে থামো

প্রতি pass শুরুতে swapped=false; exchange-এ true। পুরো pass-এ কোনো exchange না হলে unfinished prefix-এর সব adjacent pair ordered। Suffix আগেই final, তাই পুরো array sorted; থামতে পারো।

Flag প্রতিবার reset চাই। আগের true থাকলে পরে sorted prefix early exit দেবে না। Sort ঠিক, best-case সুবিধা নেই। একটি comparison-এর পর flag দেখলে পরের reversed pair থাকতেই থেমে যেতে পারো।

Already ascending n>1-এ n-1 comparison,zero swap,stop। Nearly sorted-এও লাভ হতে পারে, সব ছোট disturbance linear নয়। শেষের tiny value বামে আসতে বহু pass লাগতে পারে।

Equal-key record-এর order রাখো

Stable sort equal key-এর আগের record order রাখে। 3A,3B দুই paper-এর arrival মনে রাখো। Strict greater-than equal neighbor swap করে না। A-কে B পার হতে একসময় swap লাগত, যা হয় না।

Greater-than-or-equal করলে এই যুক্তি ভাঙে। Equal record অকারণে বদলায়, equal input-ও early stop নাও দেয়। Plain integer-এ tie reversal দেখা যায় না; label বা record ID ধরে বোঝো।

Bubble input-এই বদলায়, কয়েক counter,flag,saved value রাখে। Strict comparison-এ stable এবং in-place। গুণ দুটি আলাদা; অন্য constant-space sort tie order হারাতে পারে। Sorted number দেখে নয়, labeled equal record অনুসরণ করে তুলনা করো।

Tie-সহ পাঁচ mark সাজাও

চার shrinking sweep maximum ডানে নেয়। আট adjacent swap-এ 1 3 3 5 7।

Keyboard-এর সংখ্যা sort করো

Negative mark-ও comparison-এ সাজে। Keyboard example শেষে -2 -2 0 1 4 7।

Sorted neighbor থেকে distinct mark

Sorted হওয়ার পর পাশের value বদলালেই নতুন group। Distinct mark তিনটি।

এক pass-কে পুরো sort বলো না

এক sweep-এর চার swap-এ 3 5 3 1 7। শেষ7 ঠিক, prefix-এ এখনও উল্টো neighbor।

ধাপঅবস্থাকেন এমন হয়

পদ্ধতিটি কেন সঠিক

Inner pass-এ current right endpoint-এ এতক্ষণ দেখা সর্বোচ্চ মান। পরের comparison-এ invariant থাকে। তাই শেষে unfinished prefix-এর maximum ডানে। পরের pass-এর আগে suffix-এ already placed বৃহত্তম মানগুলো।

প্রতি pass suffix এক বাড়ায় বা no inversion বলে থামে। Swap দুই existing মান বদলায়, কিছু তৈরি-মুছে না। এতে order ও original collection থাকা দুটোই প্রমাণ হয়।

সময় ও মেমরির হিসাব

Worst comparison (n-1)+(n-2)+…+1=n(n-1)/2। Distinct reverse order-এ তত adjacent swap। তাই Θ(n²)। Uniform random permutation model-এ average-ও Θ(n²)। Early exit-এ best Θ(n),auxiliary Θ(1)।

প্রচলিত ভুল

Equal value swap করা

Strict greater-than নাও। Equality ascending মেনেই আছে; swap করলে stability proof হারায়।

Index n-1 পর্যন্ত pair scan

j+1-ও পড়া হয়। Right index n হওয়ার আগেই pair loop থামাও।

একটি swap-free comparison-এ sorted ধরা

পুরো pass বদল না হলেই unfinished prefix-এর সব neighbor order প্রমাণ।
