শুরু করা যাক

তিন-digit student code আগে শেষ,পরে মাঝের,শেষে প্রথম digit-এ সাজাতে পারো। কিন্তু নতুন digit tie হলে আগের order রাখতে হবে। LSD radix sort এভাবেই digit pass মেলায়।

LSD মানে least significant digit first:units,tens,hundreds। Later stable pass আগের lower-digit order না ভেঙে আরও ভালো order বানায়।

সিউডোকোড ও ব্যবহারের নিয়ম

for place in 1, 10, 100
    count[0..9] = 0
    count digit ((a[i] + 99) / place) mod 10 for all i
    accumulate count into prefix ends
    scan i from n - 1 down to 0; place whole a[i] stably
    copy output back into a

ধাপে ধাপে বোঝো

একবারে একটি digit নাও

Nonnegative key-তে digit=(key/place)%10। 472-এ place1→2,10→7,100→4। Integer division lower digit বাদ দেয়,remainder10 পরেরটি নেয়। Missing leading digit zero।

Bounded C-তে original -99..99। প্রত্যেক key-তে99 যোগে order-preserving0..198। Encoded key থেকে digit,কিন্তু original value move। একই constant যোগ integer order রাখে।

198 পর্যন্ত তিন decimal pass যথেষ্ট। Fixed bound-এ place multiply করে overflow ঝুঁকি নেই। General maximum নিলে place*base range ছাড়ানোর আগেই stop চাই। Exact integer digit-এ floating power নয়।

প্রতি digit-এ stable counting

Digit0..9,তাই দশ counter। প্রতি record-এর current digit count,prefix end,তারপর right-to-left buffer placement। পরের digit-এর আগে whole record copy back।

Counting sort-এর একই stable rule,পুরো key নয় এক digit-এ। Output n,count base b-তে b cell। Units থেকে tens-এ frequency বদলাতে পারে,তাই প্রতি pass reset।

শুধু digit নয়,পুরো key/record move। Digit array বানালে পরের pass-এর তথ্য হারায়। Student-এর associated field-ও সঙ্গে যাবে,identity সব pass-এ থাকবে।

Stability lower digit বাঁচায় কেন

Units pass-এর পরে last digit ordered। Tens pass ছোট tens আগে নেয়;এক tens group-এ stable হওয়ায় units order থাকে। তাই last-two-digit number-এর মতো order।

Unshifted [21,13,12]-এ stable units [21,12,13],tens [12,13,21]। Tens tie reverse হলে12,13 ভুল হতে পারে। আগের tie order না রাখলে আলাদা digit sort যথেষ্ট নয়।

Induction-এ d place-এর পরে d low digit-এ sorted। সব digit শেষে tuple পুরো key নির্ধারণ করে। এটিই LSD correctness-এর মূল।

Encoded পাঁচ-value trace

[7,3,5,3,1]-এর encoding [106,102,104,102,100]। Units6,2,4,2,0-তে original [1,3,3,5,7]। Stable placement-এ দুই original3-এর order থাকে।

এখানে tens সবzero,hundreds সবone। দুই pass আগের order অপরিবর্তিত রাখবে। কিছু না-করা pass-ও stability test। Digit boundary পেরোনো দ্বিতীয় example-এ আরও পরিবর্তন দেখো।

[-99,-98,0,99]→[0,1,99,198]। Leading zero comparison model-এর অংশ। একই তিন pass-এ negative branch লাগে না। স্পষ্ট bounded range-offset-এর জন্যই encoding উপযুক্ত।

Parameter-সহ cost বের করো

d digit pass,b base,n record। প্রতি stable counting pass-এ count initialize b,scan n,prefix b,place n,copy n:Θ(n+b)। d বার Θ(d(n+b))।

Output প্রতি pass reuse,workspace Θ(n+b),Θ(dn) নয়। C-তে pass scope-এর আগের buffer পরে বাঁচে না। Peak simultaneous storage জরুরি। Count-ও reset করে reuse।

Fixed digit count ও base-এ n-এ linear হতে পারে। Unbounded integer-এ magnitude-এ d বাড়ে;সবসময় O(n) বললে parameter লুকায়। খুব বড় base-এ কম pass হলেও count initialize-memory dominate করতে পারে।

Comparison sort arbitrary comparable key নেয়। Radix-এ positional encoding-এর digit order intended full order মানতে হবে। Variable string,signed machine integer,locale text-এ আলাদা rule চাই। ছোট signed range-এর offset সব type-এর universal recipe নয়।

ভেবে LSD বাছো

Most-significant-digit strategy উল্টো প্রান্ত থেকে group করে পরে recurse। Control আলাদা,কিছু variable-length key-তে স্বাভাবিক। Iterative LSD proof-এর সঙ্গে তার grouping মেশাবে না।

ছোট bounded key-তে LSD trace সহজ। Tiny n-এ setup insertion বা library sort-এর লাভ ছাড়াতে পারে। Domain ও memory limit দেখে নাও। সুবিধা d,b-এর উপকারী সীমার শর্তে।

পদ্ধতিটি কেন সঠিক

r low digit-এ sorted ধরো। Digit r+1-এর stable pass নতুন digit-এ order দেয়;equal group-এ আগের r-digit order থাকে। তাই combined r+1 low digit sorted। Zero pass-এর base vacuous;সবশেষে full encoded order।

Allowed range-এ +99 strictly increasing,তাই encoded ও original order একই। Buffer-এ প্রতিটি pass whole record রাখে। Fixed তিন pass unbounded power হিসাব ছাড়াই থামে।

সময় ও মেমরির হিসাব

Demo b10,d3,তাই Θ(3(n+10)),peak Θ(n+10)। Width-base variable হলে general Θ(d(n+b)) রাখো। Counting pass থেকে stability,linear buffer বলে strict in-place নয়।

প্রচলিত ভুল

Unstable digit sort নেওয়া

Later equal-digit group আগের low-digit order হারাতে পারে। প্রতিটি pass stable চাই।

Negative key-তে সরাসরি remainder

Negative remainder count index নয়। Digit নেওয়ার আগে order-preserving encoding বলো।

Range guard ছাড়া place multiply

General loop-এ integer place overflow হতে পারে। Pass bound বা multiplication guard দাও।

C17-এর খুঁটিনাটি

এখানে C17 division nonnegative encoding-এ। Fixed place-এ repeated multiplication overflow নেই।
