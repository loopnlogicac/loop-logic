শুরু করা যাক

তিন-ডিজিট student কোড আগে শেষ, পরে মাঝের, শেষে প্রথম ডিজিট-এ সাজাতে পারো। কিন্তু নতুন ডিজিট tie হলে আগের order রাখতে হবে। LSD radix সর্ট এভাবেই ডিজিট pass মেলায়।

LSD মানে least significant ডিজিট first:units, tens, hundreds। Later stable pass আগের lower-ডিজিট order না ভেঙে আরও ভালো order বানায়।

সিউডোকোড ও ব্যবহারের নিয়ম

for place in 1, 10, 100
    count[0..9] = 0
    count digit ((a[i] + 99) / place) mod 10 for all i
    accumulate count into prefix ends
    scan i from n - 1 down to 0; place whole a[i] stably
    copy output back into a

ধাপে ধাপে বোঝো

একবারে একটি ডিজিট নাও

Nonnegative কী-তে digit=(কী/place)%10। 472-এ place1→2,10→7,100→4। ইন্টিজার division lower ডিজিট বাদ দেয়, remainder10 পরেরটি নেয়। Missing leading ডিজিট zero।

Bounded C-তে original -99..99। প্রত্যেক কী-তে99 যোগে order-preserving0..198। Encoded কী থেকে ডিজিট, কিন্তু original ভ্যালু move। একই কনস্ট্যান্ট যোগ ইন্টিজার order রাখে।

198 পর্যন্ত তিন decimal pass যথেষ্ট। Fixed bound-এ place multiply করে overflow ঝুঁকি নেই। General maximum নিলে place*base range ছাড়ানোর আগেই stop চাই। Exact ইন্টিজার ডিজিট-এ floating power নয়।

প্রতি ডিজিট-এ stable counting

Digit0..9, তাই দশ কাউন্টার। প্রতি রেকর্ডের current ডিজিট কাউন্ট, prefix end, তারপর right-to-left বাফার placement। পরের ডিজিট-এর আগে whole রেকর্ড copy back।

Counting সর্ট-এর একই stable rule, পুরো কী নয় এক ডিজিট-এ। আউটপুট n, কাউন্ট base b-তে b cell। Units থেকে tens-এ frequency বদলাতে পারে, তাই প্রতি pass reset।

শুধু ডিজিট নয়, পুরো কী/রেকর্ড move। ডিজিট অ্যারে বানালে পরের pass-এর তথ্য হারায়। Student-এর associated field-ও সঙ্গে যাবে, identity সব pass-এ থাকবে।

Stability lower ডিজিট বাঁচায় কেন

Units pass-এর পরে last ডিজিট ordered। Tens pass ছোট tens আগে নেয়;এক tens group-এ stable হওয়ায় units order থাকে। তাই last-two-ডিজিট number-এর মতো order।

Unshifted [21,13,12]-এ stable units [21,12,13], tens [12,13,21]। Tens tie reverse হলে12,13 ভুল হতে পারে। আগের tie order না রাখলে আলাদা ডিজিট সর্ট যথেষ্ট নয়।

Induction-এ d place-এর পরে d low ডিজিট-এ sorted। সব ডিজিট শেষে tuple পুরো কী নির্ধারণ করে। এটিই LSD correctness-এর মূল।

Encoded পাঁচ-ভ্যালু trace

[7,3,5,3,1]-এর encoding [106,102,104,102,100]। Units6,2,4,2,0-তে original [1,3,3,5,7]। Stable placement-এ দুই original3-এর order থাকে।

এখানে tens সবzero, hundreds সবone। দুই pass আগের order অপরিবর্তিত রাখবে। কিছু না-করা pass-ও stability টেস্ট। ডিজিট boundary পেরোনো দ্বিতীয় example-এ আরও পরিবর্তন দেখো।

[-99,-98,0,99]→[0,1,99,198]। Leading zero কম্পারিজন মডেল-এর অংশ। একই তিন pass-এ negative branch লাগে না। স্পষ্ট bounded range-offset-এর জন্যই encoding উপযুক্ত।

Parameter-সহ cost বের করো

d ডিজিট pass, b base, n রেকর্ড। প্রতি stable counting pass-এ কাউন্ট initialize b, scan n, prefix b, place n, copy n:Θ(n+b)। d বার Θ(d(n+b))।

আউটপুট প্রতি pass reuse, workspace Θ(n+b),Θ(dn) নয়। C-তে pass scope-এর আগের বাফার পরে বাঁচে না। Peak simultaneous স্টোরেজ জরুরি। কাউন্ট-ও reset করে reuse।

Fixed ডিজিট কাউন্ট ও base-এ n-এ linear হতে পারে। Unbounded ইন্টিজার-এ magnitude-এ d বাড়ে;সবসময় O(n) বললে parameter লুকায়। খুব বড় base-এ কম pass হলেও কাউন্ট initialize-মেমরি dominate করতে পারে।

কম্পারিজন সর্ট arbitrary comparable কী নেয়। Radix-এ positional encoding-এর ডিজিট order intended full order মানতে হবে। ভেরিয়েবল string, signed machine ইন্টিজার, locale text-এ আলাদা rule চাই। ছোট signed range-এর offset সব type-এর universal recipe নয়।

ভেবে LSD বাছো

Most-significant-ডিজিট strategy উল্টো প্রান্ত থেকে group করে পরে recurse। Control আলাদা, কিছু ভেরিয়েবল-length কী-তে স্বাভাবিক। Iterative LSD proof-এর সঙ্গে তার grouping মেশাবে না।

ছোট bounded কী-তে LSD trace সহজ। Tiny n-এ setup insertion বা library সর্ট-এর লাভ ছাড়াতে পারে। Domain ও মেমরি limit দেখে নাও। সুবিধা d, b-এর উপকারী সীমার শর্তে।

পদ্ধতিটি কেন সঠিক

r low ডিজিট-এ sorted ধরো। ডিজিট r+1-এর stable pass নতুন ডিজিট-এ order দেয়;equal group-এ আগের r-ডিজিট order থাকে। তাই combined r+1 low ডিজিট sorted। Zero pass-এর base vacuous;সবশেষে full encoded order।

Allowed range-এ +99 strictly increasing, তাই encoded ও original order একই। বাফারে প্রতিটি pass whole রেকর্ড রাখে। Fixed তিন pass unbounded power হিসাব ছাড়াই থামে।

প্রচলিত ভুল

Unstable ডিজিট সর্ট নেওয়া

Later equal-ডিজিট group আগের low-ডিজিট order হারাতে পারে। প্রতিটি pass stable চাই।

Negative কী-তে সরাসরি remainder

Negative remainder কাউন্ট ইনডেক্স নয়। ডিজিট নেওয়ার আগে order-preserving encoding বলো।

Range guard ছাড়া place multiply

General লুপ-এ ইন্টিজার place overflow হতে পারে। Pass bound বা multiplication guard দাও।

C17-এর খুঁটিনাটি

এখানে C17 division nonnegative encoding-এ। Fixed place-এ repeated multiplication overflow নেই।
