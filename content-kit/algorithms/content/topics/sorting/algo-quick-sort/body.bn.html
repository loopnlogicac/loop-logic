শুরু করা যাক

এক mark divider করে ছোট এক পাশে,বড় অন্য পাশে নাও। তারপর আলাদা করে সাজাও। Quick sort এই partition করে। Merge sort-এর মতো পরে নয়,children সাজানোর আগেই মূল rearrangement।

Balanced ভাগে দ্রুত,কিন্তু pivot অসম কাজ বানাতে পারে। Pivot choice-এর মতো partition contract-ও জরুরি। Lomuto ও Hoare-এর boundary আলাদা,recursion নিজ নিয়ম মানবে।

সিউডোকোড ও ব্যবহারের নিয়ম

quick_sort(low, high): if low >= high: return
pivot = a[high]; i = low
for j = low to high - 1
    if a[j] <= pivot: swap a[i], a[j]; i = i + 1
swap a[i], a[high]; p = i
quick_sort(low, p - 1)
quick_sort(p + 1, high)

ধাপে ধাপে বোঝো

Lomuto একটি pivot final করে

Lomuto-তে inclusive [low,high]-এর শেষ a[high] pivot। i=low; j low থেকে high-1 scan। i-এর আগে ≤pivot,i থেকে j-1 >pivot,j থেকে high-1 এখনও unclassified।

a[j]≤pivot হলে a[i],a[j] swap,i বাড়াও। নইলে greater region-এ থাক। শেষে a[i] ও high-এর pivot swap। p=i এখন final;আগে সব ≤pivot,পরে সব >pivot।

[low,p-1],[p+1,high] সাজাও,p দুটোতেই বাদ। Empty-singleton closed interval-এ কাজ নেই। Less-than-or-equal-এ tie left-এ যায়। বৈধ হলেও pivot-এর সমান অনেক key-তে খুব unbalanced split।

শেষ value pivot-এর trace

[7,3,5,3,1]-এ pivot1 সবার ছোট। i বাড়ে না। Final swap-এ [1,3,5,3,7],p0। শুধু right interval nontrivial।

পরে pivot7-এ সবাই eligible,self-swap-সহ p4। [3,5,3]-এ pivot3 দুই3-কে left-এ নিয়ে index2-তে বসে;ফল [1,3,3,5,7]। বাকি piece singleton।

দুই index সমান swap-এ array বদলায় না,তবু written rule মেলে। Physical exchange গুনলে skip করতে পারো। Convention না বলে self-swap গোনা version-এর count-এর সঙ্গে তুলনা করবে না।

Hoare split boundary দেয়

Hoare-এ প্রায়ই middle value pivot,scan দুই প্রান্তের বাইরে। i ডানে গিয়ে ≥pivot,j বামে গিয়ে ≤pivot-এ থামে। Meet/cross হলে j boundary ফেরাও;নইলে swap করে আবার scan।

পরের value test-এর আগে scan এগোয়। Equal pivot-এও swap-এর পরে দুই scan progress চাই। Interval-এর value pivot হওয়ায় initial stopping value আছে। Recipe বদলালে bound ও pivot একসঙ্গে বিশ্লেষণ করো।

Returned j boundary,pivot-এর final position হওয়া বাধ্যতামূলক নয়। Recursion [low,j],[j+1,high]। Lomuto p-1 নিলে unsorted value বাদ যেতে পারে। উল্টোতে Lomuto pivot আবার নিলে shrink নাও হয়।

Hoare প্রায়ই basic Lomuto থেকে কম exchange করে,বিশেষত equal key-তে। তবু distant exchange equal record পার করতে পারে বলে সাধারণত unstable। Partition-এর নাম constant stack বা bad-split immunity দেয় না।

Balanced ও unbalanced recurrence

Partition Θ(n)। প্রায় সমান দুই ভাগে2T(n/2)+Θ(n),তাই Θ(n log n)। বারবার empty ও n-1-এ T(n-1)+Θ(n),তাই Θ(n²)।

Final pivot-এ ascending distinct input প্রতিবার largest নেয়। Reverse-ও extreme। All-equal-এ এই ≤Lomuto সবাইকে এক পাশে দেয়। “Sorted” সব sort-এর best case নয়।

দুই-recursive-call version worst O(n) stack;random pivot-এ expected O(log n) depth। ছোট পাশে recurse,বড়তে loop করলে guaranteed O(log n) stack। Time quadratic হলেও memory নিয়ন্ত্রণ হয়।

Random pivot-এ probability model

Randomized version active interval-এর uniform index high-এ এনে একই Lomuto চালায়। Distinct key-র প্রতিটি fixed input-এ expected Θ(n log n)। Extreme rank বারবার unlikely,অসম্ভব নয়।

Worst এখনও Θ(n²)। Fixed seed demo repeatable;usual proof-এ সত্যিকারের uniform source লাগে। C rand()%length bias দিতে পারে। Real implementation-এ উপযুক্ত unbiased choice চাই।

ছোট reproducible প্রোগ্রামে unsigned generator-এর defined wraparound ও rejection sampling bounded index দিতে পারে। Mechanism দেখায়,cryptographic randomness নয়। Pivot distribution-এর analysis pure partition correctness থেকে আলাদা।

Duplicate বেশি হলে three-way partition-এ below,equal,above আলাদা;equal group recursion চায় না। Basic Lomuto all-equal degeneration এড়ায়। এটি extra variant;animation stated two-way contract-এ প্রথম C example-এর সঙ্গে মেলে।

পদ্ধতিটি কেন সঠিক

Invariant:a[low..i)≤pivot,a[i..j)>pivot,a[j..high)unclassified। Eligible key i-তে এনে boundary বাড়ালে থাকে। বড় key reject-এ greater region বাড়ে। Final exchange পর্যন্ত pivot high-এ।

Swap-এর পরে p final pivot। Length induction-এ দুই ছোট child sorted;সব left≤pivot,সব right>pivot। জোড়া দিলে sorted,সব record অক্ষত। Strictly ছোট interval base-এ নিয়ে stop করে।

সময় ও মেমরির হিসাব

Lomuto partition linear,local workspace constant। Balanced tree-তে logarithmic level-এ linear total per level;chain n,n-1,…-এ quadratic। Simple routine unstable,stack potentially linear। Random pivot fixed distinct input-এর expected time ভালো করে,deterministic worst বদলায় না।
