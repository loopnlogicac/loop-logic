শুরু করা যাক

Roll-এ সাজানো দুই pile খাতা মেলাতে দুই সামনের ছোটটি বারবার নাও। কোনোটির মাঝখানে খুঁজতে হয় না। Merge sort আগে input ভাগ করে recursively সাজিয়ে এই অবস্থা বানায়।

নির্দিষ্ট growth-এর বিনিময়ে extra array লাগে। Balanced split logarithmic depth,প্রতি level merge-এ সব value চলে। Reverse ও sorted input-এও bad pivot-এর quadratic chain হয় না।

ধাপে ধাপে বোঝো

Half-open interval-এ ভাগ করো

merge_sort(a,temp,low,high),[low,high) সাজায়। Length<2 হলে empty/singleton আগেই sorted। নইলে mid-এ [low,mid),[mid,high) দুই nonoverlapping half;সব original position আছে।

আগে left,তারপর right recursive sort। দুটো শেষ হলে parent merge। প্রতিটি half sorted ধরে নেওয়া যায়,সব left সব right-এর ছোট নয়;range overlap ও tie থাকতে পারে।

পাঁচ value-এ length2,3;তিনেরটি1,2। একদম সমান লাগে না,ফারাক সর্বোচ্চ এক হলেই balanced। low+(high-low)/2-এ দুই boundary সরাসরি যোগও লাগে না।

দুটি sorted front মেলাও

Left front i=low,right j=mid,temp output k=low। দুটোতেই value থাকা পর্যন্ত ছোট front temp[k]-তে copy,ওই front ও k বাড়াও। Sorted half-এ front-এর পেছনেরটি তার চেয়ে ছোট হতে পারে না।

এক half শেষ হলে অন্যটির বাকি tail copy;আর cross-half comparison নেই,ভেতরে sorted। Temp-এ ঠিক high-low value। সব source পড়া শেষ হলেই a-তে copy back।

দুই half পড়তে পড়তে original-এ লিখলে unread value overwrite হতে পারে। Buffer এই ঝুঁকি সরায়। Bounded demo-তে এক64-cell buffer সব call-এ পাঠানো। General n-এ একবার proportional capacity নাও,প্রতি comparison-এ নতুন full array নয়।

পাঁচ মানের merge অনুসরণ করো

বামে [7],[3] মিলে [3,7]। ডানে [3],[1] মিলে [1,3];তার সঙ্গে [5] মিলে [1,3,5]। Final parent-এর half [3,7] ও [1,3,5]।

প্রথমে3 বনাম1-এ right1। তারপর3 বনাম3-এ left3। পরে right3,right5,শেষে left7। ফল [1,3,3,5,7],animation-এর একই input।

Boundary position ও value আলাদা লেখো। Mid original split চেনে। Merge-এ value তা পার হতে পারে,কিন্তু sorted interval-এর endpoint একই। Location বদলালেও record count থাকে।

Equality rule থেকে stability

Equal front-এ less-than-or-equal দিয়ে left আগে। Original-এ left half আগে ছিল। Induction-এ দুই half stable;এই choice global tie order রাখে।

Equality-তে right আগে নিলে সংখ্যা sorted থাকলেও split পেরোনো equal record উল্টায়। [3A],[3B]-এ [3B,3A]। Integer output ঢাকে;proof-এ label নাও।

Standard buffer version stable,strict constant-workspace অর্থে in-place নয়। জটিল in-place merge আছে,আলাদা movement-cost proof লাগে। তার গুণ এখানে বসাবে না।

সময়-মেমরি হিসাব করো,মুখস্থ নয়

m value merge-এ প্রতি iteration এক emit,পরে প্রতিটি এক copy back:Θ(m)। Balanced recurrence T(floor(n/2))+T(ceil(n/2))+Θ(n),base constant। Power of two-তে পরিচিত2T(n/2)+Θ(n)।

প্রতি full level-এর subarray length যোগ n,level Θ(log n),তাই Θ(n log n)। এই version sorted input-ও ভাগ-merge করে,best-ও একই। Already-ordered boundary check কিছু input উন্নত করতে পারে,আলাদা optimization।

Scalable shared buffer Θ(n),frame-এ অল্প index-reference হলে recursion Θ(log n)। Buffer dominate,মোট auxiliary Θ(n)। Input-ও Θ(n),তাই total linear।

Sequential merge সস্তা হলে স্বাভাবিক পছন্দ। External sort-এ storage-এর run stream করা যায়। Linked structure-এ array copy নয়,node relink হতে পারে। Representation storage detail বদলায়,divide-merge proof একই ধরনের।

Interval length-এ induction। দুইয়ের নিচে sorted। ছোট দুই half hypothesis-এ sorted;merge lemma-তে তাদের union-এর sorted permutation। প্রতিটি interval ছোট বলে base-এ পৌঁছে stop।
