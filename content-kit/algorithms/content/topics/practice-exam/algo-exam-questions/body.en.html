Practise the reasoning aloud

Use these questions as a timed midterm and final rehearsal. Write the state definition, show intermediate rows and justify the final answer. The sorting, DP and graph examples below include complete worked values so you can locate the first place your trace differs. A different equal-cost witness can be valid when the question allows ties.

1. State a binary-search invariant for a sorted array.

Before each iteration, any occurrence of the target still under consideration lies in [low,high). Compare the midpoint and retain only the half that can contain it. The interval shrinks and an empty interval proves absence.

2. Show every left-to-right bubble-sort pass on [4,1,3,2], shortening the suffix each time.

Pass 1 compares 4/1, 4/3, 4/2 and leaves [1,3,2,4]. Pass 2 compares 1/3 then 3/2, leaving [1,2,3,4]. Pass 3 makes no swap. The final order is [1,2,3,4]; the comparison counts are 3,2,1.

3. Fill the 0/1 knapsack table for weights [1,2,3], values [2,4,4] and capacity 4. Recover items.

Columns are capacities 0..4. Row 0: [0,0,0,0,0]. After item 1: [0,2,2,2,2]. After item 2: [0,2,4,6,6]. After item 3: [0,2,4,6,6]. At row 3, capacity 4 ties the previous row, so skip item 3. Take item 2, leaving capacity 2, then item 1. Weight 3, value 6.

4. Run Dijkstra from A on undirected edges AB=4, AC=2, BC=1, BD=5, CE=8, DE=2, DF=6, EF=3.

Columns A,B,C,D,E,F start [0,INF,INF,INF,INF,INF]. Settle A: [0,4,2,INF,INF,INF]. Settle C: [0,3,2,INF,10,INF]. Settle B: [0,3,2,8,10,INF]. Settle D: [0,3,2,8,10,14]. Settle E: [0,3,2,8,10,13]. Settle F: unchanged. Parents are A:none, B:C, C:A, D:B, E:C, F:E when equal paths keep the earlier parent. A-C-E-F costs 13.

5. Use Kruskal on that same A-F graph and show accepted and rejected edges.

Sorted weights: BC=1, AC=2, DE=2, EF=3, AB=4, BD=5, DF=6, CE=8. Accept BC, AC, DE, EF. Reject AB because A and B are already connected. Accept BD to join the two components. The five tree edges total 13. If remaining edges are inspected, DF and CE are rejected as cycles.

6. Derive merge sort's recurrence and explain the space cost.

Each call sorts two halves then merges in linear time: T(n)=2T(n/2)+Theta(n), with constant base work. There are log2(n) levels with Theta(n) work each, so time is Theta(n log n). A reusable merge buffer needs Theta(n) space and active recursion adds O(log n), so peak auxiliary space remains O(n).

7. Build the LCS length table for AB and AC, then recover one LCS.

Rows are empty,A,AB; columns empty,A,AC. The rows are [0,0,0], [0,1,1], [0,1,1]. At unequal B/C move up on a tie. At A/C move left. A matches A, giving LCS A of length one. Other tie rules may trace different equal-length witnesses on larger inputs.

8. Explain why Dijkstra's settled-distance proof needs nonnegative edges.

At settlement, an alternative path through an unsettled vertex cannot become cheaper if every remaining edge is nonnegative. A negative edge can violate that lower-bound argument. Example A->B=2, A->C=5, C->B=-4 settles B at 2 before discovering a path of cost 1. Bellman-Ford handles such edges.

9. Trace the prefix function for ababaca.

pi is [0,0,1,2,3,0,1]. At c, matched length 3 falls to pi[2]=1, then pi[0]=0; c matches neither b nor a. The final a extends a zero border to length one. Total fallback work remains linear by counting matched-length increases and decreases.

10. Prove that at least three exam slots are necessary and sufficient for edges AB, AC, BC, CD, DE.

The triangle ABC forces three distinct colours, giving a lower bound of three. Assign A=1, B=2, C=3, D=1, E=2. Every listed edge has different endpoint labels. This witness gives the matching upper bound, so the minimum is exactly three.

11. Distinguish NP membership from NP-hardness using m-colouring.

Membership gives a polynomial verifier for a proposed colour per vertex. Hardness requires a polynomial reduction from a known hard problem into the colouring decision problem. Checking a certificate does not by itself prove hardness, and a slow backtracking solver does not prove it either.

12. Unwind Euclid for 30 and 18 and find a modular inverse of 3 modulo 11.

30=18+12, 18=12+6, 12=2*6, so gcd is 6. Substitution gives 6=-30+2*18. Separately, 3*4=12=1 mod 11, so 4 is the inverse. The gcd of 3 and 11 is 1, which guarantees existence.

Identify the next weak point

After checking your answers, select one technique where the state or proof was unclear. Recreate its smallest example without looking, then change one condition and decide whether the same reasoning still applies. This turns revision into an active test of understanding.
