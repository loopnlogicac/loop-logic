শুরু করা যাক

ছোট টেবিলে নম্বর দেওয়া card উল্টাতে হবে। একটি খালি জায়গায় দুই প্রান্ত swap করতে পারো, অথবা সব card আরেক row-তে copy করতে পারো। দুটোই উল্টায়, দ্বিতীয়টিতে অনেক বেশি জায়গা লাগে।

Space complexity ইনপুট size-এর সঙ্গে মেমরি কীভাবে বাড়ে বলে। সাধারণত peak মেমরি জরুরি: একই সময়ে কত storage চাই? সারাজীবনে অনেক temporary object allocate-free করেও একসঙ্গে অল্প কয়েকটি থাকতে পারে।

সিউডোকোড ও ব্যবহারের নিয়ম

left = 0; right = n - 1
while left < right
    saved = a[left]
    a[left] = a[right]; a[right] = saved
    left++; right--

ধাপে ধাপে বোঝো

Auxiliary ও total space আলাদা

Input অ্যারে n cell। Auxiliary space ইনপুটের বাইরে বাড়তি কাজের storage; output গোনার convention বলতে হবে। Total space-এ input-ও আছে। Returned array-কে কিছু বই আলাদা ধরে, তাই নিজের হিসাব স্পষ্ট করো।

Iterative sum-এ sum,i ও অল্প bookkeeping, তাই Θ(1) auxiliary; input-সহ Θ(n)। Copied reverse-এ দ্বিতীয় n-element row, output ধরলে Θ(n) extra। Return করলেই cell অদৃশ্য হয় না।

Byte-এর আগে cell বা word-এ growth মাপো। int চার byte হলে n-element array-এর element 4n byte। Exact count platform-নির্ভর; cell চার বা আট byte হলেও Θ(n)। C-তে local size দরকার হলে sizeof নাও।

দুই boundary রেখে উল্টাও

এখানকার strict অর্থে in-place algorithm input-এই বদলায়, constant extra কাজের জায়গা নেয়। Reversal-এ left,right ও saved value। a[left],a[right] swap করে দুই boundary ভেতরে নাও। দ্বিতীয় growing row নেই।

[7,3,5,3,1]-এ প্রথম swap [1,3,5,3,7]। দ্বিতীয়তে সমান 3 বদলালেও ছবি এক। মাঝের 5 সরাতে হয় না। Even length-এ left right পার হলে stop। Empty-তে right=-1, array access নেই।

Saved variable swap-এ মান হারানো আটকায়। পুরোনো right বাঁচানোর আগে left সরাসরি right-এ লিখলে তথ্য overwrite। Memory বাঁচানো required multiset নষ্ট করার ছাড় নয়। Final order ও সব মূল মান আছে কি না দেখো।

Recursion frame বাঁচিয়ে রাখে

Function call ফেরার জন্য local variable ও return location-এর মতো তথ্য রাখে। এই context stack frame। Recursive call caller frame বাঁচিয়ে রাখে। Frame-প্রতি অল্প variable হলেও দীর্ঘ chain constant space নয়।

n-1 করে zero পর্যন্ত গেলে n+1 frame একসঙ্গে থাকতে পারে: Θ(n)। এক floor(n/2) call-এ depth Θ(log n)। Depth program 8,4,2,1-এ চার live level বলে; base frame-ও গোনে।

পরপর দুই recursive call peak stack দ্বিগুণ করবেই নয়। Balanced split-এ left ফিরে তারপর right শুরু। Root-to-leaf এক path-এর Θ(log n) frame, local data constant। Total call Θ(n) হতে পারে। Time branch যোগ করে, peak space একসঙ্গে জীবিত data দেখে।

Temporary array ও allocation lifetime

Merge sort একটি shared n-cell temporary array সব call-এ reuse করতে পারে। Workspace Θ(n); logarithmic stack এই order বদলায় না। প্রতি call নিজ array নিলে কখন free হয় দেখো। Halving path-এর array geometric sum, কিন্তু সব finished level-এর array রেখে দিলে বেশি লাগতে পারে।

Dynamic allocation heap-এ storage নেয়, হিসাব থেকে সরায় না। C-তে heap object-এর lifetime তুমি চালাও। শেষ ব্যবহার হলে owned allocation free করো। Local automatic array-এর pointer return অবৈধ, lifetime শেষ হয়ে যায়।

ছোট fixed capacity-তে অ্যালগরিদমে মন দেওয়া সহজ। নির্দিষ্ট int temp[64] fixed। কিন্তু যেকোনো n সামলানো merge-এ capacity বাড়বে, তাই linear workspace। Fixed demo নাকি scalable method বিশ্লেষণ করছ বলো।

মেমরির সমঝোতা দেখে পদ্ধতি নাও

Copy-তে original রাখা সহজ। In-place memory বাঁচালেও caller-এর দরকারি order নষ্ট করতে পারে। Contract দেখে নাও। Original ও reversal দুটো চাইলে অন্য output representation বা পরে restore লাগবে।

পাশাপাশি duplicate compact-এ sorted array-তে read ও write position রাখো। Write read-এর সামনে যায় না, তাই রাখা value লিখলে ভবিষ্যতের unread মান নষ্ট হয় না। Returned length পর্যন্ত prefix-ই result।

In-place ও stable এক নয়। Stable equal-key record-এর আগের relative order রাখে। In-place workspace বলে। Selection sort constant space-এ distant swap করে equal record উল্টাতে পারে। আলাদা প্রশ্ন, আলাদা প্রমাণ চাই।

পদ্ধতিটি কেন সঠিক

প্রতি reversal iteration-এর আগে [left,right]-এর বাইরের position final reversed মানে আছে। বাকি interval-এ উল্টানো বাকি মান। দুই endpoint swap-এ দুটো final, interval ছোটে invariant থাকে। সর্বোচ্চ একটি বাকি হলে সব ঠিক।

অসমাপ্ত interval দুই করে কমে, তাই stop। Compaction-এর invariant আলাদা: a[0..used)-এ processed prefix-এর প্রতি distinct value একবার; পরের read-এর আগে used≤i। দ্বিতীয় শর্ত reuse নিরাপদ বোঝায়।

সময় ও মেমরির হিসাব

Reversal floor(n/2) swap ও তিন integer-এ Θ(n) time,Θ(1) auxiliary। Copied reversal-ও Θ(n) time, এখানে output ধরায় Θ(n) space। Exact frame byte লাগে না; compiler,optimization,calling convention-এ বদলায়। Growth simultaneous frame-এ নির্ভর করে।
