শুরু করা যাক

Message-এ কোনো symbol বেশি আসে। সবার সমান bit না দিয়ে frequent-এর ছোট,rare-এর বড় code দিলে সুযোগ মেলে। Positive symbol frequency থেকে Huffman variable-length binary code বানায়।

Length ভিন্ন হলে symbol কোথায় শেষ বোঝা চাই। Prefix code-এ কোনো complete code অন্যটির prefix নয়। Binary tree-তে bit ধরে leaf পেলেই symbol চেনা যায়;separator bit লাগে না।

Objective সব frequency×code length-এর যোগ,total message bit। Leaf depth-ই length বলে weighted external path length। Decoder-এ tree/codebook-ও পৌঁছাতে হবে। Huffman data-bit minimize করে,codebook free বলে না।

ছয় symbol fixed-length-এ three bit। Total100 occurrence-এ300 bit;Huffman224। Unequal frequency ও shared codebook-এ লাভ। খুব ছোট message codebook পাঠানোর খরচ নাও তুলতে পারে।

Leaf-এ symbol frequency,internal-এ descendant sum। Queue-তে available tree root। দুই smallest তুলে parent বানিয়ে আবার ঢোকাও,এক root পর্যন্ত। Single-symbol forest এক full prefix tree হয়।

C-তে Node array ও node-ID binary min-heap। কমweight আগে,tie-তে কমID। Leaf0..n-1 হলোA onward,internal IDn থেকে বাড়ে। First minimum left bit0,second right bit1।

Tie rule codebook repeatable। অন্য tie-তেও আলাদা equally optimal code। Left-right সব উল্টালেও length এক। Decoder actual chosen book নেবে;optimal মানে unique bit string নয়।

Encode-এ root-to-leaf path বা saved table নাও,message order-এ concatenate। এখানেF0,C100,D101,A1100,B1101,E111। FACE01100100111।

Complete stream শেষ leaf emit-এর পর root-এ থাকে। Internal path-এর মাঝে শেষ হলে truncated। Nonbinary ও impossible child path reject। Valid stream unambiguous,prefix নিজে সব transmission error ধরতে পারে না।

পদ্ধতিটি কেন সঠিক

Full prefix tree-র greatest-depth sibling leaf pair নাও;deepest internal-এর দুই child leaf হবেই। Least weight x,y-কে সেখানে নিলে weighted cost বাড়ে না। ছোট weight নিচে,বড় ওপরে swap-এ change nonpositive।

তাই x,y deepest sibling এমন optimum আছে। Combined x+y leaf-এ contract করলে অন্য depth এক,x,y one edge কম। Original cost=reduced cost+x+y। Reduced optimum না হলে betterটি বসিয়ে original আরও ভালো হতো,বিরোধ।

দুটি property-ই প্রমাণ:least-two safe greedy choice,contracted alphabet একই form-এর optimal subproblem। বারবার contract করে উল্টোয় optimal tree। Single-symbol depthzero convention আলাদা।

Single-child internal redundant হলে remove-এ নিচের leaf ছোটে,objective বাড়ে না। Positive frequency-তে optimum full ধরা যায়। তাই arbitrary tree shape ধরে নয়,full sibling proof বৈধ।
