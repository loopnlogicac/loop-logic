Introduction

A bookmark tells you how far you have read in a rule. LR items use a dot as that bookmark. A collection of bookmarks records several grammar possibilities at once. The parser state keeps exactly that collection.

An LR(0) item is a production with a dot at one position on its right side. The item A → b · c says b has been recognised and c is still expected. The 0 means the item carries no lookahead component. It does not mean the running parser cannot inspect the next input token.

SLR, or Simple LR, uses LR(0) states and FOLLOW sets to restrict completed-rule reductions. ACTION chooses what to do on a terminal lookahead. GOTO chooses the state reached after recognising a nonterminal. These two tables cooperate with the stack from shift-reduce parsing.

Compute closure before following an edge

Start with S′ → · S. Whenever an item has a nonterminal B immediately after its dot, add B → · γ for every B production. Repeat this addition rule until no new item appears. The result is closure. An item whose dot precedes a terminal creates no further predictions.

For an item set I and grammar symbol X, move every dot immediately before X past that X. Then take closure of the moved set. This defines GOTO(I,X). An empty moved set produces no edge. All matching items move together; choosing only one can lose a future reduction.

For example, GOTO(I0,b) advances both S → · b and A → · b. Its target therefore contains S → b · and A → b ·. No closure expansion remains because both dots are at the end. GOTO(I0,A) instead contains S → A · a, and its a edge reaches the completed S → A a · item.

Reasoning and checks

The canonical collection is the set of distinct reachable LR item sets. Start from closure of the augmented seed. Repeatedly compute outgoing GOTOs and add any new item set. Stop when all discovered states have been processed. Equality compares complete sets, not their displayed order or their assigned numbers.

A state represents a viable prefix: a stack prefix that can occur before a valid handle is passed. The item automaton follows grammar symbols already recognised on that stack. During actual parsing, terminal transitions arise from shifts and nonterminal transitions arise from reductions. The state stack remembers the earlier context so reductions can return to the correct GOTO source.

Closure must reach a fixed point even when grammar rules are recursive. Each production has only finitely many dot positions, so only finitely many LR(0) items exist. A closure pass only adds items. The complete canonical collection also terminates because only finitely many subsets of that finite item universe exist. The number of subsets can still be large, so termination does not promise cheap construction.

An SLR grammar has no conflicts after all shifts, reductions, and acceptance entries are inserted. Detect conflicts after combining the contributions from every item and edge. A completed item does not have priority over a shift item, and earlier production numbering gives no mathematical priority. The Python implementation stores action sets so competing choices remain visible.

FOLLOW is a global approximation. It lists tokens that may follow A anywhere in the grammar. A particular item state may permit only some of those contexts. SLR can therefore introduce a conflict even when a more precise LR(1) construction is deterministic. The next topic carries context-specific lookaheads on the items themselves.

To check a table by hand, first verify the item sets and graph. Then verify each shift from a terminal edge and each GOTO from a nonterminal edge. Finally compare every reduction row with the exact FOLLOW set of its left side. This order localises a wrong cell to either a state-construction mistake or a reduction-placement mistake.

Common mistakes

Moving the dot without taking closure

A newly exposed nonterminal may require more start items. Close every GOTO result before comparing it with existing states.

Using FIRST of the right side for an SLR reduction

A completed phrase has already been read. Its legal following tokens come from FOLLOW of its left side, not FIRST of its right side.

Reducing the augmented production normally

The augmented completion means accept on $. It does not create an r0 action across the row.

Popping the initial state

Pop one state per right-side symbol and keep the exposed context state. Empty productions pop nothing.

Summary

LR(0) items record progress, closure predicts possible phrases, and GOTO builds the state graph. SLR places completed-rule reductions using FOLLOW. Continue to CLR and LALR to keep more precise lookahead information.
