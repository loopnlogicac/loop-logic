Introduction

Think of a regular expression as a plan made from small pieces. Thompson construction turns each piece into a small path diagram. You connect the diagrams using a few fixed rules. The result recognises the same strings as the expression, even when the expression contains nested choices and repetitions.

A fragment is an unfinished automaton with one entry and one exit. Thompson construction gives every expression such a fragment. The exit becomes accepting only when the fragment represents the whole expression. Internal exits lose that special role when larger fragments surround them.

This lesson uses the alphabet {a, b}. Concatenation means joining strings, the vertical bar means choice, and star means zero or more repetitions. Parentheses group operations. The usual precedence is star first, concatenation second, and union last. State numbers are labels, not quantities to add or multiply.

An epsilon transition, written ε, moves between states without consuming input. Epsilon is not a character in the source string. Such transitions let us join fragments without adding unwanted letters to the language. An NFA can follow several possible paths; acceptance requires at least one complete accepting path.

Worked examples

Build the literal and empty-string fragments

For a literal a, create a fresh entry and exit, joined by an a-labelled edge. The fragment accepts exactly the one-character string a. A literal b uses the same shape with a b edge. A fragment for ε uses an epsilon edge and therefore consumes no character.

Do not confuse the empty language ∅ with the empty string ε. The first contains no strings. The second is a string with length zero. A recogniser for ε accepts before reading a character. A recogniser for ∅ never accepts.

Join, choose, and repeat

For concatenation RS, first build separate fragments for R and S. Connect the exit of R to the entry of S with ε. Keep R's entry and S's exit as the larger fragment's boundaries. This version keeps all states distinct, so every connection remains visible.

For union R|S, create a new entry and a new exit. The new entry branches by ε into either old entry. Each old exit reaches the new exit by ε. A path chooses one branch for that occurrence of the union; it does not have to consume both branches.

For R*, create another entry and exit. Add ε from the new entry into R and directly to the new exit. Add ε from R's exit back to R's entry and onward to the new exit. The bypass accepts zero repetitions. The loop allows further repetitions after a successful copy of R.

Construct (a|b)*a from the inside outward

The expression means any sequence of a and b followed by one final a. Therefore it accepts a, ba, aa, and bba. It rejects ε, b, and ab. Before drawing any states, write those examples so you have an independent meaning check.

Build the a branch as 2 to 3 and the b branch as 4 to 5. Union entry 1 branches to 2 and 4. Both exits reach union exit 6. Star entry 0 reaches 1 or bypasses to 7. State 6 returns to 1 or leaves to 7.

Finally create an a fragment from 8 to 9. Connect star exit 7 to 8 by ε. The whole machine starts at 0 and accepts only at 9. Reaching state 7 means the repetition has ended, but the required trailing a has not yet been consumed.

Trace the full set of possible paths

The epsilon-closure of a set includes those states and every state reachable through only epsilon edges. Start by closing {0}. From 0 you reach 1 and 7; from 1 you reach 2 and 4; from 7 you reach 8. No additional epsilon move is available.

On the final b of bab, state 9 contributes no successor. The remaining repetition branch can still consume b, but it has not supplied the required final a. This explains why an earlier accepting prefix does not make every longer string accepted.

Why the construction preserves the expression

The construction works by preserving a simple promise for each fragment. A path from its entry to its exit consumes exactly a string described by that fragment's expression. The promise is easy to see for a literal. The operator rules then preserve it for larger expressions.

Concatenation forces a path through R before S, so its consumed string is a string from R followed by one from S. Union offers either complete branch, so its strings belong to either language. Star permits a finite number of completed traversals, including zero. These are precisely the three expression operations.

Fresh state labels matter to that argument. Reusing a state from an unrelated fragment can create an accidental connection. You might then enter one branch and leave through another. Number states when you create them, and record which pair belongs to each fragment.

With these rules, each literal adds two states. Each union and star adds two more. Concatenation adds one epsilon connection but no new states. Thus the construction grows linearly with the expression structure. It is not usually a minimal NFA, and it certainly does not claim to be a minimal DFA.

For a second size check, consider ab*. Two literals contribute four states, and the star contributes two. The concatenation adds no states, giving six in this convention. The language accepts a, ab, and abb. It rejects ε because the first a is outside the star.

A fragment for (ab)* also has six states here, but accepts a different language. Its star bypass skips both literals, so ε is accepted. Its repeated path must consume a followed by b. Counting states alone never establishes language equivalence.

When an exam asks for a construction, show the operator grouping, fragment boundaries, all labelled edges, the start state, and the final state. Then trace an accepted string and a nearby rejected string. A picture without those checks can conceal a missing bypass or an extra accepting state.

For the numbered example, the three literal occurrences contribute six states. The union contributes two, and the star contributes two, giving ten altogether. The table therefore needs rows 0 through 9. This count checks for an accidentally missing fragment, but the labelled edges still need inspection because a correct state count cannot detect a wrongly directed connection.

Common mistakes

Omitting the star bypass

Without the entry-to-exit epsilon edge, R* requires at least one traversal. That describes one-or-more repetition instead. Check the empty string immediately after drawing a star fragment.

Leaving internal exits accepting

In (a|b)*a, marking state 7 final would accept ε and b. Both violate the required trailing a. Only the whole fragment's exit gets the final mark.

Using epsilon as an input symbol

An epsilon edge does not advance the input position. If your trace spends a character on that edge, the trace no longer describes this NFA. Close the active set between consuming moves instead.

Forgetting grouping before construction

ab* means a followed by repeated b, while (ab)* repeats the pair. Draw a small expression tree or state the grouping before joining fragments. The outer operator determines the final construction rule.

Summary

Thompson construction joins single-entry, single-exit fragments using epsilon connections. Its local rules preserve the expression's language and keep the machine size manageable. The NFA can still have several active states. In NFA to DFA, each such active set becomes one deterministic state.
