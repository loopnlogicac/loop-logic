Introduction

Two bus stops may look different but offer exactly the same remaining routes to your destination. For recognising strings, two DFA states can also have identical futures. Minimisation combines those states while keeping every accepted and rejected word unchanged.

Two states are equivalent when every possible remaining suffix gives the same acceptance decision from both. Their labels and past paths do not matter. What matters is whether any future input can tell them apart.

A distinguishing suffix is a string that is accepted from one state but rejected from the other. The suffix may be empty. Therefore a final state and a nonfinal state are immediately different: with no further input, one accepts and the other rejects.

We minimise complete deterministic machines over a fixed alphabet. Complete means every state has a transition for each alphabet symbol. If a description omits transitions, first decide whether they imply a rejecting sink. Different assumptions about missing transitions can lead to different tables.

Remove F from the reachable recognition problem. This is not the same as proving F equivalent to another state. F cannot be visited from the start at all. The required minimal DFA describes behaviour reachable during actual runs from that start.

Some exercises deliberately include an unreachable accepting state. The same rule removes it. Do not keep it merely because it has a final mark. Acceptance of a whole word always begins from the declared start, so an unreachable state cannot affect the language.

Make the first partition

A partition divides states into disjoint, nonempty blocks covering the state set. Start with final and nonfinal states in separate blocks. Here the nonfinal block N is {A,B,C,E}, and the final block Y is {D,G}.

This initial split uses the empty suffix. Every member of N rejects it, and every member of Y accepts it. No correct minimisation can merge across this boundary. Later steps may split either block further, but never merge a final state with a nonfinal state.

Now describe each state by the blocks reached on a and b. This ordered pair is its transition signature. Use the same alphabet order for every state. A signature describes destination blocks, not destination labels.

A fixed point means another refinement produces the same partition. Do not stop merely because one pair stayed together. All blocks must be checked against the same current partition. If a split occurs, repeat so its consequences can reach other predecessor states.

Build the quotient machine

The quotient DFA has one state per final block. Its start is the block containing the old start. Its final states are blocks containing old final states. For each symbol, use any member's transition and replace the destination with its block.

Why refinement finds equivalent futures

Initial final/nonfinal blocks distinguish behaviour with no remaining input. A split based on one transition reveals a one-character extension that reaches distinguishable futures. Repeating this idea propagates distinctions backward through the machine.

Suppose two states differ on symbol x because their x transitions reach states already separated by suffix w. Then xw distinguishes the original pair. This gives a constructive explanation of each split. You can attach a witness suffix when an exam asks why two states differ.

For the reduced machine, Y differs from X and Z by ε because Y is final. X differs from Z by b. From X, b reaches nonfinal X. From Z, b reaches final Y. Thus all three remaining states are pairwise distinguishable and reachable.

Reachability plus pairwise distinguishability establishes minimality here. There cannot be a smaller complete DFA for the same language with these distinct futures. State names can change, so a different drawing with three renamed states may represent the same minimal machine.

Identical transition rows are sufficient for equivalence when final status also agrees, but they are not necessary. B loops to B on a, whereas E loops to E. Their labels differ, yet their target blocks match. Comparing raw labels would miss a valid merge.

Conversely, states that agree for one character can differ for longer suffixes. Consider start p, states q and r, and final f. If p and q both reach nonfinal states on a, they may initially look alike. When q can reach f one step sooner, a later refinement separates their predecessors.

For this unary machine, begin with {p,q,r} and {f}. State r separates first because a reaches f. Then q separates because a reaches r's new block. Finally p remains alone. Suffix a distinguishes r from q, and aa distinguishes q from p.

The simple repeated-signature algorithm terminates because a true refinement increases the number of blocks. There are only finitely many states. A straightforward implementation may do more work than specialised algorithms, but it is easy to explain and suitable for small hand calculations.

If all reachable states are final, the machine accepts every string over its alphabet and may collapse to one accepting state. If none is final, it accepts no strings and may collapse to one rejecting state. Empty blocks must be omitted from the initial partition in these cases.

These edge cases also show why a rejecting sink is not necessarily unreachable. A transition from the start may enter it on a bad continuation. Such a state belongs in the complete machine and can merge with other states that also reject every possible suffix.

Common mistakes

Merging because labels look similar

Labels carry no language meaning. Compare final status and future transitions. A single distinguishing suffix proves that two attractively drawn states cannot be combined.

Using yesterday's partition forever

After a block splits, predecessor signatures may change. Recalculate against the new partition. The unary chain demonstrates why one round is not enough.

Mixing reachability and equivalence

Reachability asks whether the start can reach a state. Equivalence asks how a state behaves on future suffixes. Perform both checks, but do not substitute one answer for the other.

Forgetting acceptance in the reduced table

The reduced state Y must remain accepting. A transition table with correct arrows but no final marks describes an incomplete recogniser. Also mark X as the reduced start because it contains A.

Summary

Remove unreachable states, partition by final status, and repeatedly split blocks by destination-block signatures. A stable partition gives a quotient DFA with the same language. Distinguishing suffixes explain why remaining states cannot merge. Next, apply recognition rules in Writing a Lexer.
