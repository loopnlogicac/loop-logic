Introduction

An NFA may keep several possible paths alive after reading a word. Imagine placing a marker on every state that could currently be active. Instead of moving many markers separately, a DFA can give the whole marker arrangement one name. That is the idea behind subset construction.

A subset state represents a set of NFA states, not one chosen path. The conversion records every possibility after the same consumed prefix. It neither guesses which path will succeed nor discards paths because another path looks more promising.

The goal is a DFA with the same accepted language. Every reachable DFA state has exactly one transition for each alphabet symbol. Its accepting status depends on the NFA states it contains. The NFA and DFA need not have equal state counts or similar diagrams.

We will convert a four-state epsilon-NFA over {a, b}. Its language is all strings ending in ab. State 1 keeps scanning any prefix. An a can also begin a candidate final pair, and b can finish that pair. The epsilon start makes the closure step visible without making the example too large.

At state 1, an a has two destinations: 1 and 2. This does not mean consuming two copies of a. Both paths describe alternatives after one input character. State 2 can consume b into accepting state 3. A path that has reached 3 cannot consume another character.

To see why ab is accepted, start at 0, take ε to 1, take a to 2, then b to 3. To see why aba is rejected, extend that accepting path with a: no transition exists. The scanning path at 1 survives, but it has not completed a new final pair.

Compute closure and move separately

move(S, x) collects all states reached from any member of S by one x-labelled transition. It does not include epsilon motion automatically. The epsilon-closure then adds all states reachable with zero or more epsilon transitions.

The start subset is ε-closure({0}) = {0,1}. State 0 belongs because zero epsilon steps are allowed. State 1 belongs because of the epsilon edge. There are no further epsilon successors. Call this set A and put it on a worklist.

For a set, closure can be found by repeatedly adding unseen epsilon successors until nothing changes. Remembering visited states prevents an epsilon cycle from causing endless work. Closure includes its original set even when that set has no outgoing epsilon edge.

The worklist begins with A. Processing A discovers B and C. Processing B discovers D. Processing C and D introduces no further sets. The construction ends only after every discovered set has a row. A new set without outgoing transitions is an unfinished conversion.

D is accepting because it contains NFA final state 3. The other member, state 1, is not final, but that does not prevent acceptance. An NFA needs at least one successful path. Requiring every subset member to be final would incorrectly reject ab.

Include an empty subset when it is reachable

Our main NFA always keeps state 1 alive after a valid symbol, so the empty subset is never reached. Other NFAs do lose every path. Consider an NFA with start 0, final 1, and only the edge 0 --a→ 1 over alphabet {a,b}.

The empty set is a real DFA state representing no surviving NFA path. It loops to itself on every symbol because moving from no states cannot create a path. It is often called a dead or sink state. Leaving that row blank produces a partial transition description instead of a complete DFA.

The conversion invariant

After any input prefix w, the DFA's current subset equals exactly the NFA states reachable after consuming w and taking available epsilon moves. This is the central invariant. It explains both the transition formula and the accepting-state rule.

Initially, neither machine has consumed a character. The reachable NFA states are exactly the start closure, which becomes the DFA start. Assume the invariant holds for w. On the next character x, move collects every possible consuming successor. Closure then adds every possible epsilon continuation. Therefore the invariant also holds for wx.

At the end of input, the NFA accepts if some reachable state is final. The invariant says those states are precisely the current subset. Marking a subset final when its intersection with the NFA final set is nonempty therefore gives exactly the same answer.

An NFA with n states has at most 2 to the power n different subsets. That is a possible worst-case count, not a requirement to draw every subset. The worklist discovers only reachable sets. Our main example has four NFA states and four reachable subset states, far fewer than sixteen possible subsets.

For practical representations, use immutable sets as dictionary keys. Sort their members only when displaying them. A sequence with repeated entries is not the mathematical set being named. Canonical identities prevent duplicate work and make it possible to check whether the worklist is finished.

State naming does not affect the language. A, B, C, and D are convenient short labels. An equally valid answer might call them D0 through D3. A reviewer must compare the associated subsets and transitions rather than demand one numbering scheme.

When solving a numerical, leave separate columns for move and closure. If a result looks wrong, these columns locate the error. Forgetting an ordinary destination differs from forgetting an epsilon continuation. The final table alone often hides which mistake occurred.

Also write the alphabet before conversion. A missing transition on b matters only if b belongs to the intended alphabet. A character outside that alphabet can be rejected as invalid input; it is not automatically another transition column. Keep the mathematical machine and its input-validation interface distinct.

A useful closure check is idempotence: closing an already closed set must add nothing. If a second closure adds a state, the first search stopped too early. Also check monotonicity: starting with more states cannot produce fewer reachable states. These properties give quick ways to inspect a hand-calculated closure without repeating the entire DFA conversion.

Common mistakes

Closing only the start state

Epsilon moves may also follow consuming edges. Apply closure after every move result, not merely once at the beginning. An NFA with epsilon edges near its final state exposes this mistake quickly.

Choosing one NFA destination

On a from state 1 in our main example, retain both 1 and 2. Picking only 1 loses a possible final pair. Picking only 2 loses the path that can begin a later pair.

Stopping when an accepting set appears

Discovering D does not complete the machine. D still needs a and b transitions. The input may continue after an accepting prefix, so unfinished rows change recognition.

Calling subset construction minimisation

Different sets may describe identical future languages. A and C demonstrate this. Keep both during conversion, then compare their behaviour using the method in the next topic.

Summary

Start with epsilon-closure, expand every reachable set using closure after move, and mark any set containing a final NFA state. Include the empty subset when it is reached. Then use DFA Minimisation to combine states that no future suffix can distinguish.
